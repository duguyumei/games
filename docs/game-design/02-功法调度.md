# 功法调度

> 状态：当前设计基线
> 确认日期：2026-08-29

每个回合开始时双方各抽 5 张真气进入行气。此后在每个行动组中，玩家选择一门功法并从行气取出满足其要求的真气。本文定义功法的输入声明、输入去向、发动条件、使用次数、结算次序与抢先判定。

回合与行动组的结构见[核心战斗](./01-核心战斗.md)。

## 1. 输入与调度

每门功法必须声明**基础牌型**作为发动条件，牌型同时决定这门功法消耗多少张行气。在此之上，功法还可以声明：

- **特殊要求**：指定属性、当前内力范围、真气状态或输入顺序；
- 哪些输入是牌型之外的额外输入；
- 是否允许本次不发动；
- 如何读取输入真气的内力值；
- 是否读取本次或此前的牌型信息。

牌型定义与特殊要求的准则见[核心战斗](./01-核心战斗.md) §5。

调度遵守：

- 每个行动组中，一方只能发动一门功法；
- 从行气取出的真气必须完整满足该功法的基础牌型与全部特殊要求，否则不能发动；
- 一张真气在同一行动组中最多分配给一门功法；
- 一门功法只能读取实际调度给自己的驭气；
- 确认前可以反复调整；确认后冻结本次调度，不再撤回或改派；
- 功法按照冻结输入结算。

功法必须为每个输入槽明确声明是否读取内力。读取时还要声明读取单张、总和、最高值、最低值、差值、阈值或输入顺序等具体规则；功法也可以只检查真气的属性、数量或状态而完全不读取内力。

只有功法正文真正读取一张驭气的内力时，才触发这张真气的「读取内力」时点及其毒发。没有读取内力的输入仍然正常成为驭气、占用本次调度资源并在回合结束时进入散气。无论功法正文是否读取内力，回合开始时计算先手仍统计第一门功法的全部实际输入。

未被任何功法使用的行气在回合结束时进入散气。因此玩家需要在「发动高牌型功法换取更强效果」与「发动多门低牌型功法换取更多行动组」之间权衡。

### 1.1 输入去向

功法分别声明输入驭气结算后的处理类型：

- **发挥型**：输入驭气进入散气；
- **流动型**：输入驭气返回行气；
- **消耗型**：输入驭气从本场战斗移除。

流动型令真气返回行气后，该真气可以在后续行动组再次分配。

### 1.2 跨行动组的调度

流动型返回的真气及功法结算中新获得的行气不打断当前行动组。当前行动组结算完毕后，若仍有可调度的行气，进入下一行动组：玩家调度本组要发动的功法，敌方按已公开的固定策略调度。

- 玩家确认某个行动组的调度后，不能回写该组已确认的功法。
- 本组中新生成的行气进入下一行动组的调度窗口，不打断当前正在执行的功法和伤害事务。
- 行气耗尽或双方都不再发动功法时，回合结束。

## 2. 发动条件与使用次数

功法可以同时配置以下三种发动条件，它们不是互斥类型：

1. **自动叠层**：指定战斗事件发生时自动增加层数，达到门槛后满足条件。
2. **单次输入**：本次必须一次提交完整的真气输入，不能跨行动补齐。
3. **累计输入**：分多次投入真气，累计张数、内力或其他明确数值；进度可以按正文指定的范围保留。

一门功法声明多种条件时，所有条件必须同时满足。除非正文明确写出「额外输入」，同一张输入真气可以同时满足该功法的属性、数量、单次输入和累计输入要求。

累计输入默认只保存计数和数值进度，不把具体真气留在功法中。真气完成本次贡献后仍按正常牌区规则进入散气。达到门槛时扣除门槛，超过门槛的余数保留。

### 2.1 使用次数

功法还可以分别配置每个行动组、每回合、每场战斗的使用次数。没有配置对应限制时，该范围内可以无限次发动，但仍必须满足全部发动条件。多个次数限制同时存在时必须全部满足。次数按功法实例分别记录；同名功法的不同实例不共享次数和累计进度，除非正文明确声明共享。

只有功法正式发动才增加使用次数。单纯增加自动层数、提交累计输入但尚未达到门槛、发动前死亡或最终校验失败，都不增加使用次数。持续效果在建立时计算一次使用次数，之后由该持续效果产生的响应不重复计算为功法使用。

累计输入是一次实际的功法运转。即使本次贡献后仍未达到发动门槛，该功法也占据所属方本次队列中的一个结算位置，并按本次实际投入真气计算先手内力，但不增加使用次数。贡献完成后，投入真气按正常牌区规则收尾。

### 2.2 自动叠层的插入时机

自动叠层在其他功法结算期间达到门槛时，不打断当前功法或当前生命损失事务。当前功法及其即时死亡检查完成后，满足全部条件的自动功法排到所属方下一次交替结算位置。多个自动功法同时满足时，按该方固定功法排列顺序进入队列。

## 3. 功法队列、抢先与先手

每门功法拥有非负整数的**抢先层数**。回合开始、双方抽到行气后，各自把本回合计划发动的功法组成有序队列。先手在回合开始时确定一次：

1. 比较双方队列第一门功法的抢先层数，层数较高的一方成为先手方；
2. 抢先层数相同时，分别读取双方第一门功法的全部输入真气；
3. 将这些输入真气此时的当前内力值相加，得到该功法的**先手内力**；
4. 先手内力较高的一方成为本回合的先手方；
5. 抢先层数与先手内力均相同时，玩家成为先手方。

先手在整个回合内保持有效：**本回合此后每一个行动组，都由先手方先结算。**

- 每个回合只判定一次先手，后续行动组不再重新比较；
- 抢先不额外生成一门功法，也不增加行动组数量；
- 抢先默认只读取层数，不消耗层数；具体效果明确写出消耗时除外；
- 一方在第一个行动组没有可发动功法时，另一方直接成为先手方，不读取空队列的抢先层数。

因为行动组的数量由行气决定，赢下抢先意味着吃到本回合所有行动组的先手。行气多的回合可以有多个行动组，因此抢先是一次高回报的单点争夺，而不是只影响一门功法。

先手内力的读取边界：

- 所有实际分配给第一门功法的驭气都计入，包括功法正文不读取内力的输入；
- 只读取真气此时已有的当前内力，不触发毒发、气力变化、次数消耗或其他效果；
- 真正轮到功法运行时，功法仍按输入顺序读取驭气，并使用毒发等效果处理后的当前内力；
- 双方都没有功法时跳过功法结算。

基础结算节奏为：

```text
行动组 1：先手方功法 → 后手方功法
行动组 2：先手方功法 → 后手方功法
……
```

一方不再发动功法时，另一方继续在后续行动组结算自己的剩余功法。先手只决定组内先后，不改变每门功法内部的效果顺序。

## 4. 压制与衔接

压制改写结算次序，衔接读取结算次序。两者都不是伤害、护体罡气或功法数值修正。

每门功法可以独立声明以下任一能力，未声明时不产生任何效果。功法不直接绑定某一个固定功法 —— 除非内容明确要求，压制和衔接都只读取公开的功法标签、牌型、输入属性、结算结果或当前状态，保持不同功法之间的可组合性。

### 4.1 压制

**压制**由刚刚结算的功法产生，作用于敌方：

- 令敌方下一门尚未结算的功法**延迟到下一个行动组**，并排到敌方队列末尾；
- 被压制的功法没有失去结算资格，只是推后；
- 被压制功法的驭气保持为驭气，跨行动组保留，直到该功法真正结算后才按其处理类型进入散气；
- 压制不减少敌方功法数量，也不取消其效果。

压制同时包含时间与位置两个约束：敌方队列只有一门功法时，靠时间约束生效（本行动组它无法结算）；队列有多门时，靠位置约束生效（其余功法先上）。

被压制的功法可以被反复压制。压制没有次数上限 —— 每次压制都要占用我方一个行动组和相应行气，因此压制总量受牌型大小与行气数量自然限制。

示例：我方本回合有 3 张行气、每门功法都带压制，敌方只有 1 张行气（队列中只有敌1）：

```text
行动组 1：我1 结算 → 压制，敌1 延迟
行动组 2：我2 结算 → 压制，敌1 延迟
行动组 3：我3 结算 → 压制，敌1 延迟
行动组 4：我方行气耗尽，无法再压制 → 敌1 结算，其驭气随后进入散气
```

敌1 从未消失，只是一直排不上。我方维持压制需要持续投入行气，因此这是节奏优势而非功法数量优势。

### 4.2 衔接

**衔接**由功法自身声明，读取本方上一门功法的状态：

- 若本方在上一个行动组结算的功法满足本门功法声明的衔接条件，则本门功法获得其正文声明的额外效果；
- 衔接不改变结算次序，不提前也不推后任何功法；
- 衔接条件读取公开信息：上一门功法的标签、输入属性、牌型、结算结果或当前状态。

衔接是功法之间的组合奖励，使连续投入的功法序列产生额外价值。压制负责改写序列，衔接负责读取序列，两者分工不重叠。

### 4.3 与抢先的关系

压制和衔接都不改变抢先判断。抢先在回合开始时判定一次，决定此后每个行动组由哪一方先结算；压制只把敌方某门功法推到后续行动组，不改变组内的先后规则。

当前基础规则不设置独立连动槽、同气增加连动或满槽追加行动。压制与衔接只作用于本回合已有的功法；只有固定内容明确写出「额外行动组」时，才会产生新的行动组。

## 5. 输入资格的确认时点

牌型在功法发动时确定，作为该次发动的公开信息保留。此后改变行气或驭气属性，不追溯改变已经成立的牌型。

功法输入资格在确认调度时确定。结算前发生的状态改变默认不会取消已经确认的功法，但功法运行时读取最新的当前属性、当前内力和状态。只有正文明确写出「结算时重新检查」时，输入资格才会在运行时再次验证。

## 6. 功法改造

功法允许改造，但具体改造结构另行设计。后续设计需要明确：

- 哪些输入、顺序或效果允许改变；
- 哪些内容保留功法身份；
- 改造发生的阶段；
- 敌方改造后如何完整展示；
- 如何避免所有功法收敛为同一个最优模板。

在上述内容确定前，不预设功法内部槽位或组件结构。
