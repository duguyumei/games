# 敌方与信息

> 状态：当前设计基线
> 确认日期：2026-08-29

## 1. 规则一致性

敌我双方使用相同的真气牌库、抽取、牌型、调度和结算规则。敌方可以拥有自己的牌库配置、专属功法、专属内功和 AI 策略，但不绕开公共战斗规则。

## 2. 敌方计划的固定与公开

每个回合中，敌方先完成：

```text
从凝气抽取 5 张真气进入行气
→ 规划本回合各行动组要发动的功法及其真气分配
→ 固定本回合计划
```

玩家开始调度前，可以观察敌方本回合的行气、计划发动的功法、各门功法要求的牌型和真气分配结果。

敌方计划固定后，不能因为玩家的选择或调度重新抽牌、改换功法或改派真气。

玩家面对的是已经固定的对手构筑，而不是临时改写的攻击脚本。

## 3. 随机效果的信息规则

随机效果在真正触发时才进行随机选择，并立即公开结果。

规划阶段只显示：

- 该效果会随机选择；
- 随机目标牌区；
- 合法目标条件；
- 当前合法目标数量。

规划阶段不显示具体目标，也不要求玩家为随机目标做选择。目标数量只用于表达随机范围，不提前揭示目标内容。

敌方的行动选择、牌型和功法调度仍然在规划阶段固定。随机目标不是敌方临时改选，而是效果触发时从当时合法目标池中抽取。随机选择不能读取触发前才产生的玩家操作，也不能让敌方临时改写已固定的行动计划。

目标池为空时，该次效果不产生结果，也不把资源自动转成其他收益。

## 4. 对敌方真气的干预边界

- 敌方已经调度的驭气不能通过普通运转取消，只能由正文明确的状态或功法效果影响。
- 冻结敌方驭气只影响读取内力的功法；不读取内力的功法不受影响。
- 改变敌方行气状态是常规控制；直接把敌方行气运转到其他牌区属于少量强控制，不作为常见效果。
- 此类运转只影响尚未开始的行动组，不追溯修改已经公开的功法计划。下一行动组开始时，敌方根据变化后的行气形成并公开新计划。
- 对敌方行气的封脉必须在敌方调度前生效；敌方计划已经固定时，效果作用于下次行动。
- 封脉目标按照确定顺序自动选取，不由玩家在敌方行气中点选。
