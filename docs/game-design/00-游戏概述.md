# 游戏概述

> 状态：初稿
> 本文是全部设计文档的锚点。下层文档与本文冲突时，以本文为准。

## 1. 一句话定位

一款以**真气调度**为核心的武侠卡牌 Roguelike：真气是可改造的资源牌，功法是消耗真气的结构，玩家在搜打撤的探索中反复打磨一套构筑。

## 2. 核心卖点

**真气不是卡牌，是资源。** 每张真气有属性（五行）与内力（数值），功法要求特定的**牌型**（高牌、对子、三连、四连、顺子）才能发动。玩家打出的不是「一张卡」，而是「一组满足结构的真气」。

**四个牌区构成流动性。** 凝气（牌库）→ 行气（可调度）→ 驭气（已分配）→ 散气（弃牌堆）。玩家每次调度都在决定哪些真气暂时离场、哪些继续参与本回合后续的行动组。

**真气可以永久改造。** 局外用资源重塑真气的属性与内力，构筑的成长发生在**牌本身**而非牌的数量上。

**行动组数量由玩家决定。** 一个回合内能发动几门功法，取决于行气怎么分配 —— 3 张全投给一门三连功法就只有一组，分给三门高牌功法就有三组。

## 3. 目标玩家

玩过《杀戮尖塔》《怪物火车》这类构筑类 Roguelike，且愿意在出牌前做计算的玩家。本作的门槛高于同类：牌型系统要求玩家理解五行 × 内力的二维结构，不提供保底手段。

## 4. 参考作品

| 作品 | 借鉴什么 | 不借鉴什么 |
|---|---|---|
| 杀戮尖塔 | 构筑的逐件成长、遗物式被动 | 线性爬塔、单一路线 |
| 逃离塔科夫 | 搜打撤结构、撤离决策的张力 | 装备损耗、PvP |
| 麻将 / 扑克 | 牌型作为发动门槛 | 运气主导 |
| 太吾绘卷 | 武侠功法的命名与气质 | 复杂的模拟经营 |

## 5. 平台与操作

**PC 优先**，键鼠操作。真气用鼠标点选，拖拽分配给功法。UI 可以信息密集 —— 玩家需要同时看到四个牌区、双方功法配置、状态层数。

**移动端适配**留在后期。UI 布局预留改造空间：核心交互（点选真气、选择功法）在触屏上应当可行，但不为触屏牺牲 PC 的信息密度。

## 6. 美术风格

**水墨写意。** 五行用墨色浓淡与留白区分，而非饱和色块。

| 属性 | 视觉方向 |
|---|---|
| 金 | 锐利的墨线，留白多 |
| 木 | 枝条状笔触，中等墨色 |
| 水 | 晕染，边界模糊 |
| 火 | 飞白，笔触断裂 |
| 土 | 厚重墨块，边界方硬 |

具体规范见 [美术风格](./13-美术风格.md)（待写）。

## 7. 单局时长

```text
一场战斗       4～6 回合，约 5～8 分钟
一次探索       3～5 场战斗，约 30～40 分钟
一个完整存档   多次探索累积局外进度，无固定终点
```

探索是可撤离的，因此单次游玩时长由玩家决定 —— 这是搜打撤相对爬塔的优势。
