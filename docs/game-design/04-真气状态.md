# 真气状态

> 状态：当前设计基线
> 确认日期：2026-08-29

本文是真气可携带状态的唯一定义处。毒量的详细规则（毒发时点与毒发流程）见[木-生发与毒](./五行/木-生发与毒.md)。

## 1. 通则

真气状态跟随真气跨牌区移动，直到状态自身被清除、到期、触发消耗或战斗结束。

真气只保存当前状态和状态自身必要的持续信息，不保存每一次状态改变的历史来源。施加、清除、转移和触发状态的动作携带本次动作的来源。

基础属性和基础内力不因普通战斗状态而改变。战斗临时状态只存在于当前战斗，战斗结束时清除。

## 2. 状态清单

- **气力**：影响真气向功法提供的内力，可正可负。气力 +1 表示提供的内力提高 1。气力附着在真气上，不是可以脱离真气单独花费的资源。气力的取值范围受该真气存有的内力约束：下限为负的存有内力，上限为存有内力的两倍。
- **毒量**：非负整数，毒发时造成毒伤的积蓄。
- **属性覆盖**：临时替换当前五行属性。
- **保留**：下一次本应进入散气时，改为进入或留在行气，并失去保留。
- **冻结**：不改变存有的内力，但该真气被所属功法读取时，最终只提供 1 点内力，持续到进入散气前。
- **归根**：下一次本应进入散气时，改为洗回凝气并消耗归根。
- **耗散**：下一次本应进入散气时，从牌库中移除，不进入其他牌区。
- **封脉**：持续到下个回合开始，期间该真气不能进行牌区运转。详见[土-岩障封脉](./五行/土-岩障封脉.md)。

功法还可以声明其他有持续时间或触发次数的状态。

### 2.1 改道状态的优先级

保留、耗散与归根都改变「本应进入散气」时的去向。同时存在时按固定优先级取一个：

```text
保留（留在行气） > 耗散（从牌库移除） > 归根（洗回凝气）
```

## 3. 存有的内力与提供的内力

真气有两个内力数值，用途不同：

- **存有的内力** = 基础内力 + 全部内力重塑。这是真气自身的容量，用于面板显示与毒发门槛判断。
- **提供的内力** = 存有的内力 + 气力（受上下限约束）。这是功法实际读取的值。冻结生效时固定为 1。

计算顺序是：存有 → 加气力 → 再判断冻结。因此冻结是最终输出覆盖，不是气力减少。

毒发门槛使用**存有的内力**：毒量大于或等于存有的内力时，运转进入散气会触发毒发。

## 4. 属性覆盖

属性覆盖是**战斗内**的临时替换，按应用顺序保存。当前属性取最后一个仍有效的覆盖；覆盖清除后恢复前一个有效覆盖，全部覆盖清除后恢复该真气进入战斗时的属性。

进入战斗时的属性由基础属性与持久重塑共同决定（见[真气系统](./08-真气系统.md)）—— 若该真气带有属性替换重塑，则恢复到重塑后的属性，而非基础属性。

真气在同一时刻只有一个当前属性。属性改变会同时影响牌型和功法适配，因此属于比内力改造更重的构筑变化。

## 5. 冻结

冻结是真气向功法提供内力时的最终输出覆盖，不是气力减少：

- 真气面板、目标选择、输入资格和毒发门槛仍使用**存有的内力**；
- 读取内力时先按存有的内力处理毒发，再令该真气向功法提供的最终内力固定为 1；
- 功法不读取该真气内力时，冻结不产生效果；
- 真气进入散气时移除冻结。

## 6. 状态的生命周期

每个状态携带一个生命周期范围，决定它何时被清除：

| 范围 | 存活到 | 写存档 |
|---|---|---|
| **探索** | 本次探索结束（撤离或死亡） | 是 |
| **战斗** | 本场战斗结束 | 否 |
| **回合** | 下个回合开始（封脉） | 否 |
| **进散气前** | 该真气进入散气（冻结） | 否 |
| **一次** | 触发一次即消耗（保留、归根、耗散） | 否 |

探索范围的状态跨战斗保留并写入存档，因此允许玩家中途退出后继续同一次探索。它也是探索深度的代价来源 —— 前一场战斗积累的毒量会带进下一场。

## 7. 净化

**净化**清除目标真气的全部战斗状态，使其恢复为进入本场战斗或在战斗中生成时的初始状态。

净化不区分正负 —— 气力、毒量、属性覆盖、冻结、保留、归根、耗散以及功法赋予的其他状态全部清除，正面状态同样被移除。因此净化既是解毒与解控手段，也可能清掉自己攒起来的正气力。

净化不改变真气当前牌区、归属和临时真气身份，**也不清除持久重塑** —— 重塑属于构筑而非战斗状态，因此净化的还原目标是「基础层加重塑层的合并结果」，而不是基础层。
