# 核心战斗

> 状态：当前设计基线
> 确认日期：2026-08-29

真气是战斗中被抽取并调度给功法的具体资源。本文定义真气本身、四个牌区、牌型，以及回合与行动组的结构。

## 1. 核心结构

一个回合的基础流程为：

```text
回合开始
→ 双方各从凝气抽取 5 张真气，直接进入行气
→ 行动组 1：双方各选择一门功法，用行气组成该功法要求的牌型并结算
→ 行动组 2：同上
→ …… 直到双方都不再发动功法
→ 回合结束，剩余行气与驭气进入散气
```

本规则的核心是流动性：玩家不仅决定本次使用什么，也在决定哪些真气暂时离开凝气、哪些真气继续参与后续抽取，以及散气何时重新洗回。

### 1.1 回合与行动组

**回合**是一次完整的立回，也是抽取和多数持续效果的计时单位。每个回合开始时双方各抽 5 张真气进入行气。

**行动组**是回合内的结算单位。一个行动组中，敌我双方各调度并结算一门功法。一组结束后进入下一组，直到双方都不再发动功法，回合结束。

行动组的数量不是固定配置，而是**由行气决定**：

- 行气跨行动组持续存在，每组消耗其中一部分；
- 发挥型功法的输入进入散气，行气随之减少；
- 流动型功法的输入返回行气，可以在后续行动组再次调度；
- 消耗型功法的输入移出战斗。

因此把 3 张行气一次性全部投入一门要求三连的功法，本回合我方就只有一个行动组；分给三门只要求高牌的功法则有三个行动组；流动型功法可以让同一张真气支撑多个行动组。

双方的行动组数量可以不同。一方不再发动功法时，另一方继续在后续行动组中结算自己剩余的功法。

**无法行动**：当剩余行气无法组成任何一门已配置功法所要求的牌型时，该方本回合不再发动功法。这没有保底措施 —— 手上的真气凑不出自己功法要求的结构，是构筑与本回合抽取的结果。

先手只在回合开始时判定一次，决定此后每个行动组中由哪一方先结算（见[功法调度](./02-功法调度.md)）。

## 2. 牌区

真气所处的四个牌区如下。它们描述真气当前的位置，不是不同种类的卡牌：

- **凝气**：牌库中的真气。
- **行气**：本回合抽到、可以调度给功法的真气。
- **驭气**：已经分配给具体功法、正在等待该功法读取的真气。
- **散气**：弃牌堆中的真气。

一张真气在任一时刻只处于其中一个牌区。「毒气」不是牌区，只是毒量大于 0 的真气统称，一张真气可以同时是毒气。

牌区的基础流转为：

```text
凝气 → 行气 → 驭气 → 散气
  ↑                      │
  └── 凝气不足时洗回散气 ──┘
```

## 3. 真气

### 3.1 属性与内力的职责

真气在同一时刻只有一个当前属性，属性改变会替换当前属性。内力分为两个数值：**存有的内力**由基础内力与持久重塑合并得到，**提供的内力**再叠加气力后得出，是功法实际读取的值。气力附着在真气上，不是可以脱离真气单独花费的资源。真气可携带的全部状态见[真气状态](./04-真气状态.md)，持久重塑见[真气系统](./08-真气系统.md)。

**属性**承担：

- 基础牌型识别；
- 功法输入资格和效果分支；
- 单属性、多属性和五行构筑；
- 属性相关的内功、异状与特殊规则。

**内力**参与基础牌型识别，也作为功法读取真气时的数值输入。内力值不预先合并为双方共用的统一数值，而是各门功法自行声明如何读取（见[功法调度](./02-功法调度.md)）。

属性改变会同时影响牌型和功法适配，因此属于比内力改造更重的构筑变化。

### 3.2 五行属性

五种属性为金、木、水、火、土。各属性的专属机制与功法见[五行](./五行/)。

### 3.3 内力值

基础内力值使用 5、6、7、8、9。

### 3.4 起始牌库

起始牌库为完整的五行与内力组合，每一种「属性＋内力值」各一张，共 25 张：

```text
金 5～9：5 张
木 5～9：5 张
水 5～9：5 张
火 5～9：5 张
土 5～9：5 张
```

**这只是构筑的起点，不是战斗时的牌库。** 牌库在局内可以构筑：获得新真气、移除真气、改造真气的属性或内力、通过重塑赋予持久状态。因此实际战斗时的牌库张数、属性配比与内力分布都由玩家的构筑决定。

牌库构成直接决定牌型的可行性。起始的 25 张里每种属性只有 5 张，因此四连（4 张同属性）与五行顺子都很难凑出；而一套刻意堆某属性的牌库可以让四连成为常态。这是构筑的核心决策之一。

### 3.5 战斗临时真气

效果可以在战斗中生成临时真气。临时真气与基础真气一样具有基础属性、基础内力、当前属性、当前牌区和全部真气状态，可以参与抽取、牌型、调度、功法输入、弃置与洗回。

「临时」只规定持久化边界：

- 临时真气默认可以在凝气与散气之间反复循环；
- 临时真气不会因为被驭使一次就自动删除；
- 战斗结束时删除全部临时真气，不写入本局牌库；
- 需要使用一次后从牌库移除的真气，必须另外具有「耗散」状态。

生成真气默认气力与毒量为 0，不继承生成来源的状态。生成与复制是两个不同动作：生成按固定模板创建；复制必须明确写出复制哪些基础信息、当前信息和状态。

临时真气仍遵守当前阶段。玩家在某个行动组确认调度后生成的行气不能回写该组已确认的功法；如果效果希望它参与当前回合，必须明确进入后续行动组的调度窗口或直接指定自动调度目标，否则应生成到凝气或散气。

### 3.6 获得真气与获得批次

「获得真气」是一个带来源和目标牌区的事件。效果必须明确真气进入哪一个牌区，不能用「新增真气」代替：

- 进入**凝气**：影响后续抽取，不影响本回合已有的行气。
- 进入**行气**：成为本回合可调度资源，可以在后续行动组参与凑牌型。
- 进入**驭气**：只有效果明确指定了功法归属时才允许，不能让玩家在功法结算中重新选择已冻结的输入。
- 进入**散气**：等待之后洗回凝气，不参与当前回合。

同一个效果一次获得的多张真气属于同一**获得批次**。自动效果可以读取批次的数量、属性和当前内力值，并在满足条件时生成新的批次。响应效果不能再次响应自己生成的同一根获取事件；同一个自动功法在同一根获取事件中最多处理一次，避免「生成两张 → 再生成一张 → 再次凑对」的无限递归。

## 4. 抽取与调度

### 4.1 抽取

每个回合开始时，从该方凝气抽取 5 张真气，直接进入行气。

- 5 张真气全部成为本回合的可调度资源，没有筛选阶段；
- 同一张真气不能在同一回合中被重复抽取；
- 行气顺序确定，不因界面重绘而改变。

**行气上限为 8 张。** 抽取只取 5 张，但保留、封脉、归根与各类运转效果会让行气跨回合累积或在回合内增加。行气已达 8 张时，任何会使其超出上限的效果不再生效：抽取跳过、运转不发生、生成到行气的真气改为进入凝气。

抽取过程中凝气不足时，将散气洗回凝气并继续抽取，直到取得 5 张或已经没有可抽取真气。已经进入本回合行气的真气不参与本次中途洗回。

### 4.2 行气与驭气

行气是本回合的调度资源，跨行动组持续存在：

- 每个行动组中，玩家选择一门功法，并从行气中取出满足该功法牌型要求与特殊要求的真气；
- 被取出的真气进入驭气；
- 没有分配的真气继续保持为行气，跨行动组保留，直到回合结束。

一张真气在同一个行动组中只能进入一个功法的驭气，不能同时分配给多门功法。功法读取驭气时，才会触发该真气规定的读取时点效果。

行气的剩余数量与组合结构共同决定本回合还能进行多少个行动组：剩余真气必须能凑出某门功法要求的牌型，否则无法继续行动。见第 1.1 节。

### 4.4 回合结束

本回合没有受到其他处理规则影响的行气与驭气最终进入散气：

- 实际被功法使用的真气进入散气；
- 未分配给功法的行气同样进入散气；
- 未被任何功法使用的行气同样进入散气。

流动型、消耗型、保留、归根、耗散及正文明确声明的牌区处理优先于上述默认收尾。

发动高牌型功法会一次消耗更多行气，因此本回合行动组更少，也让更多真气进入散气并加快牌库轮转。

## 5. 真气牌型

牌型是**功法的发动条件**。每门功法声明自己要求的基础牌型；玩家在行动组中必须从行气里取出满足该牌型的真气，才能发动这门功法。

牌型按张数递增排列：

- **高牌**（1 张）：任意 1 张真气。
- **对子**（2 张）：2 张相同属性，或 2 张当前内力值相同的真气。
- **三连**（3 张）：3 张属性全部相同，或 3 张当前内力值全部相同的真气。
- **四连**（4 张）：4 张属性全部相同，或 4 张当前内力值全部相同的真气。
- **双对**（4 张）：4 张真气组成两组对子；两组对子必须统一按属性判断，或统一按当前内力值判断，不能一组按属性、另一组按内力值。
- **顺子**（5 张）：5 张真气的属性分别为金、木、水、火、土各 1 张；或者 5 张当前内力值互不相同，排序后每张比前一张恰好高 1。内力顺子不限定起始值。

### 5.1 牌型与功法稀有度

牌型要求同时是功法的威力分层与调度成本：高牌型功法一次吃掉更多行气，因此挤压本回合的行动组数量。稀有度越高的功法通常要求越大的牌型，其代价是牺牲本回合的出手次数。

### 5.2 特殊要求

功法可以在基础牌型之上叠加特殊要求，例如指定属性、指定当前内力范围、要求携带某种真气状态，或要求输入顺序。

- 特殊要求与基础牌型必须同时满足。
- 要求越具体的功法越难在单个回合凑出。当条件苛刻到难以一次满足时，功法应改用**累计输入**（见[功法调度](./02-功法调度.md)），把凑齐条件的过程分摊到多个回合。

### 5.3 牌型作为可观察状态

一门功法完成发动后，其牌型成为公开状态。功法、内功和属性机制可以读取：

- **牌型身份**：高牌、对子、三连、四连、双对、顺子；
- **判定依据**：该牌型按属性线成立还是按内力线成立。同一组真气同时满足两条线时，两条依据都视为成立；
- **构成张数**：1～5。

牌型是双方共同可见的信息，敌方发动的功法牌型同样可以被读取。

## 6. 完整回合顺序

```text
回合开始
→ 双方各从凝气抽取 5 张真气，直接进入行气
→ 敌方固定本回合计划并向玩家展示
→ 比较双方第一门功法的抢先层数
→ 抢先相同时比较双方第一门功法的先手内力
→ 内力仍相同时玩家先手
→ 本回合此后每个行动组均由先手方先结算

行动组：
  → 双方各选择一门功法，从行气取出满足其牌型与特殊要求的真气作为驭气
  → 依次结算，每次实际生命损失后立即检查死亡
  → 死亡方取消尚未执行的效果和功法
  → 压制可令敌方下一门功法延迟到下一行动组
  → 剩余行气仍能凑出某门功法要求的牌型时，进入下一行动组

→ 双方都无法或不再发动功法
→ 双方剩余行气与驭气分别进入散气
→ 回合结束
```

先手、压制与衔接见[功法调度](./02-功法调度.md)；死亡检查见[公共机制](./03-公共机制.md)；敌方计划的公开规则见[敌方与信息](./05-敌方与信息.md)。
