# 权威文档尚未确认的问题

本文件只记录问题，不修改或补充权威设计。

1. 各精确牌型的正式开局功法序列尚未确定。纵切中的
   `data/vertical_slice_sequences.json` 只是用于覆盖接口与可玩流程的调试装配，
   不视为正式开局配置。
2. 敌人的具体牌组、功法序列、选牌策略与同步出招 AI 尚未确定。纵切使用
   `data/scripted_battle.json` 明确锁定测试敌人的牌库与逐回合出牌，只作为确定性
   测试夹具，不视为正式敌人 AI 或正式敌人构筑。
3. 五条的固定倍率、心得分组与实战规则仍待确认，因此第一阶段只实现用户要求的
   九种普通牌型；六类池结构预留“四条、五条”类别，但不识别五条。
4. 权威文档明确当前防御跨回合保留，同时要求后续重点实测是否调整。本纵切按当前
   规则保留防御，不加入衰减、清零或上限。
5. 当前只实现烈毒与蛊印续毒的第一条完整状态链。郁毒、毒效倍率、转毒、其他异状、
   协同选择 UI、内功动态插入功法位与 110 门完整功法仍不属于当前纵切；底层数据接口
   和触发队列为这些后续内容保留扩展点。
6. 同一同步伤害层中双方生命同时降至 0 时，权威文档没有确认胜负。本纵切停止战斗并
   显示“双方同时倒下：胜负规则尚未确认”，不判定玩家胜利或失败。
