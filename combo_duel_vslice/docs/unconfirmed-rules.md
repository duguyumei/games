# 权威文档尚未确认的问题

本文件只记录问题，不修改或补充权威设计。

1. 各精确牌型的正式开局功法序列尚未确定。纵切中的
   `data/vertical_slice_sequences.json` 只是用于覆盖接口与可玩流程的调试装配，
   不视为正式开局配置。
2. 敌人的正式牌组、功法序列与选牌策略尚未确定。纵切保留
   `data/scripted_battle.json` 的逐回合固定动作作为确定性测试夹具；可玩界面另使用
   同文件中的调试 AI 权重，从真实敌方手牌枚举 1～5 张选牌并按即时伤害、防御、
   功法值、连击价值与耗牌数评分。该策略仅用于让纵切可玩，不视为正式敌人 AI、
   正式敌人构筑或新增规则。
3. 五条的固定倍率、心得分组与实战规则仍待确认，因此第一阶段只实现用户要求的
   九种普通牌型；六类池结构预留“四条、五条”类别，但不识别五条。
4. 权威文档明确当前防御跨回合保留，同时要求后续重点实测是否调整。本纵切按当前
   规则保留防御，不加入衰减、清零或上限。
5. 当前只实现烈毒与蛊印续毒的第一条完整状态链。郁毒、毒效倍率、转毒、其他异状、
   协同选择 UI 与 110 门完整功法仍不属于当前纵切；底层数据接口
   和触发队列为这些后续内容保留扩展点。
6. 同一同步伤害层中双方生命同时降至 0 时，权威文档没有确认胜负。本纵切停止战斗并
   显示“双方同时倒下：胜负规则尚未确认”，不判定玩家胜利或失败。
7. 权威文档只确认了“未参与最高牌型的打出真气，其真气值总和转化为防御”的初始内功
   候选效果，没有确认其正式名称、档位、价格或正式开局配置。纵切界面直接显示“初始
   内功候选”，并通过 `data/scripted_battle.json` 将其作为玩家调试装备；这不代表正式
   名称或开局构筑已经确定。
8. 权威文档没有确认正式开局携带哪些消耗品。纵切只在
   `data/scripted_battle.json` 中调试配置“高牌心得、教皇、光环”，用于覆盖心得、强化、
   版本与共享三槽；这不代表正式开局构筑或普通获取概率。
9. 权威文档确认三类消耗品主要在战斗外使用，但当前纵切还没有修习场景或完整本局牌组
   浏览器。顶部消耗品栏暂作为明确标注的“纵切调试构筑入口”，目标范围暂取当前手牌，
   以验证使用、替换与实时数值预览。正式修习界面的目标浏览范围、战斗中能否打开构筑
   入口以及使用时机仍待后续流程设计确认。
