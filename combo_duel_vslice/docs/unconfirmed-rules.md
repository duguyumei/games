# 权威文档尚未确认的问题

本文件只记录问题，不修改或补充权威设计。

1. 玩家八种精确牌型的正式开局序列已经冻结为一槽 `basic_scatter`；`data/vertical_slice_sequences.json` 仍只是允许显式空序列的战斗调试装配，不是玩家永久配装。
2. v0.30 已确认敌方本地／远程 AI 共用合法候选、公开信息边界、并行思考、无行动窗口
   的历史积压、每 5 回合工作历史压缩和本地保底协议。第 1 层正式敌人的牌组、功法序列
   与性格权重已由[正式敌人内容](../../godot/docs/design-current/run/61-enemy-content.md)
   冻结；仍未确认的是后续层的正式敌人构筑，以及难度档位对应的意图公开级别。默认远程服务商已确认为 DeepSeek，
   OpenAI 兼容 REST 接口、默认 Flash／可选 Pro 模型、配置文件凭据边界与通用提示词职责已经写入权威文档；纵切继续
   使用 `data/scripted_battle.json` 的固定动作与 Utility 权重作为测试夹具，不代表正式
   敌人构筑或难度数值。
   战斗中退出后已经确认从战斗开头建立新尝试，旧 AI 会话只保留为审计记录；重新开始时
   是否保持原战斗种子与初始牌序尚未确认。
3. 权威设计已经确认五条是最高普通牌型，固定倍率为 `×12`，并沿用“四条、五条”
   共用功法池但拥有独立循环序列。尚未确认的是五条心得 `+3` 是否正式启用、进入普通心得
   随机池的时点与实战出现率；当前运行时已按 `×12` 识别五条，五条心得继续保持禁用。
4. 权威文档明确当前防御跨回合保留，同时要求后续重点实测是否调整。本纵切按当前
   规则保留防御，不加入衰减、清零或上限。
5. v0.30 的107门旧流派候选已经整体归档，不是当前活跃功法；当前正式目录为215门，其中213门属于五个正式池；蛊毒／成长／桥接、山系、风系、火系与首批4门特殊功法的稳定ID及池归属见权威索引。历史测试夹具不能据此进入玩家内容。
6. 同一同步伤害层中双方生命同时降至 0 时，权威文档没有确认胜负。本纵切停止战斗并
   显示“双方同时倒下：胜负规则尚未确认”，不判定玩家胜利或失败。
7. 权威文档只确认了“未参与最高牌型的打出真气，其真气值总和转化为防御”的初始内功
   候选效果，没有确认其正式名称、档位、价格或正式开局配置。纵切界面直接显示“初始
   内功候选”，并通过 `data/scripted_battle.json` 将其作为玩家调试装备；这不代表正式
   名称或开局构筑已经确定。
8. 权威文档没有确认正式开局携带哪些消耗品。纵切只在
   `data/scripted_battle.json` 中调试配置“高牌心得、教皇、光环”，用于覆盖心得、强化、
   品相与共享三槽；这不代表正式开局构筑或普通获取概率。
9. 修习展示、补货和冥想规则已由 S2.0A 冻结；仍未确认的只有完整本局牌组浏览器交互。
   战斗界面原有的当前手牌目标选择继续只作为强化与品相效果的纵切测试入口，不能代替
   本局牌组浏览器的正式设计。
10. v0.25 确认地图采用除商店外与《杀戮尖塔》一致的生成规则，并把商店替代事件统一显示
   为事件。当前事件、休息和宝箱的正式内容池尚未确认；第 1 层正式敌人内容已由
   [正式敌人内容](../../godot/docs/design-current/run/61-enemy-content.md)冻结，因此节点调度器只
   负责稳定选择已登记内容：非战斗节点使用明确标注的流程占位，普通、精英与 Boss 暂共用
   现有纵切战斗内容。调度配置不代表这些内容池已经获得设计确认。
11. 权威文档确认玩家与敌方分别拥有回合开始／结束效果，但尚未确认双方第一击同步时，
    两侧同名时点效果之间的先后规则。`BattleTimingSystem` 已提供单方 hook/order 的确定性基础设施，
    但 `BattlePassiveTimingBridge` 不把对象注册先后解释成跨阵营规则；装配发现双方同 Hook 都有
    有效被动绑定时，以 `unconfirmed_cross_side_passive_order` 明确阻断。正式加入双方同名时点的
    相互影响效果前，需要确认是同时建立、按先手值还是采用其他排序规则。
12. “风生回响”要求识别当前全部手牌可组成的最高精确牌型，但尚未确认存在多个并列最高
    牌型组时，哪一组真气作为该牌型的参与牌并用于属性条件和后续效果读取。当前运行时遇到
    不同参与牌组成的并列最高组时不擅自选组，也不执行重触；需要确认是由玩家选择、按牌区
    顺序、按真气值，还是采用其他规则。
13. 回合末由“风生回响”重触的当前功法如果继续请求玩家选择目标，现有同步行动的可恢复
    选择协议没有确认回合结束时点应暂停到何时。当前普通无选择功法可以完整重触；遇到新的
    选择请求时不自动代选，需要确认回合末选择窗口与敌方可见信息边界。
