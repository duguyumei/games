# 《组合出招》美术风格圣经 v1.0

本规范约束正式美术、外包与 AI 辅助素材。界面视觉以
`res://ui/ui_design.gd` 为唯一运行时 token 源；本文记录其美术含义，不复制或替换 Theme。

## 1. 核心方向

关键词为“暗色绢本、克制武侠、现代可读性”。画面像被岁月压暗的矿物颜料与墨线，而不是仿古滤镜；信息层级必须先于纹理。战斗内容允许锋利和速度感，但不使用赛博霓虹、欧美厚涂奇幻或二次元高饱和手游光效。

## 2. 色板

| 用途 | token | 色值 | 使用规则 |
| --- | --- | --- | --- |
| 大背景 | `background` | `#081516` | 主体底色，不叠纯黑 |
| 墨色 | `ink` | `#15191f` | 最深卡框、遮罩 |
| 面板 | `panel` / `panel_2` / `panel_3` | `#202730` / `#252c36` / `#303844` | 从外到内逐级提亮 |
| 主文字 | `cream` | `#f3e8ce` | 暖白，禁止纯白大面积铺陈 |
| 次文字 | `muted` | `#9eafaa` | 说明与非焦点信息 |
| 高价值 | `gold` | `#e9bd51` | 选择、稀有、关键边框；单屏面积不超过 8% |
| 行动 | `orange` | `#d97832` | 主行动、火与攻势 |
| 伤害 | `red` | `#d64d48` | 伤害、危险，不单独承担无障碍含义 |
| 防御 | `blue` | `#3c82bb` | 防御与冷静反馈 |
| 生机 | `green` | `#3f9c67` | 回复、林与正向状态 |
| 异术 | `purple` | `#835bb4` | 蛊毒、稀有内容、异常状态 |

同一图像允许对 token 做明度变化，不得改变色相体系。角色肤色、天然材质可扩展色域，但背景饱和度应低于交互焦点。

## 3. 线条、材质与光影

- 主轮廓使用有干湿变化的墨线，成品在 1080p 下等效 2～4 px；内部刻画 1～2 px。禁止全部轮廓同宽的矢量贴纸感。
- 材质优先绢、旧纸、木、石、青铜、布和微弱金粉。纹理对比度低于主体 20%，不得覆盖文字安全区。
- 主光为侧上方柔光，阴影边缘略散；高价值物件可有窄金边反光。禁止通体塑料高光、强 HDR 轮廓光与无来源的彩色环境光。
- 黑位保留青绿色，不压成纯黑。卡图和头像在灰度模式下仍需读出前中后景。

## 4. 人物比例与构图

- 正常成人采用 7～7.5 头身，少年 6～6.5 头身；头手不得做夸张萌系比例。
- 肖像以胸像或半身为主，眼线位于画布上方 42%～48%，视线朝向内容区。头顶留白不少于画布 6%。
- 服装来自布、麻、皮、金属小件的层叠；轮廓优先于繁复花纹。禁止无功能的大面积金属肩甲、欧美板甲和现代服饰。
- AI 产物必须人工检查手指、武器握法、衣襟结构、左右佩饰、文字形状和重复纹样。

## 5. 真气卡框

- 外框为深墨底，选中态使用 `gold`，功能类别用红/蓝/绿/紫作小面积识别，不整框染色。
- 插图占卡面 58%～66%；牌阶、属性、真气值各自保持固定信息区，不把文字烘焙进 AI 图。
- 卡框四角内缩，圆角与现有 Theme 8～12 px 的语言一致。装饰线使用单层或双层细线，禁止多重浮雕金框。
- 品相与印记属于叠加层：箔面用暖金颗粒、镭射用低饱和冷暖偏移、多彩用局部虹彩、负片用明暗反转；不得改变基础属性识别。

## 6. 图标与特效

- 图标采用“实心主形 + 一处负形 + 少量墨线”，128 px 母版在 32 px 显示时仍可辨认。不要使用文字、复杂人物或超过三层的微小结构。
- 状态图标不得只靠红绿区分；轮廓或内部符号必须不同。
- 特效遵循“起势清楚、峰值短、消散干净”。攻击峰值 80～160 ms，持续状态可循环但亮区覆盖不超过角色 30%。
- 粒子边缘可有纸纤维或墨晕，不使用硬边方形噪点、霓虹电路、镜头污渍和满屏色差。

## 7. 禁用风格

- 高饱和二次元手游渲染、Q 版大头、赛博朋克霓虹、欧美重甲奇幻、写实摄影拼贴。
- 无内容意义的伪汉字、AI 水印、签名、可辨识品牌标志、直接模仿在世艺术家的画风。
- 过度泛黄、统一颗粒滤镜、过强晕影、背景与主体同对比度、对称复制的纹样和肢体。
- 把 UI、数字、牌阶或说明文字直接生成进插图。

## 8. AI 素材人工验收

每张 AI 辅助素材必须经过两轮人工检查并在同名 `.asset.json` 留痕：

1. 来源与权利：生成平台、模型、提示词、seed、输入参考、许可条款和来源链接齐全；参考图有使用权。
2. 结构与语义：人物解剖、服饰、兵器、透视、光源、场景逻辑正确，无伪文字、水印和品牌。
3. 风格一致：色板、墨线、材质、光影、人物比例及禁用风格全部通过。
4. 生产适配：尺寸、透明边、锚点、安全区、缩略图可读性、无脏像素；以实际 UI 尺寸检查。
5. 人工修改：记录修手、重绘轮廓、调色、去伪文字等编辑；未修改的 AI 原图不能标记 `approved`。
6. 批准：至少一名美术/设计负责人填写 reviewer、时间与备注；`draft` 和 `rejected` 资源不得进入发布包。

评审时同时查看原尺寸、50% 和实际显示尺寸。任一层级出现结构错误或风格漂移即退回，不以“整体看起来不错”豁免。
