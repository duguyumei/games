### 远征压力

> 2026-09-06 重构定案（C-022/C-023，详见《25》）：旧"敌对势力警戒度"废弃（禁区遗留概念，且原实现＝行动力的影子，不产生独立决策）。压力重构为**两轴＋追杀**，**M2 已实现**：

- **禁地状态**（累计消耗行动力驱动，3 级）：每升一级随机标记 30% 地点，各洗入一张小镇物（不太强的守卫类敌人）；后续撤离点可挂状态门槛（部分 3 级关闭）。设定：禁地对闯入者的察觉度，空壳趋聚＝白细胞反应。
- **气息**（累计搜刮价值驱动，累计口径、丢物不救场）：过线触发镇物追杀——分身（血少可杀、寿命 10 次玩家行动、2:1 追逐节奏、压顶封锁、距离>3 瞬移落顶）；追杀触发时禁地状态 3 级则真身登场（永不消散）。
- **杀真身**：禁地状态清零、撤离点全开、守卫系统关闭（小镇物卡消失、分身不再刷）、随便搜；掉落＝镇物尸体（每禁地固定一件，传世档低值）。

警觉度完整形态下，警觉度增加后可能导致：

- 巡查敌人出现。
- 追踪敌人出现。
- 路线变危险。
- 撤离点减少。
- 触发围堵。

## 行动力经济（牌阵原型 v1 已实现）

所有探索动作花同一种货币：行动力。起始 40 点（**旧占位——战斗计力后必上调**，用户已拍板；预算公式补战斗项：预算≈单局可逛地块数×每块均价＋预期战斗场数×场均回合数，联动 D-057，数值进《10》），定价表（可在地点配置中调整）：

| 动作 | 点数 |
|---|---|
| 战斗·开战（主动迎战与被袭击） | **0**（开战产噪固定档照旧） |
| 战斗·每个大回合开始（双方抽牌时） | **−1**（D-058 世界钟接入：禁地状态/追杀节拍/分身寿命/迫近/警戒衰减同步推进，每大回合按低档持续产噪占位 1 格 +2、2 格 +1；静音窗开战即破；沙盒演武无 AP 不适用） |
| 开启·木箱 / 铁匣 / 金箱（弹窗开盖） | 1 / 2 / 3 |
| 搜刮·遗体行囊（弹窗开盖） | 1 ~ 3（按敌人档次） |
| 容器内翻牌（弹窗里点暗牌，D-028） | 1／张 |
| 沿通道移动 | 1 |
| 拾取 / 丢弃 / 交谈 / 打开地点卡 / 撤离 / 锦囊与穿戴整理 / 用道具 | 0 |

设计要点（C-028 换轴）：行动力是**唯一的货币也是唯一的动静计量**——开金箱 3 点比拿伤药 1 点吵（产噪按花费倍乘），0 费的拾取（含容器内拿取）也有最小动静 1 点；打开地点卡免费、走回头路收费——进山容易出山难。明牌下不设行动顺序锁：地点的牌摊成 3 列网格全亮牌、点击即互动，「敌人守物资」由**惊动制**表达（动牌产噪按曼哈顿距离喂敌人警戒，满表＝准备态，再动一次且仍在地块＝被袭击、敌方先手；警戒只有你在别处花行动力才衰减——详见《25》§4④）。

战斗计力（D-058）：战斗中行动力归 0 不中断战斗，**战后判定**——打赢但行动力已尽且不在撤离点＝力竭被擒（打不起的架别打；撤离点例外照旧，逃跑道具为泄压阀，提前排期）；增援与追杀者＝战斗中顶栏「逼近」预告、战后接战（中途入局并入 C-029）；辟谷丹暂不开放战斗中使用（战中续力留《10》再议）。

力竭：行动力归 0 且不在撤离点 = 被擒，视同死亡损失；战斗中的归 0 不中断战斗，战后判定（D-058）。

## 背包、道具与休整

- 背包格数由穿戴行囊决定（**M4 已实现，C-027 修订**：粗布行囊 5、行商背囊 8、大座行囊 12，均靠禁地搜获或仓库携出——**开局配发已取消**；没穿行囊兜底「随身衣兜」基线 5 格；换小行囊时背包件数不得超过新格数）：同名可叠物品叠放占一格，装备实例（兵器/护具/行囊）不叠堆各占一格，满格拾取/拿取被拒——先丢弃或当场用掉。穿戴栏三槽不占背包格，穿戴/卸下＝0 行动力整理类操作（终态/追兵压顶不可动）。
- 贴身锦囊（**M3 已实现**，C-024，详见《25》§6）：死亡/力竭只保锦囊（背包与穿戴当场清空），撤离全保；**格数为局外升级制（M4 修订）：初始 1 格封顶 3**，不做局内拾取物；兵器/护具/行囊放不进；探索中 0 行动力换入换出（一次一件）；囊中道具可直接使用（消耗落在囊中那份），凭证类地点条件跨囊生效；追兵压顶/终态不能整理。
- 使用道具：0 行动力，消耗物品立即生效，效果在 items.json 的 use 字段（**M1 已实现**，结构与效果词表详见《25》）：探索域走 BoardState.use_item，战斗域走 ItemEffects、**占用本回合主动行动**（与发动功法互斥；第一版战斗中只能使用不能整理背包）。
- 休整动作**已废弃**（C-022）：回血归丹药，行动力归辟谷丹（门派垄断的行粮，禁地内搜不到，叠 1）。力竭被擒含义＝"粮尽力竭"。原"真气毒全清"职能随状态系统另行定案。
- 气血贯通：战斗结果延续，玩家气血跨战斗持续（已实现）。凡"临时"效果须在数据中以 scope 标注（如毒 scope: battle），未标注的一律延续。

## 经济：禁地吞吐与垄断租金（世界观依据《03》v2.0）

### 秘籍生命周期

```text
禁地搜出秘籍/残页（未确认，占背包）
  → 撤离点二选一：
     a) 就地参悟：卷毁 → 参悟点（零风险，放弃卖价）
     b) 带出：原典=敏感物（最高档），巡界盘查概率↑（走私）
        → 据点三选一：
           完整研读（卷毁 → 学会招式/心法）
           重复研读（多余原典，卷毁 → 参悟点）
           卖给门派（钱——只收字迹完整的原典）
```

- **参悟即蚀**：参悟以真气引字入体，学一遍字褪一遍——学过的卷子是白卷，"先学再卖"物理上不成立；每份实体只有一个价值通道。认名不毁。
- **参悟点（占位名）**：重复研读获得，用于调整真气牌库（温故知新）——构筑实验的永动内循环。

### 准入与租金（钱水槽）

- **外围免费**：拾荒者的地盘，天然低保，防死亡螺旋。
- **付费直入**：向该禁地控制门派交钱，跳过外围直插深区——省行动力、开局高危。定价与深度档待定。
- **垄断租金**：装备回收折价＋手续费（门派采买）、收购销毁、拜师传授、深区直入券。

### 炼气消耗（成长水槽）

| 通道 | 内容 | 消耗 | 武侠说法 |
|---|---|---|---|
| 洗练 | 真气属性转换（杂牌 → 纯系） | 洗髓类材料＋参悟点 | 洗髓伐毛 |
| 淬炼 | 单张真气内力 +1（有上限） | 淬炼材料＋参悟点 | 淬炼真元 |
| 凝气 | 新增真气卡（扩牌库，有上限） | 凝气材料＋参悟点 | 凝气培元 |

- 材料定向产出（占位）：洗练偏药人谷、淬炼偏焚岳窟、凝气偏磐石古刹——成长系统把玩家推向对应禁地。
- **速成丹**（药人谷特产）：直接给一张高内力气卡，但带真气毒或暗伤——速成的邪路。
- 细则（上限曲线、定价）进《10》数值框架。

### 吞吐（物品水槽）

本局远征内散落区可回捡；跨局整体重生成＝禁地消解外来物，玩家不能把禁地当仓库。

### 单机经济口径

不追求永续平衡，目标：通关路上钱和物资始终有用；后期通胀由大额水槽兜底（淬炼进阶、据点升级、档案馆收集、个人线所需物）。数值配比进《10》框架。

## 撤离与死亡

成功撤离：背包与锦囊里的战利品进入仓库（**M4/C-027 已实现**），重复物可处理，任务和情报生效；**随身兵甲不入库——跟人走，耐久原样带回下一局**（存 meta 档；撤离结算文案分「入库价值」与「兵甲带回」两口径）。  
死亡或力竭被擒：背包战利品与消耗品、**穿戴栏三件（兵器/护具/行囊）全部丢失**，**唯有贴身锦囊内的物品保底回仓库**（M3/M4 已实现）；已经掌握的心法、招式和真气构筑保留。（早期"兵器不永久消失但保留磨损"的口径已废止——25 号 §1：带入即风险，死亡全丢；修理钩子留给据点设施/材料里程碑，精铁即为预留锻材。）  
主动弃局（局内弃战/标题弃档）：**与死亡同口径且不保锦囊**——物资全丢、穿戴散失、远征存档一并弃掉（C-027 统一，此前弃局不清档、旧局可被「继续远征」复活属缺陷）。死亡/撤离后不点「回据点」直接退游戏也无损：下次开机自动补结算（C-027）。  
开局流程（C-027）：据点「出发」→**备战页**（选禁地→配置栏换装＋功法/心法占位→仓库装载背包与锦囊）→出发。开局穿什么带什么全凭备战页手选——没有保底配发，空手开局合法；撤离带回的兵甲原样在身，想换只能下次备战时手动换。
