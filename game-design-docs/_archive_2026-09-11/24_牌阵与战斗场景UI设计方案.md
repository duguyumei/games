# 牌阵与战斗场景 UI 设计方案

版本：v0.26  
状态：探索（board.tscn）、战斗（scenes/battle，M7 全完成）、局外三场景（title/stronghold）均已落地；M1 物品系统（C-022）与 M2 压力与镇物（C-023）已实现
v0.2 修订（按用户反馈）：探索布局重做——中央改为牌堆大陆、动作按钮移至牌边、容器改底部上弹抽屉、右下背包+散落区（"遗留区"更名）、非当前地点牌背朝上；实施顺序探索先行。  
v0.3 修订（按用户反馈）：探索模型升级——地图改为预置"地块大陆"（方格地块 + 下方地名 + 上面一摞牌），未探索牌背朝上、走到即翻开、探索过保持离开时状态、当前高亮其他压暗；常规地点沿通道直接走，地点卡只给特殊地点（隐秘/捷径/藏宝阁/上锁房/撤离），吃打开/无视且可带物品条件（信物/钥匙）；散落区跟地点走——散落摞做散乱堆叠（随机角度与偏移，对比牌堆的整齐堆叠），点散落摞上弹抽屉互动。  
v0.4 修订（按用户反馈）：交互定稿——地块上左右两摞（左=未探索牌堆、右=散落摞），动作按钮浮在对应牌堆正上方；左堆只对顶牌出动作（拾取/无视/打开/战斗/交谈），右堆固定[展示全部]+顶牌自身动作；无视=牌滑入散落摞。  
v0.5 修订（按用户反馈，附参考图）：美术基准校准为《月圆之夜》式清亮氛围（D-041）——要夜色氛围、不要黑暗压抑；Inscryption 只取"桌面"隐喻、不取黑暗度；色板桌面底色由近黑上调为夜色青灰，明度下限=文字直接可读。  
v0.6 修订（按用户反馈，附参考图）：美术语言定为水墨武侠质感（D-042）——宣纸米白牌面、墨色剪影与笔触、赭石/土金点缀、毛笔字标签，类别色收敛为细描边/小色块；大陆衬青绿山水/宣纸纹理桌面。v0.5 的"童话感彩色牌框"系误读参考图（该图仅用于亮度校准），已修正。  
v0.7 修订（按用户反馈，M1 实装验收）：地块解剖定稿——撤销左右双摞分置，改为"顶部动作排（仅当前地块）/ 中央单牌堆 / 底部散落扇+地名居中"三段；焦点+上下文两级尺寸（当前地块卡牌比例金框、其他 0.6 缩小压暗）；小地块散落只给"散n"角标，当前地块散落扇按数量堆出+计数；散落摞去按钮化（点摞开抽屉）；地图名屏幕左上；连线收边到地块边缘；探查 UI 暂移除（规则保留）。

## 背景与问题

现 UI 是 Label/Button 直排的调试骨架，试玩暴露的问题：

- 布局无缩放适配，内容溢出被裁剪（已临时修补：stretch 缩放 + 日志滚动区）。
- 信息无层级：状态、牌阵、牌叠、遗留区、背包平铺，全靠文字行。
- 没有"牌"的视觉：地点是灰色按钮，牌叠顶、容器、真气都只是文字，搜打撤的"开包"和战斗的"发劲"没有演出落点。
- 关键操作缺确认：撤离一触即发，与 13 的"搜索和撤离必须有明确确认"冲突。
- 日志是信息主干，却最容易被挤出屏幕。

目标：不重做功能，把两个场景重排成"一张牌桌"，让 D-033 的暗黑牌桌感落地到布局、组件和演出。

## 设计原则

1. 一张牌桌：每个场景就是一张桌面——状态在桌缘，牌在桌面，日志在桌角。规则信息优先于装饰（13）。
2. 卡牌即界面：地点、牌叠顶、容器、真气、敌方意图——全是"牌"，有牌面/牌背/类别色描边；按钮只用于动作。
3. 暗桌面亮牌面：深棕黑桌面 + 暖光晕，牌面米白，信息可读性优先（14）。
4. 不可见即可得：常驻信息不藏进滚动区；任何操作两步内可达；不可用的动作必须说清原因。
5. 纯逻辑与 UI 分离不破：UI 只读状态、发动作，本方案不要求任何规则改动。
