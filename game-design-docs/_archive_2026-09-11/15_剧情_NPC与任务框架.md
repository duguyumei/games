## 叙事结构总纲

参考结构：塔科夫（商人任务链叙事＋调查式主线＋boss 有来历）与逃离鸭科夫（从第一分钟成立的个人目的＋真结局＋据点 NPC 伙伴线）。叙事厚度的来源是**任务链**，不是过场；局内只做零成本演出（口诀复诵、boss 可视化瞬间、收集物）。

## 主角与主线

- **单主角**：普通出身，武学全是拾来的——"捡什么用什么"即人设，构筑自由在世界观内成立（在源头取材＝绕过一切垄断）。
- **客串模式（后置）**：冷却制随机扮演一名同行拾山人，随机构筑随机装备，死亡只损失这一场——多角色爽点的低成本替代，兼作终极低保。
- **序章三选一"要找的人"**：师父／义姐／结义兄长（首发先做一个，其余后补）。TA 进了禁地后下落不明。
- **主线引擎＝找人下落型**：线索推进、悬念到底，故人生死与下落终局才揭晓（揭晓内容待定：生死／被蚀活着／立场反转）。
- **恐惧暗线**：空壳多为历代未归者——你找的人也可能已经如此。

### 主线六节点（gate 全为搜打撤原生目标）

| 节点 | 推进条件 | 剧情内容 |
|---|---|---|
| 序幕 | 教学局：进图→成功撤离 | 落脚栅下集，接第一条线报，认识核心 NPC |
| 一幕 | 搜集量：带回 N 件同类物 | 战利品中认出故人遗物 |
| 二幕 | 特定物：线索名录 | 指向各处藏匿点；解锁两个新禁地；故人行踪确认 |
| 三幕 | 首杀 boss | 揭开一层格局；世界阶段变化（封锁升级/控制权波动，具体后议） |
| 四幕 | 特定物×3：三样信物 | 拼出终局地点；故人下落锁定 |
| 终局 | 进入最深禁地了结 | 真相＋故人揭晓＋个人目的的了结（人／真相／出路） |

- **终局回归个人目的**，不做大格局站队选择（玩家是见证者，见《03》叙事站位）。
- **转向式结局**：终局后世界进入对应后局阶段，搜打撤继续、更高内容解锁——叙事有闭环，游戏无关机。结局只由主线 gate 触发，想刷的玩家可停在四幕。
- **死亡不改剧情进度**：已触发的线索与已带回的信物不因死亡丢失；主线永远可选，纯刷子玩法成立。

## 据点：栅下集（占位）

活人全在图外——禁地是空心的，世界的"活"由据点与门派势力承担。

### NPC＝服务＋个人线＋信任度

| NPC（占位） | 服务 | 个人线方向（占位） |
|---|---|---|
| 情报商 | 线报、任务板、档案馆兼营 | 禁地消息的掮客，知道的太多 |
| 门派采买 | 装备回收（折价＋手续费）、收购销毁窗口 | 垄断在据点里的脸；替门派跑腿的良心 |
| 铸兵师 | 修理、改造、拆解 | 为门派锻过兵的人 |
| 郎中 | 疗伤、制药 | 见惯了从禁地回来的伤 |
| 退隐高手 | 招式指点、传授 | 旧时代的活档案 |
| 被救 NPC | 入住据点，解锁服务 | 从禁地里救回来的 |

- **个人线规格**：每条 3–5 章，每章＝1–2 个任务（带回某物／击败某空壳／触发某事件）＋一段对话＋服务或信任升级。**任务链即剧情**。
- **信任度**：个人线进度与信任等级挂钩，影响服务与线报质量。

### 档案馆

可读掉落物（家书、账册、口诀残页、门派文书）集册成套给收集奖励——碎片叙事长在搜打撤的奖励里。归情报商兼营。

## 任务原则（继承 v0.1 并细化）

1. 任务是额外动机，不替代玩家主动选择地点（D-004 保留）。
2. 任务奖励优先是构筑选项、情报和 NPC 服务，而非纯面板数值。
3. 任务应说明目标、风险和可能损失。
4. **门派任务＝公司合约**：门派通过据点或采买发悬赏（收购、清扫、探路），接不接自便——给垄断打工也是合法玩法选项。

## 随机事件池（种子驱动，非剧情排期）

- **公司战争**：两派巡界队火并、劫掠、封锁变动——可躲、可捡漏、可帮一边。
- **同行**：中性同行 NPC 卡（交谈／交易／求救，救回据点解锁服务）；同行遗体（遗书、半张标记、没送出的家书）。
- **盘查**：携带敏感物提高巡界遭遇概率——**原典为最敏感一档**（走私原典出封锁线）。

## 管中窥豹窗口（示例，全部占位）

撞上"传内不传外"之墙的外门弟子、被大派吞了祖传剑谱的破落人家、闯禁地未归者的家属、把禁地外围当荒田捡的拾荒者——每条线都是垄断剥削的切片，没人说教。
