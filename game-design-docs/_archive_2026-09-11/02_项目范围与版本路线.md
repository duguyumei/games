# 项目范围与版本路线

版本：v0.1  
状态：待验证

## 开发原则

- 先验证玩法，再扩展内容和表现。
- 地图探索和战斗系统分开制作、分开测试。
- 先用纯 2D 抽象地图验证固定地点与随机状态，不提前承诺 2.5D。
- 先做一个完整可玩的垂直切片，再扩充卡池和剧情。

## 原型阶段（纸面/表格）

范围：

- 一个主角。
- 一个固定江湖地点。
- 3 个普通敌人概念和 1 个精英敌人概念。
- 少量心法、真气和武学招式。
- 3 类兵器以内。
- 3–5 种消耗品。
- 一副约 10 张的地点牌堆（含入口与 2 张撤离牌）。
- 一次完整的探索、战斗、搜集和撤离流程。

通过条件：

- 玩家能明确追求一个流派。
- 战斗规则可以手工复现。
- 继续深入和撤离之间存在真实取舍。
- 死亡损失有风险，但不会抹掉全部长期进度。

## Godot 战斗沙盒

只实现：

- 战斗状态。
- 真气抽取和牌型判定。
- 招式合法性检查。
- 玩家行动。
- 敌人意图与确定性策略。
- 伤害、状态、气血和胜负。

暂不实现：地图自由移动、复杂 NPC、联网、商店、完整装备词条和大规模剧情。

## Godot 牌阵原型

战斗沙盒之上的探索层已实现（替代原计划的节点地图，见《05》与《18》C-001）：

- 地点牌堆向外生长、牌叠顶层交互、遗留区。
- 容器统一（箱子=遗体）：开启费 + 翻牌费 + 拿取免费，可翻一半走了再续。
- 行动力经济、追兵阈值拦截、力竭判负。
- 敌人普通/精英分档，遗体按档掉落。
- 全种子驱动，GUT 覆盖规则与整局重放。

暂不实现：开包特效音效、背包上限、潜行、远征内血量贯通、物资使用效果。

## 垂直切片

目标是完成一段可以从据点开始、进入一个地点、完成数场战斗、搜到物品并成功撤离的完整体验。

## 后续版本

只有垂直切片通过玩家测试后，才考虑：

- 更多固定江湖地点。
- 更多流派和首领。
- NPC 解锁与任务线。
- 更复杂的地图状态和特殊事件。
- 存档、成就、完整剧情和发布功能。
