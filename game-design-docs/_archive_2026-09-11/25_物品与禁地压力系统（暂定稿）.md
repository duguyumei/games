## 2. 物品字段结构（定义层） ✅

底座五件＋可选件，实例层两种形态：

- 底座：`id` / `name` / `type` / `rarity` / `value`（=售价；无买价无重量）
- `icon`：贴图地址，缺省文字回退（美术后补，校验只查 res:// 前缀）
- `max_stack`：堆叠上限，缺省 99 ✅
- `charges`：使用次数（一出现即"耐久道具"，实例不叠堆）——词表保留，装备用 ⬜
- `desc`：风味文本 ✅
- 实例形态规则：**有没有私有状态（耐久/次数）决定叠不叠堆**——无则 `{id, qty}` 叠堆；有则 `{id, uid, dur}` 独立个体 ✅（M4 落地：装备实例 uid 由 MetaArchive 跨局发号；行囊无耐久故无 dur）

背包与仓库同构；穿戴栏（兵器/护具/行囊各一槽）不占背包格 ✅，**背包格数改由穿戴行囊决定**（粗布 5/行商 8/大库 12；没穿行囊兜底地图配置值——C-027 后即「随身衣兜」基线 5 格） ✅。远征存档 v3→v6（v6 带穿戴栏与装备实例，M4） ✅；穿戴栏另存 meta 档 v3（C-027 跨局角色状态，远征档里的 equipped 只是局内工作副本）。

## 3. 消耗品（五细分） ✅

`use` 三件套：`scopes`（battle/explore）、`target`（self/enemy）、`effects`（`{kind+参数}` 列表，受控枚举＝已实现执行器清单：heal / restore_ap / damage / apply_status / open_all_chests / evade_top_enemy；flee、cure_status 留后）。

| 小类 | 定位 | 样例 |
|---|---|---|
| medicine 丹药 | 恢复气血，battle/explore | 伤药（回10）、金创药（回16）、跌打酒（回22，战斗内可急用）、百年老参（回40） |
| hidden_weapon 暗器 | 一次性攻击/控制，仅 battle，target=enemy | 淬毒飞镖：直伤 10＋毒×2 |
| tool 机关工具 | 搜索规避，仅 explore | 百匣钥（开当前地点全部箱子，0 行动力）；迷踪香（C-028 改静音窗：N 点行动力内动牌不产噪，遮住气息偷东西）；火折子（黑暗地形后续） |
| provision 行粮 | 回行动力 | 辟谷丹三品：下品回3/中品回5/上品回8，**叠1**，**禁地内搜不到**（门派垄断） |
| credential 凭证 | 无 use，被特殊地点引用消耗 | 青锋剑令（藏宝阁）、铜钥匙（上锁的房间）——接地点卡既有 require_item 机制 |

关键定案：

- **休整动作废弃**。回血归丹药、行动力归辟谷丹；力竭被擒含义变为"粮尽力竭"
- 辟谷丹带 `no_drop`（掉落黑名单）：任何稀有度掉落池抽不到它——"禁地内搜不到"由数据保证 ✅
- 辟谷丹是结构自限的：回的力照常花、照常喂禁地状态——**买得到路程，买不到安全**
- 暗器直伤**绕过护体真气（guard）**，按敌人「道具伤害减免」打折（听风辨器）：normal 0% / veteran 20% / elite 35% / master 50%，向下取整；敌人定义可用 `item_damage_reduction`（0~1）覆写个别特例 ✅
- 使用道具：探索中 0 行动力；**战斗中占用本回合主动行动**（与发动功法互斥，敌方回合/演出中不可用；装配中先自动取消） ✅
- 战斗中第一版**只能使用、不能整理背包**（换锦囊/挪动物品随锦囊系统） ✅
- 道具伤害减免进敌人定义；数值全占位，进《10》框架
- 淬毒飞镖的毒：**已拍板（2026-09-10）——先取消现行淬毒效果，毒系统整体重做**（方向＝真气毒，见《26》§1.1），具体落法后续实现；原"走战斗现有 poison"默认口径作废

## 4. 禁地压力系统（两根轴＋追杀） ✅（M2 已实现；撤离点状态门槛、追杀庇护道具为后续钩子）

设定总纲：**禁地不是废墟，是睡着的东西**。空壳＝历代闯入者被吞后的残余（白细胞）；古之物是它身体的一部分；门派只管封锁线门口（准入/收费/撤离点），线内无人巡。废弃旧"警戒度"概念（D-030 禁区遗留，原实现＝行动力的影子，不产生独立决策）。

**① 禁地状态**（累计行动力驱动，3 级）：每升一级随机标记 30% 地点，各洗入一张**小镇物**（不太强的守卫类敌人）。后续钩子：撤离点挂状态门槛（部分 3 级关闭）。

**② 气息**（累计搜刮价值驱动，累计口径、丢物不救场）：过线触发追杀。

**③ 镇物追杀**：

- 出生：玩家**当前地点**牌堆顶
- 节奏：分身每 2 次玩家行动走 1 步（固定）；真身随机 1~2 次
- 移动：不在玩家地块→朝玩家移 1 格（非玩家地块只做驻留标记，不占牌堆）；在玩家地块→压牌堆顶，**压顶即封锁**（不打它翻不了下面的牌）
- 瞬移条款：轮到它行动时距离 >3 格（或庇护道具到期）→ 直接落到玩家当前牌堆顶
- 分身：血少可击杀，奖励很小；同屏只一只（气息连过线排队，现役死了才上）；**寿命 10 次玩家行动**（占位），可见倒计时，气尽自散，散后等气息下一条线
- 真身：**追杀触发时禁地状态为 3 级即出真身，否则分身**（按次判，在场不替换）
- **杀真身**：禁地状态清零、撤离点全开、守卫系统关闭（现存小镇物卡消失、分身不再刷新）、随便搜（原敌人不动）——但禁地状态照常累计（撤离门槛继续有效，随便搜≠无限待）
- 真身掉落＝**镇物尸体（固定战利品）**：每禁地固定一件，传世档低值（"杀过它"的凭证，不是发财路）。青锋守冢剑灵 → 守冢断剑（占位 120）。名剑·湛卢（200）回归可搜战利品
- 分身/真身接战走正常战斗流程，败给它按普通败北口径
- 追杀庇护道具（一定期间不被追杀）：后续

### ④ 地点警戒·惊动制（C-028 已实现）

「敌人守物资」的表达方式：不再锁行动顺序，而是**动了它守着的东西就会惊动它**。

- 明牌契约：只有你惊动的（警戒满表袭击）、和追杀你的（镇物迫近），会打你；看/走/0 行动力翻腾永远免费。
- 产噪＝牌的互动（拿取/开箱/搜遗体），按曼哈顿距离传播：1 格内 +2×行动花费、2 格 +1×；0 费互动（拾取）最小动静 1 点；进地块、交谈、整理、用道具、静音窗内动作＝无声；开战最吵（固定档：1 格 +4、2 格 +2，静音窗也遮不住打斗）。
- 警戒上限默认 10（占位），个别敌人可覆写；满表＝准备态（红「！」），刚满表的那次行动不咬（逃生窗：primed），下一次行动后仍在地块→被袭击（敌方先手）；多只满表逐只来；离开地块＝安全，但只有你在别处花的行动力才消警戒（每点 −1，掉出满表解除准备态）——消警戒的时间同时喂禁地状态与追杀节拍，磨蹭有代价。
- 连坐：地块网格里上下左右连通的敌牌算一组，迎战一张整组上（C-029 多人战斗引擎前＝组内逐场 1v1）；镇物独来独往不连坐。
- 迷踪香＝静音窗（3 点行动力，占位）：窗内动牌不产噪；第 N 点余量护住第 N 次动作（扣窗前先判覆盖）。
- 遗体规则：普通敌人/真身胜后原地变遗体（弹窗翻牌搜刮，与箱子同规则），**搜空也不消失**（灰化留场）；小镇物与镇物分身被打死直接消失、无掉落；清场＝现存小镇物卡消失、分身寿命尽自散。

### ⑤ 战斗接入世界钟（D-058，设计定案待实现）

- **每大回合开始（双方抽牌时）−1 行动力**，统一触发 AP 全钩子：禁地状态累计（长战惊动"白细胞"）、追杀节拍（追杀者打架时继续逼近）、分身寿命（长战可耗死分身、气尽自散）、迫近（压顶中每回合 +1，满层扑上＝战后接战追加）、警戒衰减（别处口径照旧——打架时远处敌人回落）。
- **战斗噪声**：开战固定档照旧（1 格 +4、2 格 +2）；每个大回合按低档持续产噪（**占位**：1 格 +2、2 格 +1）——缠斗持续作响，近处升温、远处回落。
- **静音窗开战即破功清窗**（打斗遮不住，不按回合慢慢烧）——统一口径下唯一显式特例。
- **增援/追杀者到达＝战后接战**：战斗中顶栏「脚步声逼近」预告（邻居满表/追杀者接近，不打断当前战斗），战后追加进接战队列逐场打；中途入局＝多人合战引擎，并入 C-029 再议。
- **力竭战后判定**：战斗中行动力归 0 不中断战斗；打赢但行动力已尽且不在撤离点＝力竭被擒（撤离点例外照旧）；**逃跑道具为必需泄压阀，提前排期**；辟谷丹暂不开放战斗中使用。
- 工程口径：战斗引擎零改动——TurnManager 发"大回合开始"事件，扣力与全钩子由 ExpeditionSession 接（同 heal_player 回调模式）；沙盒演武无 AP 概念自动跳过。
