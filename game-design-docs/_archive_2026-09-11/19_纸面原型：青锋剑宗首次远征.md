# 纸面原型：青锋剑宗首次远征

版本：v0.1  
状态：历史参考——节点结构已被卡牌牌阵替代（见《18_设计决策日志》C-001），资源闭环思路仍可参考；不代表最终数值

## 原型目的

用一局小规模远征检查以下闭环：

```text
选择地点 → 进入固定地图的随机状态 → 搜索 → 独立战斗 → 资源消耗
→ 警觉度上升 → 继续深入或撤离 → 带回或损失战利品
```

## 进入前状态

```text
目标流派：剑法连击
心法：调息诀
招式：试剑式、回风剑、穿云剑、一线天
兵器：青锋剑，耐久 4/4
护具：旧皮甲
消耗品：金疮药×2、迷烟×1、飞刀×1
气血：30/30
伤势：0
警觉度：0/6
战利品背包：0/8
```

## 本局地图状态

- 出生点：后山密林。
- 开放撤离点：南山道、后山密道。
- 封锁撤离点：西侧山门。
- 高价值搜索点：藏经阁。
- 巡逻点：演武场。
- 初始警觉度：0。

## 节点一：废弃镖车

玩家选择搜索。

获得：

- 《回风剑》残页。
- 锻材×1。
- 银两×20。

状态变化：

```text
警觉度：0 → 1
背包：0/8 → 4/8
```

## 节点二：山口伏击

地图切换到独立战斗场景。敌人为两名山匪。

玩家第一回合抽到：

```text
4·刚、4·柔、4·快、4·沉、5·刚
```

玩家可以将 4、4、4、4 组成四连，施展《穿云剑》，再用剩余的 5 施展《试剑式》。

战斗结果：

```text
气血：30 → 23
青锋剑耐久：4 → 3
警觉度：1 → 2
```

获得：

- 铁背短刀。
- 解毒丸。

## 节点三：旧庄密室

玩家有两个选择：

```text
A：搜索密室，可能获得高级剑法，但警觉度增加
B：前往旧药铺，恢复部分气血，但收益较低
```

为了追求目标流派，玩家选择 A。

获得：

- 《七星剑谱》残页。
- 青锋剑改良图。

状态变化：

```text
警觉度：2 → 4
背包：7/8 → 8/8
```

警觉度超过阈值，地图上生成鹰爪门追兵。

## 节点四：鹰爪门追兵

玩家有两个选择：

```text
A：正面战斗，保留已有战利品
B：使用迷烟规避，但必须放弃一件普通物资
```

玩家选择正面战斗。

战斗结果：

```text
气血：23 → 15
青锋剑耐久：3 → 2
警觉度：4 → 5
```

获得：

- 鹰爪门身法残页。

由于背包空间不足，玩家放弃铁背短刀，保留剑谱、兵器图和身法残页。

## 节点五：回返路口

当前状态：

```text
气血：15/30
青锋剑耐久：2/4
金疮药：2
迷烟：1
警觉度：5/6
```

玩家可以继续深入寻找更高级剑谱，也可以前往后山密道撤离。

玩家选择撤离。

## 成功撤离结果

正式带回：

- 《回风剑》残页。
- 《七星剑谱》残页。
- 青锋剑改良图。
- 鹰爪门身法残页。
- 锻材×1。
- 银两×20。
- 解毒丸。

回到落脚处后：

- 如果《回风剑》已经掌握，可以选择研读为剑法心得，或出售。
- 青锋剑保留 2/4 耐久，需要修理。
- 未使用的金疮药、迷烟和飞刀仍在仓库。

## 如果在节点四死亡

- 节点一至节点四获得的未确认战利品全部丢失。
- 已有的调息诀、已掌握招式和真气牌库保留。
- 青锋剑不永久消失，但保留磨损或增加修理成本。
- 已使用的消耗品消失。
- NPC 解锁、地点情报和已完成的长期剧情保留。

## 本局暴露的问题

1. 警觉度 5 时立即撤离是否最优，还是仍应有足够理由继续深入。
2. 追兵战斗和普通战斗是否有足够不同。
3. 兵器耐久每场减少 1 是否过于规律。
4. 背包 8 格是否能产生选择，而不是单纯增加整理负担。
5. 玩家在没有四连时是否仍然有有意义的招式。
