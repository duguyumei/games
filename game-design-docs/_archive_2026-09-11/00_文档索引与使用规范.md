# 江湖险地远征：设计文档索引

版本：v0.2（卡牌牌阵基线）  
状态：基线建立中  
最终决策人：用户  
文档协助与维护：AI

## 项目边界

本目录记录一款纯武侠、单人 PvE、搜打撤与原地回合制战斗结合的卡牌构筑游戏（战斗为版图内浮层，D-058）。

明确不混入以下仙侠元素：秘境、灵石、法宝、灵根、修仙境界、灵气等。地图在世界中称为“禁地”或具体地点，战斗中使用心法、真气、武学招式和兵器。世界观详见《03》v2.0（禁地·门派即公司）。

## 文档状态

- **已确认**：用户明确表示可以暂时确定，或没有提出反驳。
- **待验证**：提出了方向，但必须通过纸面原型或 Godot 原型验证。
- **待决策**：存在多个互斥方案，尚未选择。
- **暂不制作**：明确排除在当前原型或 MVP 之外。

## 使用规则

1. 《23_战斗系统v1_设计与Godot实现规格》是第一版战斗规则和原型范围的最高权威来源；《06_战斗系统总纲》和《07_功法、心法、真气与兵器构筑》提供摘要和构筑说明。
2. 《09_远征资源、消耗与撤离损失》是搜打撤资源循环的权威来源；《05_江湖地点与地图随机状态》是牌阵探索模型的权威来源。
3. 具体卡牌和招式数值最终应进入独立数据表；本阶段文档中的数值只作为原型假设。
4. 修改“已确认”内容时，必须在《18_设计决策日志》中记录原因、影响范围和是否需要返工。
5. AI可以起草、扩写、模拟和检查；用户保留最终创意、体验和范围决策权。
