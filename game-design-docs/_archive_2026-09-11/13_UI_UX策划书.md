# UI/UX 策划书

版本：v0.1  
状态：框架，等待战斗和地图原型

## 页面范围

### 据点

（骨架已落地 M6：主菜单 → 据点导航 → 出发进探索，仓库真实入库；制作/购买/升级/图鉴/NPC 线报为占位）

- 角色和武学构筑。
- 真气牌库调整。
- 兵器、护具和道具准备。
- 仓库。
- NPC和线报。
- 选择江湖地点。

### 地图

- 当前地点牌与已连通通道。
- 当前地点牌堆与散落区（已发现物）。
- 开放的撤离点。
- 行动力与追兵进度（牌阵原型）。
- 警觉度（长期方向）。
- 气血和伤势。
- 背包容量和未确认战利品。

### 战斗

- 玩家气血、内力和状态。
- 当前真气牌。
- 可组成的牌型提示。
- 可用招式及兵器限制。
- 敌人意图。
- 回合阶段和行动顺序。
- 战斗日志。

### 结算

- 获得物品。
- 损失物品。
- 带回仓库的物品。
- 重复物处理选项。
- 伤势和兵器状态。

## 交互原则

- 规则信息优先于装饰。
- 玩家必须知道为什么一个招式不能使用。
- 玩家必须知道敌人下一步大致要做什么。
- 玩家必须区分“已拥有资产”和“本次未确认战利品”。
- 搜索和撤离操作必须有明确确认，避免误触丢失高价值物品。

## 氛围与演出（方向：暗黑牌桌，D-033）

- 整体为低亮度牌桌：深棕黑桌面 + 暖光晕，牌面米白保证信息可读——暗的是桌面不是牌。
- 氛围动态化（暂不实现）：警戒度驱动全局压抑递增（光晕收缩、降饱和、朱红脉冲、锣声渐密），地点类型驱动局部底色（山道月蓝、竹林冷青、藏经阁金漆沉光），两者叠加。
- 开包演出分级：翻牌按稀有度 1~4 递进（粒子+音效），传说级金色爆发 + 重音 + 屏幕轻震。
- 警戒升级：锣声 + 全屏桌缘泛红提示 + 日志播报，不打断当前操作。

## 暂不冻结

- PC 键鼠布局。
- 是否兼容手机触屏。
- 战斗场景的最终镜头和动画表现。
