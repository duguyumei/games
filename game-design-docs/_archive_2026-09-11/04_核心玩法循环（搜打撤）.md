# 核心玩法循环（搜打撤）

版本：v0.2  
状态：结构已确认（v0.2 战斗连续性修订，D-058），数值待验证

## 场景关系

搜索地图和战斗同场不切场景（D-058，修订 D-003；细则见《18》C-030）：

```text
江湖险地版图（board）
  → 遇敌：战斗以全屏浮层在版图内原地开打
    （敌面板锚定敌牌格位；战斗背景随当前地块氛围；
     版图顶栏与周围地块压暗可见——行动力、禁地状态、气息
     与邻居警戒角标在打架时照常跳动；镜头不切）
  → 战斗结束：浮层落下，遗体落在眼前格位
```

版图负责路线、搜索、事件、警戒和撤离；战斗负责心法、真气、牌型、招式和敌我结算。两边共用同一个世界钟（行动力）：战斗每个大回合开始 −1 行动力，禁地状态、追杀节拍、警戒照常推进——打得快就是省（口径详见 09/25）。

## 一次远征流程

```text
落脚处准备
  → 选择想去的江湖地点
  → 选择本次目标流派或目标物品
  → 装备心法、真气、招式和兵器
  → 携带消耗品
  → 进入由地点牌堆生成的牌阵（见 05）
  → 翻牌叠：搜索、战斗、处理事件
  → 气血和伤势持续，兵器磨损，道具减少
  → 警觉度上升，可能出现追兵
  → 继续深入或前往撤离点
  → 成功带回或死亡损失
```

## “搜”

搜是对牌叠顶层的一次次抉择（牌阵模型见 05）：

- 处理或无视：任何非战斗牌到顶都是二选一，垃圾不必进背包。
- 顺序即命运：箱子压弟子还是弟子压箱子，同一地点两种命。
- 容器取舍：付不付开启费、再翻一张还是留着下次、翻一半被追兵打断。
- 值不值得为底下的东西打顶上这仗（可花行动力探查牌叠构成）。
- 背包有限时带走什么、丢下什么（丢弃物落在遗留区，可捡回）。

## “打”

打是在版图内浮层原地开打（D-058），以心法、真气牌型、武学招式和兵器兼容为核心，不要求高频实时反应。每个大回合消耗 1 行动力并推进世界钟——缠斗有代价，速攻就是省；增援与追杀者在战斗中逼近、战后接战。

## “撤”

撤是把未确认战利品变成长期收益的唯一方式。玩家可以主动前往开放的撤离点，而不必完成 NPC 的强制任务。

## 失败与成功

成功撤离：本次物品进入仓库，重复内容可以研读、出售或拆解。  
远征中死亡：未带出的本次战利品和本次携带的消耗品损失；已经拥有的心法、招式和真气构筑保留。
