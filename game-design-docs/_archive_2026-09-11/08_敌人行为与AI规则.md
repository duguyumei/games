# 敌人行为与 AI 规则

版本：v1.0  
状态：第一版敌人行为规则摘要  
战斗底层、行动权和信息边界以《23_战斗系统v1_设计与Godot实现规格》为准

## 总体原则

敌人不使用机器学习。敌人 AI 是可读、可测试、可重放的规则策略。

敌人与玩家共用战斗规则。敌人拥有自己的真气牌库、隐藏手牌、心法、功法、兵器、护境和弃牌区，并且只能从当前手牌能够合法发动的功法中选择行动。

## 行为层级

### 普通敌人：自我状态优先

大多数普通敌人主要关注自身：

- 气血低时防御或撤退。
- 满足牌型时使用招式。
- 有负面状态时优先处理。
- 蓄力完成后释放强招。

### 精英敌人：有限反应

精英可以读取玩家公开状态，但只使用明确写定的条件：

- 玩家有护境时使用破防。
- 玩家正在蓄力时使用打断。
- 玩家连续使用同类招式时切换针对性防御。

### 首领：阶段化脚本

首领根据血量阶段、场上状态或玩家触发条件切换行为模式，不进行无限制的通用搜索。

## 行动选择算法

```text
读取当前公开状态
  → 读取敌人自己的隐藏手牌
  → 筛选满足条件且合法的招式
  → 按优先级排序
  → 锁定第一个符合条件的行动
  → 向玩家显示锁定意图
  → 等敌人取得行动权后执行，不因玩家随后行动临时换招
```

示例：

```text
铁掌门徒：
1. 气血低于 30% 且可疗伤时，疗伤。
2. 玩家有护境时，破防。
3. 可以使用重击时，重击。
4. 否则使用基础掌法。
```

## 意图显示

敌人意图至少显示：

- 功法名称和行动类型。
- 目标。
- 预计最终伤害、护境或其他数值。
- 将施加的状态和附加效果。

敌人具体手牌、牌库顺序、实际使用的真气和未选择的其他合法功法不公开。意图显示的是敌人下一次已经确定的行动；除非玩家明确改变其结算条件，否则不能与实际结算产生无法解释的偏差。

## 暂不实现

- 敌人对玩家隐藏手牌进行作弊式读取。
- 敌人对所有未来牌序进行深层搜索。
- 依据玩家所有历史行为进行机器学习式适应。
