# 纸面战斗包可执行说明

版本：v0.2  
状态：历史聊天试玩说明  
关联文档：《21_第一版纸面战斗包》；当前战斗规则以《23_战斗系统v1_设计与Godot实现规格》为准

> 历史说明：本文档中的同花、冻结、护脉功、蓄势区、消耗区和通用反击架势仅保留作测试过程记录，不属于当前 v1 战斗规则。

## 这是什么

《21_第一版纸面战斗包》记录的是要测试什么；本文件记录的是怎么实际玩。

有两种试玩方式：

1. **聊天试玩**：用户只需要做玩家决策，AI负责发牌、记录牌区、执行敌人和计算结果。
2. **纸面试玩**：把下面的牌和表格抄到纸上，或用扑克牌代替真气牌，手工执行。

第一次建议使用聊天试玩，因为规则歧义可以立即记录，不需要先制作实体卡片。

## 一、纸面材料

### 真气牌

准备 24 张基础牌：

```text
风1 风2 风3 风4 风5 风6
林1 林2 林3 林4 林5 林6
火1 火2 火3 火4 火5 火6
山1 山2 山3 山4 山5 山6
```

如果使用普通扑克牌：

```text
方块 = 风
梅花 = 林
红心 = 火
黑桃 = 山
A、2、3、4、5、6 = 牌面内力 1、2、3、4、5、6
```

移除 7、8、9、10、J、Q、K。每张牌只保留一个属性和一个牌面内力。

基础牌库中同一点数最多只有 4 张，只能组成四连。测试五连时，另拿一张牌作为临时重复牌，例如再加入一张 `风4`。这不代表正式牌库已经确定允许重复；它只用于验证五连规则。

### 其他记录物

用纸笔或硬币记录：

- 玩家气血。
- 敌人气血。
- 护境。
- 兵器耐久。
- 蓄势值。
- 当前手牌。
- 牌库、弃牌区、消耗区和蓄势区。

## 二、第一次试玩采用的临时配置

这只是纸面测试配置，不是最终槽位设计：

```text
心法位：1
功法位：4
每回合真气：5 张
玩家气血：20
敌人气血：30
玩家先行动
```

第一次只使用剑法测试组：

```text
兵器：青锋剑，耐久 3/3
心法：调息诀
功法：回身卸力、穿云式、五岳归元、借力反打
```

这组配置的目的是测试：高牌、对子、四连、五连、回流、弃置、蓄积、时机限制和兵器兼容。

## 三、战斗开始

1. 将 24 张基础真气牌洗匀，作为牌库；只有进行五连固定手牌测试时才加入临时重复牌。
2. 把弃牌区、消耗区和蓄势区放在旁边。
3. 玩家气血设为 20，青锋剑耐久设为 3。
4. 敌人选择“山匪刀客”，气血设为 30；敌人另有自己的牌库和隐藏手牌。
5. 第一大回合开始，双方分别从自己的牌库抽 5 张。
6. 敌人从合法功法中锁定下一行动，公开名称、目标、预计最终数值和附加效果，但不公开手牌。
7. 记录玩家手牌，由玩家先取得行动权。

## 四、一回合到底怎么操作

### 步骤 1：看手牌

玩家拿到 5 张真气，例如：

```text
风4、林4、火4、山4、风6
```

这 5 张牌可以组成：

- 四连：4、4、4、4。
- 三连：任意 3 张点数为 4 的牌。
- 对子：任意 2 张点数为 4 的牌。
- 高牌：任意 1 张单牌。

### 步骤 2：选择一个功法

玩家从已装备的 4 个功法中选择一个可以发动的功法。

例如选择《穿云式》：

```text
兵器要求：剑
牌型要求：四连
效果：伤害为传输内力总和÷2；达到20内力时，攻击前额外移除2点护境
真气处理：弃置
```

玩家选择：

```text
风4、林4、火4、山4
```

因为装备的是青锋剑，兵器条件满足；因为 4 张牌的牌面内力都是 4，牌型条件满足，所以功法发动。

### 步骤 3：结算功法

按照下面顺序处理：

```text
确认兵器条件
  → 确认牌型
  → 计算有效内力
  → 计算传输内力
  → 执行伤害或状态效果
  → 执行真气处理
```

《穿云式》结算后：

```text
传输内力：4+4+4+4=16
伤害：16÷2=8
风4、林4、火4、山4：进入弃牌区
青锋剑耐久：3 → 2（战斗结束时统一扣除，本回合先不扣）
```

### 步骤 4：敌人行动

本次使用确定性敌人“山匪刀客”。它与玩家一样从自己的牌库抽牌，只能使用隐藏手牌实际能够组成的牌型。

敌人的选择优先级：

```text
1. 气血不高于12，且能建立高于当前值的护境时，使用《横刀护身》。
2. 否则有对子时，使用《断岳斩》。
3. 否则用当前最高点单牌使用《试刀》。
4. 没有合法功法时收势。
```

敌人功法：

- 《试刀》：高牌；伤害等于传输内力；真气弃置。
- 《断岳斩》：对子；伤害等于传输内力总和；真气弃置。
- 《横刀护身》：对子；护境覆盖为传输内力总和；真气弃置。

敌人锁定一个攻击意图后，玩家可以在自己的行动权中提前建立《借力反打》，也可以施展其他功法。敌人不会在玩家行动后临时换招。

《借力反打》：

```text
牌型：高牌，选择 1 张真气
时机：自己的行动权
效果：建立反击架势；下次受到攻击时伤害-3，攻击结算后反击3点
真气处理：发动时进入架势区，触发后回流
```

如果用剩余的风6提前建立架势，随后敌人的攻击为4：

```text
玩家受到伤害：4 → 1
敌人受到反击：3
风6回到当前手牌
```

反击的自动触发不是一次新行动。风6回流后，只要再次取得行动权，仍可再次发动这门功法。

### 步骤 5：继续或结束本回合

玩家每次重新取得行动权后，可以使用任意条件满足的功法；功法默认没有每回合次数限制。

例如第一手牌中使用《穿云式》后，还有风6；如果《借力反打》尚未使用，可以在敌人攻击时用这张高牌发动《借力反打》。

玩家还可以选择：

- 暂让：只放弃当前行动，对方行动后仍会再次询问。
- 收势：当前大回合不再主动行动。

双方均收势，或者双方连续暂让，大回合结束。双方行动次数不要求相等。

### 步骤 6：回合结束

1. 未处理的手牌进入弃牌区。
2. 已弃置的牌留在弃牌区。
3. 已消耗的牌进入消耗区，本场战斗不再回来。
4. 蓄积的牌留在对应功法的蓄势区。
5. 护境剩余值跨大回合保留。
6. 抽牌堆不洗牌；下回合正常抽5张，只有抽牌堆不足时才洗混弃牌区补抽。

## 五、固定手牌测试

在真正洗牌前，先按下面五组手牌测试规则。

### 手牌 A：测试四连和兵器

```text
风4、林4、火4、山4、风6
```

必须检查：

- 装备青锋剑时，能否发动《穿云式》。
- 选择 4、4、4、4 时，是否正确识别为四连。
- 这 4 张同点牌不能被误判为顺子。
- 没有装备剑时，《穿云式》是否不能发动。

### 手牌 B：测试五连和重复牌

```text
风4、林4、火4、山4、风4（临时重复牌）
```

必须检查：

- 5 张牌面内力都是 4 时，是否正确识别为五连。
- 任取其中 4 张是否可识别为四连。
- 临时重复牌只用于本项测试，不把正式牌库复制规则视为已经定案。

### 手牌 C：测试顺子

```text
风2、林3、火4、山5、风6
```

必须检查：

- 2、3、4、5、6 是否正确识别为顺子。
- 连续点数不能被误判为四连或五连。

### 手牌 D：测试三连和对子

```text
风3、林3、火3、山1、火6
```

必须检查：

- 风3、林3、火3 是否识别为三连。
- 任意两张 3 是否识别为对子。
- 三连和对子同时存在时，由玩家选择使用哪一个功法。

### 手牌 E：测试同花

```text
风1、风2、风3、风5、风6
```

必须检查：

- 只有 5 张全部为风时，才能识别为同花。
- 3 张风不能触发同花。
- 同花牌型如果没有装备对应功法，则只是普通手牌，不自动产生效果。

## 六、冻结真气测试

将以下手牌放入手中：

```text
火5（冻结）、林2、火1、山1、风3
```

规则：

- 火5 的牌面内力仍然是 5。
- 火5 仍按火和 5 参与牌型。
- 火5 的有效内力最多为 1。
- 需要内力门槛的功法只能按有效内力或传输内力计算。
- 使用《护脉功》时，本回合冻结牌的有效内力最低为 2，但冻结状态仍然存在。

## 七、完成一场测试的最低要求

至少完成：

1. 一次四连剑法攻击。
2. 一次对子防御。
3. 一次敌人攻击和《借力反打》响应。
4. 一次真气回流后再次交给合法功法。
5. 一次弃置牌进入弃牌区。
6. 一次蓄积牌进入蓄势区。
7. 一次兵器不匹配导致功法不能发动。
8. 一次敌人按照固定规则行动。

## 八、聊天试玩的具体方式

如果不想准备纸牌，可以直接在聊天中进行。

用户只需要说：

```text
开始剑法测试。
```

之后 AI 负责：

- 发出当前 5 张真气。
- 显示可用功法。
- 显示敌人意图。
- 记录手牌、弃牌区、消耗区、气血、护境和兵器耐久。
- 执行牌型和内力计算。

用户只需要做选择，例如：

```text
用风2、林3、火4、山5发动穿云式。
```

或：

```text
不用功法，结束玩家行动。
```

第一次测试推荐使用聊天试玩，因为它不需要你自己记牌和计算，重点是判断决策是否有趣、规则是否自然。
