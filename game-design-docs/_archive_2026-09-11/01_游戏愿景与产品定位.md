# 游戏愿景与产品定位

版本：v0.1  
状态：已确认基线，细节待验证

## 一句话定位

一款纯武侠题材、单人 PvE 的卡牌构筑搜打撤游戏：玩家先决定想发展的武学流派，再进入固定的江湖险地搜集秘籍、真气构筑内容、兵器和道具，就地进入战斗浮层（版图内原地开打，世界钟持续，D-058）后选择继续深入或撤离。

## 玩家体验目标

1. **目标导向的构筑**：玩家可以先决定“我想玩什么”，再寻找实现该方向的组件，而不是完全由随机奖励决定流派。
2. **流派的个人归属感**：心法、真气牌库、武学招式和兵器共同构成玩家自己的武学体系。
3. **有计划的风险取舍**：玩家判断当前收获是否值得继续深入，以及气血、伤势、药物、兵器状态能否支撑下一场战斗。
4. **规则透明的战斗**：敌人行为可预测、可解释、可复盘；不依赖高频实时反应。
5. **撤离的价值感**：搜到的物品只有成功返回落脚处才真正成为长期收益。

## 目标玩家与平台

- 目标平台：优先 PC；手机兼容暂不作为第一阶段约束。
- 游戏模式：单机 PvE。
- 玩家控制：一个主角。
- 单场战斗目标时长：约 3–5 分钟；复杂战斗约 5–10 分钟（待原型验证）。

## 核心循环

```text
决定目标流派
  → 选择江湖险地
  → 准备心法、真气、招式、兵器和道具
  → 探索由地点牌堆生成的牌阵
  → 遇敌并原地进入战斗浮层（版图内开打，世界钟持续）
  → 消耗气血、药物、暗器和兵器状态
  → 获取未确认战利品
  → 继续深入或撤离
  → 成功带回并改进下一次构筑
```

## 明确不做的核心方向

- 不做《杀戮尖塔》式“抽到什么才决定玩什么”的纯随机流派形成。
- 不做高频实时闪避、瞄准和反应操作。
- 不做一开始就联网、多角色队伍或复杂 MMO 系统。
- 不使用仙侠世界观资源来解释武侠系统。
