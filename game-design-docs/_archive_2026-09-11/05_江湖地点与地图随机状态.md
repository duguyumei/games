## 地图模型

每个江湖地点是版图上的一个**方格地块**：地块底部一行地名，地块上立着左右两摞牌。开局即按种子生成整块大陆（常规地点的位置、类型与通道一次铺好）；随机的不只是地点状态，还有大陆布局与地点卡的藏法。全部由一个种子驱动，整局可重放。

- **地块大陆（外层）**：入口固定开局且已探索。常规地点沿已连通通道直接移动（1 行动力），不需要抽地点牌。未探索地块只有一摞扣着的牌堆；移过去即探索翻开（顶牌亮出）；探索过的地块保持离开时的状态（指本局远征内；跨局按"禁地吞吐"整体重生成，见《03》）。通道双向通行。
- **牌堆与散落区（内层）**：每个地块两摞牌——左侧**牌堆**（未探索卡牌，整齐堆叠），铁律不变：**只能处理最顶一张；离开地点永远自由**；右侧**散落区**（已探索卡牌，散乱堆叠）：被无视的牌、搜刮/无视后的遗体、丢弃的物品都搁在这里，不限顺序、随时处理、走了还能回来。
- **地点卡**：只给需要解锁的特殊地点（隐秘点/捷径/藏宝阁/上锁房间/撤离点）。混在常规地块的牌堆里（多沉底），到顶同样【打开/无视】；无视进散落区，以后可再开。打开条件数据化：`require_item` + `consume`——捷径无条件、藏宝阁要信物、上锁房间要钥匙（钥匙类默认消耗）。效果两类：捷径在两个既有地块间接通新通道；藏宝阁/上锁房/撤离点长成新地块节点并接线。撤离点地块探索后常驻特殊标记（多撤离点）。

## 牌的种类

| 牌 | 位置 | 交互 |
|---|---|---|
| 零散物品 | 牌堆 | 到顶：[拾取]入包 或 [无视]挪进散落区 |
| 敌人 | 牌堆 | 到顶：[战斗] 或离开（不能无视，仍压牌堆） |
| 箱子 | 牌堆 | 到顶：[打开]付开启费 或 [无视]，两条路都进散落区 |
| 特殊 NPC | 牌堆 | 到顶：[交谈]（0）或 [无视]，进散落区后可再谈 |
| 地点卡 | 牌堆 | 到顶：[打开]（可能要特定物品）或 [无视]；捷径接通道，其余长新节点 |
| 警戒增援 | 牌堆 | 警戒升级时被洗入随机地点牌堆的敌人牌，规则同普通敌人 |
| 遗体 | 牌堆顶→散落区 | 敌人被打败后**原地压顶**变遗体，是容器；到顶：[搜刮]付开启费 或 [无视]，两条路都进散落区（C-019；走开也自由，回来还在顶上） |
| 撤离点 | 地点卡 | 开出撤离点地块，站上去 [撤离]（0 行动力） |

## 卡牌不消失，只转化

物品消失是因为进了背包；地点卡消失是因为变成了新地块或新通道；敌人被击败后原地变遗体留在网格里（C-019/C-028：明牌网格下随时可搜、可绕开、可走开）；容器拿空后空壳留在网格原位。任何明牌都是"处理或绕开"的决策点——垃圾不会自动进背包占用空间。

## 容器统一

箱子和遗体是同一套规则（C-028 网格化后保持 D-028 弹窗翻牌口径）：点击容器牌付开启费 → **弹出容器小窗**，内容物摊成一排未翻开的暗牌 → 逐张翻牌（1 行动力/张）→ 拿取免费。可以翻一半、拿一半、合窗离开，回来再点容器接着翻（暗/亮状态保留在牌上）；拿空后空壳静置在网格原位（遗体搜空也不消失）。已开盖的容器再点＝免费续翻视图。

开启费按档次：木箱 1 / 铁匣 2 / 金箱 3 / 遗体行囊 1~3（按敌人档次）。内容物在生成时按掉落表掷定（稀有度权重或指定物品池），走种子。翻牌要付行动力，因此"再翻一张还是留着下次"是真实决策；翻牌与拿取在惊动制下都产噪（按行动花费倍乘、0 费拿取最小动静 1 点），警戒升级还可能在开包中途把敌人洗进你所在的地块。

## 警戒度与力竭

- 警戒度分等级（第一禁地占位配置：12 骚动 / 24 戒备 / 36 围剿）。累计消耗行动力到达阈值即升级：动静引来空壳趋聚、封锁巡界响应，若干张敌人牌被洗入随机已探索地点的牌堆（随机位置）——退路可能因此被堵，打不打由你，不设强制拦截。等级越高增援越强（第三档出现深区强者）。机制即 D-030 不变；世界观解释见《03》（空壳无意识，趋聚是对动静的本能反应）。
- 行动力归 0 且不在撤离点 = 力竭被擒，物资全丢；在撤离点上归 0 则安全。
- 这是"敌对势力警觉度"长期概念（见《09》）的 v1 形态；强制拦截战（引擎已支持，留作 scripted 事件）、路线危险、撤离点减少、围堵等完整效果仍是后续方向。

## 每局随机内容（种子化）

- 大陆布局：常规地点的位置、类型与通道连接。
- 地点卡藏在哪些地块的牌堆里、什么位置（含撤离卡）。
- 每个牌堆内部顺序。
- 敌人牌的具体敌人（从地点配置的敌人表抽）。
- 容器内容物（生成时掷定）。
- 捷径接通的目标地块。
- 警戒增援落在哪个地点、洗进牌堆哪个位置。

## 示例：青锋剑冢（第一版大陆；旧称青锋剑宗，占位名）

世界观：两百年前一夜消失的剑派，山门至今空转（详见《03》）。旧文案中"弟子进出、堂口转移"的活地区解释已废止。

- 入口：南山道·入口（固定开局，已探索）。
- 常规地点池：南山道（偏遭遇战）、竹林（偏散货）、演武场（多敌）、厢房（多箱子）。
- 地点卡：捷径（无条件）、藏宝阁（信物解锁，精英守金箱）、上锁的房间（钥匙解锁）、撤离点×2。
- 信物/钥匙从容器与零散物品掉落表产出，保证"有锁必有钥匙"。
