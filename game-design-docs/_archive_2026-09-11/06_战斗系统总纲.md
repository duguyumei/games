# 战斗系统总纲

版本：v1.0  
状态：第一版战斗规则摘要  
详细规则与 Godot 实现范围见《23_战斗系统v1_设计与Godot实现规格》

## 战斗定位

独立的回合制武学战斗。玩家和敌人共用同一个规则底层：双方都有真气牌库、手牌、心法、功法、兵器、护境和真气去向。敌人不采用玩家式自由思考，而由可复现的行为策略选择合法功法。

## 共享底层

双方共享：


- 气血、护境、真气和功法结算规则。
- 真气牌型判定。
- 招式合法性检查。
- 伤害、防御、破防和异常状态结算。
- 回合顺序和优先权。
- 招式的效果解析。

控制方式不同：

```text
玩家：PlayerController，接受玩家选择
敌人：EnemyPolicy，根据预先写定的规则选行动
```

## 大回合与行动权

```text
回合开始
  → 双方各自从牌库抽取本回合真气
  → 自动结算心法和回合开始效果
  → 敌人根据隐藏手牌锁定并公开下一行动意图
  → 先手方获得行动权
  → 当前方选择发动功法、暂让或收势
  → 行动权交给另一方
  → 双方均收势，或双方连续暂让时，大回合结束
```

- 发动一门主动功法消耗本次行动权；结算后行动权交给对方。
- 功法默认没有“一回合一次”限制。只有功法文字明确规定时才限制回合或整场使用次数。
- 暂让：当前不行动，将行动权交给对方；对方行动后，本方仍可重新行动。
- 收势：本方在当前大回合不再主动行动，之后轮到本方时自动暂让。
- 一方的行动次数取决于自己的手牌、功法和选择，不要求与另一方相等。
- 受击类或反击类效果由具体功法自行定义，不建立通用的反击架势底层。

## 护境

- 每个角色在基础规则下只能同时拥有一个护境。
- 新护境直接覆盖旧护境，不进行数值叠加；即使新值更低也会覆盖。
- 护境剩余值跨大回合保留。
- 强化现有护境、保留旧护境或拥有多个护境只能由特定功法明确提供。

## 牌库循环

- 大回合结束时，手中剩余（未发动功法使用）的真气随机洗回抽牌堆（不放回顶部，避免连环废手；C-015）。
- 已发动功法使用的真气进入弃牌区，不回牌库——"出过劲的才散，没用过的收回"。
- 抽牌堆顺序由洗回的剩余真气重排；下回合抽牌时若抽牌堆不足，先抽完剩余牌，再洗混弃牌区并补足手牌。
- 第一版不设置通用消耗区和蓄积区；具体功法如需特殊去向，必须在功法自身规则中明确。

第一版原型暂用每回合从真气牌库抽取5张，组合成牌型，用于发动不同招式。详细规则见《23_战斗系统v1_设计与Godot实现规格》：

- 高牌（单牌，即选择 1 张真气）。
- 对子（2 张牌面内力相同）。
- 三连（3 张牌面内力相同）。
- 四连（4 张牌面内力相同）。
- 五连（5 张牌面内力相同）。
- 顺子（5 张牌面内力连续）。
- 不使用同花、两对、葫芦、同花顺等牌型。

五连要求同一点数至少有 5 张牌，因此正式牌库必须允许重复真气，五连才可能成立。是否允许同属性、同点数的真气重复，以及重复数量上限，尚未定案；纸面测试需要五连时临时加入重复牌。

## 确定性要求

- 敌人手牌和牌库顺序对玩家隐藏。
- 敌人下一门已锁定功法、目标、预计最终数值和附加效果提前显示。
- 已锁定意图不会根据玩家随后采取的行动临时换招。
- 敌人行动条件和优先级明确。
- 相同状态下的行动可以复现。
- 多个行动同优先级时使用固定的决胜顺序。
- 随机抽牌使用可重放的随机种子。
- 不出现规则外的隐藏行动。

卡牌游戏可以有随机抽取；确定性指行为可解释、可复盘，不是完全取消随机。

## 当前实现边界

- 选牌确认前可取消，确认后不可取消。
- 心法只作为被动或指定时机效果，不占用行动权。
- 敌方手牌、牌库顺序和实际使用真气不向玩家公开。
- 兵器耐久属于远征资源，暂不阻塞战斗沙盒实现。
