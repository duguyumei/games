## 0. 一句话

真气层是"与对手共桌的牌桌对话"：**入关吸当地气海 → 丹田存气 → 三张成型出功法沉入副露／架势弃牌喂河 → 吃碰杠截对方的弃牌**；行动权敌我轮流、截牌半路抢——真气层与行动层共用同一套流动制协议。

## 1. 真气牌

- 真气牌 ＝ **属性（风/火/山——三门基础属性，占位，对应麻将三门花色）× 数值（2–8，占位）**。原第四属性"林"退役（2026-09-14 用户裁定：基础属性收敛为三门与麻将对应）。
- **对子**＝两张全同（属性、数值皆同）；**刻子**＝三张全同；**顺子**＝同属性数值连三。
- **属性不锁功法**：属性的意义来自牌型数学（顺子必须同属性、对子/刻子必须全同）——属性＝身份轴经牌型落地，不经"功法挂锁"。
- **字牌（红中类）映射未拍板**（挂 §15）：候选＝万能牌／状态牌／特殊属性。《我在地府打麻将》的宝牌（单张染色带效果、不碰牌型判定）是"状态牌"方向的现成参照。
- 无品级（下中上退役）、无真气量公式。

## 2. 功法

- **输入固定三张**：刻子或顺子，功法声明要哪种。不存在一张/两张输入的功法。
- **升级＝威力档**（基值/系数/词条），不变输入。
- **威力 ＝ 基值 ＋ 系数 × 数值和**（占位）。高低顺（二三四 vs 六七八）是天然的强度梯度，像追宝牌。
- **打出去向＝副露区**：功法消耗的牌（主动打出＋吃碰杠截来打出的）沉入**自己的副露区**——公开、锁死、不可截、不回流。它同时是"本场出过什么招"的记录。

## 3. 区域与术语

| 名词 | 含义 |
|---|---|
| **丹田** | 手牌；上限＝该单位的丹田容量（玩家 8 占位；敌方＝对手卡起手张数——身体各有大小） |
| **气海** | 关卡环境灵气＝**共墙**；双方共吸；每关配置（对手卡主场）；**单向耗尽、永不回流** |
| **牌河** | **个人的**弃牌区（麻将式各弃各的）；收一切**弃牌**（架势弃牌现在；功法弃牌将来入河但不开窗）；架势弃牌开截牌窗；气海干涸后疲劳抽牌只抽自己的河 |
| **副露区** | 个人的功法打出记录（打出＋截牌打出）；锁死不可截 |
| **本命牌组** | 玩家收藏（占位 12 张），开局洗抽 8 入丹田，战中不回流。**系统挂起**（2026-09-15：不再扩展，剩 4 张不入场的问题挂 §15） |

## 4. 开局

- 玩家：本命洗抽 8 入丹田；敌方：对手卡 `hand`＝其本命开局（张数即其丹田容量）；气海按对手卡 `deck` 配置展开洗匀。
- 战中一切补给（被动补满、架势纳牌、功法提牌）一律来自气海；气海干涸后改抽自己的牌河（见 §7）。

## 5. 行动权与行动（流动制，2026-09-15 定案）

- **敌我轮流**：每次原子行动结束后，行动权**被动流向**对面；流可在半路被截牌**主动抢回**（见 §6）。
- **被动获得行动权 → 补满丹田**（吐纳气海，容量为准）；**主动夺取（截牌）→ 不补满**。一次流动二选一：放行拿被动拍（补满＋一次普通行动，窗口死）或截链（不补满，连打，无普通行动）。
- **破绽**＝下一次**被动**获得行动权时跳过该次行动（破绽耗掉、立即放行；补满照常发生）。主动夺取不受破绽影响。破绽不叠加。
- **原子行动两枚**：
  - **打出功法**：三张刻/顺成型 → 结算 → 三张沉入副露区；
  - **架势**（原调息→换牌→架势，2026-09-15 改名）：弃 1–4 张入**自己的牌河**＋纳至丹田容量；费一拍；不限次（限速器＝让权代价＋喂牌风险）。
- **蓄力**：轮到蓄力方＝自动充能一拍（引而不发）；蓄力期间不可截牌（蓄力锁，核心层判定）。冷却钟每拍起手走一次，截牌链内不重复走。
- 气竭判负规则**退役**（2026-09-15）：疲劳是唯一兜底（§7），死局在结构上不可能。
- 被袭击（敌方先手）保留：只改开战谁先动。先机诀轻改造：被袭击时夺取先手（原判定制 seize 语义迁移）。

## 6. 牌河与吃碰杠（截即打，2026-09-15 定案）

- **窗口只认架势弃牌**：对方最近一次架势弃入其牌河的那批牌可截；功法打出的（副露区）永不可截；功法弃牌入河但**不开窗**（心法位扩展点，§15）；自家弃牌不可自截；**窗口在你第一次放行时即死**（过水不追，不可翻旧账）；蓄力中无窗。
- **截即打**：吃/碰不是囤牌——截来当场与手中搭子组成刻子/顺子，**立即发动**一门冷却好的对应功法（碰/杠→刻子功法，吃→顺子功法）。不满足"有功法可发"则无截。
- **碰**＝河牌＋手里两张全同 → 刻子轰出；**吃**＝河牌＋手里两张连张 → 顺子轰出；均无破绽。
- **杠**＝河牌＋手里三张全同 → **四张升档立即轰出**＋**被杠者一枚破绽**；**无补牌**（2026-09-15 定案：麻将"杠后补一张"不移植）。
- **截牌链**：每次截牌结束后行动权照常流向对面，但你可再截（半路抢回）——链内只有截即打，无普通行动；链长天然受限于批内牌数、手中搭子对数与功法冷却。
- **敌方同构必截**：敌方用**与玩家同一条规则**（其真实手牌判定，非 authored 规格）；轮到截即**能截必截、按序截**（杠＞碰＞吃，同优先按入河顺序；功法取其功法表声明序第一个可付的）。零评估、可预测、可钓。
- **应显示（实时）**：敌方**此刻**能截哪些牌（由其手牌＋功法冷却实时计算）明码显示给玩家——你架势弃牌前看得见雷区。信息不对称为何不追平：敌方是确定性内容非博弈主体，机制对等（同一套窗口/截即打/不补满规则）才是要对等的；藏起来＝罚藏，违反透明边界。泄露的手牌结构（"它能碰山4"⇒它有两张山4）即读牌层本身。
- 敌方人格换住处：不再声明钩子，**手牌构成＋气海配比**天然决定它爱截什么——对手卡仍是"一张卡一套考卷"。

## 7. 气海与疲劳（单向耗尽，2026-09-15 定案）

- 气海＝共墙，单向耗尽，**无任何回收**（"河洗回气海"退役）。总量＝关卡时钟（对手卡配置，占位）。
- **气海干涸后**：一切抽牌（补满/架势纳牌/功法提牌）改为**从自己的牌河随机抽**；墙里有牌先抽墙，缺口才碰河。
- **疲劳**：每次**抽牌动作**（不论张数）只要碰到河＝吃一次疲劳伤害，**按方递增**（第 1 次 1 点、第 2 次 2 点、第 3 次 3 点……炉石式）；**真伤**——直接砍气血，不过护境、不受任何效果影响、不可抵消。
- **河抽空后照样抽**：抽不到牌但疲劳照结算（有缺额要补＝抽牌动作成立）。因此死局不可能存在：气海干→疲劳开计→双方站着掉血→血先光的一方死。**疲劳是唯一兜底**。
- 你截牌截的是**对方的河**，疲劳抽的是**自己的河**——你的河既是你的反噬燃料池又是对方的截牌猎场；架势弃牌＝喂对面截牌＋给自己留后路，两个决定叠在同一个动作上。

## 14. 证伪预测（数字全占位）

- 玩家架势从不考虑"喂截"安全 → 应读数醒目度或代价不足；
- 顺子长期凑不齐（只打刻子）→ 气海数值密度或丹田容量失衡；
- 截牌链一场出现 3+ 连发或从未出现 → 窗口宽度/搭子门槛失衡；
- 战斗普遍短于 10 拍/长于 30 拍 → 气海总量与疲劳节奏失衡；
- 气海干涸后的疲劳期一闪而过/拖沓 → 疲劳基数与递增步长失衡。
