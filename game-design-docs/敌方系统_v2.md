## 0. 定位与总纲

- 敌人是**对手**（身份），职责是**验证/发挥玩家的构筑**。敌人系统是**内容问题，不是 AI 问题**：产出物不是智能，是一张张**对手卡**。
- **同核不同脑**（全人形，2026-09-13 定案）：身体与玩家同一语法——功法表（真功法）、真气手牌、调息回填、共用状态词表与结算管线、血量≈玩家、可驱毒（净身式这类功法自带条件）。
- **行动空间与玩家同构**：敌人只有**发动功法**与**调息**两种行动（玩家将来多一种道具；敌人永不用道具）。
- **脑是哑执行器**：无评估、无权重、无概率——回应＝数据。引擎只有一个从上到下的行走器，复杂度住在卡数据里，按需生长（演武场逼出来，不前置枚举）。
- 对标业内：退化版行为树（Selector/Fallback＋装饰器）＋FF12 Gambit 式条件规则表；站在"可预测可调试"极，弃 Utility/GOAP 极。

## 1. 对手卡数据模型

| 数据面 | 内容 |
|---|---|
| 面板 | 气血（≈玩家量级） |
| 功法表 | 真功法条目（techniques.json 同池同语法，敌我可共用——对手卡＝功法橱窗） |
| 真气 | 起手手牌＋牌库**每个敌人单独配置**（2026-09-13 用户裁定）。正式写法＝配置式：`hand: ["山下品", ...]` 简写串、`deck: {属性: {品级: 张数}}`（一处可改）；显式卡列表仍受支持（测试/奇构用）；回填只会调息，倾泻—回填循环与玩家对称。青锋暂配：起手 山下×2 风下 火下，牌库 每属性 下×3＋中×1＝16 张 |
| 换手策略 | 调息弃牌谓词（数据）：全换／只换下品／弃上品／弃孤张（首版已实装）；保多弃少／限量N／弃旧／为下一招保型（扩展位） |
| 行为链梯 | 见 §2 |
| 钩子 | 见 §3 |

## 2. 脑：行为链梯

- **一行一链**：`条件 → 尝试功法`。每次**它行动之后**锁定意图（意图＝即将进行的行动，功法或调息）。
- 判断顺序：**自况条件 → 账面可付（凑不齐＝Failure 落链）→ 行为冷却（最后一层：可行却被拦 → 跳过并递减）**。
- **调息也是意图**：清单末位无条件链＝调息地板。想逼它调息只有打失能（让它凑不齐任何功法）。
- 链数＝广度（性格宽度）；链内嵌套＝深度（普通敌人 1 层／精英 2 层／boss 3 层，**按需生长**：精英的第二层只补真实漏洞，不机械配平）。
- 自况条件键（白名单）：`guard_lt / guard_gt / hp_lte / status_gte`。
- 性格原型：优先反制/防御/攻击＝梯子排序模板；注重自身/玩家/固定＝条件键源。排序模板做成骨架库（提案态，未实装）。
- 防呆三阀（不写补丁规则）：真气耗竭（每招真付账，刷屏自灭）、规则冷却（判断的属性）、变招有价（见 §3）。

## 3. 钩子：意图转换系统（一个管道，两族）

> **注**：本节为 v1.5 时代设计——authored 钩子系统已在 v2.2 旧战斗中被**同构必截**取代（能截必截零评估，应实时显示），详见《设计沿革档》§三 3.1（2026-09-15 头注）。留档供重启敌方设计时参考。

**统一语义**：钩子＝**事件瞬间唤醒**（订阅事件钟，演出贴事件原位）→ 四查（武装／事件踩中／可付／≠当前意图）→ **意图翻牌**（翻牌即演出，展示永不静默错位）→ 当拍执行 → 付价。

| | 乱 | 应 |
|---|---|---|
| 事件源 | 它的自况事件（护境被击碎等） | 你的公开事件（你调息等） |
| 目的 | 自救（换更优意图） | 压制你 |
| 预置灯 | 无（事件本身可见，翻牌即演出） | 有（武装门，见下） |
| 破绽归属 | **它**（后坐：翻牌的招执行完入账，下一拍错失——先落子后踉跄） | **你**（触发即得破绽，钉住你一拍） |

- **破绽记在被抓住的那一方**（全局总则）：你钓它的乱＝偷它一拍；它埋应钓你＝偷你一拍。交互天平由此对称。
- **敌人也是卡牌（2026-09-13 用户拍板，试玩反馈）**：演武场择敌区敌情不再是文本块——敌人以卡牌呈现（与功法/心法卡同族视觉），点击弹出对手卡详情页。
- **乱的显示裁定（2026-09-13 用户拍板）**：乱钩一律**无战斗内预置显示**（翻牌即演出，静态明码进演武场敌情面板/图鉴）。"血量低于一半触发某功法"这类阈值转折**属敌方心法位内容**，将来经心法栏披露——不并入乱钩。应手照旧恒亮灯（扳机是你的动作）。
- **应手武装门**：每次它行动后离散评估三问——要不要开（authored 逻辑）／能不能开（可付性：付不起＝无法监控，灯哑）／冷却好了没。武装态锁定到下次行动；玩家看到一盏灯（亮／歇N／哑），条件与配置图鉴/悬浮明码。
- **蓄力期间钩子全灭**（蓄力锁，全局规则）：起蓄后不可换功法，双方同规。
- 需前置的重招（如蓄势斩）当不了瞬发应手——可付性天然筛除；跨拍应手的成立条件是起势式＋钉（否则你的应答拍会拆掉它）。
- 事件白名单（现两枚，按需生长）：乱`guard_broken`；应`player_breathed`。

## 4. 冷却体系（两刻度四挂点，全局规则）

| 名字 | 刻度 | 挂点 |
|---|---|---|
| 功法冷却（行动冷却／歇N） | 自身行动前全体-1，执行时置满 | 功法（双方） |
| 钩子冷却（行动冷却／歇N） | 同上 | 应/乱（AI 专有） |
| 行为冷却（机会冷却／隔N） | 判断条件最后一层：可行却被拦时-1，执行时置满 | 行为链级（AI 专有） |
| 心法冷却 | 行动类心法→行动冷却；触发类心法→机会冷却 | 心法（双方） |

三原则：①冷却是判断的最后一层（前置条件不过，它不发言）；②拦截时才减、执行时置满；③锁意图时点＝它行动之后。

## 5. 透明边界（罚行不罚藏）

| 信息 | 它看你 | 你看它 |
|---|---|---|
| 已发生的行动（发动功法/调息/蓄力/盾碎） | ✅ 合法键 | ✅ 意图＋日志＋灯 |
| 公开状态（血/盾/状态/蓄力中/手牌**张数**） | ✅ | ✅ |
| 手牌内容／牌库 | ❌ | ❌（长期可学：图鉴/重复遭遇） |
| 意图 | 你没有显示（真脑） | ✅ 永远明置（写出来的脑） |

- 应手必须亮灯预置：扳机是**你的决定**，你必须先看到雷才能给自己的动作定价；乱不需要灯：扳机是已发生的世界事件。
- **WHAT 永远明码，WHEN/WHETHER 是功课**——博弈住在时机层（踩不踩/何时踩/怎么耗它），不住信息层（是什么）。
- 玩家的虚招成立基础：绊线可见＋带冷却＋必炸（数据不决策，它忍不了）——假动作可耗它的冷却窗。

## 6. 首张对手卡：青锋剑徒（数值全占位）

```
真气：起手 山下×2 风下 火下 ｜ 牌库 每属性 下×3＋中×1（16 张·本卡暂配，真气池每敌单独配置）｜ 换手：弃孤张
梯（带记忆 Selector，行动后锁定）：
  盾<3 → 重盾式（一气·盾 10+2×量）
  盾>8 → 蓄势斩（二重·蓄力1·伤 8+4×量）
  力≥3 → 连风式（二重·双段伤）
  磨刃式（一气·力+1，隔1）
  调息（地板）
钩子：乱·护境被击碎→重盾式（歇2）｜应·你调息→窥隙脚（一气·伤 2+1×量，歇3，武装：盾≥3）
```

- 性格读法（全明牌）：怕没盾（乱钩）、盯你调息（应钩）、憋大招时六亲不认（蓄力锁）、空窗隔拍磨刃（隔1）。
- 玩家的三档答案：裸调息吃钉／先挂盾再调耗它一脚／封它的风让灯哑。
- **证伪预测**（数字全占位，预测被杀回结构层重审）：
  - 若玩家从不看灯就调息 → 灯的醒目度不足或钉的代价太轻；
  - 若盾 3–8 空窗期玩家毫无压力 → 磨刃/蓄势斩的空窗张力不足；
  - 若蓄势斩全程从未落地 → 蓄力锁的"安全窗"补偿过度（玩家白嫖拍子太多）；
  - 若战斗普遍短于 10 拍 → 双方数值失衡，先校准拍级产出再调卡。
