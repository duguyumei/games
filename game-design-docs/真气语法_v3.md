## 0. 一句话

108 张共墙、13 张手（手牌＋3×明式＝13 一本账，**收敛于 13 而非每时刻相等**——重击挖坑后逐拍回填）、每拍摸牌开始打出结束（摸 3 起、**打出恰一次：至多超几张、至少一张**）、碰杠截牌（**吃仅对虚招**）截后弃 1、功法＝打出（占行动、耗式入河不回填、效果按**前摇**延迟）、守功法＝行动期间免费吃罡气（摸牌后出牌前）、赢＝清空对方气血。**无回气拍（无死拍）**：手牌不是时机权威。

## 1. 牌与墙

- 真气牌 ＝ **属性（万/筒/条，与麻将同三门）× 数值（1–9）**。
- **气海＝108 张全幅均匀共墙**（三门 × 九值 × 4 张，与麻将序数牌同构）；双方共吸；**全部 108 张常规流转（无死牌岭）**。
- 对子＝两张全同；**刻子**＝三张全同；**顺子**＝同属性数值连三；杠＝四张全同。
- **数值＝结构身份，不扛力度**：力度住在功法配方与词条（§5）。1/9 边张与中张的差异是连接性（结构性梯度），非强弱。
- 气海干涸 → **气河整条洗回气海**（惰性重洗，供应无限）。

## 3. 回合与行动权（v3.6 拍结构）

**一拍 ＝ 摸牌或招架 → 自动效果 → 附属行为 → 完成一次打出。** 所有流程都"摸牌开始、打出结束"，无死拍。

- **正常拍**：
  1. 自动摸 3（基础值，功法/心法词条可增减）＋罡气 +1；**缺牌补充**：摸后手牌仍低于静息上限 → 额外补 ⌊气力÷3⌋ 张、至多补到容量（每拍只查一次）。
  2. **自动效果**：在途功法到期即发动（见下）等系统自动结算。
  3. **附属行为**：变招、护体等窗口内免费操作（任意次；将来道具/治疗也住这里）；运转类效果（弃/摸/换牌）由功法/护体/心法携带，执行时点都在本阶段。**每个附属行为作为一个完整单位结算，结算完手牌＝0 → 立刻获得破绽、本拍就地终止、轮到敌方**（弃后摸回类中间态不算；空手兜底＝后果制，无预防制 UI 拦截）。
  4. **打出恰一次：张数＝max(1, 手牌数−静息上限)**——超几张打几张；没超额也打出至少一张（虚招）。一批打出＝一次攻击。
  5. 流向对方。
- **攻击四式（打出分类）**：打出时**实时判定**有无超额——**有超额＝普攻**（100%＋50%×副露面子组数，可被碰/杠拆解取消）；**无超额＝虚招**（0 伤，可被**吃**/碰/杠截走——空手虚架，门户全开）；**重击**＝功法打出（耗式，不可截）；**反击**＝招架后的打出（0 伤暂定、**不可被截**——一次交换至多一招架，链条天然封死；将来伤害只走功法词条、明码印刷）。
- **在途功法＝前摇**：功法**声明前摇**（默认起点＝式数 1/2/3，可按功法强度单调，非等式），按**对方经过拍数**计（招架拍算一拍、破绽拍照常推进）；**发动那一刻打出式**（入河明牌＝天然预告）；到期在**发射者自身摸牌后的自动效果阶段**结算（招架拍/破绽拍不摸牌→不解算）。前摇期间照常摸牌/变招/普攻收拍，**但不能发动防御**（与"护体期间不能发功法"互斥对称——进攻承诺与防御承诺互斥）。在途至多一门；断势归内容词条。
- **截牌拍（碰/杠/吃）**：截牌＝本拍的摸牌环节——截 1 张（杠另岭上摸 1）→ 附属行为 → 反击打出（张数同 max(1) 规则）→ **反击牌不开窗** → 流向对方。截牌拍不能发功法。
- **守功法＝行动期间免费即时**：无打出不占行动，罡气是唯一代价；窗口＝自己这拍的摸牌后、出牌前（附属行为阶段）；对方回合与截牌决定期无窗口；破绽拍无窗口。
- **破绽拍＝只自然摸牌**：无附属行为、无打出、不解算在途、不截牌。破绽生产通道：**手牌清零就地触发**。
- **吃**：**吃仅对虚招开放**——可截性梯度＝虚招全开（吃/碰/杠）＞普攻半开（碰/杠）＞重击/反击闭门；越危险的打出越不可截。吃成的顺子＝轻式入副露。
- 架势不是玩家主动行动：正常拍里玩家的常规决策＝选哪种打出（弃哪几张或发哪门功法）。

## 4. 式

- **六式全攻**（防守走罡气资源，§5）：**顺＝轻式、刻＝重式**，三门各一对。名目占位：万顺=点／万刻=崩，筒顺=刺／筒刻=劈，条顺=碾／条刻=撼。轻重＝功法配方的价格语言（崩×2 重击 vs 点×3 连击）。
- **截来的式**：碰/杠＝重式、**吃＝轻式**（吃仅对虚招）；手牌暗顺＝轻式自产——轻式两条进料：自产＋吃虚招。
- 六式只做功法配方的价格语言：**式不携带独立伤害效果**——伤害全部走打出阶梯（虚招/普攻/重击/反击，§13.1）。
- **暗式**＝手牌成组可被功法直接消耗（不必晒出）。**消耗不回填**：明暗消耗都是 3 张入气河、坑留给摸牌——式数＝配方价（付式后手牌低于上限、逐拍回填＝节奏价），罡气＝防御价；三层价格零特例，全由静息账本（手牌＋3×明式＝13）一本账结出。
- 明暗取舍：明＝供给靠截＋对手可读；暗＝隐藏配方进度＋自产。
- 功法耗式**不开截牌窗**（式是"用尽的气"不是"递出的牌"；开窗变体＝待拍板项，见 §11）。
- **杠**＝四张全同：**本门万能式**（可当本门轻式或重式，向下兼容——押本门，待确认）＋**岭上摸 1**＋**无破绽**。108 墙下四张天然存在，稀有度＝麻将原生。**暗杠**：手里摸齐四张自晒——免费动作、不占打出、窗口＝选打出阶段（free_fire）：四张入副露成本门万能式＋岭上摸 1＋罡气 +1；不开截牌窗；之后照常选打出。**加杠**（往自己的碰上补第四张）：待拍板（见 §11）。

## 5. 功法

- 功法＝式的配方（如 点穴式＝点×1），可跨式（崩＋劈这类；攻守混合配方留作内容杠杆）。**数值与词条固定，不挂牌面点数**——式组合是价格语言，效果与词条是内容引擎（同价不同效＝流派内选择）。
- **攻功法：打出形式之一**——吃式、**占行动权**（每拍至多一门，与普攻/虚招打出互斥为"本拍的打出"；**无超额前置**——静息位也可发）、效果**在途**（v3.6 前摇：功法声明拍数、按对方经过拍数计、我方摸牌后自动效果阶段发动，§13.6；期间可被"断势"类效果击碎、不能发动防御）。冷却词条留给大招级功法差异化。
- **守功法：行动期间免费即时**——吃罡气、**不占行动**（无打出）；窗口＝自己摸牌后、出牌前（§3）。
- **罡气**（名字占位）：行动赚取——**每次摸牌/招架（碰/杠/吃）+1、上限 5**（全走内容层，§13.3）；护体期间冻结（不增）。**防龟缩的独立旋钮**（反拖底时钟职能＋攻功法可断势）。
- 功法升级＝威力档（搜集层概念，随搜集层立项挂起）。

## 10. 证伪预测（数字全占位；已失效项见《设计沿革档》§一 1.4）

- 平均回合数超 20 → 先拧罡气上限/速率，不急加回全局时钟；
- 罡气永远花不出去或永远不够 → 只调速率参数，不动结构；
- 六式轻重档无感（玩家把点式崩式当同一种用）→ 合并计价，砍符号数；
- 拉锯（连续互截）一串 3+ 口频发 → 第一闸门＝限一窗一口，不砍机制；
- 13 张读牌负担过重（玩家明确看不过来）→ 降 10 再试，不动其他规则；
- 玩家从不为配方改变留牌/弃牌 → 价格语言失效，回审符号空间；
- 明式（截来重式）出场率碾压暗式 → 检查轻式自产供给（摸牌结构），而非给重式加价。

### 13.1 攻击四式（虚招/普攻/重击/反击）

```
一拍 ＝ 摸牌或招架 → 自动效果（在途到期发动等）→ 附属行为（防御/变招/未来道具治疗）
      → 完成一次打出（张数＝max(1, 手牌−静息上限)：至多超几张、至少一张）
```

| 打出 | 定义 | 伤害 | 可被截 | 被截后果 |
|---|---|---|---|---|
| **虚招** | 打出时**无超额**（手牌 ≤ 静息上限，实时判定） | **0** | **吃／碰／杠** | 无伤害可取消；对方取材成式 |
| **普攻** | 打出时**有超额**（一批＝一次攻击） | **100%＋50%×副露面子组数** | 碰／杠 | 伤害取消（拆招），对方反击无伤 |
| **重击** | 功法打出（耗式在**发动那一刻**入河明牌） | 功法倍率（点穴式 200%），按**前摇**延迟落地 | **不可截** | 无截牌应对，靠前摇期间护体窗 |
| **反击** | 招架后的打出 | **0（暂定）**——将来伤害只走功法词条、明码印刷 | **不可截** | 取材，再反击无伤 |

- **可截性梯度＝门户开放度**：虚招全开＞普攻半开＞重击/反击闭门——越危险的打出越不可截。**可截性由系统仲裁**（吃按钮亮不亮引擎算），**伤害永不挂历史条件**（牌面即真相管数值、系统仲裁管动词）。
- **吃仅对虚招开放**：吃成的顺子＝**轻式**入副露；招架家族＝吃/碰/杠三种，都＋罡气＋接续行动＋触发拆招诀。
- **反击不可截** ⇒ 一次交换至多一招架（我打出→你拆→你反击→回到正常轮转），链条天然封死；且反击的牌＝**绝对安全弃牌**（不开窗）——招架附送的出牌位。
- **副露面子＝常驻光环**：每组（含吃来的顺子）给普攻 +50%；功法烧掉副露面子时光环同步 −50%。
- **虚招的牌是玩家选的** ⇒ 恢复期弃"喂不出对方吃/碰/杠的牌"＝安全牌技术（麻将 genbutsu 直觉）。
- 架势＝普通摸牌（纳气不是攻击）；招架＝碰/杠/吃（以截代摸）。

### 13.2 变招（按拍充能，归气力）

- **充能：每个自身拍＋（1＋气力）**（摸牌环节计一次；招架拍也计；变招本身不重复触发；破绽拍不计）。**6 充能＝1 次机会**，余量保留；**机会上限 9**（内容可扩）。
- 基线（气力 1）＝每拍 2 充能＝**约 3 拍 1 次机会**；气力 5＝每拍 1 次。
- 换手牌 1 机会/张（弃 1 摸 1）；换面子组（手牌暗组与副露明组一视同仁，3 或 4 张）3 机会/组、弃整组摸等量、**每组 50% 伤害**。变招弃牌入气河不开截牌窗。
- 心法拆招诀：每次招架额外 +1 充能。

### 13.3 三力（现存轴＝内力三力＋武学＋三门牌型空间）

| | 王国 | 规则 |
|---|---|---|
| **劲力** | 出力 | 攻击面板＋2/点（基础攻 10，1:5 比例） |
| **骨力** | 承伤 | 防御＋1/点，承伤比＝5/(5＋防御)；**不管血量** |
| **气力** | 流转 | 每拍变招充能＋1；每逢 3 点，缺牌补充＋1（摸后仍低于容量时补 ⌊气÷3⌋、至容量） |

- 1:5 比例＋K=5 使劲/骨边际曲线**逐点严格对称**（同为 1/(5＋N)）——不对称只来自成长向量漂移（血量逐组涨利骨、敌方成长稀释劲），归 §14 观察项。
- **罡气上限（5）/罡气获得（+1/摸牌与招架）/摸牌数（基础 3）/丹田容量（13）/变招机会上限（9）全走内容层**，不进加点——资源型数值要么全进属性要么全进内容，不骑墙。

### 13.4 护体（守功法＝护身槽；基础件＝铁布衫）

- 费 **3 罡气** → **80% 免伤，持续 3 个敌方拍**（敌方拍末 −1）；持续期间**每累计减免 5 点，免伤率 −10%**（最低 0）；每次激活从 80% 起算。
- **双向承诺互斥**：护体期间不能发功法 ⇄ **重击在途期间不能发动防御**——进攻承诺与防御承诺互斥，前摇越长锁得越久（"越强等得越险"的完整版）。
- 期间罡气冻结（不增）。
- 伤害管线无盾站（倍率×面板 → K 曲线 → 护体免伤 → 气血）；回血与"格挡 N 次"留内容层。

### 13.5 构筑槽位

- **心法槽／功法槽／护身槽＝构筑本身**：初始各 1、解锁至 5（解锁＝阶段拓槽奖励，见 §14）。三基础件（数值占位）：**点穴式**（点×1，200%，前摇 1）｜**铁布衫**（见 13.4）｜**拆招诀**（招架 +1 充能）。

### 13.6 前摇（重击时序）

- 功法声明前摇（默认起点＝式数 1/2/3，按强度单调可调）；**按对方经过拍数计**（招架拍算一拍、破绽拍照常推进——破绽夺的是应对机会，不延长等待）。
- **式在发动那一刻打出**（入河明牌＝配方全公开的天然预告）；到期在**发射者自身摸牌后的自动效果阶段**发动（时间到即发动；招架拍/破绽拍不摸牌→不解算，词条可改）。
- 等待期照常摸牌/变招/普攻收拍，**不能发动防御**、不能再发第二门（在途至多一门）；断势＝内容词条（PENDING_BROKEN）。

### 13.7 观察项（演武场）

四攻击密度链（无回气空拍＋每拍必打出＋虚招零伤已对冲一半——盯 TTK、碰杠频率→罡气通胀→铁布衫覆盖）｜变招基础频率三倍放缓在气 1 的手感（6 门槛是主旋钮）｜前摇默认档与"在途锁防御"的暴露压力（重击后连 punish 是否致死→降反击/调前摇，不动结构）｜劲骨成长向量漂移（见 13.3）｜缺牌补充当前休眠（等深配方功法）｜破绽×前摇交互（落在破绽拍＝对方无应对——破绽生产器获得攻击价值，内容钩）｜"防御"边界（运转类回复算不算在途锁的防御——等首张此类内容出现时定）。

### 13.8 实现级默认（均可翻案）

虚招判定含"恰好等于上限"（无超额口径）；破绽拍不充能不补罡气外收益（只摸牌＋罡气 +1）；吃多顺位自动取首个可用组合（确定性顺序）；AI 吃=贪心必截；机会满 9 后充能不积压；暗杠不触发拆招诀；变招弃牌不开窗；前摇未满遇我方拍不解算继续等；手里有对子的批位只列碰不列吃（碰优先于吃的枚举默认）；多截应答全部无效＝按放行收窗（普攻照落地——不得白吃取消）。

## 14. 成长与轮结构（第一组已实装——挑战层 v1.4，2026-09-16；多组化后置）

> 数值全占位（演武场校准）。实现细则与场景链见《组挑战_代码设计_v1》。
> **实装修订三处（相对本节原冻结文本）**：①槽位解锁＝**修习内历练消费**（价随已解锁数递增、上限各 5），替代"阶段拓槽奖励"；②每胜历练入账＋组终战（第 3 战）不再发结算奖励（小丑牌对齐：胜利屏战绩总览直接终局）；③图鉴＝发现制收藏（获得/交战才亮，v2.2 旧页退役出图鉴）。

- **轮形**：5 组×3 战（两小怪＋一 boss），估 30–50 分钟；8 组留作延长版。
- **内力点**：开局 3 点总量、默认配置 1/1/1、**首战锁死，第一战后方可调整**；每胜 +1（终局前共 17、单项最高 15）；**无单项硬上限**（K 曲线自限）。**洗点免费、每战后**（身份住武学不可洗、数值住内力随便洗——两层分工）。
