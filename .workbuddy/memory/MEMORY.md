# MEMORY（qi-forge-2 长期项目记忆）

## 设计定位（2026-10-30 用户裁定 · 最高优先级，压过一切既有档）

- **唯一不变项＝「卡牌构筑」。** 用户明确否定「卡牌肉鸽」定位——本项目不是 roguelike deckbuilder。
- **系统／美术／设定全部可改**，含：器灵设定本身、备战舱、6 组×3 场、奖励七类池、多单位战斗层、耐久跨场持久制。
- 判据（凡不服务此三者的系统即为可删候选）：①卡池——选择必须有代价（容量稀缺，不是「全都要」）；②组合——A+B 的效果须大于两张牌各自功劳之和；③检验——关卡提出的问题，牌组能答得上也能答不上。
- 已知短板：**横向 combo 几乎为零**（每种功法仅 2 张、无配对卡），是当前最优先的内容工作，优先级高于任何新系统。
