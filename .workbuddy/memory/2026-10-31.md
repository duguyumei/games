# 2026-10-31

## 吸血鬼爬行者考古（新建 references 档）

- 新增 `design-docs/references/吸血鬼爬行者_机制与数据考古_v0.1.md`。
- 关键事实：该作是 **IL2CPP**，全网无反编译源码（GitHub 37 仓逐一扫过，无 dump.cs）；可读逻辑只能读开源 mod（BetterCards 110KB 单文件 / BetterAutoPlay 的 ComboManaSorter 50KB / advisor 的 GameState 48KB）。
- 数据层一手源：`SurvivatonsAndMore/VampireCrawlersFiles`（游戏 Data 目录 JSON，1.5.x）。原始 JSON 不入仓，只提炼入档。
- 核心机制：连击＝法力**严格递增**出牌，倍率＝层数，乘进伤害；且**连击是遗物 Combo Stack 赋予的规则**，不是天生。卡池靠宝石孔＋进化（配方按 cardGroup 配对）双重稀缺。
- 对我方价值最高三点：①费用阶梯式顺序约束（解「横向 combo 为零」的低成本解）②连击的物理表达（举 ×2→砸下，粒子/震动按层数）③角标挂 `_costText` 兄弟并镜像到右上（坐标系自适配，可直接用于工厂卡右上留空位）。
- 待裁（未落地）：是否引入顺序约束骨架 / 颜色触发轴 / 连击跨回合保留。
