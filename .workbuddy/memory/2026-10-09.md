## 新机制设计讨论（游戏设计师专家轮·修仙构筑单机）

- 用户提出新游戏概念（与 forbidden-gamble 现行项目无关，纯新机制讨论）：修仙题材构筑游戏，功法（术法手动触发+心法功能型）+装备（2武器1防具3饰品），灵气自动增长、装备按频率自动攻击、敌人自动战斗。
- 关键定案（用户原话口径）：
  - 功法双轴：品阶（境界准入档，金丹只刷得到≤金丹，高品走策略/特殊途径）+ 稀有度（同档梯度+特效规则如自动施放）——agent 建议名"品阶"避免与术法熟练度等级混淆，用户问的就是这个。
  - 属性四维：体魄/灵力/神识（暴击率+暴伤）/身法（攻速%，基础攻速在武器上）；不要悟性。
  - 熟练度多源：施放（战斗内累积、胜利入账——agent 防拖延流建议）、心法联动（"用剑法时其余剑法+1"）、重复购买（价格须随等级递增）；卸下术法熟练度清零。
  - 换流派靠策略牌+流派特性，不靠保留熟练度。
  - 平台定案：单机买断、纯 PvE。
- agent 分析结论：整机市面空位（The Bazaar 构筑经济×修仙放置长线×手动施法核心操作）；策略牌含丹药/锻体/锻造族谱；历练经济闭环靠重复购买+策略消耗当 sink。

## 熟练度收入设计轮（同日续）

- 用户提案：战斗施放不给熟练度、只有重复购买给（动机：消灭频繁刷），自感"有点不对"求诊断。
- agent 诊断：纯购买三死因——刷没消灭只是换成刷钱（循环同构）、练功代入感死（熟练度名存实亡）、心法联动失业（"使用剑法时其余剑法+1"失去触发时刻）。真病根＝按次收入养拖延流，不是战斗给不给。
- agent 推荐（待用户确认）：三源结构——工资（胜利结算：本场使用过的已装备术法平坦+N）/ 奖金（心法联动·策略·首杀成就，每场封顶）/ 快车道（重复购买、价格随等级递增）；核心不变量＝熟练度一切收入按场结算封顶、胜负挂钩。防御型术法参与判定须含施盾/治疗。先例 PoE 技能宝石（装上即随经验成长），反例上古卷轴按次练级（原地起跳练轻功）。
