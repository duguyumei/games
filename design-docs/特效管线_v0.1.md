# 特效管线 v0.1（qi-forge / VC 复刻线）

> 2026-11-07 立。用户裁定：**保留招式制**（不转武器卡）；**每张卡都可以有专属设计**——
> 普通卡走通用语法（填表），招牌功法走专属定制（分镜）；两者同一接口、同一实验室验收。
> 本档＝工作流定稿＋首个样板（直刺 v1）。静态皮（卡框/图标/HUD）归《美术管线 v0.1》，
> 本档只管**会动的层**。

## 0 一句话

**特效不是"给卡配动画"，是"给卡写一份档案"**：普通卡填表，招牌卡写分镜；先定档案，再看画面；
不合格整档回炉——不单帧打补丁。

## 1 双轨制

| 轨 | 用于 | 载体 | 成本 | 归谁 |
|---|---|---|---|---|
| **A 通用轨**（语法） | 普通卡：直刺／下斩／上撩／劈空斩／连珠刺／撩月斩／重劈／重撩 | `QiVcFxSpec.gd` 一条字典 | 只填表，**零新图** | 我 |
| **B 专属轨**（定制） | 招牌功法：万化十四剑／万剑归宗／子母剑／连环剑／掌法级大招 | `qiforge/fx/Fx_<名>.gd` 独立分镜（可带自有场景/贴图） | 一卡一批，**允许出图** | 我出一版，用户裁 |

**归轨判据（一句话）**：画面上**是否出现一个新的"主体"**——
14 把剑／龙／掌印／法阵／召唤物／剪影 = 有主体 → **B 轨**；
只有光、墨、点、线、位移、错峰 = 无主体 → **A 轨**。

- 归轨**不是终身制**：A 轨卡以后想升级成 B 轨，直接搬家，接口不变（`play(events)`）。
- 判据是"主体"，不是"强度"：劈空斩再重也是 A（一道弧），14 剑再轻也是 B（14 个主体）。
- 制度上**每张卡都允许 B 轨**；预算上按档排期（§9）。

## 2 档案（Effect Spec）

### 2.1 A 轨：一行参数

```gdscript
"zhici": {
    "carrier": "line",          # blade_sheet 格位：line/arc/vertical/upcut/cross/round/spiral/diag/tip
    "impact": "pierce",         # 命中族：pierce/cleave/upcut/blunt
    "amps": {
        "needle_len": [90, 150], "needle_w": 10,   # 针长区间(px，按距离 clamp) / 针宽
        "core": 64, "star": 22, "spray": 4,        # 白核直径 / 星芒长 / 墨点数
        "shake": 1.8, "hitstop": 25, "recoil": 4,  # 震屏 / 卡帧(ms) / 后仰(px)
        "glint": 0.16,                              # 收势扫光透明度
    },
    "ornament": ["aim_line", "thread", "glint", "pinholes"],
    "repeat_jitter": 9,
}
```

**两个字段不手填，由数据推出**（卡表已按索敌重排，这是红利）：

| 派生字段 | 来源 | 映射 |
|---|---|---|
| `trajectory` | 卡的 `targeting` | `single`→direct／`right_left`→sweep_rl／`front_row`→sweep_row／`random`→wander／`bouncy`→bounce |
| `impact` | 卡的 `stance` | 斩→cleave／刺→pierce／撩→upcut（护体/功能卡不出手） |

其余字段：`n`（段数）、`gap`（击间隔）、`lead`（起手延时）**全部来自账本**（§3），不由卡面写死。

### 2.2 B 轨：一份分镜

```gdscript
# qiforge/fx/Fx_WanHua14.gd
extends Control
func play(events: Array) -> void:   # events 与 A 轨同构（账本快照）
    ...
```
分镜必须写清四段（§6 步 3）：**起（预兆）→ 承（主体登场）→ 转（落账）→ 合（收尾）**，
并注明总时长、全屏占用区域、是否允许连播。

### 2.3 统一接口
`_combat_fx.play(card_id, events)`：内部查档案，A 轨走语法播放器，B 轨实例化专属节点。
**调用方（`QiVcScreen`）只给卡 id 与账本，不关心走哪轨。** 以后加卡＝加档案，不改调用方。

## 3 账本（唯一数据源）

- 来源：`QiVcTargeting.calculate(ctx)` → `hits:[{uid, amount, is_crit}]`（**有序**，第 0 条＝第一击）
  ＋ `damage{}`／`kills[]`／`bounce_hits`／`explosion_hits`／`overkill_used`。
- 屏幕侧快照：每条 hit 补 `rect`（目标矩形，命中瞬间拍下，敌人重建不追）与 `idx`。
- **特效只读账本**：不算伤害、不掷骰、不改数值——错也是账本的错，画面上不改账。
- 静默口径：溢出结转与击杀溢出**不出事件、不出画面**（只对 `hits` 列里的条目出画面）。
- 死亡收尾仍归 `_enemy_death_fx` 唯一管；B 轨可读 `kills` 做造型，**禁止双写死亡动画**。
- **待补字段**（实现直刺时一并补）：每条 hit 的 `col`（右→左序号，同排重击时做散点用）
  与 `seq`（全局击序）；`overkill_chain` 暂不做画面。

## 4 观感硬规（预算、层级、打击感）

| 项 | 规 |
|---|---|
| 时长 | 1~2 段 ≤ 0.36s；3~6 段 ≤ 0.55s；B 轨 ≤ 1.20s，且**不可连续排队**（同回合连打时后一张让位） |
| 连打 | 共用 `_fx_busy_until`，后一张晚起手 ≤ 0.12s；绝不成队列 |
| 层级 | 战斗特效层 z 85；**B 轨全屏件不得盖手牌区**（FrameHand y ≥ 872）与左右栏（x<373 / x>1547） |
| 伤害数字 | 合并窗 220ms 不变：同敌合并、异敌各飘各自目标上方；数字永不进 FX 层 |
| 打击感三件 | 卡帧 25ms（1~2 段 40ms）／震屏 ≤ 2.2 且 ≤ 0.10s／目标后仰 ≤ 5px |
| 力度分层 | **普通卡不许铺满**：扫光/爆点/长拖尾只给重击位与 B 轨 |
| 颜色 | 只用调色板：墨（#2E241A）、纸白、朱红、青；A 轨不许出现新色相，新色相先改规格 |
| 屏幕遮挡 | 任何件不得压住：剑（z 5）、手牌（z 10+）、气珠轨道（65/68）、HUD（66） |

## 5 资产纪律

- **A 轨零贴图**：只用现有 `blade_sheet.png`（3×3 九格）＋`fx_sheet`（3×3）＋程序化件
  （Line2D／Polygon2D／CPUParticles2D／径向渐变）。
- **B 轨才出图**：一表一类（绿幕 3×3），出图前必须先写清**"用在哪几张卡的哪一帧"**；
  写不出这一句，就不出图（省一次生成成本）。
- 1× 导入、不放大；带文字/数字的图一律不收（文字由代码画）。

## 7 实验室（QI_FXLAB）

**为什么建**：现在验一个特效＝跑一次截图 → 看一帧 → 再改，一轮 3~5 分钟且只能看一帧；
实验室把"一次看一帧"变成"一次看全卡"。这是整条管线唯一的效率杠杆。

规格（后批实装）：
- 单屏列出全部攻击卡（真卡面），点一张即播，可只播命中；
- 时间轴滑杆 0.1×～1×（实现＝`Engine.time_scale` 局部替身或 tween 手动步进）；
- 叠加参考：目标矩形框／轨迹折线／击序编号；
- 一键导出 4×N 拼图（每卡 4 帧），供用户裁决。

## 8 直刺 v1（首个样板）

### 8.1 需求句
**"右→左六连点刺：数得出五六下、看得出从右往左扫、刺是点不是弧、收在左端。"**

### 8.2 归轨：A（无主体，全程序化）

### 8.3 档案
```gdscript
"zhici": {
    "carrier": "line", "impact": "pierce",
    "amps": {"needle_len": [90, 150], "needle_w": 10, "core": 64, "star": 22,
             "spray": 4, "shake": 1.8, "hitstop": 25, "recoil": 4, "glint": 0.16},
    "ornament": ["aim_line", "thread", "glint", "pinholes"],
    "repeat_jitter": 9,
}
```

### 8.4 时间轴（6 段；`lead 0.06`／`gap 0.05`）

| t (ms) | 事件 |
|---|---|
| 0 | 起手：出牌点一道极细指引线（1.5px，alpha 0.22）指向最右目标，110ms 淡出 |
| 60 | 第 1 击（最右）——针／白核／星芒／顺向墨／后仰 全套 |
| 110 | 第 2 击 |
| 160 | 第 3 击 |
| 210 | 第 4 击 |
| 260 | 第 5 击 |
| 310 | 第 6 击（最左） |
| 310→400 | 折线整体淡出、全排扫光掠过、落点针孔浮现 |
| 400→520 | 收干净（≤ 0.55s 上限内） |

**节拍 50ms＝3 帧**：快到成"连珠"，慢到肉眼数得出 6 下。

### 8.5 每击五件（层内 z 从下到上）

| 件 | 做法 | 时间 | 参数 |
|---|---|---|---|
| 折线 `thread` | Line2D 1.2px 墨 alpha 0.30，**每击 append 一个落点**（天然累积生长） | 全程，末击后 180ms 整体淡出 | 无图 |
| 针孔 `pinholes` | 3px 深墨点＋1px 白心，每落点一枚 | 末击后浮现，350ms 淡出 | 无图 |
| 墨点 `spray` | 4 颗 6~9px，**沿刺入方向 ±18° 锥形前喷** 55~95px，衰减停 | 220ms | `_dot` 径向 |
| 针 `needle` | blade_sheet 第 1 格（横刺）拉成细长；pivot 在**针尖**（目标侧）；朝向＝**上一个落点→当前落点**（首击＝手牌方向） | 10ms 进、110ms 收；scale.x 1.15→0.75 | len 90~150 clamp、w 10 |
| 白核 `core` | 径向渐变白点 | 12ms 进、130ms 收 | 直径 64，scale 0.7→1.15 |
| 星芒 `star` | 4 条白线（十字＋45°），各 22px／1.6px，中心炸开 | 40ms 长、70ms 收 | 程序化 Line2D |
| 收势 `glint` | 一条横向高光（全排宽 × 26px，白 alpha 0.16）沿折线方向掠过 | 90ms | 可关 |
| 反馈 | 目标后仰 4px、hitstop 25ms、震屏 1.8/0.08s | — | — |

### 8.6 与现版差异（7 条）

1. 现在**每击只有一笔短痕** → 现在五件套；"刺"的针尖读感靠星芒＋白核。
2. 现在**没有方向** → 折线累积＋针朝向上一落点，第一眼能看出右→左。
3. 现在**数不出几段**（间隔 0.035~0.11 乱）→ 固定 50ms 节拍。
4. 现在墨**四散 180°**（钝击感）→ 顺刺入方向锥形前喷（穿透感）。
5. 现在白芒 120px／0.16s（过大过久）→ 64px／0.13s。
6. 现在震屏 3.5/0.12、后仰 7px（偏重）→ 1.8/0.08、4px。
7. 现在首击**凭空出现**在目标处 → 起手指引线与出牌点动作接起来。

### 8.7 边界情形

- **单体敌人连吃 6 击**（只剩 1 只）：所有落点重合 → 按 `repeat_jitter 9px` 绕 8px 环散点
  （角度 137° 递增），读成"同一处被连戳"，不叠成一坨；针朝向保持手牌方向不旋转。
- **打不死/溢出**：溢出结转静默，不额外加画面（账本口径）。
- **6 段只出 2 条 hits**（敌人提前死光）：时间轴按实际 hits 数缩短，末击后走收势，不空放。

### 8.8 段数自适应

```
gap  = clamp(0.30 / n, 0.04, 0.08)     # n=1→0.08(无意义) n=2→0.08 n=6→0.05
lead = 0.06
总长 = lead + (n-1)*gap + 0.21          # n=6→0.52s ✓ / n=2→0.35s ✓
```

### 8.9 拼图验收（4 帧）

t = 60ms（首击）／160ms（中段）／310ms（末击）／430ms（收势）。
判据：① 慢放数得出 6 击；② 1× 第一眼看出右→左；③ 6 个数字不叠；④ 手牌/剑/气珠不被盖。

## 11 三式分辨（占位，防串味）

| 式 | 轨迹 | 命中 | 一句话 |
|---|---|---|---|
| **刺** | 折线顺发（点对点） | pierce | 密、细、连续、顺向前喷的墨 |
| **斩** | 横弧一次刮过整排 | cleave | 一次、宽、慢、横飞的白闪與墨 |
| **撩** | 上挑弧，单点 | upcut | 一下、挑、墨滴上抛后下坠 |
