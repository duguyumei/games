# 特效制作经验 v0.1

> 2026-11-08 立档。来源＝直刺特效从零到定稿的全过程（约 60 轮返工换来的）。
> 用途：以后做斩／弹射／范围／万剑归宗时直接照这份走，别再重踩。

---

## 一、协作流程（比技术更重要）

| 教训 | 做法 |
|---|---|
| **先量，再画** | 任何「位置／比例／间距」都必须先从截图或参考图**量出像素坐标**再动手。凭感觉摆的位置几乎必错 |
| **一张图 > 一段话** | 用户描述「交错」「剑环」时，先画**一张示意图**让他确认，再改代码。凭空实现＝返工 |
| **一次只改一个变量** | 间距、速度、角度、层数分开调；同时改三个，出问题无法归因 |
| **不要嘴硬** | 没量数据前不要断言「均匀／一致」。这次我用错误的测量法（按 y 带切分）得出「等距」，被用户当场推翻 |
| **复述确认** | 每轮改动前，用自己的话把需求复述成一张表（「我理解到的规格」），用户点头再动手 |
| **慢放看细节** | 正常速度只能看「有没有」，看不出「顺不顺」。用 `QI_FXSLOW` 10 倍慢放抓帧，问题一目了然 |

## 二、直刺特效的定稿参数

### 剑阵（出鞘）

| 项 | 值 |
|---|---|
| 中心 | 血珠（`_hp_orb_center()`，实测 331,724） |
| 出鞘 X | **全部相同**（血珠正上方），只靠 Y 区分 |
| 出鞘 Y | **只分两层**，层间距 **30px**（0/2/4 上层，1/3/5 下层） |
| 出鞘姿态 | **剑柄朝上、剑尖朝下**（抽剑时剑尖最后离鞘） |
| 现用剑型 | 短剑（100px）；重剑 140×0.7、长剑 150 待接入 |
| 出鞘时长 | 0.25s |
| 蓄力停顿 | 0.02s（几乎没有） |
| 逐把错开 | 由「刀长 + 5px」反推：`stagger = (L+5)/speed` |

### 飞行

| 项 | 值 |
|---|---|
| 转向 | **原地**转 0.12s，**转完才平移**（同时转会甩出一条弧线） |
| 路径 | **纯水平直线**，保持自己的 Y |
| 速度 | 统一线速度 1400px/s；**远近只改时长，不改速度**（否则队形拉散） |
| X 间隔 | 刀长 + 5px（100+5 = 105px） |
| 命中 | 剑**尖**停在卡缘+18px（不是剑柄插进去） |
| 命中即消失 | 溅墨 + 卡面白闪 + 抖动 + 后坐 + 顿帧 + 伤害数字 |

### 穿透刀（无目标 / 死亡事件）

- 判定：`death == true` **或** `uid < 0` **或** 没有 rect；
- 表现：穿过原来的位置，**飞到最右边（x=1720）淡出**，不溅墨、不落账。

### 伤害数字

- 寿命 **0.20s**（淡入 0.10、上浮 30px、0.72 后淡出）；
- 伤害为 0 的事件**不弹数字**（死亡只播碎裂）。

### 时间轴（正常速度）

```
出鞘 0.25s → 蓄力 0.02s → 原地转向 0.12s → 水平飞行（按距离算时长）
每一把错开 (刀长+5)/速度 ≈ 0.075s
```

## 三、Godot 实现要点（踩过的坑）

| 坑 | 现象 | 解法 |
|---|---|---|
| **独立 tween 漂移** | 每把剑单独 `tween_interval` 错开，跑起来间距不均（105 vs 31px） | **统一时钟**：一个 `tween_method` 驱动全部剑，位置＝`起点 + 速度 × 已飞时间` |
| `bool(null)` | 运行时 `Nonexistent 'bool' constructor`，tween 回调中断、剑冻住 | 用 `Dictionary` 记录状态（`fired.has(i)`），不要用 `Array` 塞 null |
| `null as bool` | `Invalid cast: could not convert value to 'bool'` | 同上，用 `has()` 判断 |
| 闭包捕获已释放实例 | `Trying to assign invalid previously freed instance` | 局部变量**不写类型** + `is_instance_valid()` |
| `var t := create_tween()` | 偶发 `Cannot infer the type` | 显式 `var t: Tween = ...` |
| 资源未导入 | `preload ... has no resource loaders` | 先 `--headless --import`；代码里用 `ResourceLoader.load()` + 空值兜底 |
| 抓帧安全闸 | 10 倍慢放跑到 16s 就被掐断 | 安全闸按 `QI_FXSLOW` 放大 |
| 慢放系数漏乘 | 慢放时剑提前飞走、队形错乱 | `draw / hold / turn / stagger / fly` **全部**乘 `slow_k()`，速度按 `1/K` 缩 |

## 四、验收方法

1. **抓帧器**：`QI_FX=1 QI_FXSCENE=1` ＋（长动画）`QI_FXSCA=1`；关键节拍手动排 fracs。
2. **场景要有「一击必杀」**：只有死亡才会触发碎裂、经验掉落、补位——血厚的场景验证不到。
3. **像素测量**：不要靠眼睛判断间距。按层切开、量**刀柄 X**，输出间距表。
4. **判定标准**：日志 `SCRIPT ERROR` 必须为 0；冻帧（连续几帧位置一模一样）＝回调里有运行时错误。
