# 美术规格 v0.2（暖雪语言 · 卡牌游戏 · 静态背景）

> 2026-11-05 立，替代 v0.1。方向已确认：**我们是静态背景的卡牌游戏**，暖雪只借图形语言，不搬它的动态战场。

## 0. 一句话

**背景退后、卡牌中心**：静态纸底降对比、加暗角、去杂物；卡牌/敌人/数字最亮最清楚；UI 件用暖雪的**骨白＋朱砂＋断线边缘**语言。

## 1. 层级（从后到前）

| 层 | 内容 | 明度 | 细节 |
|---|---|---|---|
| L0 背景 | 静态纸底/区域场景 | 中低对比，暗角压边 | 少，边缘不抢 |
| L1 敌人/立绘 | 剪影＋一处高饱和 | 中 | 中 |
| L2 卡牌 | 手牌、卡面 | 最亮（纸＋金框） | 高 |
| L3 HUD | 血/气/式/按钮/经验条 | 中，骨白线＋朱砂点 | 低 |
| L4 特效/数字 | 伤害、剑光、提示 | 最高 | — |

## 2. 背景处理规则（当前纸底）

- **降饱和 35–45%**、**压对比（黑场抬高、白场压低）**；
- **暗角**：四角乘 0.55–0.75，中心保留；
- **去边缘杂物**：竹、梅、山这些不要贴到 HUD 区域；
- 背景亮部占比目标 **≤ 25%**，且不得比卡牌亮。

## 3. UI 件语言（暖雪向）

- 骨白 `#e8e4dc` 线、朱砂 `#b02a2a` 点、墨黑底；
- 断线/毛边，无渐变无高光；
- 红只做血/危险信号，金只做名字/关键，青只做气/盾；每色 ≤ 2% 画面。

## 4. 尺寸（1920×1080）

| 件 | 尺寸 |
|---|---|
| 血心 / 气珠 | 120 |
| 卡堆 | 96 |
| 式（方/圆） | 56 / 34（卡面） |
| 按钮 | 260×64 |
| 属性格 | 56 |
| 经验条 | 780×164 |
| 卡牌 | 216×304（手牌 0.72） |

## 5. 验收

- 和暖雪参考**并排截图**：背景是否退后、卡牌是否最跳、红色是否只在信号处；
- 不合格先改背景/明度，不单件返工。

## 6. 定案（2026-11-05 用户拍板，交接用）

**背景**：静态纸底（`qiforge/assets/hud/scene.png`），无装饰、低对比、远山淡影；玩法区干净。

**玩家手牌**：1920×1080 下 216×304（0.72 档），羊皮纸＋金框，不变。

**敌人＝卡堆制**（取代立绘站牌）：
- **最多 5 列**；**每列张数由遭遇配置决定**（1..N，卡堆深度随之变化，不写死 3 张）；列 x≈360/640/920/1200/1480，卡 **190×250**；
- 后排只**向上**偏移，每张 **16px**，**不做横向偏移**；
- 压暗：中排 0.86、后排 0.72；顶张亮、可点、z 最高；
- **无血条、无名字**（信息走悬停浮窗）；数值/名字不进卡面；
- 档位靠框：小怪＝细骨白框(2)、精英＝金框(3)＋顶部菱、Boss＝红框(4)＋冠＋红光；
- 死亡＝顶张移除，下一张顶上（补位 0.2s）。

**敌人素材**（占位，已抠图去绿边）：`qiforge/assets/hud/enemy_1.png`（乞丐）、`enemy_2.png`（强盗）、`enemy_3.png`（刀客）。

**HUD 件**：血心/气珠 120、卡堆 96、式 56、按钮 260×64、属性格 56、经验条 780×164；经验条待换（现用 `c_xpbar`，偏亮）。

**待办**：精英/Boss 框资产、悬停浮窗（血量/意图）、补位动画、区域背景（region→背景）。
