# 素材库调研 v0.1（2026-10-28）

## 裁定（用户）

- **游戏语义图标**（盾/毒/破绽/封穴/杀意等状态与徽记）：统一走 **game-icons.net**——SVG 下载、白线稿化、按状态色染色进项目；**CC BY 3.0 需署名**（已挂主菜单页脚一行）。
- **UI 骨架件**（按钮/面板/框条）：继续 **Kenney**（CC0）。
- STS2 解包美术仅内部参照、不得分发进项目（既有规）。

## 候选库实测（2026-10-28）

| 库 | 内容 | 许可 | 结论 |
|---|---|---|---|
| [game-icons.net](https://game-icons.net/) | 4,180 个游戏语义图标（Lorc/Delapouite/sbed 等），SVG＋PNG 批量包、单色可染 | CC BY 3.0（署名） | **采用**（手绘线稿风与水墨/线徽同族；卡牌/桌游事实标准库） |
| [Kenney Game Icons](https://kenney.nl/assets/game-icons) | 105 个手柄/接口提示图标（2014） | CC0 | 不对口（非武器/防御语义）；Kenney 继续供 UI 骨架（ui-pack） |
| [itch.io CC0 筛选](https://itch.io/game-assets/assets-cc0/free) | 逐包核对 | 混合 | 备选淘货地 |
| [OpenGameArt](https://opengameart.org/) | 社区库 | 可筛 CC0 | 老牌备选 |
| Lucide / Tabler | 通用 UI 图标 | MIT | 无游戏幻想语义，不采用 |
