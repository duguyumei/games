# 参照·太吾绘卷真气与命中（v0.1）

> 他作参照档：记已印证机制＋我方映射。2026-10-25 立档，结论已经用户过目。灰机wiki 403，战斗内操作细节未三验；系统全貌多源一致。

## 1. 真气系统（多源一致）

- 真气四轨：**摧破→攻向、轻灵→速度/身法、护体→防御、奇窍→特殊**。我方旧名（摧破/护体/轻灵）源于此；现行更名为**催破／护体／身法**（字形以「催破」为准）。
- 真气**直接提供大量属性**（命中／化解／移速／威力等），是属性主来源之一；输出角色多配摧破、防御角色多配护体——**配比即 build**。
- 战斗界面**两行显示**：上行＝当前战斗真气、下行＝底子真气；战斗中存在「凝聚真气」操作与分配调整（操作细节未三验）。

## 2. 命中对比（多源一致）

- 攻击判定对比三对：**力道 vs 卸力、迅疾 vs 闪避、精妙 vs 拆招**；差距越大伤害越高，反之被化解。我方三命中与受击措辞（卸力/闪避/拆招）的出处即此。

## 3. 我方映射（借什么／不借什么）

- **借**：真气＝属性直接来源的作用定位；命中对命中（同名列对比）的结构；战斗内「当前值／初始值」两行显示。
- **不借**：第四轨奇窍；凝聚／手动调气操作（我方真气**不可手动操作**，战斗内只走被动回归——回归制为我方自设，星铁篇亦无此件）。
