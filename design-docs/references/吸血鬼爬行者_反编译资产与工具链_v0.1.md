## 二、与既有链路的分工（证据分级制对齐）

| 问题类型 | 首选通道 | 说明 |
|---|---|---|
| 这个方法内部逻辑是什么 | **ghidra_decomp 直读** → 存疑回 IsilDump 汇编 | 伪码＝同一份汇编的便捷视图，**效率工具非证据层升级**；落码引用注释仍锚地址 / ISIL 行号 |
| 类结构 / 字段 / 谁存在 | csall（索引） | 不变 |
| 谁在调 X / 时序 / 时长 | lldb 活体探针（终裁） | 地址归位改查 method_table.tsv，不再现场枚举 |
| 数值 / 逐实例配置 | rip/ 资产 YAML | 不变 |

## 三、验收与可靠性（2026-11-21）

- **d__280 MoveNext**（原版胜利协程状态机）：725 行 C 伪码，DiscardHand / DiscardComboPile / Delay(1000) / TryAddDiscardPileToDeck / WaitWhile / Delay(500) 与此前 ISIL 逐 Call 考古真值**逐条对上**，时长为字面量直读。
- **PlayerModel 298 方法**与 lldb 运行时枚举数**精确相等**；HandPileView 21 / CardView 110 同源可查。
- **SetSpeed 静态 0x3BC23E4 ↔ 运行时 0x12cbb63e4**：平移验证通过（样例 slide=0xF8F92000，按会话重算）。
