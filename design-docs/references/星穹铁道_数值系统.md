# 参照·星穹铁道数值系统（v0.1）

> 他作参照档：仅记**已多方印证**的机制与数值＋我方映射结论。2026-10-25 立档，结论均已经用户过目。未确证项明确标注，不猜测。正文规则见《基础规则 v0.2》，本档只管出处。

## 1. 行动条与速度（中英文 5+ 源印证）

- 行动条总路程 **10000**；**行动值 AV＝10000÷速度**；AV 归零者行动，行动后重置、全局时间推进。
- 速度＝基础×(1+速度%)＋固定值。
- 拉条／推条按**百分比路程**（提前 X%＝视为已跑 X%×10000）。
- 换速时当前 AV 等比重算：新 AV＝当前 AV×旧速÷新速。
- 角色速度不随等级成长（示例角色恒 110）。
- 等效速度换算例：150 速＋25% 提前 → 一动 50 AV → 等效 200 速。

## 2. 伤害公式（多源印证）

- 总伤害＝(攻击×技能倍率＋固定伤害)×暴击×增伤区×易伤区×防御区×抗性区×减伤区×韧性区；**同区加算、异区乘算**。
- **防御区＝(200＋10×攻方等级)÷(200＋10×攻方等级＋守方防御)**；怪物防御＝等级×10＋200 → **同级对打恒 50%**（整套公式的锚）。
- 韧性区：未击破 ×0.9（二源印证，可信未三验）。
- 基础暴击 5% 率／50% 伤。

## 3. 量级锚（已确证）

- 4★角色 20~80 级完整成长表（血/攻/防，含晋阶前后）：30 级 390/241/175 → 80 级 882/546/396；5★ 档约高一成半。÷10 后即我方 G1~G6 锚表（见《基础规则 v0.2》§10）。
- 敌方：防御走上述公式；血量结构＝基础值(93.0)×等级系数×自身调整×精英组别调整（**系数表为图片源，未取得**）。
- **敌方 HP/ATK 60 级行值未确证**——各数据站表格均为图片或动态页（Fandom 超时／NGA・3DM・TapTap 图片／米游社・知乎・官方 wiki 403）。我方以回合预算反推代替，此条仅作日后 sanity check。

## 4. 我方映射（借什么／不借什么）

- **借**：乘区结构与「同区加算异区乘算」、防御区 50% 同级锚、AV 行动条全套、量级锚（÷10 后采用）。
- **不借**：暴击区／韧性区（我方均无）、Boss 量级（4v1 语境不适用）、长线养成曲线。
- 对应关系：威力倍率↔技能倍率位；伤害增幅↔增伤区；伤害减免↔减伤区；异常区↔易伤区；三命中差值对比↔抗性区位（我方自设项）。
