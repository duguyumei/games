## 1. 类全景（结构级实证；文件前缀 Nosebleed.Pancake）

### GameLogic/Weapons/ —— 索敌算法库（→ 我方 `QiVcTargeting.gd`）

| 类 | 职责 |
|---|---|
| **WeaponTargeting**（abstract） | 索敌＋伤害模拟核心。**模拟结算跑在 EnemyStatData 内存副本上，不动 Model** |
| WeaponTargetingBehaviour | 每次瞄准/命中的策略回调（CherryBombTargetingBehaviour＝概率爆炸追击的子类） |

| RandomTargeting | 随机列（列袋不重复） |
| InfiniteCorridorTargeting | 伤害随穿透距离递增 |

关键结构（C# 反编译原文）：

```csharp
enum PierceType { OncePerEnemy, MultiHit, MultiHitSwitchTarget }
enum TargetingPriority { None, Attacking, Defending }
struct TargetingData { bool IsInOverkill, OverkillCardDoesDamage; int AliveCount;
                      bool IsOvenkiltUnlocked, RowContainsPriorityEnemy, BounceChainEnded; }
struct EnemyStatData { double RemainingHp, RemainingArmor; int FreezeStacks; }
struct CritExplosionTrigger { int Column; double BaseDamage, DamageMultiplier; int OriginDamageIdx; }
```

`CalculateEnemiesToHit → InitialiseLists(frontEnemies→enemyRow+账本+deadCounts) →

ApplyWeaponHitsToEnemy(逐击: CritChainState.RollCrit → EnemyModel.GetDamageToDo →

GetBounceChance`；优先敌：`RowHasRemainingPriorityEnemy`；`GetPierce/PierceAlwaysMultiHits`。

## 6. 时序优先级体系（2026-11-08 补记——用户问「多段打死全场后余段表现/升级为何不等特效」）

原版为**四层异步结构**（ISIL 铁证在案）：

| 层 | 触发器 | 时点 | 等特效吗 |
|---|---|---|---|
| 数据（伤害账/经验） | 方法直调 | 打出帧/死亡帧即时 | 不等（`EnemyModel.OnDied→AddEnemyXp` 死帧入账） |
| 表现（武器/跳数/珠/条） | 物理时序（运动件 Tick→伤害点） | 异步逐帧 | 即特效本身（每击有 WaitForSeconds 微停顿） |
| 模态（升级三选一） | XP 响应式变量→View 旁路 | 条满帧即弹 | **不等**（`PlayerXpBarView.UpdateXp→DoViewLevelUp→TryOpenChooseCardModal`） |
| 流程（回合/胜利转场） | GameStateMachine 状态机 | **等表现清空** | **等** |

- **余段空放**：账单打出瞬间算定（`Weapon.OnSpawned(damageParams,…)` 全程携带）；
  运动件（ArcMovement 等）`RefreshTarget` 查 `WeaponCollision.AreAllTargetsHit` 推进/收尾；
  死目标段跳过（`DoDamageToTarget` null/不活跃 return），**武器必须飞完全程**；
  武器动画期 `GameView.RegisterUpdatingView` 自注册（`IsAnyViewUpdating=true`）。
- **胜利为何等特效（铁证）**：胜利判定挂 `EnemyEncounterModel.RefreshHealth` 尾部（全灭→
  `OnEncounterDefeated→Globals.RaiseEncounterDefeatedEvent`→切 `EncounterDefeatedState`）；
  判定本身死帧即时，但该态 `ExecuteTask` 协程收尾＝
  `WaitWhile(CommandRunner.IsProcessing ‖ GameView.IsAnyViewUpdating)→Delay→转场`
  （lambda 见 EncounterDefeatedState_NestedType___c__DisplayClass2_0 `<ExecuteTask>b__0`）。
- **升级为何不等**：升级弹窗不是流程节点而是数据旁路模态（Odin 响应式变量链）；
  弹窗模态盖住一切→无视觉撕裂，故有插队权；`ContinueXpFillAfterLevelUp` 处理连升排队。
- **其他等待点**：`PlayerEndTurnState.DelayExecute`＝WaitUntil×2（卡效清→弃牌→弃牌动画完）；
  `PlayerModel.OnEncounterDefeated_d__280` 内 WaitUntil 等三堆 Count 清零；
  `PlayCardLockCount` 出牌锁＝交互旁路不拦流程。
- **我方对齐（2026-11-08 实装）**：拍制空放（`total_strikes`＋`map_strike_beats`——每拍 1 hit
  ＋紧随 deaths、余拍 blank 空放，胜利收口在循环尾＝等全部刀飞完）＋弹窗世界暂停
  （`get_tree().paused`＋弹窗 WHEN_PAUSED；经验珠维持珠到才入账——用户裁）。
