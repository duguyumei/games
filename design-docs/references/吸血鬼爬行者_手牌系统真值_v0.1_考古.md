## 一·五、FanCardRotation 完整汇编层破译（2026-11-12 定稿，全部常量从二进制字节实锤）

```
若 n ≤ s_minCardsToFan(=2)：  t = 0
否则：                        t = 2·i/(n−1) − 1
mag = RotationOffsetCurve(|t|) × MaxRotationOffset      ← 0x7FFFFFFF AND＝Mathf.Abs
z   = (t > 0 ? −mag : mag) + DefaultCardRotation.z      ← 0x80000000 XOR 取负＋cmpless 选符号
槽位[i].rotation = EulerRad((def.x, def.y, z) × Deg2Rad)
```

常量表（GameAssembly.dylib x86_64 切片 __TEXT.__const，VA 0x502b960 起；**胖二进制须先加切片偏移 +16384**，lipo -detailed_info 取）：
0x502B964=1.0f／0x502B9B0=0.0174532925×双lane(Deg2Rad)／0x502B9C0=0x80000000(符号)／**0x502B9D0=0x7FFFFFFF(Abs 掩码)**／0x502BB34=−1.0f／0x502BBB8=−0.5f／0x502C0C0=Deg2Rad。

**结论（2026-11-12 深夜破案修订）**：±15° 是**槽位层**值（布局容器 transform），卡**视觉层**（`_baseTweenOffset`）每帧被两个写入者操作——`UpdateHandTilt`（Lerp 向槽位角，过渡用）＋`RotateToFollowVelocity`（同帧后跑＝赢家：`SetEulerAnglesIfDifferent(_baseTweenOffset, 钳制(速度角, ±draggedRotationAmountDegrees=3.5°))`）→ **静止手牌视觉倾角 ≤±3.5°，槽位的 15° 被内层抵消**。原版手牌的「扇」＝位置弧（中卡 +32）＋近乎直立的卡。我方初版把槽位值当视觉角→「倾角大非常多」（用户 F6 抓包）——已改 `HAND_ROT_MAX=3.5°`。15° 布局值保留注释备查。

## 一·六、弧案终审（2026-11-12 深夜·实机图＋汇编双证定案：**弧＝死代码，手牌平排**）

`FanCardPosition`（弧）与 `AlignOnSecondaryAxis` **从未被调用**——`AlignChildrenAlongAxis` 汇编指令 033-043：`(isVertical^1)==axis`（当前是次轴）时**直接弹栈 return 不做任何事**；水平组 SetLayoutVertical（axis=1）与垂直组 SetLayoutHorizontal（axis=0）都走这条空返回。槽位 Y 全由自身锚点决定＝**齐平平排**。MaxPositionOffset 32/PositionOffsetCurve/「≤2 张取 t=0.5」全部＝死代码里的数。

**勘案过程三连反转**：①抬高版（沿用旧拱形方向）被 F6 否 → ②下沉版（`axisOffset −= 曲线×32` 汇编铁证＋六环透出链验证）又被 F6 否＋用户实机图（7 张手牌、悬停最右、中间卡不下沉）→ ③终审找到缺失的**第零环＝入口门**：函数体每步都对，但它根本不上膛。**教训：逐环验证函数体之前先验证函数被调用（死代码里住着活数学）。** 我方落地＝平排（弧常量/曲线退役，行锚回贴底上提 5）。

次轴死代码的连带推论：`GetChildAlignmentOffset`（次轴对齐计算）同死；布局只活**主轴**（间距/劈开/槽位旋转）。

**那 Y 到底谁定的（真逻辑）**：`CardSlot.prefab`（guid 0415d2ea，实测）锚 (0,0)-(0,0)＝父物体左下角、anchoredPosition (0,0)、100×100、pivot (0.5,0.5)；`GetPooledCardSlot` 实例化后仅 `SetParent(_cardSlotContainer)`＋SetAsFirst/LastSibling，**代码零干预 Y** → 所有槽位天然锚在同一条底线上＝平排；整排高度由 HandPile 锚位（底部居中上提 37）决定。**「平」是锚点默认行为＋没人动它，不是算出来的。** 死代码＝上代弧系统遗迹（配置精调过说明曾活过，后改平排＋劈开方案未删旧件）；HandPileFanConfig 因此**半死半活**（旋转/劈开段活、弧段死）。〔衍生律：**配置调得再精细也可能属于死系统——配置存在≠系统活着，参数与调用链要一起验**〕
