## 2.5 雪原场景——先前量错了，以 ws_19 / ws_21 为准

- **ws_04 不能当样本**：它中间开了物品弹窗，**弹窗给背景加了暗色遮罩**，雪是被遮罩压暗的（弹窗自身亮度 0.64，去掉弹窗后整图仅 0.18）；
- **干净雪地战斗取 ws_19 / ws_21**：

| 区域 | 亮度 | 颜色 |
|---|---|---|
| 雪面（ws_21 中） | **0.63** | `#8aa6ad`（冷灰蓝） |
| 雪面（ws_19 中） | 0.55 | `#7b8e94` |
| 树影/暗部 | **0.14** | `#1b2526` |
| 天空 | 0.08 | `#131516` |
| 整图（ws_19 / ws_21） | 0.32 / 0.28 | 亮部 23% / 20%，暗部 26% / 43% |

**结论**：雪地战斗是**中亮场景**（均亮 0.28–0.32，雪面 0.55–0.63），但——
1. 雪是**冷灰蓝**（`#8aa6ad`），不是暖白；
2. **深色剪影压场**（树 0.14、天 0.08）；
3. **暖色点火**（火把/灯笼）做点缀；
4. HUD 仍带**深色底条**；弹窗出现时整屏再压一层遮罩。

## 3. 结构拆解

**战斗屏（ws_05 / ws_08）**
- 背景：近黑，只留少量环境光（烛火/地砖/雪）；
- HUD：**极简**——左上一条血条（红）＋小图标；Boss 条在底部，细长、两端金饰；没有大面板、没有花纹框；
- 敌人：高对比剪影＋少量高饱和（红眼、紫皮），轮廓清楚；
- 特效：亮（金光/剑气/粒子），**是画面里最亮的东西**；
- 文字：金色衬线/书法体，只出现在名字与关键提示。

**菜单屏（ws_03）**
- 宣纸底＋墨色晕染＋细金线，红印章点缀；信息密度高但对比低；
- 结论：**战斗屏走暗、菜单屏走纸**，两套分开。

## 4. 对《气铸》VC 线的可执行结论

1. **战斗场景低 Key**：暗部 40–86%、亮部 ≤ 5–17%；允许雪原这类中亮场景，但必须**冷灰、低饱和、带深色剪影**；禁止暖白纸做大面积战场；
2. **HUD 只留信号**：血/气做成细条或小徽章，不要大面板；红=血/危险、金=名字/关键、青=气/盾，**每色占比 ≤2%**；
3. **敌人剪影优先**：暗底上高对比轮廓＋一处高饱和（眼/刃）；
4. **特效最亮**：伤害数字、剑光、命中闪白，亮度高于 HUD；
5. **菜单/弹窗另走纸面**（现有纸底可用在菜单，不进战斗屏）；
6. 现有《美术规格 v0.1》的调色板按此表修正（把“骨白大面积”改成“近黑大面积＋骨白只做线/字”）。
