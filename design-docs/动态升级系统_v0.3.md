## 一、一句话定义

每出一张，同型且不高于它的余牌，各升一级（等级 +1、费用 +1）。

## 二、为什么替换掉「连击」

旧系统的病根是**没有棘轮**：筛选条件开链那一刻就固定，连到第 10 张和第 1 张允许的牌一样多
——只有收益没有代价；链长记在全局徽上，玩家脑子里还要自己做型匹配；断链惩罚是外加规则，
越补越复杂。新系统三件事一起解决：

- **棘轮长在牌上**——每打一张，同类牌就贵一级；代价与收益是同一个数字（等级）。
- **状态看得见**——等级与费用写在每张牌脸上（费用转金＝已升过级）。
- **零惩罚条款**——切招不清局、不重置计数，只是放弃已积累的等级；没有任何「断链」规则。

## 三、预备层（定义，不是公理）

- **型集**：每张牌带一个型集，装它属于的型——短剑 {短}／长剑 {长}／巨剑 {巨}；
  **万能牌（变招）＝全集 {短, 长, 巨}**。
- **接**（旧词「同型」）：两张牌的型集**有交集**。
- **换**（旧词「切招」）：两张牌的型集**无交集**。接/换是完美二分——一张牌对另一张必居其一。
- **费用锁定**：万能牌的牌面词条——初始费用 0，永不因升级 +1 费（与「消耗」同级的卡面数据）。
- 回合首张无上一张 → 不可能「换」，不触发切招。

## 四、三条公理（全部绑在「打出 p」上）

执行顺序＝⓪ p 自身效果 → ① A2 判定 → ② A1 升级 → ③ A3 万能 → ④ 记上一张的型。

| # | 公理 | 触发 |
|---|---|---|
| **A1 升级** | 与 p **接**、且等级不高于 p 的手牌 → 等级 +1、费用 +1（费用锁定牌不加费） | 每次打出 |
| **A2 切招** | p 与上一张**换** → 与 p **换**的手牌 → 等级与费用复原到初始值 | 切招时 |
| **A3 万能打出** | p 是万能牌 → 与 p 接的手牌（＝全体）→ **费用复原到初始值**；结算在 A1 之后 | 打万能时 |

- 单次打出内三步**永不打架**：A1 升级集（接）与 A2 复原集（换）天然互斥；A2 与 A3 永不同帧
  （万能牌恒接，「换」条件结构性为假）。全系统唯一的顺序约束＝A1 在 A3 前。
- 「先效果后升级」：p 抽进手的新牌以初始值参与本次 A1（等级 0 ≤ 任何 p）。

### 推导表（全部由定义自动成立，无需另立规则）

| 结论 | 怎么来的 |
|---|---|
| 万能牌会被任何牌升级 | 万能与谁都**有交集** → 恒接 → A1 自动命中 |
| 万能牌不算切招 | 恒接 → 永不满足 A2 的「换」 → 结构性不可能 |
| 切招时万能牌**不复原** | 复原条件＝「与 p 换」；万能与 p 恒接 → 永不复原（它只升不掉） |
| 万能牌后打任何牌也不切招 | 同上 |
| 打出万能牌 → 手牌费用复原 | A3；等级照走 A1（等级高于它的牌不 +1 级——已裁：无所谓） |

## 五、复原语义（公理只说「复原到初始值」，何时复原在此定义）

- **离开手牌即复原**：打出／弃置／碎牌／消耗，等级与费增量一律清零。
- 由此覆盖三条路径：进弃牌堆＝初始值；回合结束（整手冲弃）＝初始值；抽到的牌＝初始值进场。
- 「初始值」暂全为 0；局内固定升级抬高某张卡的初始等级/费用＝后续轮获取通道。

## 六、双轨与倍率（引擎现值）

| 轨 | 决定什么 | 怎么变 |
|---|---|---|
| 等级 | 效果强度（占位公式：每级总输出 +30%，暂定可调） | A1 时 +1；A2 复原 |
| 费用 | 要花的气（底价＋费增量） | A1 时 +1；A2/A3 复原；**活查询**（显示/校验/扣费同源） |

- 气经济不动：基础 2、护栏 6、回合重置——低气期自然玩成浅梯多切换，气成长后才能深链。
- 碎牌不动（同实例一回合 3+1、第 5 次碎）——成本棘轮先掐普通循环，碎牌专咬万能清费循环。

## 七、门控与裁决记录（2026-11-10）

- **门控沿用宝箱内功制**：内功「动态升级」（id 沿用 `combo_stack`——地图宝箱硬编码联动）
  装备后三公理生效；未获＝三步全跳、等级与费用纹丝不动（记型仍照记，式槽显示用）。
- 切招判定＝**型集无交集**（集合制终裁）：万能牌不属于「其他型集合」的旧句作废。
- 万能打出＝先 A1 后 A3（「给等级、费用推回起点」）；等级高于万能的牌不 +1 级＝已裁无所谓。
- **无型牌不存在**（用户裁）：所有卡都落型集；现役卡表三张（下斩·巨／连环刺·短／上撩·长）。
  **空型打出＝卡表数据违例，引擎直接 push_error**、三公理照跳（审计轮补裁）。
- 切招浮字只列**真正掉级**的牌；无实际损失时只发「切招！」（审计轮补裁）。
- 金丹徽（旧连击全局数显示件）**先隐藏**（`SHOW_COMBO_BADGE` 常量门，重开改 true 即可）。
- 万能牌进卡组的数量/稀有度＝后议（现役零张 flex 卡，引擎逻辑照公理写全）。
