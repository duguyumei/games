# 属性与养成 v0.1

> 2026-11-07 属性轮立档（用户令：对齐蓝本数值系统——黄卡三型／属性四层／局外金币）。
> 蓝本证据住 `references/吸血鬼爬行者_伤害管线逆向_v0.1.md`＋wiki Cards 页原文。

## 一、属性四层（对应原版 GetStartingX 三参＋本场增量）

| 层 | 载体 | 生命周期 | 对应原版 |
|---|---|---|---|
| 基础 | `STATS.base`（QiVcData） | 恒定 | PlayerConfig |
| 局外养成 | `QiVcMeta`（user://qi_vc_meta.json） | 跨 run 永久 | ProgressionData |
| 本局（dungeon） | `run.dungeon_stats` | 本局跨场 | dungeon 型黄卡 |
| 本场（encounter） | `battle.encounter_stats` | 本场（实例销毁清零＝原版 OnEncounterDefeated 重算回基线） | encounter 型黄卡 |

合成：`get_starting_stats(meta, run)`＝base＋progression（每级 PROGRESSION_PER_LEVEL）＋dungeon 增量；战斗现值＝`stat_val`＝starting＋encounter。dungeon 型黄卡打出→增量写 run＋**重合成 starting**；encounter 型→写 battle 层（不回流 run）。

## 二、属性轴（pct 轴 100 基；计数轴 0 基）

might（伤害乘区，每击 round(v×might%)）／area（溅射——机制留位）／duration（时长——留位）／amount（弹数：hits+N）／magnet／recovery／deal_count（每回合多抽 N）／scavenge／growth（经验乘区）／curse（敌血乘区＋金币经验增益——难度轴）／luck（暴击率 +0.2%/点）／greed（金币乘区）／reroll／banish／skip／revival（复活次数）／risk／charm／max_hp（血上限，涨上限同涨当前血）。

## 三、黄卡三型（wiki 原文实证「encounter 或 dungeon」＋Destroy 标签）

- **dungeon 型**（属性成长类默认）：打出→`stat` op duration:"dungeon"→写 run.dungeon_stats
- **encounter 型**：打出→写 battle 层，战斗结束消失
- **Destroy 型**：卡 `exhaust: true`（打出进消耗区）；效果多为 encounter 层一次性
- 黄卡 kind="stat"——**连击中立**（不涨不磨）；出题器低级段（≤2 级）只出攻击，stat 卡中高级入池

落表 19 张（wiki 真值）：菠菜/嫩菠菜（might +10/20%）、蜡烛族（area 5/10/15%）、空心之心（+3HP Destroy）、永恒之心（+1HP）、王冠族（growth 15/20% Destroy）、石面具（greed 10% Destroy）、三叶草（luck 10%）、骷髅咒（curse 5% Destroy）、分身器族（amount +1/+2）、护腕（deal_count +1）、咒术书（duration 留位）、提拉米苏（revival Destroy）、吸引球（即抽 1）、友谊护符（combo_base 留位）。

## 四、局外金币（对应原版 meta 金币）

- **来源**：胜场金币＝击杀 XP 总值×greed（`battle.gold_reward()`→`player_out["gold"]`→Root 入 `_meta.add_gold`＋run.copper 累计显示）；地图宝箱 20 同入
- **消费**：地图屏「修行」面板——12 轴×5 级，花费 `50×(level+1)`（自拟曲线）；`try_upgrade` 扣金写档
- **生效**：新战斗 setup 时 `run._meta` 注入 meta_snapshot → 三层合成

## 五、数值标注

PROGRESSION_PER_LEVEL（might 5/amount 1/…）与花费曲线为**自拟**（蓝本资产数值住 .assets，AssetRipper 提取另行请示后对齐）；luck→暴击 0.2%/点、curse→敌血 1:1 为自拟曲线。
