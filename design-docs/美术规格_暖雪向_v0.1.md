# 美术资源规格 v0.1（暖雪向 · 暗色水墨扁平）

> 2026-11-05 立。适用：VC 复刻线战斗 HUD / 卡面 / 敌人 / 背景。
> 目的：把“AI 一件件抽”改成“先定规格、再批量出件”，消除四套语言混用。

## 1. 一句话风格

**暗色水墨 + 扁平 UI**：大面积墨黑打底、骨白/宣纸做对比、少量朱砂点睛；笔触粗糙、边缘毛、**无渐变无高光**。参考《暖雪》的暗色水墨与扁平界面。

## 2. 调色板（唯一）

| 名 | 值 | 用量 |
|---|---|---|
| 墨黑 | `#0d0d0f` | 65% |
| 炭灰 | `#1c1b1d` | 底色/面板 |
| 烟灰 | `#3a383b` | 次级 |
| 骨白 | `#e8e2d2` | 文字/高光面 20% |
| 宣纸 | `#cfc6ae` | 纸面 |
| 朱砂 | `#b23a2e` | 点睛 10% |
| 暗红 | `#6e2119` | 阴影红 |
| 石青 | `#2f5d7c` | 冷色点 |
| 旧金 | `#a8863f` | 极少量边线 |

规则：所有件只许用上表颜色＋透明度；新增颜色必须先改此表。

## 3. 线条与质感

- 外轮廓 **2–3px**（1920×1080 下），内线 1–2px；
- 边缘**毛边/断线**（像笔没蘸满墨），不要平滑矢量边；
- UI 件**无渐变、无高光、无立体厚度**；最多 2px 偏移暗影；
- 背景允许墨晕渐变，但整体压暗、低对比（相邻明度差 ≤ 35%）；
- 禁止：金线雕花、3D 光泽、厚涂、写实材质。

## 5. 资源清单（分批出）

1. **HUD 图标**：血心、气珠、卡堆、式圆×5、式方×5；
2. **UI 框**：按钮、经验条、属性格底、卡面外框；
3. **卡面**：宣纸底＋墨框＋效果区＋名字带（不用金饰）；
4. **敌人**：墨影剪影＋朱砂红晕（3–5 个）；
5. **背景**：现有水墨场景 → 降饱和 40%、压暗 25%、加暗角。

## 6. AI 出图规则

- 每批**一张表**、纯绿 `#00FF00` 背景、**无文字无数字**、组件内部留白当数字底；
- 统一尾巴（每张必带）：
  > dark wuxia ink-wash, warm-snow-like, charcoal black + bone white + vermilion accents, rough broken edges, flat colors, no gradients, no highlights, no 3D, no text, no numbers, green screen, 2048×1152
- 同一批用**同一张已批准的件**当参考图（风格锚）；
- 每批出 2 版选 1；不合格**整批重抽**，不单件混用；
- 打样先行：每类先出 1 件（1 图标＋1 按钮＋1 卡面），确认后再批量。

## 7. 落地规则

- 件按 **1× 尺寸**导入，禁止放大（笔触会糊）；需要大图就重出；
- 颜色一律走 `QiStyle` 调色板常量，不在场景里散写；
- 背景统一后处理：降饱和／压暗／暗角，保证 HUD 与敌人跳出来；
- 所有 HUD 文字/数字由代码画（字体 Noto Sans SC），件里**永远不带字**。
