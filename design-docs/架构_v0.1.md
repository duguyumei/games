## 2. StR 分层（长游戏的骨架）

- **Action 管道**（`scripts/actions/`，autoload `ActionHandler`/`ActionGenerator`）：一切行为＝可复用 action（攻击/抽牌/买卡/生成地图/结束回合/状态增减）；action 可生成与改写 action（嵌套逻辑：循环/随机/条件）。
- **Interceptor**（`scripts/action_interceptors/`）：action 执行前动态改写（防抽牌/涨价/格挡保留/攻击加强）；**敌方意图、卡面描述、出牌校验与 action 走同一条计算管道**——显示即结算。
- **Validator**（`scripts/validators/`）：条件逻辑，UI 与规则共用。
- **规则件目录**：`scripts/status_effects/`、`scripts/artifacts/`、`scripts/card_decorators/`、`scripts/run_modifiers/`、`scripts/combatants/`。
- **数据层**（`data/`）：`PrototypeData`/`SerializableData`/`CardPlayRequest`；代码生成、可导出 JSON；ContentPack 自动归类（加卡自动进对应池）。
- **流程层**：三幕/事件对话状态机/开局选项/进阶（StR 缺省结构；现役局结构＝VC 线五层地牢，见《战斗基础规则_v0.4》）。
- **基建**：确定性 RNG 分轨（autoload `Random`）、`StatsHandler` 统计钩子、SerializableData 存读档＋自动存档、Mod 支持、图鉴样例。
- **autoload 全表（14）**：Signals／Scenes／Scripts／FileLoader／Random／Global／GlobalTestDataGenerator／GlobalProdDataGenerator／ActionHandler／ActionGenerator／DebugLogger／HandManager／SoundManager／StatsHandler。
- **addons**：sound_manager（音频）＋label_font_auto_sizer＋smooth_scroll_container（StR 自带）＋card-framework（我方并入）。

## 3. 现役游戏线（VC 复刻线，2026-10-31 起）

- **主入口** `qiforge/QiVcRoot.tscn`（project.godot 主场景，2026-11-10 切）：`QiVcRoot.gd` 流转宿主（地图⇄战斗⇄奖励/修行，`run` 状态唯一持有者）。
- **地图**：`QiVcMapScreen`（明雷/宝箱/铲子/出口＋BFS 寻路）＋`QiVcMapGen`（固定教程层＋种子随机层）。
- **战斗**：`QiVcBattle.gd` 纯逻辑 RefCounted（signal 驱动、可无头直测）＋`QiVcScreen` 表现宿主（HUD/敌阵/特效/回放队列）＋`qiforge/vc/` 手牌 1:1 层（原版 CardView 同构 16 类）＋`QiVcTargeting`（账单制索敌/伤害模拟，预览与结算同链）＋`QiVcEnemyActions`（敌方意图/排清制）＋`QiVcEffects/QiVcFxSpec/QiCombatFx/QiXpFx` 特效层。
- **奖励与局外**：`QiVcReward`（三选一）＋`QiVcCabinet`（地图/战斗共用机壳）＋`QiVcMeta`（`user://qi_vc_meta.json` 金币养成跨局档）＋`QiVcData`（卡/敌/层/属性唯一数据源）。
- **公共件**（两线共用）：`QiCardStyle` 卡牌工厂／`QiStyle`／`QiFontBank` 字体／`QiDialog` 弹窗／`QiKeywordTooltip` 词条浮窗。
- **StR 层地位＝基底暂留**：14 autoload 预载（拆则炸启动），整层剥离属独立批次（见剥离清单）；现役 VC 线不走路 StR Action/Interceptor 管道。旧线（QiRoot/QiBattleScreen/QiPrepBay 等）2026-11-10 已物理归档 `.archive/2026-11-10-old-line-battle-prep/`。

## 4. 引擎与工具链

- StR 目标 Godot 4.6；本机现役 4.7.1。**兼容校验（2026-10-24，副本上做）**：导入 exit=0、headless 冒烟零 SCRIPT ERROR——4.7.1 开发可用；真身工程文件保持 4.6 原封未动。
- 渲染器 gl_compatibility（StR 缺省；2D 卡牌够用，改 Forward+ 待定）。
- 我方窗口 **1920×1080**（2026-10-25 用户裁定，与系统蓝本同分辨率）。
- **启动帧时序（2026-11-15 开局首帧案）**：Godot `_ready` 与场景加载同帧；`_ready` 内同步启动的出场动画/追槽会吃到加载长帧的 `delta`。原版抽牌为命令/协程，装载后正常帧步进。此类启动必须让过加载帧或按原版启动层映射；验收看 `frame/delta/Tween scale`，不能只看最终位置。节点/矩形全静而画面仍动时另查像素层（tilt/sheen/hov，差异 #32）。案卷：`references/吸血鬼爬行者_手牌系统真值_v0.3.md` §十九；差异登记 #31/#32。
