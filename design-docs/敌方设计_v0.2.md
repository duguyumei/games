# 敌方设计 v0.2

> 2026-10-28 敌人优化轮二改（用户口述全量重做）：组构成＝G1 三场直录；五原型套件重设计；Boss 去镜像改召唤制；
> 敌方护盾持续制（撑过我方回合、于己下次行动时清）；标记集火制（无视嘲讽）；伤害三型意图可辨。
> 数值锚＝《基础规则 v0.8》§11；数值全暂定可调。

## 一、总则

1. **成长竞速**（设计方向）：核心比拼＝双方成长速度；敌方亦随战斗成长（当前实现：成长由回合时钟或自身行动驱动，且经意图提前一拍可见）。
2. **伤害三型**：敌方行动分**攻击伤**（走我方防御：攻击×倍率＋威力缩放）／**功法伤**（无视我方防御：基值＋威力缩放）／**毒**（间接，穿盾穿挡）。意图徽章按型着色：**攻红／法紫／毒毒色**，数值同色。
3. **敌方护盾持续制**：敌方护盾**不随回合末清空**——撑过整个我方回合，于该敌**下次行动开始**才清（蓝本格挡同制；我方护盾仍回合末清）。敌方眩晕同理＝跳过一次行动即消耗。
4. **标记集火制**：我方器灵被标记时，敌方攻击类伤害**优先命中被标记者，且无视嘲讽**（优先级：标记 → 嘲讽 → 随机）；意图目标预览同口径。
5. **行动池**：等权随机、同行动不连用三次、带冷却按冷却、Boss 按形态过滤池；行动数值吃属性缩放（力量层抬攻击、强度层抬威力）。
6. **两仪解锁**：G1 第 3 场（两仪剑主）胜利 → 两仪刀剑直接入后备＋跨局解锁（存档元数据，弃档不清）；未解锁局不进「新增器灵」池。

## 二、辅助类两分（2026-10-28 用户口径）

辅助型单位分两种构型：**效果跟自身**（自养成长，如凝神涨强度）与**效果跟其他人**（养队/干扰，如授刃/封穴咒）。
