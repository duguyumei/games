# 连击与「式」改版提案（v0.1）

> 2026-11-08 起草。**提案，未落地**——按《AGENTS》口述为准制，须用户确认后才会进代码与《基础规则》。
> 起因：现役连击只有「耗式牌」才涨，功能牌吃不到连击，出现"哪些牌参与连击"这类记忆负担；而直接照抄原版（每张都涨）又会丢掉「式」这个差异化设计。

## 一、核心改动：式＝当前架势（状态），不是资源

| | 现役（资源制） | 提案（状态制） |
|---|---|---|
| 「式」是什么 | 攒在身上的层数（斩式 ×3） | **你此刻处于哪一式**（斩／刺／撩） |
| 怎么变 | 出牌攒、耗式牌消耗 | 打某式的牌 → **进入该式**；不打就保持 |
| 连击 | 只有耗式牌涨；不耗式的按实付气磨损 | **同式连打就涨；换式断链**；功能牌不涨不断 |
| 气费折扣 | 耗 1 式抵 1 气（软折扣） | **取消**，气费回归固定值 |

一句话：**式不再攒也不再耗，它只是「这一路招式」的当前状态；一直走同一路，连击就长。**

## 二、卡牌只有四类：三型 + 变招

2026-11-08 用户裁定：**全项目所有卡牌都落在这四类之内**。

| 类 | 说明 | 色标 |
|---|---|---|
| **短剑** | 轻、快、连击向（现命名示例：鱼肠剑） | 蓝 |
| **长剑** | 长、控场/架式向（现命名示例：工布剑） | 墨 |
| **巨剑** | 重、破防/守势向（现命名示例：巨阙剑） | 红 |
| **变招** | 标记类：不锁定剑型，照常 +1，让下一张牌接上链 | 金 |

- 〔鱼肠／工布／巨阙＝当前命名示例；正式名与它们各自的额外效果，归**武器层**，见下〕
- **变招是稀有标记**，不是效果牌的默认（2026-11-08 用户裁定：把变招当通用"太廉价"）

### 分层：卡牌只记「型」，不记「哪把剑」

| 层 | 记什么 |
|---|---|
| **卡牌** | 只记剑型（短剑／长剑／巨剑）或带「变招」标记 |
| **武器层**（后续系统） | 决定这一型当前用哪把具名剑（鱼肠／工布／巨阙或其他）、它的立绘与额外效果 |

这样将来出武器系统时：**换武器＝换名字/立绘/附加效果，卡牌分类与连击规则一行都不用改。**

## 三、连击规则（完整表）

定义：

- 回合开始时 **连击 = 0**，当前剑型 = 无
- **每打出一张牌，连击 +1**（**变招也算 +1**，不只是桥）
- **结算倍率 = 连击**（线性）

| 打的牌 | 连击 | 说明 |
|---|---|---|
| 短剑 → 短剑 | 1 → 2 | 同剑续链 |
| 短剑 → 巨剑 | 1 → **1** | 硬换剑＝断链，从 1 重开 |
| 短剑 → **变招** | 1 → **2** | 变招照常 +1，**且不锁定剑型** |
| …变招 → 巨剑 | 2 → **3** | 变招之后打巨阙，链**不断**，接成巨阙链 |

举例：

```
短剑 → 短剑 → 变招 → 巨阙     连击 1 → 2 → 3 → 4   ✅ 变招换路不掉链
短剑 → 短剑 → 巨阙            连击 1 → 2 → 1       ❌ 硬换剑断链
```

**一句话：三型定链，变招换路；同型续、异型断、变招不散且照涨。**

## 四、影响面（2026-11-08 用户裁定后）

**数值与气费一律不动。** 本提案只改「连击怎么涨」和「式是什么」，不改任何卡的费用与伤害。

| 项 | 处理 |
|---|---|
| 气费体系 | **不改**——取消「耗式抵气」后，卡面费用维持现值，不做重标 |
| 数值 | **不改**——连击倍率**线性 ×N**（连击 n → 乘以 n），沿用现有倍率通道，不新增/不重调基数 |
| 卡面文本 | 需要改：凡写「耗式／得式／攒式」的描述要换成「进入某式」的表述 |
| 战斗结算 | 需要改：`combo_count` 的涨法、取消「按实付气磨损」、取消 `_need_stance` 的降费 |

## 五、式不做「门槛」，只做「触发条件」

2026-11-08 用户裁定：**不做「某些牌只在某式下才能打」**——那等于除费之外又加一道限制。
式只作为**状态**，用于触发**额外效果**（抽牌／回气／减费／加伤之类），不用于卡「能不能打」。

例：某张奇窍写「处于撩式时：抽 1 张」；某张刺牌写「延续刺式时：回 1 气」。

## 六、表现侧（美术线可独立先做）

- 连击徽：显示「式色 + 连击数」；换式断链时给一次短促的断裂反馈；通用牌结算时徽记闪一下但数字不动
- 卡面：四脉色标（斩红／刺蓝／撩墨／通用灰）
- 伤害预览：按新的连击倍率显示，通用牌按当前连击
