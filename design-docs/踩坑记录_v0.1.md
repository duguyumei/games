# 踩坑记录 v0.1（2026-11-05）

## 1. 按钮“不居中”反复错
- 现象：按钮文字在护手槽里总是偏下，调位置也修不好。
- 根因：**文字是在按钮矩形里居中的**。按钮矩形（44px 高）比护手**镂空**（约 35px 高）大，
  文字按矩形中心排，就落在镂空中心下方；只改矩形位置（top/bottom 一起平移）不解决，
  因为矩形比洞高，无论怎么移都不对齐。
- 正确做法：**按钮矩形 = 可见镂空本身**（本例 267–406 × 827–857），文字自然落在洞心。
- 教训：嵌槽的控件要按“**洞**”定尺寸，不是按“**外框/带**”定尺寸。

## 2. 场景 .tscn 改动后解析失败
- 现象：Godot 起不来 / 卡住，日志报 `Parse error [Resource file ...tscn:NNN]`。
- 根因：①`ExtResource("xx")` 用了未声明的 id；②节点块之间缺空行。
- 教训：手改 tscn 后必查——每个 `ExtResource` 有对应 `[ext_resource]`、每个 `[node]` 前有空行。

## 3. 资源改了游戏里没变
- 根因：贴图走 `.import` 时，覆盖 PNG 不会自动重导入。
- 做法：改图后跑一次 `godot --headless --import`；或走运行时 `Image.load_from_file`。

## 4. “牌堆被切”误判
- 根因：用旧配置（堆高 92、数字在下）的结论推断新状态，没复测。
- 教训：位置/裁切类结论必须**看当前截图或量像素**，不能凭历史配置推断。

## 5. 改 tscn 字体不生效
- 现象：把卡堆数字的 `theme_override_font_sizes/font_size` 从 22 改到 68/110，截图完全没变。
- 根因：**运行时代码又覆盖了一遍**——`QiVcCabinet.gd` 里 `QISTYLE.font(c, 22, true)` 给 DrawCount/DiscardCount 统一设字，tscn 的值被盖掉。
- 教训：改样式不生效时，先搜同名节点在代码里的 `QISTYLE.font/text_color` 覆盖点；**tscn 与代码两处都要改**，或把代码改成读 tscn。

## 6. 手改 tscn 的重复属性
- 现象：块里出现两组 `layout_mode/offset_*`，解析或取值异常。
- 根因：正则只替换了块头一部分，旧块尾巴留在后面，后写的重复键生效。
- 教训：改节点一律**整块替换**（从 `[node` 到下一个 `[node`），改完 grep 一遍重复键。

## 7. 气珠轨道与吸入（2026-11-06，一整轮返工换来的）

### 7.1 「闪一下」的三种真因（都踩过）
- **层级掉档**：飞行粒子挂在屏幕根（z 0）下设 91 → 绝对 91；并入后挂到轨道（z 66）下设 2 → 绝对 68。并入那一帧整颗往下掉 23 层。
  - 教训：**跨父节点交接时，按「绝对层级」对齐**，不要按子节点 z 值对齐。
- **透明度清零**：飞行段透明度走 `sin(t·π)`，终帧正好为 0；并入后有一段「落位」期跳过了透明度更新，于是 0 一直挂着 → 看起来是「飞进去然后消失」。
  - 教训：接管期也要每帧维护可见属性，别只维护位置。
- **拖尾滞留**：到站后拖尾还保留 0.12 秒（点已不再更新，是一条定住的亮线）。
  - 教训：拖尾透明度要在行程末尾就收到 0。

### 7.2 「吸附感 / 停顿感」的真因
- 末段**径向**插进环 → 速度方向指圆心，而轨道是切线，差 90°，并入必然改向。
- 修法：**捕获螺旋**（一个函数，不是拼接）
  `f(θ) = 1 + (f0−1)(1−u)²`，`f` 是相对轨道半径的倍数
  - `f ≥ 1` 恒在环外；`f'(u=1)=0` → 接点切线＝轨道切线（C1，无折角）
  - θ 单调递增 → 全程顺时针（用 `wrapf(..., 0, TAU)` 保证，别用 `-PI..PI`）
  - `θ > θ₁` 直接取 `f=1`，自然等于环绕轨道本身（末半圈完全重合）
- 速度也要对齐：飞行时长按**路径长度自适应**（`dur = len/760`），末端速度＝轨道线速度（`SPIN × 70px`），用三次多项式 `p(u)` 锁两端速度。

### 7.3 跨度太短的「钩子」
- 半径从 4.6 倍收到 1 倍，若只给 30° 角度行程，曲率半径会掉到 **3px**（肉眼就是折角）。
- 教训：**跨度 < 120° 就加整圈**（`span += 2π`），把收缩摊到更长角度；120° 时曲率半径约 30px，200° 约 39px。

### 7.4 不重叠
- 「按角度排序后重排槽位」会因 0/2π 接缝错位而横穿（看起来逆行/重叠）→ 改为**邻居间距松弛**：`spd = V_NORMAL − (gap_behind − gap_ahead)·GAIN`。
  - 符号别写反：后面空得多要**减速**等人（写成加速会正反馈聚堆，实测 `2.44,2.44,2.44`）。
- 只许减速（`V_MAX = V_NORMAL`）时收敛较慢；把「最慢」抬太高会显得卡住。
- 最后一道保险：每帧把速度钳到 `(gap_ahead − MIN_GAP)/delta` 以内。

### 7.5 其他
- `for k in 1..12:` 不是合法区间，GDScript 要用 `range(1, 13)`。
- 飞行终点**不要加随机抖动**，否则并入时会有一两像素的位移。
- 速度变化本身也要平滑（`lerp(prev, target, delta*5)`），否则「速度突变」看着像「位置跳」。
