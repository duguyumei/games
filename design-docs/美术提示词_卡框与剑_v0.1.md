# 美术提示词：卡框 + 左右剑（v0.1）

> 2026-11-08 立。**格式规则（用户多次强调）**：①一条用途＝**一条提示词**，不要把四种拆成四段；②提示词给**完整可复制的整段**，不拆「基础＋变体」让人自己拼。

## 一、卡框（一条，一次出四款）

```
中国水墨武侠卡牌游戏 UI 素材，宣纸质感，毛笔笔触，墨色浓淡自然，留白讲究，边缘有飞白枯笔；纯卡牌外框，无文字无人物无场景；背景完全透明；四边宽度均匀、中心区域留空可拉伸（九宫格用），线条闭合、四角完整、装饰不出界；边框统一金线（金色描边，与现役卡面一致），除金色外不施其它彩色；同一套风格出四款花纹不同的外框：一款轻快纤细、一款笔锋绵长带锋、一款厚重飞白墨块压角、一款笔断意连留白多；四款并排看要能一眼区分，但风格是一家人；高清、边缘锐利、无锯齿。负面：文字、汉字、logo、水印、人物、脸、手、场景、渐变、除金色外的其它彩色、霓虹、3D 渲染、写实照片、噪点、锯齿、边框断裂、装饰出界、中心有图案。
```

## 二、左右剑（一条，一次出四柄）

```
中国水墨武侠游戏 HUD 道具，同一套风格出四柄：短剑（轻短）、长剑（细长带锋）、巨剑（宽厚重心低）、断刃（缺一段留缺口）；均为侧视剪影，毛笔笔触，墨色单色，剑柄在下剑尖朝上，轮廓清晰可辨；背景完全透明；高清、边缘锐利、无锯齿。负面：文字、logo、水印、人物、手、场景、彩色、霓虹、3D 渲染、写实照片、装饰花纹堆砌、模糊。
```

## 三、出图规格

| 项 | 要求 |
|---|---|
| 卡框尺寸 | 1024×1536（与 216:304 同比例），后期缩到 256×360 |
| 九宫格边距 | 成品尺寸下 26px |
| 背景 | 必须透明；白底要抠图 |
| 入仓 | 卡框 → `qiforge/assets/card_frames/`；剑 → `qiforge/assets/hud/` |

## 四、迭代

- 中心被画满 → 加重「中心区域留空可拉伸」
- 上了别的色 → 加重「除金色外的其它彩色」
