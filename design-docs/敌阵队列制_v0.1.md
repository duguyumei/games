## 三原则（原文）

1. **同时，只有最前面那一排会行动。**
2. **替补过来的会跳过这一次行动。**
3. **前排敌人死亡后，后排的非精英敌人会替补（顺位上来）；精英敌人会占据整个一排。**
   （精英敌人后批实装，本轮只留位。）

## 术语与语义

- **排（row）**：横向并排的若干敌人＝一排；排与排纵深排列（后排在前排身后，压暗错位）。
  一排可 1~N 人，排内全员并排、全部行动（都是前排时）。
- **前排**：`row == 0` 的排。**敌方回合只结算前排的意图**——后排不掷结算、不显示意图、
  不进合击预估（「校验只校验前排的」）；后排不管玩家做什么都不会行动。
- **顶替（2026-11-07 终裁修正：死一个就替补一个）**：前排每死一人 → 紧邻后排**最左存活者**
  立即顶上前排（row=0）——前排始终保持满员（有后排时）；顶上来的那个 `skip=1`
  （跳过当次敌方行动，原则②）；后排其余原地不动。一次范围杀前排两个＝后排顺位顶两个。
  后排耗尽后前排死几个少几个。
- **替补/补位入场**（refill、遭遇池轮换）：新敌排到**最后排之后**（候补队列尾），轮到
  顶上时同样适用原则 2 跳过一次。
- **我方攻击目标**：front＝最前排最左存活敌（逐个击破）；all 类范围＝全场（含后排）。

## 数据结构

- 编队嵌套＝排：`group = [[a, b], [c, d]]`＝前排 a,b／后排 c,d（index 0 为前排）；
  平铺 `[a, b]`＝一排（全前排，行为同旧制——非教程遭遇兼容）。
- 敌字段 `row`（0＝最前）；顶替＝全体 row −1。

## 显示

- 每排横排居中（按本排人数取宽）；纵深排错位压暗（row 越深越暗、z 越低）。
- 后排无意图显示（无类型无数字无光带）；顶替上来那排跳过的回合同样无意图。

## 教程层编队（2026-11-07 定）

从下往上：第一场＝一排 1 → 第二场＝**一排 3** → **宝箱**（内容物＝内功「连击堆叠」——连击
靠宝物解锁，开局不带）→ 第三场＝**一排 5** → 出口。
