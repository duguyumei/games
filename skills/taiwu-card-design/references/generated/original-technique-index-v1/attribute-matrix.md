## 4. 使用边界

- 本表适合发现差异、选择后续精读样本，不直接生成属性特点。
- 同一功法可以命中多个关键词标签。
- “恢复”可能指恢复资源、伤势或距离，需要回到索引中的正逆练原文确认。
- 原作混元必须逐门重新归类；在此之前，五属性结论只覆盖原生属性样本。
