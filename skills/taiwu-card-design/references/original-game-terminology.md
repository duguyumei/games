# 原作术语与反编译证据记录

更新时间：2026-07-27

本文件用于保存原作术语的准确含义与证据，避免后续重复查询或反编译。用户已经提供的具名功法正逆练正文不在此重复抄录；本文件只解释影响卡牌转译的术语。

## 记录要求

每条反编译结论必须包含：

```text
术语
准确语义或公式
游戏buildid
程序集、配置表、类型或方法
证据摘要
记录日期
对当前卡牌转译的影响
```

没有buildid或具体证据位置的推测不得标为“已反编译确认”。百晓册证据与反编译证据分开记录。
