# 当前功法卡面语言与字段

更新时间：2026-07-31

本文件只定义卡面字段和写作规范。战斗时序、距离、资源、运行栏和事件语义以项目中的`combat-foundation-final-v1.md`与`combat-events-v0.1.md`为准；费用、关键词和转译规则见`technique-foundation-v0.1.md`。

## 1. 当前类型

| 类型 | 设计职责 |
| --- | --- |
| 催破 | 起手、蓄式、待发动并造成主要攻击结果 |
| 护体 | 运行型进入护体栏持续防御；一次型获得护盾并在结算后弃置 |
| 轻灵 | 运行型进入轻灵栏并决定行步或跳步；一次型结算后弃置，可以提供功法移动或短时效果 |
| 奇窍 | 进入奇窍栏持续监听或登记一次性隐藏效果 |
| 行为 | 普攻以外的角色主动行为，不进入运行功法栏 |
| 同伴 | 独立支援行为或响应，不等同角色移动 |
| 内功 | 决定主修或辅运规则，并提供自身属性联动与常驻被动 |

不要使用旧`武技、轻功、心法`分类替代当前正式类型。

## 2. 通用字段

每张功法按需要记录：

```text
名称
类型
属性
品级
所属门派（隐藏元数据）
标签（隐藏元数据）
基础耗内力
最终费用上下限
所用兵器或兵器门类
基础命中
基础威力
优势部位
目标与目标部位
进入的运行栏
思绪窗口
运行功法窗口
监听事件ID
before/main/after允许行为
次数限制
持续或结束条件
正常结束、主动结束、替换、破坏、弃置与移出战斗去向
正式能力文本
设计目的与风险
```

没有意义的字段省略，不用空值填满卡面。

### 隐藏门派与标签元数据

- 每张具名功法必须在设计记录与结构化数据中保存`所属门派`；该字段默认不显示在玩家可见卡面。
- `标签`用于构筑筛选、内容检索及明确指定标签的规则；没有标签时可以省略，不填写空值。
- 隐藏标签本身不产生战斗效果。只有规则正文明确读取某个标签时，该标签才参与结算。
- 所属门派与标签不得替代卡面必须公开的属性、类型、兵器门类、费用或效果条件。
- 铸剑山庄的所有内功自动记录`标签：解封`。
- 铸剑山庄所有兵器门类为`剑法、刀法、长兵`的功法自动记录`标签：解封`；其他门类不因所属铸剑山庄而自动获得该标签。

## 3. 类型专属字段

### 催破

至少写清所用兵器或兵器门类、式需求、基础发动时间、基础命中、基础威力、目标部位、优势部位、发动内力和发动效果。武器只提供自己的优势距离，同一武器下的催破不另设距离身份。额外说明起手、式满、待发动、发动前、命中后或结算后的特效时点。

多段催破的基础威力是整张功法的总预算，不能让每段重复使用完整威力。

同时比较命中与威力时使用`初始命中`和`初始威力`，在发动前改写后再分别计算，不写成最终数值回溯。

自动运行其他催破统一写`无消耗运行`，并紧接写明候选牌区、品级或门类筛选、目标部位、本次发动时间修正与最低值。该词表示跳过起手和蓄式、直接进入待发动阶段，不默认免除发动内力。

### 护体

运行型护体至少写清启动内力、持续时间、护体值或闪避、防御内容、运行时效果和正常结束效果。破坏与替换默认不触发正常结束收益；被封禁时持续时间仍减少，但卡面结束收益无效。

一次型护体至少写清施展内力、基础护盾、即时效果与结算后去向。它不进入或替换护体栏，没有持续时间，也不提供持续护体值、闪避、反震或固定减伤；结算后进入弃牌堆。所有来源的护盾直接相加，回合结束最后统一清零。

### 轻灵

运行型轻灵至少写清启动内力、移动类型（行步或跳步）、持续时间、每回合功法移动次数、命中加值或闪避、运行时效果和正常结束效果。命中型与闪避型默认互斥；只有明确标记的特殊综合型可以同时提供两者。功法移动必须说明发放时点、绑定思绪与方向；同一思绪可以同时包含多次功法移动和行为移动。轻灵作为本回合任一次实际移动的移动类型来源时，持续时间减少2，否则减少1，同回合多次移动仍只减少2。

一次型轻灵至少写清施展内力、功法移动次数、一次效果与结算后去向。它不进入轻灵栏，没有持续时间，不提供常驻命中或闪避；功法移动使用当前运行轻灵的移动类型，没有运行轻灵时默认为行步。卡牌结算后进入弃牌堆，不替换运行中的轻灵。

当前不存在统一追加投入并按比例放大功法数值的通用机制。只有卡面明确写出的独立“额外支付内力”才产生该卡指定的效果；额外支付不是基础费用字段，也不自动放大命中、威力、护体、闪避、护盾或持续时间。

### 奇窍

持续型奇窍没有通用生命值和持续时间；写清运行栏、周期效果或监听事件，以及明确的破坏、弃置、替换条件。触发型奇窍写清隐藏登记、触发事件、公开与消耗方式。

一次型奇窍写清启动内力与即时效果；结算后进入弃牌堆，不进入或替换奇窍栏。触发型一次性奇窍运起后进入奇窍栏并登记一次触发；触发后进入弃牌堆，未触发前仍按运行奇窍处理。

卡组中的奇窍若具有战斗开始效果，必须把该段与运起后的监听分开写，不能让未抽到的卡牌提前获得其他运行能力。

### 行为与同伴

写清所属思绪层、对象、是否消耗、公开时点和完成后的去向。所有行为牌的基础耗内力固定为0，使用行为牌及其卡面主体均不要求支付内力；行为牌不写正数耗内力，也不受功法费用增减影响。同伴造成距离变化时使用距离调整语义，不写成角色移动。临时同伴只使用一次时写`使用后移出本场战斗`。

通用行为牌`疗伤`统一写作：

```text
疗伤｜行为｜耗内力0
恢复相当于最大生命30%的生命，使用round_half_up取整。
使用后移出本场战斗。
```

通用行为`化气`统一写作：

```text
化气｜行为｜耗内力5
规划时选择一路真气。若该路尚未达到上限且能够支付5点内力，支付5点内力，获得1点所选真气。
```

由功法授予的催破强化行为统一使用以下句式，不写“发动前可以临时选择”或自动支付：

```text
规划此行为时，选择一张已经起手且尚未发动的我方催破。
结算此行为时，若该催破仍已起手且尚未发动，……；否则，此行为落空且不支付资源。
```

催破强化行为占用一个完整思绪，选择锁定到具体催破实例，不得在结算时改选。本回合内才起手的催破不能成为该回合强化行为的目标。强化初始命中或初始威力时必须写明对应层级；支付失败、目标提前离场及强化后的持续时点必须写清。

以支付轻灵真气来扩大已起手催破攻击范围的强化统一写作`注气`，不附带模式选择：

```text
你获得“注气”催破强化行为。
规划此行为时，选择一张已经起手且尚未发动的我方催破。
结算此行为时，若该催破仍已起手且尚未发动，支付X点轻灵真气；该催破本次攻击范围扩大Y档。
```

除非卡面明确例外，同一来源不能对同一张催破重复注气。注气不是行为牌，仍占用完整思绪并按卡面支付真气。

使部位状态等级效果无效统一写作“我方所有部位的二级伤势效果无效”等明确句式；它不移除标记、不降低等级、不阻止继续累积，也不影响未被写出的其他等级效果。

### 内功

至少写清属性、品级、主修生命加成、最终生命、主修气海值、未计周天最大内力、初始催破/护体/轻灵/奇窍真气、主修核心规则、辅运被动规则和周天属性。四路初始真气按该品级总量分配，并固定按`催破/护体/轻灵/奇窍`顺序展示。`最终生命 = 人物基础生命30 + 当前主修内功的生命加成`；卡面直接记录该内功调整后的生命加成，不另写“个体修正”。每种内力属性只有一套共享的三段周天进度、倍率与额外效果，不为每门内功分别设计。内功没有独立生命值或战斗启动耗内；辅运不提供生命、气海、周天或初始真气。已学会功法一律不因属性受构筑或使用限制；属性只用于卡面明确的属性联动及奖励池倾向。不得把原作属性内力转换翻译为功法属性转换、跨属性构筑许可或使用资格。

旧版引诀依赖抽牌顺序，在无手牌体系中已经废弃。具名内功若保留引诀主题，必须重制为不依赖手牌与牌堆的新效果，不得沿用旧模板。

### 真气文本

- 增加当前值写`获得X点催破/护体/轻灵/奇窍真气`；允许穿过0降低时写`失去X点……真气`。
- 作为费用且不能进入负数时写`支付X点……真气`或`消耗X点……真气`，并写清支付失败后主体是否取消。
- 从敌人转到自己时写`吸取X点……真气`；目标单独损失且自己独立获得时必须拆成两句，不能写成吸取。
- 设为0写`将……真气归零`；临时、静默、恢复至初始值、倍增、减半和改变自然运转时必须明确写出来源、时点、持续与是否触发真气增减效果。
- 卡面明确支付真气强化某门功法属于该卡独立效果，不得使用已经废弃的通用资源加投术语，也不授予其他功法相同权限。

## 4. 正式文本

- 固定次数写作：`一回合一次，当……时，……`
- 固定时点直接写：`战斗开始时`、`回合开始时`、`思绪结束后`、`运行时`、`正常结束时`。
- 授予通用反击能力写`运行期间可以反击`。额外强化分别写在`反击前`或`反击命中后`，不要重复抄写通用反击触发条件。
- 一次型护体统一写`获得X点护盾`。护盾默认直接相加并在回合结束最后清零，不写同名不可叠加、刷新或独立持续时间。
- 区分`运起时`、`运行期间`、`运行时`、`发动前`、`发动时`和`结算后`，不要混用。
- 取消单个主体写`使该效果无效`；持续失效使用`封禁`。封禁运行功法时使其占栏但效果无效；封禁非运行卡牌时使该牌在手牌中不能使用，且仅在位于手牌的回合结束时减少持续时间。被封禁卡牌若将因非破坏效果进入弃牌堆，改为将该牌自身置入拥有者手牌，不额外抽牌；破坏与移出本场战斗不受影响。只有卡面明写`不可避免地封禁本功法X回合，且无论所在牌区都正常减少`时，才跳过封禁阻止与牌区暂停规则。
- 强制支付写`若……且能够支付X点内力，则自动支付……`；条件不满足时不触发，也不消耗次数或层数。
- 修改费用写清基础值、持续范围和叠加；最终启动或发动费用限制在`1至基础耗内力的两倍`。
- `威力`仅指护体递减前的威力计算；护体递减后的数值写`直接伤害`；真气与破绽结算后的数值写`最终直接伤害`。卡面必须按实际修改阶段选词，不得以“增威”指代伤害加值。
- 百分比必须写明其作用层级与对象，例如“本次攻击的初始威力翻倍”或“本次攻击造成的最终直接伤害×1.25”；不得仅写“伤害提高25%”。
- 反震统一写`对攻击者造成等于本次实际受到伤害X%的反震伤害`。“实际受到伤害”指护盾吸收后的实际生命损失`actual_hp_loss`，不是护盾前的最终直接伤害；不得简写为“反震最终伤害”。
- 命中结果统一使用`未被化解`、`部分化解`与`闪避`三档；部分化解与闪避均为“被化解”，其中闪避是特殊化解。卡面写`本次攻击无法被化解`，不写“强制完美命中”；该效果只决定命中结果，其他附带后果必须另写。
- 每门具名功法只对应一张功法卡，不使用已废弃的“效果唯一”字段；“唯一功法”只表示特殊品级。
- 数值默认使用`round_half_up`，只在完整公式结束后取整，除非规则明确例外。
- 由功法提供的角色主动移动统一写`功法移动`；`行步`与`跳步`只表示当前运行轻灵决定的结算方式。行为自身提供的移动写`行为移动`；非角色来源只写`使距离前进/后退X档`。
- 写清`一层`、`一种`、`一个标记`和`一级`，不要相互替代。
- 失神不是标记；正式文本统一写`获得X层失神`、`移除X层失神`和`失神层数`，不写“失神标记”。
- 卡面只描述玩家需要知道的结果；事件ID和调试字段放在结构化数据或设计记录中。

## 5. 原子与钩子检查

设计每个效果时确认：

1. 原子在哪个窗口锁定。
2. 哪些`before`钩子可以修改、取消或使其无效。
3. 主体开始前是否需要重新检查目标和支付。
4. `main`完成后发送哪些`after`事件。
5. 来源被破坏或封禁后，已锁定原子是否仍按通用规则完成。
6. 战斗开始效果是否错误激活了卡牌其他能力。
7. 是否会与同名效果、双方同窗效果或响应链形成无限循环。

## 6. 交付检查

- 卡面身份是否清楚，不依赖隐藏底层知识。
- 距离、部位、先机、发动时间和式是否各司其职。
- 周期效果是否明确属于运行功法窗口。
- 主动结束、正常结束、替换、破坏、弃置和移出战斗是否混淆。
- 是否产生无代价循环、绝对必带或无法响应的锁死。
- 测试值是否明确标记，未确认规则是否仍停留在提案状态。
