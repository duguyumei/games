# 璇女派三品功法池 v0.1

更新时间：2026-07-29  
状态：三品轻灵、护体与奇窍玩法结构已确认；所有具体数值均为测试值

## 1. 共同口径

- 本批原作九、八、七品功法在当前体系中均为`三品（1级）`，基础启动耗内力依次使用`3/4/5`。
- 本批功法的当前属性为`玄阴`；每门功法保存隐藏元数据`所属门派：璇女派`，不显示在玩家卡面。
- 运行型轻灵只在运起时支付启动内力，不支付维持费用；持续时间按现行轻灵通用规则减少。
- 本批不使用旧格位、对位、脚力、气、起手式、瞬发或唯一标签。琴类兵器使用当前武器规则中的`琴`门类。
- 命中、闪避、持续时间、功法移动、费用、累计次数与失神数量均为测试值。

## 3. 轻灵

### 梅点头

```text
类型：运行型轻灵·命中型
所属门派：璇女派
标签：琴、持续
属性：玄阴
品级：三品
启动耗内：3（测试值）
移动类型：行步
持续时间：6回合（测试值）
命中：+2（测试值）
每回合功法移动：1

回合结束时，若你本回合曾以琴类兵器命中敌人，本功法持续时间+1，最多恢复至6回合。
```

同一回合命中多次仍只恢复1点持续时间。先执行轻灵通用持续时间扣减，再结算本效果；因此使用本功法提供的移动时，本回合净减少1点持续时间，未使用移动时可以维持运行。

### 上玉阁

```text
类型：运行型轻灵·特殊综合型
所属门派：璇女派
标签：命中、闪避
属性：玄阴
品级：三品
启动耗内：4（测试值）
移动类型：行步
持续时间：5回合（测试值）
命中：+1（测试值）
闪避：2（测试值）
每回合功法移动：1
```

原作以一项命中或化解补充其他分项；当前不保留多套命中属性，改为同品低档的特殊综合型轻灵。它不读取其他轻灵数量，也不建立旧格位联动。

### 别离步

```text
类型：运行型轻灵·命中型
所属门派：璇女派
标签：失神、连续命中
属性：玄阴
品级：三品
启动耗内：5（测试值）
移动类型：行步
持续时间：5回合（测试值）
命中：+2（测试值）
每回合功法移动：2

运行期间，你的兵器攻击每累计命中敌人3次，使敌方获得3层失神。
本功法离场时，清除不足3次的累计记录。
```

未被化解与部分化解均属于命中；闪避不累计。一次兵器攻击无论包含多少段或命中多少部位都只累计1次。达到3次后立即清零并重新累计。

## 4. 护体

### 精卫填海式

```text
类型：一次型护体
所属门派：璇女派
标签：失神、无式
属性：玄阴
品级：三品
施展耗内：4（测试值）
基础护盾：6（测试值）

使敌方获得3层失神和2个无式。
获得6点护盾。

结算后本卡进入弃牌堆，不进入或替换护体栏。
```

失神与无式分别按各自的状态、余式盘规则处理；敌方余式盘满时，无式正常参与余式盘溢出替换。

## 5. 奇窍

### 冰清玉洁

```text
类型：一次型奇窍
所属门派：璇女派
标签：失神、功法强化
属性：玄阴
品级：三品
启动耗内：3（测试值）

本回合，你的功法使敌方获得失神时，
该次获得的失神层数×1.2，使用round_half_up取整。

结算后本卡进入弃牌堆，不进入或替换奇窍栏。
```

只有由我方功法直接产生的失神增加获得强化；普攻特性、同伴、其他状态及敌方自身来源不受影响。同一回合可以强化多次功法失神，回合结束时该效果失效。

### 墨玉功

```text
类型：持续型奇窍
所属门派：璇女派
标签：失神、恢复
属性：玄阴
品级：三品
启动耗内：5（测试值）

回合结束时，我方失神自然消退后，额外移除1层失神。
```

我方没有失神时效果落空；敌方失神的自然消退不受影响。

## 6. 事件与实现依赖

- 梅点头在琴类兵器的`attack_hit_result_after`记录本回合命中标记；轻灵运行窗口的`agility_duration_decay`完成后，在`round_end`使持续时间恢复1，且不超过6。
- 上玉阁的命中与闪避分别进入`attack_accuracy`的攻击方固定命中加值和防守方固定闪避来源；它是卡面明确的特殊综合型例外。
- 别离步在每次兵器攻击的`attack_hit_result_after`按攻击原子累计，而不是按伤害段累计。每达到3次，通过状态变化入口增加3层失神，并立即发送`defeat_check`。
- 冰清玉洁在自身`card_effect`中登记至本回合结束的功法失神倍率；符合条件的失神变化在`before`窗口将请求量乘1.2，并在完整公式末`round_half_up`。卡牌主体结算后立即进入弃牌堆，倍率记录独立保留至回合结束。
- 墨玉功在我方`round_end`的失神自然消退完成后额外移除1层失神；两次变化分别发送失神变化与战败检查。


## 6. 测试观察
- 精卫填海式在一次型护体的功法原子中先施加3个失神、再加入2个无式、最后获得6点护盾；测试敌方余式盘已有特殊式时的溢出顺序与蓄式压制强度。

- 梅点头与虎丘试剑、风火真形诀同属武器命中维持轻灵，但门类、品级、命中或闪避类型与每回合移动不同；测试时比较其实际维持率和武器绑定代价。
- 别离步同时取得三品命中加值、2次功法移动和失神压缩，应重点记录触发所需回合、反击或追加攻击带来的累计速度，以及失神自然消退后的实际净收益。
- 冰清玉洁使用百分比放大本回合功法失神，1层失神经取整后仍为1层；测试时重点比较同回合多次3层及以上失神来源，避免形成过高的集中爆发。
- 墨玉功令我方每回合最多自然减少2层失神，测试其对低频失神敌人的针对强度。
