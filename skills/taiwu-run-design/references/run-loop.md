# PVE单局流程

更新时间：2026-07-20  
状态：总体方向已确认；节点数量与奖励比例待定

## 核心结构

- 游戏优先制作PVE，单场战斗保持1对1。
- 构筑分为`永久收藏 -> 本局功法库 -> 当前战斗卡组`三层。
- 战斗奖励进入本局功法库，不强制直接塞入当前卡组。
- 只在修习节点或击败剑冢后更换内功、武器和卡组；战斗中构筑固定。
- 剑冢是主要Boss，顺序具有随机性；具体Boss机制不在本文维护。

## 开局

1. 选择一种内力属性及该属性的一门三品主内功。
2. 选择一把兼容武器。
3. 获得一组基础卡牌与一个起始功法传承。
4. 进入第一阶段地图；基础卡组、生命与手牌上限由装备内功共同确定。

## 阶段成长

- 击败剑冢后，从`开辟新属性`与`精研已有属性`中选择。
- 开辟新属性：获得该属性三品内功，开放对应三品奖励。
- 精研已有属性：提高该属性奖励品级上限，并获得新开放品级的一门内功；旧内功不升级或消失。
- 最终最多装备3门内功和3把武器，本局功法库可以收藏更多。
- 武器开放武技门类；本局获得的不同同门类武技数量决定后续高品奖励是否出现。

## 节点职责

| 节点 | 主要产出 |
| --- | --- |
| 普通战斗 | 常规卡牌、少量资源 |
| 精英战斗 | 构筑核心、强物品或高品候选 |
| 事件 | 带条件的转型、代价与长期结果 |
| 修习 | 调整卡组、内功与武器 |
| 剑冢 | 阶段解锁与主要成长选择 |
