# 内功与局内成长规范v0.1

更新时间：2026-07-20  
状态：基础结构已确认；解锁阈值与具体数值待测试

本文件只维护内功结构与局内解锁。具名功法的卡面效果由独立的 [太吾卡牌设计Skill](../../taiwu-card-design/SKILL.md) 维护。

## 1. 三层构筑

- `永久收藏`：局外已经拥有或解锁的内容。
- `本局功法库`：本次PVE流程获得的内功、武器与功法。
- `当前战斗卡组`：从本局功法库中选择、满足当前装备条件的牌。
- 奖励不强制直接塞入战斗卡组；只在修习节点或剑冢后调整装备与卡组。
- 本局解锁决定奖励可能出现什么；当前装备决定什么能进入战斗卡组；当前卡组内容不参与解锁计数。

## 2. 内功结构

### 已确认

- 内功位于抽牌卡组外，最多装备3门。
- 一品最高、二品居中、三品最低。
- 品级是不同内功的固有品级，内功本身不升级。
- 默认取消正练、逆练；只有少量确实形成两种Build的特殊内功才允许二选一。
- 门派取消为机械标签与构筑限制，只保留为资料、名称、美术和世界观出处。
- 原作依赖“本门功法”的内功必须围绕实际机制重做，不能为了保留旧文本重新建立门派限制。

### 当前方向

- 3个装备位暂按1门主内功与2门辅内功组织。
- 每门装备内功只有一个特效，装备后均生效；主内功额外决定当前内力属性等结构信息。
- 同名内功不能重复装备；本局功法库可以收藏超过3门内功。
- 新内功进入本局功法库，不会自动替换当前配置。

## 3. 卡组、生命与手牌上限

- 基础功法卡组张数暂定10。
- 基础最大生命暂定30。
- 基础手牌上限暂定5，绝对上限暂定15。
- 每门内功印有`功法容量`、`生命根基`与`手牌上限`三个数值。

```text
功法卡组准确张数 = 10 + 所有装备内功的功法容量之和
最大生命 = 30 + 所有装备内功的生命根基之和
手牌上限 = 5 + 所有装备内功的手牌上限之和 + 其他效果
```

- 武器提供的普攻属于独立招式牌库，不计入功法卡组张数。
- 更换内功后必须重新调整卡组到准确张数。
- 更换内功不能免费疗伤：`新当前生命=min(旧当前生命, 新最大生命)`。
- 功法容量与生命根基不随品级单调提高；强特效、卡组厚度和生命之间形成取舍。
- 普通内功统一提供手牌上限`+1`，不随品级提高；特殊内功可以用更高数值替换该`+1`。
- 任何效果计算后的手牌上限不能超过绝对上限15。
- 第一轮测试范围：单门内功功法容量`+2至+5`、生命根基`+3至+8`。

## 4. 非摧破合法性

- 非摧破包括护体、轻灵、奇窍等，不分别建立类型解锁等级。
- 非摧破牌记录属性、品级与功法类型；门派不参与规则。
- 当前装备的同属性内功决定非摧破入组品级：三品只许可三品，二品许可二、三品，一品许可全部。
- 本局已经开放某属性的对应品级后，该牌可以在奖励中出现；未装备对应内功则暂留本局功法库。

## 5. 内功与属性解锁：暂定

- 开局选择一个属性并获得该属性的一门三品主内功。
- 击败剑冢后可在两种成长中选择：
  - `开辟新属性`：获得一个未解锁属性的三品内功，开放该属性三品奖励。
  - `精研已有属性`：将一个已解锁属性的奖励上限提高一品，并获得一门新开放品级的内功。
- 原有内功不会因精研而升级或消失。
- 辅内功是否只提供属性许可，还是也改变当前内力属性，仍待确认。

## 6. 摧破解锁：当前推荐，待确认

- 武器决定当前可以使用的摧破门类与普攻式，不直接决定摧破品级。
- 本局获得的不同同门类摧破决定该门类的品级上限；当前卡组是否携带不参与计数。
- 暂定门槛：获得3种不同三品摧破后开放二品奖励；获得3种不同二品摧破后开放一品奖励；重复副本不计数。
- 达到门槛只允许高品摧破出现在后续奖励中，不直接赠送具体牌。
- 摧破入组必须同时满足：装备支持其门类的武器、装备对应属性内功、本局已开放该门类品级。
- 摧破属性只要求属性兼容，不再叠加内功品级门槛，避免双重品级限制。

## 7. 待确认

1. 主内功与辅内功是否需要不同效果强度，还是所有装备内功特效完整生效。
2. 第一、第二辅内功位的具体解锁节点。
3. 功法容量与生命根基的正式数值区间。
4. 基础手牌上限5、每门普通内功`+1`与绝对上限15的正式数值。
5. 属性奖励采用完全随机，还是保证当前配置可用牌与转型牌的固定比例。
6. 摧破造诣门槛采用3种，还是按不同门类牌池规模调整。
