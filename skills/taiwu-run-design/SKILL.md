# 太吾总体流程设计

## 读取

- 讨论一局从开始到结束、节点与奖励节奏时，完整读取 `references/run-loop.md`。
- 讨论内功位、卡组容量、属性/品级/摧破解锁时，完整读取 `references/neigong-run-progression-v0.1.md`。
- 不读取其他太吾 Skill；问题明确跨到卡牌效果、Boss机制或物品内容时再交给对应所有者。

## 边界

- 本 Skill 决定“何时获得、何时能选、何时能改卡组”，不设计奖励卡本身。
- 剑冢在流程中的数量与顺序归这里；剑冢Boss的战斗机制归 `taiwu-boss-design`。
- 物品掉落节奏归这里；具体物品效果归 `taiwu-item-design`。
- 数值以能否形成路线选择、转型窗口与重复游玩为标准，不用稀有度掩盖无选择的奖励。

## 维护

用户确认后，更新对应参考的当前规则、待定项和简短决策记录。不要加载历史总纲。
