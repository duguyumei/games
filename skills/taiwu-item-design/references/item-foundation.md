# 物品设计基础

更新时间：2026-07-20  
状态：武器类别已有战斗规则；具体物品体系待定

## 第一版类别建议

| 类别 | 生命周期 |
| --- | --- |
| 具名武器 | 装备后改变招式牌组成、合法武技或一个专属效果 |
| 护具 | 装备后提供一个防御或状态规则 |
| 消耗品 | 战斗前或规划阶段使用一次 |
| 遗物式物品 | 本局持续生效，通常不进入卡组 |

## 约束

- 物品效果优先改变已有卡牌、资源、奖励或规则，不新增独立物品能量条。
- 具名武器必须继承所属武器类别的距离行和基础招式逻辑；例外写在物品上。
- 消耗品必须写清使用时点、是否占格、是否进入卡组和本场/本局去向。
- 第一版不同时引入耐久、重量、随机词缀与复杂锻造材料。

## 待确认

- 物品品级是否沿用一至三品。
- 物品奖励与卡牌奖励的出现比例。
