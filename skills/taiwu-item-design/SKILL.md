# 太吾物品设计

## 读取

- 完整读取 `references/item-foundation.md`；讨论具体物品类别时再读取对应独立文件。

## 边界

- 武器类别、普攻招式牌库和式的规则归 `taiwu-combat-design`；具体具名武器的效果归这里。
- 物品何时掉落与奖励数量归 `taiwu-run-design`。
- 由物品生成的卡牌文本需要符合 `taiwu-card-design`，但物品本体仍由这里维护。
- 第一版不同时建立装备耐久、重量、品质随机词缀和锻造材料四套经济。

## 维护

每件物品记录类别、槽位、品级、获得途径类别、持续范围、效果和离场方式。用户确认后更新对应参考。
