# 太吾战斗设计

## 当前权威

只使用：

- `godot/docs/combat-foundation-final-v1.md`
- `godot/docs/combat-events-v0.1.md`

`references/core-rules.md`、`combat-core-v0.1.md`、`card-types-v0.1.md`和`slot-resolution-v0.1.md`属于已废弃的旧2×3/六号位原型，不得用于当前规则判断。

## 读取

1. 先用`rg -n '^## |^### '`定位两份当前权威文档的标题。
2. 普通问题只读取相关小节；涉及事件ID、原子顺序、取消、破坏、封禁或回放时，再定点读取事件文档。
3. 出现旧`号位、气、武技、轻功、心法、奇窍生命`术语时，先判断是否为历史残留，不得把旧“气”资源与现行四路真气混同或直接迁入当前规则。
4. 不得因为文件位于同一目录而顺带读取；只打开完成当前任务明确需要的文件。
5. 已标记废弃的文件默认禁止读取。只有用户明确要求迁移、历史考据或版本对照时，才可用`rg`定位并读取必要片段，不得完整通读。
6. 只有问题涉及生命、最大内力、品级费用、命中、威力、护体、闪避或持续时间时，才定点读取`combat-foundation-final-v1.md`第11节的数值护栏。

## 边界

- 本Skill定义通用规则与可用字段，不命名或设计具体功法。
- 具名功法、内功、同伴或行为效果归`taiwu-card-design`。
- 武器普攻通用规则归这里；具名武器物品效果归`taiwu-item-design`。
- 武器实例上的专属配置字段统一称为`铭刻`，不按武器门类拆成“剑铭”或“兵器铭”。
- Boss与敌人必须遵守这里的规则；专属机制归各自内容Skill。
- AI如何选择行动不属于战斗规则。

## 命中与伤害维护口径

- 命中结果固定为三档：`未被化解（H>=E）`、`部分化解（H<E<2H）`、`闪避（E>=2H）`。未被化解与部分化解均为命中；部分化解与闪避均为化解；不再建立“普通命中”或“完美命中”第四类术语。
- `H=E`归入未被化解。部分化解的接触威力为`max(1, P-(E-H))`；闪避不进入护体和伤害流程。
- 卡面“本次攻击无法被化解”对应攻击上下文`forced_undissolved=true`：跳过命中、闪避与化解判定，锁定未被化解与接触威力=最终威力；护体、真气、破绽、最终直接伤害、护盾和战败检查照常进行。其他附带后果不得默认推导。
- 修改数值时严格区分初始威力、护体后直接伤害与最终直接伤害；百分比必须有明确阶段、对象、基准和完整公式后的取整点。命中和闪避只使用固定加减或明确结果例外，不使用百分比乘法。

## 维护

- 结构规则更新`combat-foundation-final-v1.md`；事件ID、原子顺序和回放语义更新`combat-events-v0.1.md`。
- 新规则必须写清时点、费用、对象、次数、持续、去向、同时结算边界以及已锁定原子的处理。
- 数值区间必须标为测试值；不得把平衡项写成冻结结构。
- 每次修改后检查两份文档是否仍残留旧2×3、六号位、气资源、“完美命中”或“普通命中”表述。
