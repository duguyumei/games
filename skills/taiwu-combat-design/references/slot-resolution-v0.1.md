# 站点UI与号位结算规范v0.1

状态：v0.3原型已实现；部分同号位细节待定  
更新时间：2026-07-19

> 本文件记录站点界面、武器招式、气预测、功法停运和1至6号位结算。`prototype/`的v0.2版本已经实现本规范的主流程；其中明确标记的临时算法仍需对局验证，不能把原型数值自动视为最终规则。

## 1. 首页结构

首页暂时只提供三个入口：

1. `卡牌`：查看已拥有或已解锁的卡牌与功法资料。
2. `卡组`：配置内功、武器、功法卡牌及正逆练。
3. `站点`：进入实际对局。

三个入口先保证功能完整，不要求在规则原型阶段制作正式美术。

## 2. 站点界面

### 已确认

- 手机端以竖屏为主要布局；敌我两组两行三列在视觉上镜像拼成三列四行，完整战场、双方核心状态和我方手牌必须在常见手机视口内同时可见，不依赖页面纵向滚动。
- 中部三列四行战场优先占用可用宽度并在剩余高度内垂直居中；左右侧轨只保留必要宽度，不改变六格位置和尺寸基础。
- 左侧纵轨从上到下为`敌方气 -> 敌方式 -> 撤回 -> 我方式 -> 我方气`；右侧纵轨从上到下为`敌方牌堆 -> 敌方状态 -> 确认 -> 我方状态 -> 我方牌堆`。
- 敌我状态逐条竖向排列，不设固定可见数量；渲染层按实际可用高度决定可见项，超出显示区域时在末尾显示省略号。点击状态后再打开完整列表或详情。
- 顶部工具栏左侧只放战斗日志，右侧只放设置，中间留空；回合数和阶段保留在战场中轴。
- 左右纵轨的敌方段和我方段分别使用约`18%`浅灰透明底，中央部位状态带处留出断层，不能形成贯穿敌我的整条灰轨。气和式不再显示“敌气/敌式/我气/我式”文字，由位置表达归属。
- 屏幕最底部只固定己方头像、姓名、装备内功、生命与失神；功法/普攻机会切换改用生命栏边缘的悬浮按钮。
- 敌我入口均显示为`牌堆`；敌方入口只显示抽牌堆数量，我方牌堆为统一入口，点击后弹出功法或普攻机会模式下的抽牌堆与弃牌堆详情。
- 取消独立的底部牌堆/记录工具栏；平行手牌位于我方六格下方，不覆盖场地。手牌容器完全透明，同一张战场背景连续延伸到生命栏上方；空间不足时由生命栏遮住卡牌下部，点击或按住后再把选中牌向上完整抬起。
- 弃牌堆可以查看已经公开的内容；抽牌堆不能泄露牌序。
- 我方手牌始终全部同向平行排列，不使用横向滑动列表；手牌增加或屏幕变窄时保持可读牌宽并自动收紧可见间距、提高重叠，手牌减少时自动展开。
- 功法卡与战斗格使用完全相同的瘦长比例和实际占格尺寸；卡牌进入格子后占满原格，不保留额外内边距或“卡片套卡片”。为增强层次，已占用牌面视觉上浮约`3px`并带实体厚度阴影，但不能挤压相邻格或改变布局。第一版静态布局暂用`5:7`验证，最终比例待确认。
- 当前静态视觉只使用用户提供的同一张暖色荒漠砖面图作为连续底层，不再为十二个站点格加载裁切图片。规则格位置和尺寸优先于原图格线；若两者无法完全吻合，允许视觉格线偏差。参考图只用于确认空间层次，不视为正式美术定稿。
- 手牌卡面必须使用不透明表面；重叠通过位置和层级表达，不能让下层文字透过上层卡牌干扰阅读。
- 出牌以拖动为主要交互：按住或轻触后卡牌抬起并完整显示卡面信息，拖动时卡面略高于手指跟随，合法格高亮；释放到合法空位完成暗置，释放到非法格或战场外返回原位。

### 后续实现要求

- 站点必须让玩家在不打开额外说明页的情况下看到当前生命、气、具体式、运行功法、待停运状态和六个号位。
- 普通规划状态下，空战斗格可以低强调显示号位和空间位置，例如`2号位 / 中段·前`，帮助拖放；卡牌进入后该提示完全消失并改为显示卡牌信息。规则引擎仍保存内部号位，结算时通过成对高亮和中轴进度表达顺序，战斗记录仍可引用号位。
- 功法与普攻卡面必须显示六格合法位置，合法格亮起、非法格变暗；选中卡牌后战场同步高亮合法空位。
- 运行中的功法需要提供“停止运行”和“撤回停止”交互，不使用会暗示立即腾格的即时删除反馈。
- 战斗记录要逐条显示号位、揭示、扣费、式变化、效果上线、停止运行、伤害和离场。
- 自动结算必须真实地逐帧推进规则状态，不能先得到最终结果再播放与场面脱节的假动画。
- 界面需要按顺序区分回合开始、规划锁定、回合执行和回合结束；回合开始与回合执行显示1至6推进，回合结束显示6至1推进及统一收尾。
- 回合执行中的每个号位先显示双方掀牌，再显示实际发生的类型层；普攻和摧破需要有可区分的基础动画及事件文字。
- 当前结算号位在双方战场同步高亮；敌我战场之间显示回合数和当前阶段，并在结算时切换为六步进度。战斗日志入口固定在顶部左侧，记录按发生顺序从前往后排列。
- 双方破绽/封穴状态行统一集中在战场中轴，敌方状态行位于回合轴上方，我方状态行位于回合轴下方；三行共同组成贯穿左右侧轨的全宽部位状态分隔带。
- 失神与生命共享一条视觉轴：最大生命中未拥有的部分为空；当前生命范围内，橙色有效生命从左开始，失神色紧接在其右侧。`有效生命=当前生命-失神`，橙色部分归零时角色失败，同时保留当前生命与失神数值。

### 双方效果面板：已确认

- 站点必须分别显示`我方效果`与`对方效果`，不能把双方效果混成一个无归属列表。
- 双方状态常驻区改到右侧纵轨，使用更大的可读字号逐条竖排；不设置固定条数，按实际高度截断并只在溢出时显示省略号。点击后打开完整状态列表，点击单个状态进入对应详情。
- 效果面板汇总当前公开且与规则结算有关的效果，包括运行功法效果、内功效果、状态、增减益和层数。
- 每条效果至少显示：归属方、效果来源、简明效果文本和当前层数；存在剩余回合、剩余触发次数、所在号位或待停运状态时一并显示。
- 功法仍在战斗格中显示占位与类型；效果面板显示它正在产生的实际规则修正，两者职责不同。
- 对方尚未掀开的行动和其他隐藏信息不得提前出现在效果面板。
- 新功法在掀牌后、对应类型层结算前可以显示为`待生效`；完成扣费并上线后改为`生效中`。
- 运行功法标记停止后显示`待停止`，在轮到自身号位与类型层前仍保留在效果面板；真正停止后才移除。
- 内功效果从战斗开始即显示；主运、辅运或其他来源需要明确标记，避免玩家无法判断效果来自哪门内功。
- 玉卮等层数状态必须实时显示正练/逆练、当前层数及归属方。
- 上、中、下三列不再重复显示部位名称；每列只把`破`六格与`穴`六格压在同一行。列的空间位置本身表达上中下段，也不显示独立等级数字和剩余回合数字。每个亮格代表总计1个剩余回合：1至2格为一级、3至4格为二级、5至6格为三级；统一收尾时从右侧熄灭1格，跨过4或2格边界时播放降级反馈，归零时清空。

### 效果条目的推荐字段

| 字段 | 示例 |
| --- | --- |
| 归属 | 我方 / 对方 |
| 来源 | 玉卮手、某奇窍、主运内功 |
| 效果 | 双方摧破总直接伤害+1 |
| 层数 | 2层 |
| 时限 | 剩余回合或触发次数 |
| 位置 | 5号位 |
| 状态 | 待生效 / 生效中 / 待停止 |

完全相同的效果是否合并显示由其叠加规则决定；在叠加规则确认前，不能只因名称相同就擅自合并来源。

### 侧轨确认、撤回与平行手牌

- `撤回本轮`位于全宽部位状态带左端并使用白字，`确认`位于右端；空间不足以竖排后，两个按钮统一使用横排文字。分隔带中部承载双方部位状态、回合、阶段和六步结算进度。
- `撤回本轮`是低强调操作：点击后把本轮暗置卡牌退回原手牌，恢复本轮开始时的场上位置、停运/继续运行选择和资源预留。它不回滚回合开始阶段已经发生的抽牌、回气、寒毒或其他效果。
- `确认`是规划阶段唯一高强调操作。确认后不能再修改规划、撤回本轮或取消确认。
- PVE中确认后立即进入回合执行；未来PVP中确认后界面进入只读等待态，显示`已确认，等待对方`，双方均确认后自动执行，不提供取消确认。
- 进入执行后，中央按钮区转换为当前六步结算进度与跳过动画入口，不新增第二条控制栏。
- 平行手牌以卡牌顶端名称、费用和类型色作为紧凑状态下的主要识别信息；手牌容器完全透明，位于我方六格下方且不覆盖场地，战场背景连续显示到生命栏。生命栏可以遮住牌面下部；轻触或按住会把选中牌向上抬起并展示完整卡面，再继续拖动进入出牌状态。
- 平行排列必须容纳当前手牌上限的全部卡牌，不通过横向滚动隐藏边缘牌；牌数增加时通过收紧可见间距、提高平行重叠保持全部可见。

## 3. 气条与预测用量

### 已确认

- 气上限为5。
- 每回合恢复3气，不超过上限；这是下一版必须实现的原型值，数值强度仍待对局测试。
- 气条使用`可支配气 / 当前气`显示规划后的预测用量。
- 运行功法下一次需要支付的维持气，在规划阶段先占用气预算。
- 新暗置卡牌的确定气费也占用气预算，但实际扣费发生在其号位结算时。
- 把运行功法标记为停止后，立即取消其本回合维持费预留，因此预测可支配气增加；功法本身仍运行到对应号位。
- 撤回停止后，重新预留其维持费。

示例：当前拥有3气，场上两个奇窍各需维持1气：

`可支配气 / 当前气 = 1 / 3`

若两个奇窍都标记停止运行：

`可支配气 / 当前气 = 3 / 3`

### 预测公式

`可支配气 = 当前气 - 未停运功法的维持预留 - 新暗置卡牌的确定气费预留`

预测值不能小于0。规划阶段不能提交确定费用已经超过当前气的方案。

### 待定

- 更早号位的功法确定恢复气时，是否计入后续号位的可用预测。
- 条件性回气、被打断或费用变化如何显示，不应让一个单一数字制造虚假确定性。

## 4. 式与武器普攻机会

### 已确认

- 式不再抽象为力式、巧式、疾式，而是武器招式产生的具体式。
- 式采用共享总上限5，右侧式条显示最多五个实际式符号，而不是只显示一个总数。
- 摧破支付具体式组合，例如拳掌摧破可以需要`点+拿`，剑法摧破可以需要`刺+刺`。
- 每把武器向独立招式牌库提供三张普攻牌，底部武器页改为显示当前抽到的招式手牌，不再固定展示全部机会。
- 同一把特殊武器可以提供两个相同招式；当前确认乐器可以包含两个`音`。
- 武器普攻不进入功法抽牌卡组且不消耗气，使用后进入独立招式弃牌堆。
- 招式牌库重整不触发周天或内息紊乱。
- v0.3暂按一至三把武器每回合整备2、3、4张、招式手牌上限5测试；未使用的招式牌保留到下回合。
- 普攻成功命中后获得该普攻对应的具体式；被化解时是否产式沿用当前待验证规则。

### 当前已给出的武器示例

| 武器 | 三张基础普攻牌 | 命中后获得 |
| --- | --- | --- |
| 手套 | 崩、拿、点 | 对应获得崩式、拿式、点式 |
| 剑、刀示例 | 劈、刺、撩 | 对应获得劈式、刺式、撩式 |
| 特殊乐器示例 | 音、音、弹 | 两张音牌均获得音式 |

完整武器与招式映射仍待设计，不把以上示例擅自扩展到所有武器。

## 5. 六个号位

### 已确认编号

| 距离/部位 | 上段 | 中段 | 下段 |
| --- | ---: | ---: | ---: |
| 前排 | 1 | 2 | 3 |
| 后排 | 4 | 5 | 6 |

- 前排从上到下对应1至3号位。
- 后排从上到下对应4至6号位。
- 号位仍同时表达部位和距离，但现在也决定本回合的结算时机。

## 6. 按号位结算

### 已确认

1. 回合开始先恢复气、补充功法牌并按武器数量整备招式牌，再处理寒毒等全局回合开始状态。
2. 回合开始随后按`1 -> 2 -> 3 -> 4 -> 5 -> 6`处理双方现有功法的回合开始效果。
3. 双方根据回合开始后的实际资源进入规划阶段，同时暗置，并可标记运行功法停止或撤回停止，然后同时锁定。
4. 回合执行按`1 -> 2 -> 3 -> 4 -> 5 -> 6`推进，同一编号的双方号位同时处理。
5. 新功法只有在回合执行轮到自己的号位时才揭示、实际扣费并开始运行或执行效果。
6. 运行功法只有在回合执行轮到自己的号位时才实际停止、效果消失并离场。
7. 六个号位执行结束后，先处理幻毒等全局回合结束状态，再按`6 -> 5 -> 4 -> 3 -> 2 -> 1`处理双方场上功法的回合结束效果，同号位仍同时处理。
8. 回合结束的最后统一减少破绽、封穴及其他按回合计时状态的剩余回合，并处理到期。
9. 破绽或封穴当前等级到期时不直接移除：三级降为二级、二级降为一级并重置2回合，一级到期才消失。

### 已确认的号位内优先级

回合执行进入一个号位后，使用以下固定结构：

1. `掀牌`：绝对最高优先级。双方该号位的新暗置行动必须先同时公开，任何普通功法类型都不能插到掀牌之前。
2. `奇窍`
3. `护体`
4. `轻灵`
5. `普攻`
6. `摧破`

除掀牌为确定的绝对最高优先级外，`奇窍 -> 护体 -> 轻灵 -> 普攻 -> 摧破`是当前暂定的类型顺序，后续出现真实规则冲突时再在对应类型内部细分。

- 同一类型层内，双方效果同时处理，不比较玩家先后手。
- 费用实际扣除、持续效果上线、待停止功法失效以及该类型的行动，都在对应类型层处理。
- 较早类型造成的状态变化会影响同号位更晚类型；较晚类型不能追溯修改已经完成的较早类型。
- 例如同号位己方奇窍对阵对方普攻：双方先掀牌，奇窍层先上线效果，随后普攻层结算，因此该奇窍可以影响对方同号位普攻。
- 如果双方同号位都是护体，则掀牌后在护体层同时处理。

### 同号位影响边界

- 每位玩家的一个号位最多容纳一个行动，因此新功法不可能影响己方另一张同号位卡牌。
- 新生效功法在同号位最多只可能影响对方同号位行动；此外可以影响双方更晚的号位和后续回合。
- 例如己方5号位放奇窍，己方不可能再有另一张5号位摧破受到它强化；由于奇窍优先于普攻和摧破，它可以影响对方5号位的普攻或摧破，也能影响更晚号位。
- 已经结算完的更早号位不会被后来生效的功法追溯修改。

### 后续细分原则

- 当前不为每张卡牌增加速度值。
- 只有当同一类型内部出现无法用同时结算处理的真实冲突时，才增加该类型的子优先级或明确关键词。
- 新增子优先级必须保持双方对称，不能转化为隐藏先后手。

### 回合结束的反向顺序

- 写有“回合结束时”的效果不在该卡的回合执行号位触发，而是在六个号位全部执行后进入回合结束阶段。
- 例如1号位功法写有“回合结束时恢复1生命”，该效果在回合结束从6号位推进到1号位时才触发。
- 反向顺序使小号位在回合执行中更早、大号位在回合结束中更早；这是位置取舍，不是玩家先后手。
- 回合结束同号位的双方效果继续使用同时快照，不比较玩家顺序。
- 回合开始与回合结束是否复用回合执行的类型优先级仍待确认；在出现真实冲突前，不为它们增加速度字段。

## 7. 运行功法的停止与撤回

### 已确认

- 玩家可以在规划阶段把己方运行功法标记为停止运行。
- 标记停止后，功法不会立即离场、不会立即失效，也不会立即腾出格子。
- 锁定前可以撤回停止，使功法恢复普通运行状态。
- 进入结算后，只有轮到该功法所在号位，它才真正停止、效果消失并进入弃牌堆。
- 该格在本轮规划中始终被占用；功法结算离场后，要到下一次规划时才能放入新行动。
- 标记停止会立即取消维持费预留，但在实际轮到该号位前，功法仍可影响更早号位。

### 必须实现的状态

| 状态 | 占格 | 效果 | 费用预测 | 能否撤回 |
| --- | --- | --- | --- | --- |
| 运行中 | 是 | 生效 | 预留维持费 | 可标记停止 |
| 待停止 | 是 | 到本号位前仍生效 | 不预留维持费 | 锁定前可撤回 |
| 已停止 | 否 | 失效 | 不预留 | 否 |

## 8. 当前原型实现状态

`prototype/`的v0.3代码已经替换旧的抽象式、回气2、全局类型阶段、回合开始统一维持、固定武器机会和单一对局入口，并实现本文件第9节的主体验收项。

`回合开始 -> 规划锁定 -> 回合执行 -> 回合结束`、开始阶段1至6、结束阶段6至1，以及破绽/封穴的分层持续规则是在v0.3之后修订的目标规则，当前代码尚未实现。

以下细节仍是原型临时实现：

- 玉卮按每个至少有摧破成功造成伤害的号位消耗1层，新获得的层数不在本号位消耗。
- 同列奇窍每轮最多因成功命中失去1生命，在回合结束统一处理。
- 护体支付最后一次维持费后，在该回合结束时达到持续上限并离场。
- 同回合尚未确定命中的普攻产式不进入后续摧破的规划预算。
- 内功效果面板与构筑许可已经展示，但除主运最大生命外尚未全部接入战斗结算。
