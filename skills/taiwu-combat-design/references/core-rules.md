# 战斗核心规则摘要

更新时间：2026-07-20  
状态：当前规则入口；详细数值仍需原型测试

## 战场与时序

- 战斗为1对1，双方各有`2x3`战斗格；三列对应上中下部位，两行对应距离层级。
- 前排上中下为1至3号位，后排上中下为4至6号位；每格只能容纳一张行动或持续武学。
- 不设置独立行动次数，六格、手牌、气、式与持续占格共同限制行动。
- 回合顺序为`回合开始 -> 规划锁定 -> 回合执行 -> 回合结束`。
- 双方同时暗置并锁定，执行时按1至6号位处理；同号位双方同时结算。
- 每个号位先同时掀牌，再暂按`心法 -> 护体 -> 轻功 -> 招式 -> 武技`处理。
- 回合结束效果按6至1处理，随后统一减少持续状态。

## 卡牌生命周期

| 类型 | 规则身份 |
| --- | --- |
| 武技 | 蓄势一回合后攻击，主要支付具体式 |
| 护体 | 高启动气、低维持气、有限持续，没有生命值 |
| 轻功 | 立即移动或周转，结算后弃置 |
| 心法 | 有生命和维持气、无默认持续上限，生命不能替角色挡伤害 |
| 招式 | 武器提供的普攻，不耗气，结算后进入招式弃牌堆 |

## 资源

- 气上限5、初始2、每回合恢复3；普攻不消耗气。
- 具体式共享上限5，不自动恢复，由武器招式等效果获得，供武技支付。
- 起手4张，每回合开始抽1张，包括第一回合。
- 基础手牌上限5，每门普通内功`+1`，绝对上限15。
- 满手抽牌直接弃置；上限降低时从左向右弃牌直至符合上限。
- 牌库耗尽后重洗弃牌堆并完成周天，每次周天增加内息紊乱与递增生命损失：数值暂定。

## 武器与招式

- 最多装备3把武器；每把武器向独立招式牌库加入3张普攻。
- 一至三把武器每回合暂按整备2、3、4张，招式手牌上限5。
- 普攻基础暂按威力1、命中1，命中后获得对应具体式。
- 武器决定招式、武技门类和合法距离行，不决定武技品级。

## 命中与护体

- 攻击没有速度、穿护或随机命中率。
- 无对应护体时直接命中；有`护体X`时，命中不高于X则完全化解，否则造成完整威力。
- 被完全化解的普攻不造成伤害，也不产式；护体不会因挡住攻击损失耐久。

## 状态摘要

- 角色只使用一条当前生命；失神覆盖当前生命，有效生命归零时失败。
- 上中下部位各最多一个破绽和一个封穴，最高3级，每级基础持续2回合并逐级退化。
- 破绽暂定提高该部位直接伤害；封穴暂定提高该部位非普攻武学气费。
- 毒由一种当前毒性与共享毒量组成；六毒按各自行为即时触发，不建立六条独立毒槽。

## 待确认

1. 同类型内部冲突、同时治疗与同时致死。
2. 护体全挡或全中的数值标尺。
3. 心法按号位或按整轮失去生命的方式。
4. 两个距离行是否足以表达距离。
