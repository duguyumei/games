# 功法卡牌类型原型v0.1

状态：用户方案已记录，优化规则待确认与纸面测试  
更新时间：2026-07-20

## 1. 四类功法的结构身份

四类功法不只按“做什么”区分，还要按“在场多久、何时付费、如何离场”区分：

| 类型 | 主要职责 | 生命周期 | 主要费用 | 默认去向 |
| --- | --- | --- | --- | --- |
| 摧破 | 造成主要伤害 | 蓄势一回合后进行一次攻击 | 式为主，气为辅 | 攻击后弃置 |
| 护体 | 化解攻击、保护部位 | 立即生效的短期姿态 | 启动费高、维持费低 | 到期或停止维持后弃置 |
| 轻灵 | 移动场上功法或周转资源 | 揭示后立即结算 | 气 | 结算后弃置 |
| 奇窍 | 建立长期规则与构筑引擎 | 无固定持续上限，但有生命值且需要维持 | 打出与维持费用相同 | 生命归零或停止维持后弃置 |

这四种生命周期是当前推荐的类型边界。它能避免护体和奇窍都变成“每回合交气的持续卡”，也能防止轻灵只是换名字的抽牌法术。

按号位结算时，双方先同时掀牌，再暂按`奇窍 -> 护体 -> 轻灵 -> 普攻 -> 摧破`处理。对应类型的支付、上线、停运、行动和触发在自己的类型层发生；同类型双方同时处理。

所有持续功法都各占一个独立战斗格，不允许护体与奇窍叠放在同一格。护体当前建议保护同一部位列，因此可以用同列另一个距离格的护体保护奇窍；代价是该列两个行动位都被持续功法占用。

## 2. 气预测、号位支付与停运

### 用户方案

- 护体打出时支付较高气，后续每回合开始支付较低气，并有最大持续时间。
- 即使只开启一回合，也希望延迟到下一回合开始再多支付一次维持费。
- 奇窍打出与后续维持支付相同气，没有最大持续时间。

### 已确认的新规则

旧的“回合开始统一支付全部维持费”不再作为后续实现目标。新版采用：

1. 回合开始恢复3气，不超过上限5。
2. 规划阶段为未停运功法的维持费和新暗置卡牌的确定费用预留气。
3. 界面用`可支配气/当前气`显示预留后的预测值。
4. 玩家可以把运行功法标记为停止运行，取消其维持费预留；锁定前可以撤回。
5. 标记停止不会让功法立即失效或腾格；轮到它所在的1至6号位才真正停止并离场。
6. 未停运功法也在轮到自身号位时实际支付维持费。

待停止功法在轮到自身号位前仍占格并生效，但本回合不再预留维持费；这是用户明确要求的预测与时序规则。

详细状态和时序要求见[号位结算规范v0.1](./slot-resolution-v0.1.md)。

### 最大持续时间的推荐计法

- 护体打出的回合计为第1个生效回合。
- 每个回合结束时增加1个已持续回合。
- 达到最大持续时间后的具体离场号位仍需按新结算规则确认。
- 玩家可以在规划阶段标记提前停止，锁定前可以撤回。

该算法避免“持续1回合究竟收几次钱”的歧义。

## 3. 摧破

### 已确认边界

- 摧破负责主要伤害。
- 默认蓄势一回合并占据原格。
- 卡面战斗字段为威力、命中、所需式、所需气和词条。
- 默认攻击后弃置；“持续在场”等词条可以例外。

### 类型身份

- 摧破的代价主要是式、提前暴露和占格时间，不依赖复杂效果文本。
- 轻灵可以在摧破发动前改变其所在格；按号位结算后，移动发生在目标摧破号位之前还是之后会改变其本回合能否发动，精确规则待确认。

## 4. 护体

### 用户方案

- 护体负责防护。
- 护体没有生命值或耐久，普通攻击不会通过造成伤害将其破坏。
- 同时具有打出费用、持续维持费用和最大持续时间；费用在规划时预留并在所在号位实际支付。
- 典型例子是打出消耗3气，后续每回合消耗1气。

护体只会因达到最大持续时间、停止支付维持费，或被明确写有移除效果的功法解除而离场。

### 推荐卡面字段

| 字段 | 含义 |
| --- | --- |
| 护体值 | 能化解多高命中的攻击 |
| 启动气 | 打出时支付的气 |
| 维持气 | 后续每个生效回合支付的气 |
| 最大持续 | 包含打出回合在内，最多生效多少回合 |
| 词条 | 少量例外能力 |

### 测试数值

- 普通护体：启动气2至3、维持气1、最大持续2至3回合。
- 强护体可以提高护体值或持续时间，但不应同时在两项都达到同品级上限。
- 护体当前建议保护其所在部位列的两个距离格，不保护其他部位列。

## 5. 轻灵

### 两个子方向

1. `挪移型`：改变已经在场的己方功法位置，间接提高攻击的命中机会或保护关键持续卡。
2. `周转型`：抽牌、弃牌、回收场上功法或恢复少量气，形成节奏优势，但不使用速度数值。

### 挪移的同时行动规则

- 轻灵在自己的号位揭示并结算，不再默认早于全部护体和攻击。
- 被移动的卡牌与目的格必须在暗置锁定时选定，不能在看到对手揭示内容后再选择。
- 目的格必须在轻灵结算时合法且为空；不合法则移动失败，轻灵仍然支付费用并弃置。
- 摧破被移动后按新号位确定部位、距离和后续结算时机；如果目的号位已经结算完，本回合如何处理仍待确认。

锁定时选定目的格非常重要。若允许揭示后再选，轻灵会从“预测工具”变成无风险反应牌，破坏双方同时暗置的核心。

### 防止轻灵同质化

轻灵不靠“抽牌数字不同”区分，而靠移动几何与资源转换区分：

| 模板 | 基础效果 | 主要区别来源 |
| --- | --- | --- |
| 换段 | 将一张在场功法移至同一距离行的另一部位列 | 可移动的功法类型、跨越部位数 |
| 进退 | 将一张在场功法移至同一部位列的另一距离行 | 武器合法距离行与距离规则 |
| 换位 | 交换两张己方在场功法 | 两张牌的类型限制 |
| 回身 | 将一张己方在场功法返回手牌，再恢复1气 | 放弃场面换资源 |
| 筛选 | 抽2张牌，然后弃1张牌 | 筛牌而非无条件赚牌 |

设计约束：

- 三品轻灵只做一个主要动作。
- 二品可以在满足位置条件后附带抽1张牌或恢复1气。
- 一品可以组合移动与周转，但不能同时无条件净抽牌并净回气。
- 纯粹的“抽X张”或“恢复X气”只保留少量基准牌，其余轻灵必须与位置、回收或弃牌发生关系。
- 任何能够回复等于或高于自身费用的轻灵，都必须有消耗、回收场上牌或每回合限用等约束，防止免费循环。

## 6. 奇窍

### 用户方案

- 奇窍拥有生命值。
- 打出费用与每回合维持费用相同。
- 奇窍没有最大持续时间。

### 当前推荐，待确认

- 奇窍生命值只决定奇窍自身是否离场，不能阻挡、吸收或减少角色受到的伤害：`已确认`。
- 旧建议是某部位列在统一攻击阶段至少被命中一次后，该列每张奇窍失去1生命；改用1至6号位后，按单个号位还是按整轮限制一次仍待确认。
- 特殊卡牌以后可以直接损伤或恢复奇窍生命，但第一版不建立额外的奇窍攻击目标系统。
- 生命归零时立即弃置。
- 奇窍没有最大持续时间；只要在自身号位持续支付气且仍有生命，就可以留场。

这套规则让对手可以通过攻击奇窍所在部位列拆除引擎，又不需要重新增加“攻击目标”字段。奇窍受损与角色受伤同时发生，不存在伤害转移。

### 推荐卡面字段

| 字段 | 含义 |
| --- | --- |
| 生命 | 奇窍能够承受多少次规则定义的同列命中事件，不能替角色挡伤害 |
| 气费 | 打出时与每回合维持时支付的相同费用 |
| 持续效果 | 留场期间生效的单一核心规则 |

### 测试数值

- 普通奇窍：气费1、生命2至3。
- 强奇窍可以为气费2；每回合自然恢复已经改为3气，需重新测试多奇窍同时维持的上限。
- 不允许基础奇窍每回合无条件恢复等于自身维持费的气，否则维持成本失去意义。

## 7. 卡面复杂度约束

- 一品卡以一个主要动作为上限。
- 二品卡可以增加一个条件或小型附带收益。
- 三品卡可以形成两段协同，但不同时覆盖伤害、防御、过牌和回气多个维度。
- 启动费、维持费、最大持续和奇窍生命使用卡框图标展示，不写成长段规则文本。
- 通用的维持、移动、奇窍生命损失与离场规则写在规则书，不在每张卡上重复。

## 8. 待确认问题

1. 同一类型内部是否需要比“双方同时处理”更细的子优先级。
2. 护体最大持续时间到期后，在自身号位还是回合结束时离场。
3. 轻灵的被移动卡与目的格是否必须在暗置锁定时一并选定。
4. 周转型轻灵是否接受“抽2弃1”为基准，而不是无条件抽2。
5. 奇窍是否采用“所在部位列本回合至少被命中一次，阶段结束失去1生命”的拆除方式。
6. “护体与奇窍各占一格、同一部位列护体可以间接保护奇窍”的空间成本是否合适。
7. 轻灵把摧破移入已经结算或尚未结算的号位时，本回合发动时机如何变化。
8. 奇窍的“同列被命中后失去1生命”在按号位结算下是每号位最多一次还是每回合最多一次。
