# 战斗核心数值原型v0.2

状态：部分规则已确认，命中与护体算法待纸面测试  
更新时间：2026-07-20

> 文件名暂时保留 `combat-core-v0.1.md` 以维持现有引用；本文内容已经按第二轮讨论修订。

## 1. 设计原则

### 已确认

- 卡面效果和字段保持克制，共通行为写入基础规则，不在每张牌上重复。
- 不使用随机命中率、暴击率、穿护、速度和百分比减伤。
- 上中下段的暗置选择承担主要猜招压力。
- 第一版只使用单一生命值；外伤、内伤暂不建立两套伤害系统。

## 2. 回合补牌与手牌上限

### 已确认

- 每回合按基础规则自动抽牌称为“回合补牌”。
- 不设置“运转”关键词；卡牌效果直接写抽牌与弃牌数量。

### 暂定

- 起手4张；每回合开始补1张，包括第一回合。
- 基础手牌上限5，每门普通内功提供`+1`，所有效果结算后不超过绝对上限15。
- 抽牌时手牌已满，抽到的牌直接进入弃牌堆；上限降低造成溢出时，从左向右弃牌直至符合上限。
- 规划锁定后的回合执行或回合结束阶段抽到的牌不能在本回合重新暗置，只能从下一回合开始使用。
- 回合开始发生在规划之前；该阶段通过基础补牌或效果获得的牌可以用于紧随其后的本轮规划。
- 抽牌堆不足时，按周天规则重洗并积累内息紊乱。

## 3. 无速度的同时结算

### 已确认

- 卡牌没有速度字段。
- 结算主顺序来自1至6号位与少量关键词优先级，而不是每张攻击牌比较速度。
- 同一编号的双方号位同时处理，不产生隐性先后手。

### 已确认的号位主顺序

1. 回合开始：先恢复3气、执行回合补牌并整备武器招式，再处理寒毒等全局回合开始状态，随后按`1 -> 2 -> 3 -> 4 -> 5 -> 6`处理双方现有功法的回合开始效果。
2. 规划锁定：双方根据回合开始后的实际资源暗置行动，为新卡和未停运功法预留费用，选择停运或撤回停运，然后同时锁定。
3. 回合执行：按`1 -> 2 -> 3 -> 4 -> 5 -> 6`推进，每个编号同时处理双方对应号位。
4. 号位内处理：双方先同时掀牌，再暂按`奇窍 -> 护体 -> 轻灵 -> 普攻 -> 摧破`处理实际扣费、效果上线、待停运功法离场、行动与触发。
5. 回合结束：先处理幻毒等全局回合结束状态，再按`6 -> 5 -> 4 -> 3 -> 2 -> 1`处理双方场上功法的回合结束效果，随后统一减少破绽、封穴及其他按回合计时状态的剩余回合，并处理到期与离场。

同号位双方攻击使用该号位统一快照同时计算；即使双方在同号位同时受到致命伤害，双方行动仍然结算。回合开始与回合执行中，不同号位之间按1至6保留前面号位已经造成的状态变化；回合结束中按6至1保留前面结算号位已经造成的状态变化。

新功法不可能影响己方另一张同号位卡牌，因为每方每个号位只能容纳一个行动；它最多只可能影响对方同号位，随后可以影响更晚号位。较早类型可以影响同号位较晚类型，例如新奇窍可以影响对方同号位普攻。

掀牌是绝对最高优先级，不属于可被普通类型插队的速度层。同一类型的双方效果同时处理；未来只有出现无法用同时结算解决的真实冲突时才增加该类型内部子优先级。

详细要求见[号位结算规范v0.1](./slot-resolution-v0.1.md)。

## 4. 摧破卡面

### 已确认的战斗字段

| 字段 | 作用 |
| --- | --- |
| 威力 | 成功命中后造成的基础伤害 |
| 命中 | 判断攻击能否突破对应部位列的护体效果 |
| 所需式 | 支付的崩、拿、点、劈、刺、撩等具体式及其组合 |
| 所需气 | 需要支付的气；可以为0 |
| 词条 | 少量例外规则，如“不可打断”“持续在场” |

门派、武器、内力属性和品级属于构筑标签，不计入上述战斗字段。

### 不印在卡面上的共通规则

- `目标`：卡牌放在上、中、下哪一列，就攻击对方对应部位。
- `速度`：不存在该字段；攻击在自身号位结算，同号位双方同时处理。
- `穿护`：不存在该属性，由命中与护体效果直接判定是否化解。
- `蓄势`：摧破默认等待一回合并持续占据原格，例外才写成词条。
- `距离`：不写成单独文本字段；卡面以六格亮暗图直接显示合法号位，武器功法从对应武器继承前排或后排限制。
- `去向`：摧破攻击后默认进入弃牌堆，带“持续在场”等词条时例外。

## 5. 武器普攻与具体式

### 已确认

- 每把武器向独立招式牌库提供三张由武器决定的普攻牌，不再固定展示三个机会。
- 同一把特殊武器可以提供两张相同招式；当前确认乐器可以包含两个`音`。
- 武器普攻不消耗气，轮到所在号位时揭示并结算，随后进入招式弃牌堆。
- 每张普攻牌命中后获得对应的具体式；例如手套提供崩、拿、点，剑、刀示例提供劈、刺、撩。
- 五个具体式共享总上限5，摧破按具体组合支付，例如`点+拿`或`刺+刺`。
- 普攻未命中或被护体化解时不获得式。
- 招式弃牌重洗不属于功法周天，不增加内息紊乱。

### 暂定模板

| 示例普攻 | 威力 | 命中 | 命中后获得 |
| --- | ---: | ---: | --- |
| 崩/拿/点 | 1 | 1 | 对应具体式 |
| 劈/刺/撩 | 1 | 1 | 对应具体式 |

第一版仍先让普通武器牌使用相同威力和命中，武器差异优先来自可放号位、产生的具体式、可用摧破和武器自身能力。v0.3已经实装十类基础武器表，具体数值仍待对局测试。

## 6. 命中、护体与伤害

### 已确认的边界

- 普攻成功命中造成1点伤害。
- 攻击没有独立穿透或穿护属性。
- 是否被护体挡住，应由攻击的命中与对应护体效果共同决定。
- 护体没有生命值或耐久，攻击与护体的比较不会削减或破坏护体本身。

### 推荐测试模型，尚未确认

第一版采用“全挡或全中”，不计算护甲减伤：

1. 攻击先检查其所在距离行是否合法，以及是否被提前打断。
2. 攻击对应的部位列没有生效护体时，攻击直接命中。
3. 该部位列存在 `护体X` 时，分别检查每次攻击：
   - 若攻击命中小于或等于X，攻击被化解，造成0伤害，也不产式。
   - 若攻击命中大于X，攻击突破护体，造成完整威力。
4. 同列多个护体只取最高X，不相加。
5. 护体在自身生命周期内不会因挡住攻击而损失耐久；是否继续运行由持续时间、维持和停运规则决定。

因此基础伤害公式只有：

`被护体化解 -> 0伤害`

`成功命中 -> 造成等同威力的伤害`

该模型让“命中”同时承担攻击稳定性和突破护体的职责，不需要再增加穿护。高命中是强项，设计摧破时必须用较低威力、更高费用或更窄的式组合交换。

### 例子

一张摧破放在中段，威力3、命中2。对方中段有 `护体1`：

- `2 > 1`，摧破命中，造成3点伤害。

若对方中段有 `护体2`：

- `2 <= 2`，摧破被化解，造成0点伤害。

无须读取目标、速度、穿护或减伤公式。

### 失神与有效生命：已确认结构；恢复规则待定

- 角色同时记录`当前生命H`与`失神S`；失神不作为真实伤害直接扣除当前生命。
- `有效生命 = max(0, H - S)`。界面在当前生命范围内从左到右连续显示有效生命与失神，最大生命中尚未拥有的部分保持为空。
- 例如最大生命32、当前生命26、失神4时，血条显示22格橙色有效生命、紧接4格失神色和最后6格空缺，不把失神画在最大生命最右端与当前生命分离。
- 当有效生命归零，即`S >= H`时角色失败；当前生命因普通伤害降至0也属于同一失败结果。因此普通伤害压低当前生命时，也可能使已有失神覆盖全部剩余生命。
- 失神不利用上中下部位破绽，也不被普通护体化解；具体哪些功法能够减少失神、失神是否自然衰减、疗伤是否只恢复当前生命仍待确定。

### 正逆练：已确认；固定伤害修正数值：待按新生命标尺重测

- 第一版不使用“直接伤害提高或降低X%”。整数修正仍是目标方向，但基础生命和摧破威力将整体提高，旧的`+1/-1`不能直接视为新标尺定案。
- 原作的百分比伤害修正优先换算成整数修正；`30%`曾按`+1`或`-1`测试，后续需要与新的生命、摧破和破绽数值一起重新标定。
- 修正作用于“一张摧破造成的总直接伤害”，不按伤害段数重复计算；减伤后的直接伤害最低为1。
- 正练与逆练不作为两张独立收藏卡。组卡时为同名功法选择一种练法，同一卡组内所有同名卡共享该选择，进入战斗后不能切换，且两个版本共享同名卡数量限制。
- 只为正逆效果确实产生不同构筑或打法的功法保留双版本；不要求每张功法为了形式完整而拥有两段近义文本。

#### 玉卮手效果原型

玉卮手成功命中并造成伤害后，运用者获得2层对应的“玉卮”状态；玉卮手本次伤害不受刚获得的状态影响。

- `正练·玉卮`：任一方的摧破造成直接伤害时，该张摧破的总直接伤害`+1`。
- `逆练·玉卮`：任一方的摧破造成直接伤害时，该张摧破的总直接伤害`-1`，最低为1。
- 原方案为每经过一个至少有摧破成功造成直接伤害的攻击阶段失去1层；改用1至6号位后，“一次有效攻击阶段”需要重新定义，当前原型按整轮还是按单个号位扣层均未定案。
- 层数只表示剩余生效阶段，不提高修正幅度；同一角色的同种玉卮状态上限为2，再次获得时补至2层。

这样保留了正练“双方爆发”和逆练“双方压制”的构筑区别，同时避免按攻击次数扣层造成隐性先后手。

## 7. 距离行与部位列

### 已确认

- 三列确定上、中、下攻击部位，因此卡面不需要目标字段。
- 两行确定距离层级；距离如何具体运作尚未确定，当前不能写成摧破卡面属性。

### 当前推荐，待确认

- 原型阶段把两行暂称“近距行”和“远距行”。
- 武器规定其普攻与对应摧破只能放在一个距离行，不再设置通用的两行均可类别。
- 拳掌与奇门只能放前排；剑、软兵与暗器只能放后排。其余武器逐类决定。
- 该规则暂时表达的是武器的出手空间，不声称已经完整模拟双方动态距离。
- 如果纸面测试证明两条距离行只有格子颜色之分，再单独讨论是否需要一个全局距离标记；在此之前不增加距离资源。

## 8. 部位、破绽与封穴

### 已确认结构

- 上、中、下三个部位不设置独立生命，只承载部位相关状态和攻击目标信息。
- 每个部位最多显示一个破绽标记和一个封穴标记。
- 两种标记均为1至3级，各等级基础持续2回合；获得标记的当回合计时，并在回合结束效果全部完成后的统一收尾中减少剩余回合。
- 同等级再次施加时不叠加强度，将当前等级的剩余时间刷新至较长者。
- 更高等级覆盖当前等级并以2回合开始计时；低等级施加不能降低当前等级，也不能延长高等级的剩余时间。
- 当前等级的持续时间归零时，标记自动降低1级，新等级重新获得2回合；一级归零后标记消失。三级标记因此最多按`3级 -> 2级 -> 1级`持续6个计时回合。
- 标记不会因一次攻击或一次费用支付而消耗。
- 三级破绽与封穴只由特定Build和少数三品功法建立，不作为三品功法的通用效果。

### 当前效果方向，数值待测试

- 破绽提高对应部位受到的直接伤害，普攻与摧破均可利用；间接伤害、失神和内息紊乱不利用部位破绽。
- 封穴提高对应部位两个格子的非普攻功法气费，普通攻击不受影响；是否同时影响启动费和维持费需要结合气预测测试。
- 一个部位只有一个当前生效等级，因此多个等级不相加；一级、二级、三级分别对应多大的伤害与气费修正仍待高生命标尺测试。

### 待确认

- 回合结束中新施加的标记是否也在同一轮统一收尾立即减少1回合。
- 普通功法只能施加一级、通过连续点穴或破绽效果逐级提高，还是允许少数三品专精功法直接施加三级。
- 降低等级、缩短当前阶段或完全解除标记的反制效果分别开放给哪些护体、奇窍、内功或基础牌。

## 9. 毒素系统的设计边界

### 已确认背景

- 不把烈毒、郁毒、赤毒、寒毒、腐毒、幻毒六种毒全部做成独立基础状态；六毒的信息量已经超过其他伤势机制的总和。
- 不采用毒素自动衍生另一种毒素，也不建立原作式混合毒素表。
- 单一生命值已经取代内伤与外伤两套生命，毒素不再按内伤毒与外伤毒区分。
- 毒素属于角色全局状态，不占上、中、下部位的破绽或封穴位置。

### 暂定规则

- 中毒状态由`当前毒性 + 共享毒量`组成；只要毒量大于0，就必须存在一种有名称的毒性，不设置无属性毒。
- 保留烈毒、郁毒、赤毒、寒毒、腐毒、幻毒六种毒性，但同一角色默认只显示一种当前毒性和一份毒量，不建立六条独立毒量轨道。
- 不再给角色身上的毒设置1至3级；施毒功法本身的品级决定施毒数值与是否拥有催毒等能力，不转化为“三级毒状态”。不设置独立的`转毒`关键词。
- 对无毒目标使用`施毒X`时，建立该毒性并获得X毒量；对相同毒性再次施毒时，毒量增加X。毒量没有硬上限，只表示当前毒性还能毒发多少次，不提高单次毒发强度。
- 对已有其他毒性的目标使用`施毒X`时，当前毒性改为本次施加的最新毒性，新毒量为`max(原毒量, X)`，既不把两种异毒相加，也不因切换毒性降低已经建立的毒量。
- 更换毒性时，烈毒普攻累计等只属于旧毒性的触发进度清零；共享毒量按上述公式保留，避免把一种毒的触发条件继承给另一种毒。
- 每次毒发完成后消耗1毒量；毒量降至0时毒性一并移除，不退化为无属性毒。一个事件能否连续触发多次，由该毒性的触发规则决定。
- 第一版只允许一种毒性共存；允许少数Build同时保留多种毒性属于后续扩展。

例：`赤毒5`受到`寒毒2`后变为`寒毒5`；`赤毒2`受到`寒毒5`后变为`寒毒5`；`寒毒5`再次受到`寒毒2`则因同毒叠加变为`寒毒7`。

### 六毒触发原型

| 毒性 | 暂定触发事件 | 暂定效果 |
| --- | --- | --- |
| 烈毒 | 中毒者累计完成3次普攻结算后 | 受到2点间接伤害；累计数减3 |
| 郁毒 | 中毒者每次完成轻灵结算后 | 受到2点间接伤害 |
| 赤毒 | 中毒者的摧破成功开始运行、进入蓄势时 | 受到2点间接伤害 |
| 寒毒 | 中毒者的回合开始时 | 减少1气 |
| 腐毒 | 中毒者的护体成功开始运行或支付维持费继续运行时 | 受到2点间接伤害 |
| 幻毒 | 中毒者进入回合结束阶段时 | 获得2点失神 |

- 六毒跟随各自事件即时毒发，不再设置统一的回合结束毒发阶段。
- 烈毒按“完成普攻结算”累计，不要求命中或造成伤害；累计数跨回合保留，毒性被清除或更换时一并归零。同一轮达到两组3次时可以毒发两次，但每次都要有毒量可供消耗：`暂定实现解释`。
- 郁毒、赤毒与腐毒只在对应功法实际支付成功并进入结算或运行后触发；仅掀牌但支付失败不触发。效果目标或移动失败是否仍算完成轻灵结算，留待样牌测试。
- 寒毒在规划前的回合开始触发：基础回气完成后实际减少1气并消耗1毒量。玩家随后按扣除后的实际气值规划，不需要为寒毒额外预留费用。
- 幻毒暂在回合结束阶段开始时触发，不直接减少当前生命；获得的失神会压缩有效生命，当失神覆盖全部当前生命时失败。失神的自然衰减与驱散方式尚未确定。
- 附毒摧破的直接伤害与毒伤分开结算。相同品级和成本下，其毒实际触发后的总期望伤害应高于普通摧破，作为延迟、可驱毒和可通过改变行动规避的风险补偿；具体差值等待新生命标尺后测试。
- 疗伤与驱毒作为通用效果关键词，由具体卡牌承载，不设置每回合都能点击的免费角色动作。
- 基础疗伤、驱毒牌对所有构筑开放，但是否加入卡组由玩家选择；新手起始牌组可以各包含一张，不强制所有合法卡组携带。

## 11. 待验证问题

1. `护体X` 全挡或全中的结果是否太极端，还是能强化同时暗置的猜招感。
