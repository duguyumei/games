# 太吾事件设计

## 读取

- 完整读取 `references/event-foundation.md`；当前没有已确认事件池，不加载其他设计 Skill。

## 设计规则

1. 每个事件至少提供两个结果可预估、代价不同的选择。
2. 标明触发条件、可见信息、即时结果、延迟结果、是否可重复与进入哪个事件池。
3. 优先使用已有生命、手牌上限、本局功法库、物品和路线状态，不为单个事件新增永久资源。
4. 事件负责选择与叙事，不承担Boss技能、普通敌人套牌或地图拓扑。
5. 奖励只引用奖励类别；具体卡牌与物品效果交给对应 Skill。

## 维护

用户确认事件模板或事件后，更新 `event-foundation.md`；未确认样例保持为提案。
