# 事件设计基础

更新时间：2026-07-20  
状态：尚无已确认事件；仅确定模板

## 事件字段

| 字段 | 内容 |
| --- | --- |
| 名称与主题 | 玩家看到的事件身份 |
| 进入条件 | 阶段、属性、物品、生命或既有选择 |
| 公开信息 | 选择前明确展示的代价与可能结果 |
| 选项 | 至少两个资源或路线不同的选择 |
| 即时结果 | 当场结算的生命、卡牌、物品等变化 |
| 延迟结果 | 后续节点、事件池或Boss变化 |
| 重复规则 | 每局次数、冷却或互斥事件组 |

## 当前约束

- 不用纯随机好坏替代选择；随机结果必须先公开范围。
- 事件可以提供转型机会，但不直接绕过属性与品级解锁。
- 事件奖励只引用卡牌、物品或流程中的已有对象。
- 当前没有门派机械限制，门派只可作为叙事来源。
