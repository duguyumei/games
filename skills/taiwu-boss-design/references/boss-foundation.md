# Boss设计基础

更新时间：2026-07-20  
状态：剑冢作为主要Boss已确认；具体Boss尚未设计

## 单个Boss模板

| 字段 | 说明 |
| --- | --- |
| 身份 | 主题、内力属性、武器与核心机制 |
| 考题 | 主要检验的玩家能力或构筑弱点 |
| 阶段 | 触发条件、规则变化与持续时间 |
| 预告 | 玩家在规划前能看到的意图或危险 |
| 反制 | 至少两种可行应对，不要求唯一卡牌 |
| 专属内容 | 少量Boss卡、状态或规则例外 |
| 奖励类别 | 解锁、卡牌、物品或路线变化，不在此写具体掉落数量 |

## 当前约束

- Boss仍使用双方`2x3`战场和同时规划，不另做完全不同的战斗游戏。
- 每个阶段只突出一个主要新规则，避免多个不可见例外同时出现。
- 难度来自可学习的压力和组合，不来自偷看玩家暗牌。
