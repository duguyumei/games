# 组合出招当前设计源 v0.11

状态：52 张完整真气牌组、8 张基础手牌、基础概率与数值口径、同步出招与连击框架、成长、地图、修习经济、强化、版本、气印与异状框架已确认；具体数值仍待实测调整
日期：2026-08-04

## 1. 设计目标

验证玩家是否愿意为了下一次更好的牌型，管理手牌、牌库和弃牌机会。

本项目借鉴《小丑牌》的牌型识别、牌面数值、倍率和效果联动，但最终结果是对战行动，不是筹码计分。

数值不是唯一成长目标。功法和内功负责提供更多战术效果、资源控制和敌我互动；公共真气成长应克制纯倍率叠加，避免最终仍变成只追求最高数值的计分游戏。

### 1.1 正式世界观映射与讨论术语

卡牌本身不是招式，而是供功法调动的真气；真正的招式由功法产生。正式描述统一使用以下映射：

| 《小丑牌》或讨论术语 | 正式术语 | 含义 |
| --- | --- | --- |
| 扑克牌、卡牌 | 真气 | 被抽取、留在手中并用于组合出招的基础单位 |
| 牌面、牌阶 | 牌阶 | A、2～10、J、Q、K；负责识别对子、顺子、高牌等普通牌型 |
| 计分值、牌值 | 真气值 | 负责基础值和读取牌值的效果；数字牌按牌面，J／Q／K 为 11，A 为 12；基础真气值最高为 12 |
| 花色 | 真气属性 | 风、林、火、山四种属性 |
| 牌型 | 牌型 | 真气组成的结构，继续使用通用扑克牌名称 |
| 小丑牌 | 内功 | 常驻规则改写与构筑核心 |
| 塔罗牌 | 丹药 | 一次性增加、删除、复制、强化或转化真气 |
| 星球牌 | 心得 | 精进指定牌型的功法倍率，并获得该牌型功法 |
| 幻灵牌 | 天材地宝 | 稀有且强力地改造真气、内功或整个构筑 |
| 蜡封 | 气印 | 在出招、留手、弃掉等特定时点触发的真气效果 |

风、林、火、山在第一版只是真气属性标签，不各自附带公共攻击、防御、抽牌或恢复效果；这些差异由具体功法和内功建立。为了便于对照《小丑牌》和讨论概率，设计讨论中仍可继续使用“卡牌、花色、小丑牌、塔罗牌、星球牌、幻灵牌、蜡封”等原术语；正式界面、世界观说明和最终规则统一使用右侧术语。完整牌组中牌阶与真气值不再完全相同，因此涉及 A、J、Q、K 时不能笼统使用“点数”，必须明确说牌阶或真气值。

## 2. 出招结构

### 2.1 普通牌型

只使用普通扑克牌名称：

```text
高牌、一对、两对、三条、顺子、同花、葫芦、四条、同花顺
```

一次出牌只选择一个最高牌型。牌型只负责决定倍率，不把多个牌型的数值倍率相加。

当前使用以下固定基础倍率：

| 牌型 | 基础倍率 |
| --- | ---: |
| 高牌 | ×1 |
| 一对 | ×2 |
| 两对 | ×2 |
| 三条 | ×3 |
| 顺子 | ×4 |
| 同花 | ×4 |
| 葫芦 | ×4 |
| 四条 | ×7 |
| 同花顺 | ×8 |

这些倍率是当前计算基线，具体数值仍需与生命、功法和内功效果共同测试。

### 2.2 真气值与数值计算

暂定采用与《小丑牌》相近的计数方式：通常只有组成最高牌型的真气参与基础值计算。

每张普通真气同时记录三个基础属性：

```text
牌阶：负责识别高牌、对子、两对、三条、顺子、葫芦、四条
真气值：负责基础值及其他读取牌值的效果
真气属性：风、林、火、山；负责同花及功法属性条件
```

普通牌阶与真气值固定对应如下：

| 牌阶 | 真气值 | 牌阶顺序 |
| --- | ---: | --- |
| 2～10 | 等于牌面数字 | 2 < 3 < … < 10 |
| J | 11 | 10 < J |
| Q | 11 | J < Q |
| K | 11 | Q < K |
| A | 12 | K < A |

J、Q、K虽然真气值都为 11，但牌阶不同，不能互相组成对子、三条、葫芦或四条。A是最高牌阶，高牌判断中高于K；顺子是唯一例外，A既可以作为低端组成 `A、2、3、4、5`，也可以作为高端组成 `10、J、Q、K、A`，不能用于其他首尾相接的顺子。A在两种顺子中的真气值都固定为 12。

```text
基础值
= 所有参与数值计算的真气自身贡献之和
+ 装备中的箔面内功数量 × 3
+ 其他明确的基础值修正

基础伤害 = 基础值 × 固定牌型倍率

未增幅功法值 = 基础值 × 功法倍率

多彩增幅
= 参与数值计算的多彩真气触发次数 × 20%
+ 装备中的多彩内功数量 × 20%

功法值 = 向下取整[未增幅功法值 ×（1 + 多彩增幅）]

功法倍率
= 固定牌型倍率
+ 该牌型累计心得倍率
+ 参与最高牌型的倍率牌触发次数 × 2
+ 本次幸运牌成功触发次数 × 3
+ 参与数值计算的镭射真气触发次数 × 1
+ 装备中的镭射内功数量 × 1
+ 其他真气、功法或内功明确提供的倍率修正
```

普通真气每次触发时的自身贡献等于有效真气值；奖励牌与玻璃牌会改写有效真气值，箔面版本再为该次自身贡献增加 3 点。石头牌没有真气值，不参与普通牌型，但每次触发时固定贡献 10 点；箔面石头牌每次贡献 13 点。赤印可以令同一张真气的自身贡献、强化和版本额外触发一次。详细规则见 6.5 节。

固定牌型倍率决定基础伤害。累计心得倍率、倍率牌、幸运牌、镭射版本与多彩版本只改变功法值，不改变基础伤害；功法或内功只有在效果文本读取功法值时才会受到这些修正。没有读取数值的固定效果，例如“下回合手牌上限 +1”，不会被倍率放大。

普通牌型中参与数值计算的真气数量：

```text
高牌：只计算最高的一张
一对：计算组成一对的两张
两对：计算两组对子的四张
三条：计算三张同牌阶真气
顺子：计算组成顺子的五张
同花：计算组成同花的五张
葫芦：计算三条与对子共五张
四条：计算四张同牌阶真气
同花顺：计算组成同花顺的五张
```

例如 `7、7、7、3、3` 组成葫芦，五张牌全部属于最高牌型，所以基础值是 `7+7+7+3+3=27`；牌型倍率取葫芦倍率。

例如打出 `7、7、4、3、A`，最高牌型是一对，只有两张7参与基础值，所以基础值是14；其余三张随本次出牌进入弃牌堆。

例如 `J、J` 可以组成一对，基础值为 `11+11=22`；`J、Q` 虽然真气值同为 11，但牌阶不同，不能组成一对。顺子 `A、2、3、4、5` 的基础值为 26，顺子 `10、J、Q、K、A` 的基础值为 55。

没有参与最高牌型的多余普通真气默认不增加基础值，也不触发自身的强化、版本或气印，只会随本次出牌进入弃牌堆。石头牌的固定贡献是强化规则的明确例外；功法或内功也可以明确改写这条规则，让额外真气参与计算或产生效果。

#### 基础概率

概率统计固定使用以下基线：

```text
52 张未改造基础真气
随机抽取 8 张作为手牌
玩家可以从中选择打出 1～5 张
总手牌样本数 = C(52,8) = 752,538,150
```

“可主动组成概率”表示随机 8 张中至少存在一种选牌方式，可以准确组成该牌型；由于玩家永远可以只出 1 张，所以高牌为 100%。这一列的不同牌型可以同时存在，不能相加。

“最高牌型概率”表示按普通牌型强弱判断，这 8 张能够组成的最高牌型；各行互斥，合计约为 100%。

| 牌型 | 可主动组成概率 | 最高牌型概率 |
| --- | ---: | ---: |
| 高牌 | 100% | 7.1061% |
| 一对 | 88.7920% | 31.3728% |
| 两对 | 43.7409% | 34.2522% |
| 三条 | 12.0075% | 5.1151% |
| 顺子 | 9.8030% | 8.9129% |
| 同花 | 6.9154% | 6.7572% |
| 葫芦 | 6.1846% | 6.0664% |
| 四条 | 0.336124% | 0.336098% |
| 同花顺，不含皇家同花顺 | 0.073168% | 0.072618% |
| 皇家同花顺 | 0.008619% | 0.008619% |
| 五条 | 0% | 0% |
| 同花葫芦 | 0% | 0% |
| 同花五条 | 0% | 0% |

皇家同花顺只是同花顺的特殊名称，固定倍率和机械规则与同花顺相同。把皇家同花顺合回同花顺后，“最高牌型概率”为约 `0.081237%`。主动组成事件可能重叠，例如同一手 8 张牌可能同时含有皇家同花顺和另一组同花顺，所以主动组成概率不能直接把两行相加。

五条、同花葫芦和同花五条在未改造的 52 张牌组中严格不可能；只有增加、复制或修改真气后才可能出现。

| 一对 | 30.5 | 32 | 8～48 |
| 两对 | 60.9 | 60 | 20～92 |
| 三条 | 68.5 | 72 | 18～108 |

| 同花 | 152.3 | 152 | 84～216 |
| 葫芦 | 152.3 | 156 | 48～232 |

#### 不增加统一牌型筹码

《小丑牌》的结算是“牌型基础筹码 + 参与计分的牌面筹码”，再乘倍率。本系统确认不增加统一的牌型基础筹码，也不采用“（牌型基础筹码 + 真气值总和）× 倍率”；基础伤害只使用“基础值 × 固定牌型倍率”。

“功法值”不是另一份伤害或筹码，而是功法和内功在需要数值缩放时读取的计算结果。原作的牌型基础筹码在本系统中由具体功法的固定效果、最低效果或其他战斗作用承接；没有读取功法值的固定效果不会被倍率放大。这样可以保留牌型特效的价值，而不让高阶牌型、持续回合、防御和反伤随一段统一基础数值整体膨胀。

### 2.3 同步出招与连击

双方不是轮流先后结算伤害，而是在每个回合的第一击同步出招：双方先各自确定本次打出的真气，再开始结算。敌方不能在玩家已经确认本次出牌后，读取该次选牌再临时改招。

一次双方都出牌的同步结算顺序如下：

```text
双方各自确定本次出牌
→ 分别识别最高牌型，计算基础值、基础伤害与功法值
→ 双方本次功法与内功同时建立防御、标记和其他本次效果
→ 双方基础伤害同时结算
→ 双方由本次效果建立的额外伤害同时结算
→ 执行本次抽牌、弃掉、锁定、夺取、回收等牌区效果
→ 双方将本次打出的真气置入弃牌堆或按效果移出牌组
→ 双方结算“出牌结算结束时”的留手效果
→ 本次出牌全部结算完成后，分别检查连击
```

例如双方本次都“获得 5 点防御，并造成 5 点伤害”，则双方先同时获得防御，再同时受到 5 点伤害；两边的伤害都会先扣除对方刚获得的防御。没有出牌的一方不会触发新的“出牌时”功法或内功；但已经存在的持续效果、受伤效果和防御仍按其文本正常结算。

**连击**指一方在本次出牌全部结算完成后，于本回合内再次获得出牌机会。连击不是新回合：不重新补牌、不重置“本回合”效果、不减少持续回合数，也不会自动将弃牌堆洗回牌库。

一方只有同时满足下列条件，才可以进入连击：

1. 本次已结算的功法或内功明确赋予该方连击；
2. 该方当前仍有至少一张可以打出的手牌；
3. 若连击文本限制下一次牌型、牌型类别、真气属性或其他条件，当前手牌中存在合法的下一次出牌。

连击资格只在本回合内有效，玩家可以选择不继续出牌。除非功法或内功明确写有“可继续连击”，同一个连击来源每回合最多触发一次；任何会在连击中抽牌、回收或重复赋予连击的效果，都必须在自己的文本中写明次数上限，避免无限循环。

连击检查完成后，按双方资格进入下一击：

```text
双方都有连击
→ 双方再次各自确定一次出牌，并按同步结算顺序处理

只有玩家有连击
→ 玩家再次出牌；本击只结算玩家新触发的功法、内功与伤害

只有敌人有连击
→ 敌人再次出牌；玩家不能在本击操作手牌，本击只结算敌人新触发的功法、内功与伤害

双方都没有连击
→ 本回合结束；下一回合开始时双方按各自手牌上限补牌
```

因此，连击消耗的是当前剩余手牌，而不是免费获得新手牌。8 张基础手牌下，连续打出两个五张牌型不可能自然发生；若某门功法或内功希望让顺子、同花、葫芦等五张牌型连续出招，必须明确提供抽牌或回收，并写明次数上限。

涉及双方在同一结算层争夺同一张真气的具体冲突规则，待夺取、交换类功法进入正式功法池时一并定义；在此之前，第一批功法避免设计会让双方同一时间移动同一张指定真气的效果。

### 2.4 功法

功法是绑定牌型的特效。完整的出牌、同步伤害与连击检查顺序见第 2.3 节；双方都出牌时，同一结算层中的功法和内功同时处理，只有一方连击时则只处理该方新触发的出牌效果。

每个功法只能绑定一个触发牌型。九种普通牌型各有一个固定功法位置，开局各自使用一个基础功法。同一牌型可以获得多个不同功法；新功法进入本局功法库，不会自动替换、遗忘或出售旧功法。玩家调整装备时，从对应牌型的已获功法中选择一个装备到该位置。

功法的真气条件分为两类：

```text
通用功法：只限制牌型
属性功法：限制牌型，并要求参与最高牌型的真气中至少有指定数量属于某一真气属性
```

属性功法必须在文本中同时写明属性和数量，例如“一对，其中至少 1 张为火”或“三条，其中至少 2 张为山”。第一版每门属性功法只要求一种属性；只检查参与最高牌型的真气，不检查额外打出的真气或仍在手中的真气。万能牌在牌型识别和功法属性条件中同时视为风、林、火、山，明确读取原始属性时仍读取其印刷属性。

普通牌型识别与固定牌型倍率只取最高牌型，功法也只取最高牌型对应的功法；基础值和功法倍率再按第 2.2 节及其他明确效果修正。一次出牌只触发一个功法一次；组成葫芦的三条和对子、组成同花顺的顺子和同花，都不再额外触发各自的功法。

- 只检查本次实际选出的牌，不检查仍在手中的牌。
- 如果没有装备该牌型的功法，牌型的基础值和倍率仍然正常计算，但不产生功法特效。
- 如果装备了属性功法但本次真气不满足其属性与数量条件，基础伤害仍正常结算，但该功法不触发。
- 功法产生的新牌、新效果不能在同一次出牌中递归触发功法。

高牌功法可以在自己的效果文本中读取本次打出的全部散牌。例如五张牌没有组成其他牌型时，仍然只触发一次高牌功法，但该功法可以按五张牌的真气值总和提供防御。这不是五次高牌触发。

九种牌型各保有一个当前使用的功法位置，共九个功法位置。每个位置只能装备一个当前功法；没有装备的已获功法继续保留在本局功法库。内功另有六个装备栏位。

| --- | --- | --- |
| 高牌 | 获得本次所有打出真气的真气值总和的防御 | 高牌只触发一次；可以读取全部散牌，作为主动防守选择 |
| 一对 | 下回合手牌上限 +1 | 简单直接，作为一对的低阶节奏收益 |
| 两对 | 云环掌：下回合抽牌后，将 `功法值 / 10` 张真气的属性改为火 | 需要指定目标范围，建议只允许选择我方手牌，避免随机改牌不可控 |
| 三条 | 获得 `功法值` 点防御；本回合防御减少时，对敌方造成 `本回合防御减少值 × 0.01 × 功法值` 点伤害 | 按本回合防御减少总量计算；完整基础牌组中三张A组成三条时，无成长功法值为108，加入成长后仍需实测反伤强度 |
| 顺子 | 下回合抽牌后，从敌方牌库随机抽 1 张加入我方手牌；若功法值 > 100，再从敌方手牌随机抽 1 张置入我方牌库 | 效果方向清楚，但“敌方手牌→我方牌库”很慢，可考虑置入我方手牌或牌库顶 |
| 同花 | 获得 `功法值` 点防御；接下来 `功法值 / 25` 回合，手牌上限额外 +1 | 完整牌组提高了平均真气值，持续回合数需要重新实测 |
| 葫芦 | 将弃牌堆中的 `功法值 / 25` 张牌洗入抽牌堆 | 适合一次性牌库规则，保留 |
| 四条 | 接下来 `功法值 / 50` 回合，敌方手牌上限 -1 | 稀有且强控，保留；最低持续 1 回合 |
| 同花顺 | 额外造成 `功法值 × 0.01 × 我方总真气数量` 点伤害 | 先按我方本场总真气数计算，包含牌库、手牌、弃牌等未被移除的真气；基础牌组由40增至52后该效果自然提高30%，系数必须重新实测 |

没有心得、强化、版本或其他倍率修正时，功法值等于基础伤害；倍率牌、幸运牌、版本或明确的功法与内功效果可以使两者不同。

### 2.5 内功

内功承担类似《小丑牌》的常驻规则改写：

- 可以改变抽牌、弃牌、倍率、牌型识别或功法触发条件；
- 暂设四个档位，档位主要用于出现概率与内容组织，不决定固定价格；
- 占用六个内功装备栏位，并受到清楚可见的格式／类型限制；
- 不绑定某一个普通牌型，除非内功文本明确这样写。

获得的内功进入本局内功库，不会因为六个装备栏位已满而自动替换、遗忘或出售已有内功；未装备内功保留但不生效。每个内功必须在文本中明确自己的触发时间，例如玩家回合开始、出牌、玩家回合结束、战斗胜利、完成节点或进入修习。内功不能在同一次出牌中无限生成牌型或递归触发功法。

功法是“某个牌型出现时做什么”，内功是“整套牌组和战斗规则如何被改写”，两者不能混成同一类效果。

#### 初始内功候选 v0.1

```text
未参与最高牌型的打出真气，其真气值总和转化为防御。
```

例如打出 `4、4、2、3`，最高牌型是一对，基础伤害为 `(4+4)×2=16`，触发一对功法；未参与一对的 `2、3` 额外提供 `5` 点防御。

该效果属于内功，不是默认出牌规则。没有装备此内功时，未参与最高牌型的牌只会被弃置，不提供额外防御。

### 2.6 获得、装备与遗忘

获得、装备和遗忘是三个独立动作：

```text
获得：加入本局功法库或内功库
装备：占用对应的九个功法位置或六个内功栏位并使效果生效
遗忘：玩家主动将已获功法或内功移出本局，并获得该武学标明的遗忘所得
```

未装备不等于遗忘，也不会自动换算为历练。功法与内功都可以存在已获得但未装备的状态。每门武学分别记录档位、修习价格和遗忘所得；档位与价格没有固定对应关系，不同档位的价格区间可以重叠。

## 3. 已确认的牌组与战斗基础规则

```text
基础牌组：风、林、火、山 4 种真气属性 × A、2～10、J、Q、K 13 个牌阶，共 52 张
玩家与敌人的基础手牌上限：默认 8 张
玩家初始生命：100
敌人初始生命：100
单次出牌候选：1～5 张
未选中的手牌：继续留在手牌中
被打出或弃掉的牌：进入弃牌堆
主动弃牌按钮：没有
弃牌动作：只由明确写有“弃掉”的功法或内功效果执行
一场战斗内：牌组只使用一次，不自动将弃牌堆洗回牌库
每个回合开始时：玩家与敌人分别按当前手牌上限统一补牌，最多补到各自手牌上限
牌库不够时：只补到能补的数量，不自动洗回弃牌堆
牌库和手牌都没有可用牌时：本场战斗不能继续
每个回合的第一击：玩家与敌人各自确定一次出牌后同步结算；后续出牌只按第 2.3 节的连击资格发生
玩家牌库与手牌都没有可用真气、且敌人尚未倒下时：本场战斗失败
战斗结束后：本场战斗的牌区清空并为下一场战斗重新整理
```

每次出牌不自动立即补牌；补牌统一发生在下一回合开始。52 张基础真气是当前正式基线，后续成长在此基础上增加、删除、复制、修改或附加效果。单次出牌上限仍为 5 张，不随手牌上限提高。

52 张牌组与 8 张基础手牌是配套基线，不拆开视为两个独立调整：完整牌组会稀释同牌阶组合，增加手牌则提供足够的牌型与属性选择。8 张手牌中选择 1～5 张共有 218 种组合，因此战斗界面和规则计算器必须提供：

- 按牌阶与真气属性整理手牌；
- 选牌时即时显示最高牌型；
- 即时显示当前功法的牌型及属性条件是否满足；
- 即时显示基础伤害与功法值。

打出的牌在行动结算后进入弃牌堆，但这项牌区移动不视为“弃掉”。只有功法或内功明确执行的弃牌动作，才触发“每弃掉一张牌”类效果。

## 4. 固定牌型倍率与心得倍率

固定牌型倍率不成长，始终使用第 2.1 节的基线，只决定基础伤害。心得提供另一条独立的累计成长：提高指定牌型的功法倍率，但不提高固定牌型倍率或基础伤害。

使用一份心得时，立即执行两项效果：

1. 按该牌型所在分组增加其累计心得倍率；
2. 从该牌型的功法池中随机获得一门功法。

| 心得分组 | 对应牌型 | 每份心得增加的功法倍率 |
| --- | --- | ---: |
| 低级牌型 | 高牌、一对、两对 | +1 |
| 中级牌型 | 三条、同花、葫芦 | +2 |
| 高级牌型 | 顺子、四条 | +3 |
| 同花顺 | 同花顺 | +4 |

每种牌型分别累计自己的心得倍率。例如使用两份三条心得后，三条累计心得倍率为 +4，不会提高同花或葫芦。所得功法进入对应牌型的功法库，不自动替换当前装备的功法；重复功法的处理规则待功法池设计时确定。

具体真气增益、版本、功法或内功也可以临时或有条件地修正功法倍率。第一版的倍率修正优先采用加减；只有多彩版本明确在功法倍率计算完成后进行百分比增幅。

概率统计统一按第 2.2 节的 52 张基础真气、8 张基础手牌与实际选牌规则计算。当前概率是未改造基础牌组的数学基线，不是完成平衡后的掉落率或实战出招率。

## 5. 玩家成长

一局内的成长由四部分组成：

1. **内功**：六个装备栏位，提供常驻规则改写或触发条件改变；未装备内功保留在本局内功库。
2. **功法**：九个牌型位置，每个牌型位置装备一个当前功法；未装备功法保留在本局功法库。
3. **真气**：可以增加、删除、复制、修改牌阶与属性，并获得增益或异状。普通的牌阶修改会同步更新基础真气值；只有明确写出的强化、版本或其他效果才会在不改变牌阶的情况下修改有效真气值。
4. **心得、丹药与天材地宝**：心得精进牌型并获得功法；丹药定向强化或转化真气；天材地宝进行更稀有、更强力的构筑改造。

固定牌型倍率不成长；功法倍率可以来自累计心得倍率、具体真气增益、功法或内功。

## 6. 心得、丹药、天材地宝、增益与异状

### 6.1 三类一次性修习内容

组合出招系统使用三类一次性修习内容：

| 内容 | 参考来源 | 当前职责 |
| --- | --- | --- |
| 心得 | 《小丑牌》星球牌 | 对应一种普通牌型；提高该牌型的累计功法倍率，并随机获得一门该牌型功法 |
| 丹药 | 《小丑牌》塔罗牌 | 定向增加、删除、复制真气，修改牌阶或属性，或为真气施加强化及其他常规转化 |
| 天材地宝 | 《小丑牌》幻灵牌 | 稀有且强力地改造真气牌组或内功，是施加版本与气印的主要来源，并允许比普通丹药更大幅度的收益、代价与结构变化 |

心得的倍率分组与累计规则见第 4 节。丹药和天材地宝主要在战斗外使用，产生持续至本局结束的构筑变化。三类内容的持有栏位、具体池和获取价格仍待确定。

### 6.2 六类真气效果

每张真气在真气值和属性之外，最多同时拥有三类增益与三类异状：

| 性质 | 类别 | 主要作用 | 单张真气上限 |
| --- | --- | --- | ---: |
| 增益 | 强化 | 改变真气的身份或使用方式 | 1 |
| 增益 | 版本 | 提高真气本身的数值或品质 | 1 |
| 增益 | 气印（讨论术语：蜡封） | 在打出、留手、弃掉等特定时点触发 | 1 |
| 异状 | 出招异状 | 该真气被打出时影响本次行动或持有者 | 1 |
| 异状 | 留手异状 | 该真气位于手牌时持续影响持有者 | 1 |
| 异状 | 特殊异状 | 改变出牌资格、牌区移动或其他特殊规则 | 1 |

一张真气的三个不同增益类别可以同时生效，三个不同异状类别也可以同时生效。例如普通强化真气可以同时具有强化、版本、气印、烈毒、破绽和封禁；但不能同时拥有烈毒与郁毒，因为二者都属于出招异状。石头牌是例外：可以拥有版本和气印，但不能拥有任何异状。

内功不拥有强化、气印或真气异状，但每门内功可以拥有一个版本。箔面、镭射、多彩可以用于真气或内功；负片只能用于内功。功法当前不拥有版本。

同一类别不能同时叠加两个效果。再次获得同名临时效果时只刷新其持续时间；施加另一个同类别临时效果时，新效果覆盖旧的临时效果。战斗中的临时效果可以暂时覆盖同类别的本局常驻效果，但不会删除它；临时效果消失后，原本的常驻效果恢复。用丹药或天材地宝替换同类别的本局常驻效果时，旧效果被永久替换。

### 6.3 常驻与临时

类别和持续性是两个不同维度：

| 持续性 | 主要来源 | 默认结束时间 |
| --- | --- | --- |
| 本局常驻变化 | 丹药、天材地宝、明确写出成长效果的内功 | 本局游戏结束 |
| 当前战斗临时变化 | 敌我功法、敌我内功 | 当前战斗结束，或效果文本写出的更早时点 |

功法默认只施加当前战斗中的临时变化。内功既可以在战斗中临时施加效果，也可以明确产生本局常驻变化，但必须在文本中写清持续时间。普通敌人造成的异状默认在战斗结束时清除；跨战斗异状只由明确写出的丹药、天材地宝、事件、Boss或特殊内功产生。

触发术语统一如下：

- **参与最高牌型**：只有组成最高牌型并以自己的有效真气值计入基础值的真气满足；对应《小丑牌》的普通“参与计分”。
- **参与数值计算**：包括参与最高牌型的牌，以及本次固定为基础值提供 10 点的石头牌。石头牌不因此成为最高牌型的一部分。
- **打出**：玩家本次选择并使用了该真气，不要求它参与最高牌型；出招异状按此口径触发。
- **留手**：该真气当前位于手牌；离开手牌后立刻停止留手效果。
- **弃掉**：只有功法或内功明确执行的弃牌动作；正常打出后进入弃牌堆不算弃掉。

### 6.4 第一批异状候选

| 异状 | 类别 | 当前效果 | 叠加口径 |
| --- | --- | --- | --- |
| 烈毒 | 出招异状 | 打出此牌时，持有者受到等于此牌真气值的伤害；此牌被打出或被效果明确弃掉后移除烈毒 | 同一张牌不能重复拥有；一次打出多张烈毒牌时分别结算 |
| 郁毒 | 出招异状 | 本次打出的牌中每有 1 张郁毒牌，本次行动值减少 20% | 按打出的郁毒牌数量相加；最低行动值与数量上限待测试 |
| 散气 | 出招异状 | 此牌参与最高牌型时，提供的有效真气值减半，向下取整；牌型识别仍读取原牌阶与原始属性 | 每张散气牌分别修改自己的数值贡献 |
| 破绽 | 留手异状 | 持有者受到伤害时，手牌中每有 1 张破绽牌，本次受到的伤害提高 20% | 按手牌中的破绽牌数量相加；上限待测试 |
| 封穴 | 留手异状 | 持有者造成伤害时，手牌中每有 1 张封穴牌，本次造成的伤害减少 20% | 按手牌中的封穴牌数量相加；最低伤害与数量上限待测试 |
| 封禁 | 特殊异状 | 此牌被抽入手牌后，本回合不能打出；本回合结束后移除封禁 | 同一张牌不能重复拥有；多张牌可以分别被封禁 |

“同一种异状不叠加”限制的是同一张牌上的同一个类别。不同牌可以各自拥有同名异状，并按效果读取的牌张数共同生效。后续异状必须归入出招、留手或特殊三类之一，不再任意增加新的异状槽位。

### 6.5 《小丑牌》增益映射审计

原作普通扑克牌可以同时具有一个强化、一个版本和一个蜡封；本系统的真气保留“一个强化、一个版本、一个气印”的结构，并根据对战中的基础伤害、功法值、防御与历练重新解释具体效果。

#### 强化

八种强化平级，不设置普通、罕见、稀有、传奇等强化档位。下列四组只用于修习界面展示和理解功能，不代表强弱顺序；若某个效果要求随机产生一种强化，八种强化默认等权，除非效果文本另有说明。

| 功能组 | 强化 |
| --- | --- |
| 稳定数值 | 奖励牌、倍率牌 |
| 组牌与爆发 | 万能牌、玻璃牌 |
| 留手与填充 | 钢铁牌、石头牌 |
| 经济与随机 | 黄金牌、幸运牌 |

| 强化 | 正式效果 | 结算边界 |
| --- | --- | --- |
| 奖励牌 | 此牌参与最高牌型时，提供的有效真气值为基础真气值 +2 | 牌型识别仍使用原牌阶；增加的 2 点同时进入基础伤害与功法值 |
| 倍率牌 | 此牌参与最高牌型时，本次功法倍率 +2 | 多张倍率牌正常相加，不设额外上限；不增加固定牌型倍率，也不改变基础伤害 |
| 万能牌 | 识别牌型与检查功法属性条件时，此牌同时视为风、林、火、山 | 只改变属性识别，不改变真气值；牌仍保留原始印刷属性，供明确读取原始属性的效果使用 |
| 玻璃牌 | 此牌参与最高牌型时，提供的有效真气值为基础真气值 ×2；整次出牌结算后有 1/4 概率永久移出本局牌组 | 只翻倍此牌自己的真气值贡献，不翻倍整次基础值；牌型识别仍使用原牌阶；每次出牌只进行一次损毁判定，不因其他重复触发再次判定 |
| 钢铁牌 | 持有者每次出牌结算结束时，若此牌仍在其手牌中，获得等于此牌真气值的防御 | 多张钢铁牌分别生效，暂不设置额外上限；长期占据手牌位置是其使用代价 |
| 石头牌 | 此牌失去牌阶、真气值和属性，不参与任何普通牌型；与至少一张非石头牌一起打出时，固定为本次基础值提供 10 点 | 不能单独打出；计入一次出牌的 1～5 张上限；多张分别提供 10 点；它不属于最高牌型，但其 10 点计入基础值后，视为参与本次数值计算 |
| 黄金牌 | 战斗胜利时，若此牌仍在持有者手牌中，获得 3 点历练 | 多张分别生效，暂不设置额外上限；战败不结算 |
| 幸运牌 | 此牌参与最高牌型时，分别进行两项独立判定：1/5 概率使本次功法倍率 +3；1/15 概率获得 20 点历练 | 两项可以同时成功；多张分别判定并正常相加，暂不设置额外上限；未参与最高牌型的幸运牌不判定 |

奖励牌示例：一张奖励 7 与普通 7 组成一对，牌型仍是一对 7，基础值为 `(7+2)+7=16`。

倍率牌示例：三条 `7、7、7` 中有两张倍率牌时，基础值为 21，基础伤害为 `21×3=63`，功法倍率为 `3+2+2=7`，功法值为 `21×7=147`。

石头牌示例：打出 `7、7、石头牌` 时，最高牌型为一对，基础值为 `7+7+10=24`，基础伤害为 `24×2=48`。石头牌不占据对子中的牌，但占据本次三张出牌中的一张。

石头牌可以拥有一个版本和一个气印，但不能拥有任何异状。一张真气转化为石头牌时：

- 保留已有版本和气印；
- 清除已有的出招、留手和特殊异状；
- 此后不能再被施加任何异状；
- 仍可被抽取、打出、弃掉、回收、复制、删除、夺取；
- 版本与气印可以作用于石头牌；需要判断该牌是否参与数值计算时，只要本次基础值加入了它的固定贡献，就视为满足。

丹药为真气施加强化时，第一版沿用下列目标数量：

| 强化 | 一次丹药的目标上限 |
| --- | ---: |
| 奖励牌 | 2 张 |
| 倍率牌 | 2 张 |
| 幸运牌 | 2 张 |
| 万能牌 | 1 张 |
| 玻璃牌 | 1 张 |
| 钢铁牌 | 1 张 |
| 石头牌 | 1 张 |
| 黄金牌 | 1 张 |

同一张真气只能拥有一种强化；为已有强化的真气施加另一种强化时，新强化替换旧强化。八种强化的具体数值作为第一版正式基线，后续只通过实测调整。

#### 版本

原作箔面、镭射、多彩可以用于普通扑克牌和小丑牌；负片不能用于普通扑克牌，但可以用于小丑牌。本系统对应保留：箔面、镭射、多彩可以用于真气或内功，负片只能用于内功。真气和内功使用相同版本数值，先保持直觉一致，后续再根据实测分别调整。

| 版本 | 真气上的效果 | 内功上的效果 |
| --- | --- | --- |
| 箔面 | 此牌每次参与数值计算时，该次自身贡献 +3 | 装备期间，每次出招的基础值 +3 |
| 镭射 | 此牌每次参与数值计算时，本次功法倍率 +1 | 装备期间，每次出招的功法倍率 +1 |
| 多彩 | 此牌每次参与数值计算时，本次多彩增幅 +20% | 装备期间，每次出招的多彩增幅 +20% |
| 负片 | 不允许施加于真气 | 该内功装备时，内功栏位上限 +1 |

多彩真气与多彩内功的百分比先全部相加，最后对未增幅功法值乘算一次并向下取整。例如两次多彩真气触发与一门多彩内功共同生效时，多彩增幅为 60%，而不是连续乘以三次 1.2。多彩只提高功法值，不提高基础伤害。

只有装备中的负片内功提供额外栏位。负片内功本身占用一个内功栏位，同时令栏位上限 +1，因此净占用为 0；即使当前栏位已满，也允许直接装备负片内功。多门负片内功可以叠加，未装备的负片内功不提供栏位。装备或卸下负片内功时，已装备数量与栏位上限同步增减 1。

同一张真气或同一门内功最多拥有一个版本。再次施加另一个版本时，新版本替换旧版本；负片不能作为真气版本的候选结果。石头牌保留并正常使用箔面、镭射和多彩版本。

#### 气印（讨论术语：蜡封）

| 气印 | 原作蜡封 | 正式效果 |
| --- | --- | --- |
| 金印 | 金色蜡封 | 此牌每次参与数值计算时，获得 3 点历练 |
| 赤印 | 红色蜡封 | 当此牌自身产生一次合格的数值或触发效果时，将该牌自身的这次结算额外执行一次 |
| 蓝印 | 蓝色蜡封 | 战斗胜利时，若此牌仍在手牌中，获得最后一次打出牌型对应的一份心得 |
| 紫印 | 紫色蜡封 | 此牌被功法、内功或敌方效果明确弃掉时，获得一份随机丹药 |

金印使用“参与数值计算”口径：普通真气必须参与最高牌型，石头牌只要提供固定贡献也可以触发；未参与最高牌型的多余普通真气不触发。多张金印分别生效，第一版暂不设置每场上限；若后续回收体系令经济失控，优先改为“每张金印每场最多获得一次”。

赤印只额外结算该张真气自身，不重新识别牌型，不再次触发功法、内功或赤印自身，也不触发其他牌。合格范围包括：

- 该牌自己的数值贡献；
- 该牌强化产生的数值、倍率、概率判定或合格触发；
- 该牌箔面、镭射、多彩版本的结算；
- 该牌在同一时点触发的异状；
- 该牌的留手效果或战斗胜利效果。

万能牌的全属性身份属于持续身份，赤印不会令其进一步增强。玻璃牌的自身贡献可以被赤印额外结算，但整次出牌仍只进行一次 1/4 损毁判定。赤印钢铁牌会额外获得一次防御，赤印黄金牌在胜利留手时会额外获得一次历练，赤印幸运牌会重新进行两项独立判定，赤印石头牌会额外提供一次固定贡献。

蓝印只在战斗胜利时结算，战败不结算；“最后一次打出牌型”读取玩家本场最后一次成功出招识别出的最高牌型。多张蓝印分别获得心得，第一版不额外限制生成数量；若未来心得设有持有栏位，则必须有空位才能生成。

紫印只响应规则术语“弃掉”。正常打出后进入弃牌堆、删除、摧毁、夺取或玻璃牌损毁均不触发；被我方或敌方效果明确弃掉都可以触发。回收后再次被明确弃掉时可以再次触发。多张紫印分别生效；若未来丹药设有持有栏位，则必须有空位才能生成。

同一张真气最多拥有一个气印；施加新气印时替换旧气印。内功和功法不能拥有气印。强化、版本和气印的数值作为第一版正式基线，后续根据实测调整。

四种气印平级，不按颜色划分强弱档位；它们的实际价值取决于出招、留手或弃牌构筑。具体出现率和天材地宝投放方式留待修习内容池设计。

## 7. 修习与历练

历练是本局唯一的经济类资源。战斗胜利后进入修习，消耗历练进行本局成长：

- 获取内功；
- 获取功法；
- 获取或使用心得、丹药与天材地宝；
- 增加、删除、复制、修改真气，或为真气与内功施加本局常驻效果；
- 冥想，刷新当前修习选项。

地图不设置商店节点。修习在战斗胜利后的流程中出现；商品数量、基础冥想费用和连续冥想费用仍待平衡。

### 7.1 战斗奖励与精进

| 战斗节点 | 胜利奖励 |
| --- | ---: |
| 普通敌人 | 3 点历练 |
| 精英敌人 | 4 点历练 |
| Boss | 5 点历练 |

每完成一个节点，自我精进一次：

```text
精进所得 = 当前持有历练 / 5
单次精进最多获得 5 点历练
所有除法向下取整
```

节点奖励、内功收益与精进在同一节点中的准确先后顺序仍待计算器测试；无论顺序如何，一个节点只精进一次。

### 7.2 档位与价格

功法和内功暂设四个档位。档位与价格没有必然对应关系：档位主要控制出现概率和内容组织，每门武学单独标价；高档位通常可以较贵，但不同档位允许价格重叠。当前仅冻结下列经济内功的普通档与价格，不建立“普通档固定4点”之类的统一公式。

### 7.3 第一批经济内功 v0.1

| 编号 | 内功效果 | 档位 | 修习价格 |
| ---: | --- | --- | ---: |
| 1 | 每次进入修习时，本次修习获得 1 次免费冥想。冥想会刷新当前修习选项。 | 普通 | 4 |
| 2 | 战斗结束结算时，若本场战斗从开始至结算前弃牌堆数量从未减少，则抽牌堆每剩余 1 张牌，获得 1 点历练；每场最多获得 20 点。 | 普通 | 4 |

## 8. 地图与战斗流程

一局游戏分为三层。每层由不同节点组成，节点类型可以包括普通战斗、精英战斗、事件、休息和特殊战斗；每层末尾固定进入该层 Boss 战。

```text
进入第1层
→ 选择本层节点
→ 战斗节点胜利后进入修习，再返回本层路线
→ 完成本层路线并进入层末 Boss
→ Boss 胜利后进入修习
→ 进入下一层
→ 第3层末 Boss 战胜利后结束本局
```

地图只负责节点选择，不提供普通商店节点；修习承担本局内的购买和冥想刷新。

## 9. 对战结果

基础伤害不是分数，而是本次行动默认造成的伤害。功法或内功可以在此基础上追加：

- 防御；
- 抽取、弃掉、锁定、夺取或回收真气；
- 其他明确写出的战斗效果。

除非功法或内功明确改写规则，基础伤害不会被改成另一种资源；高牌功法可以在造成高牌基础伤害的同时，按打出的散牌真气值提供防御。

敌人的攻击也应由它当前组成的普通牌型和已装备效果产生，不能退回固定的“攻击值／防御值”两个数字。

防御是功法或内功的效果，不是独立的牌型，也不是某种真气属性的公共效果。高牌可以使用“造成基础伤害并获得防御”的基础功法。

防御是持续保留的数值，可以在多次出牌中累积。受到伤害时，先从防御中扣除；伤害超过当前防御的部分才扣生命。若伤害没有耗尽防御，剩余防御继续保留；防御不会因为回合结束或没有出牌而自动清零。

## 10. 资源控制

资源优先使用牌区表达：

```text
手牌、剩余牌库、弃牌堆、已锁定牌、敌方手牌
```

功法或内功可以明确执行一项或少量牌区操作：

```text
抽牌、保留、弃掉、锁定、夺取、回收
```

这些操作是效果，不是额外的“势”或“能量”数值。第一版每个效果最好只作用于一个牌区、一个时间点，避免一次效果同时抽牌、弃牌、锁牌和夺牌。

弃牌不会在本场战斗中自动回到牌库；只有功法或内功明确写出“回收”时，牌才会重新变为可用资源。

## 11. 下一项实验

制作纯规则计算器，显示：

```text
给定一手8张真气
→ 枚举选择1～5张的方案
→ 识别最高普通牌型
→ 检查当前功法的牌型与真气属性条件
→ 结算参与数值计算真气的强化、版本与气印触发次数
→ 计算基础值
→ 读取固定牌型倍率、累计心得倍率与其他功法倍率修正
→ 得到基础伤害与功法值，但暂不造成伤害
→ 只触发最高牌型对应的功法一次，并触发已装备内功
→ 结算基础伤害、额外伤害、防御或牌区操作
→ 显示未参与牌型的真气被弃置
→ 回合开始时按手牌上限从剩余牌库补牌，基础上限为8张
→ 牌库不足时只补到能补的数量，不自动洗回弃牌堆
```

计算器先不加入完整敌人 AI、功法卡池或局外成长；先验证这条计算链是否清楚且有选择。
