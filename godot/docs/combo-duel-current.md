## 1. 设计目标

验证玩家是否愿意为了下一次更好的牌型，管理手牌、牌库和弃牌机会。

本项目借鉴《小丑牌》的牌型识别、牌面数值、倍率和效果联动，但最终结果是对战行动，不是筹码计分。

数值不是唯一成长目标。功法和内功负责提供更多战术效果、资源控制和敌我互动；公共真气成长应克制纯倍率叠加，避免最终仍变成只追求最高数值的计分游戏。

### 1.1 正式世界观映射与讨论术语

卡牌本身不是招式，而是供功法调动的真气；真正的招式由功法产生。正式描述统一使用以下映射：

| 《小丑牌》或讨论术语 | 正式术语 | 含义 |
| --- | --- | --- |
| 扑克牌、卡牌 | 真气 | 被抽取、留在手中并用于组合出招的基础单位 |
| 牌面、牌阶 | 牌阶 | A、2～10、J、Q、K；负责识别对子、顺子、高牌等普通牌型 |
| 计分值、牌值 | 真气值 | 负责基础值和读取牌值的效果；数字牌按牌面，J／Q／K 为 11，A 为 12；基础真气值最高为 12 |
| 花色 | 真气属性 | 风、林、火、山四种属性 |
| 牌型 | 牌型 | 真气组成的结构，继续使用通用扑克牌名称 |
| 小丑牌 | 内功 | 常驻规则改写与构筑核心 |
| 塔罗牌 | 丹药 | 一次性增加、删除、复制、强化或转化真气 |
| 星球牌 | 心得 | 精进指定牌型的功法倍率，并从该牌型所属共用功法池获得功法 |
| 幻灵牌 | 天材地宝 | 稀有且强力地改造真气、内功或整个构筑 |
| 优惠券 | 正式名称待定 | 由事件、精英与 Boss 提供的本局永久装备道具，修改修习、获取、价格、刷新、容量或其他系统规则 |
| 蜡封 | 气印 | 在出招、留手、弃掉等特定时点触发的真气效果 |

风、林、火、山在第一版只是真气属性标签，不各自附带公共攻击、防御、抽牌或恢复效果；这些差异由具体功法和内功建立。为了便于对照《小丑牌》和讨论概率，设计讨论中仍可继续使用“卡牌、花色、小丑牌、塔罗牌、星球牌、幻灵牌、蜡封”等原术语；正式界面、世界观说明和最终规则统一使用右侧术语。完整牌组中牌阶与真气值不再完全相同，因此涉及 A、J、Q、K 时不能笼统使用“点数”，必须明确说牌阶或真气值。

## 2. 出招结构

### 2.1 普通牌型

只使用普通扑克牌名称：

```text
高牌、一对、两对、三条、顺子、同花、葫芦、四条、同花顺
```

一次出牌只选择一个最高牌型。牌型只负责决定倍率，不把多个牌型的数值倍率相加。

当前使用以下固定基础倍率：

| 牌型 | 基础倍率 |
| --- | ---: |
| 高牌 | ×1 |
| 一对 | ×2 |
| 两对 | ×2 |
| 三条 | ×3 |
| 顺子 | ×4 |
| 同花 | ×4 |
| 葫芦 | ×4 |
| 四条 | ×7 |
| 同花顺 | ×8 |

这些倍率是当前计算基线，具体数值仍需与生命、功法和内功效果共同测试。

### 2.2 真气值与数值计算

暂定采用与《小丑牌》相近的计数方式：通常只有组成最高牌型的真气参与基础值计算。

每张普通真气同时记录三个基础属性：

```text
牌阶：负责识别高牌、对子、两对、三条、顺子、葫芦、四条
真气值：负责基础值及其他读取牌值的效果
真气属性：风、林、火、山；负责同花及功法属性条件
```

普通牌阶与真气值固定对应如下：

| 牌阶 | 真气值 | 牌阶顺序 |
| --- | ---: | --- |
| 2～10 | 等于牌面数字 | 2 < 3 < … < 10 |
| J | 11 | 10 < J |
| Q | 11 | J < Q |
| K | 11 | Q < K |
| A | 12 | K < A |

J、Q、K虽然真气值都为 11，但牌阶不同，不能互相组成对子、三条、葫芦或四条。A是最高牌阶，高牌判断中高于K；顺子是唯一例外，A既可以作为低端组成 `A、2、3、4、5`，也可以作为高端组成 `10、J、Q、K、A`，不能用于其他首尾相接的顺子。A在两种顺子中的真气值都固定为 12。

```text
基础值
= 所有参与数值计算的真气自身贡献之和
+ 装备中的箔面内功数量 × 3
+ 其他明确的基础值修正

牌型基准值 = 基础值 × 固定牌型倍率

牌型基准值只供功法、内功或毒异状在文本中明确读取；本次出牌不再自动造成伤害。

未增幅功法值
= 基础值 × 功法倍率
+ 其他明确的功法值固定修正

功法值增幅
= 参与数值计算的多彩真气触发次数 × 20%
+ 装备中的多彩内功数量 × 20%
+ 功法、内功或其他效果明确提供的功法值百分比增幅

功法值 = 向下取整[未增幅功法值 ×（1 + 功法值增幅）]

功法倍率
= 固定牌型倍率
+ 该牌型累计心得倍率
+ 参与最高牌型的倍率牌触发次数 × 2
+ 本次幸运牌成功触发次数 × 3
+ 参与数值计算的镭射真气触发次数 × 1
+ 装备中的镭射内功数量 × 1
+ 其他真气、功法或内功明确提供的倍率修正
```

普通真气每次触发时的自身贡献等于有效真气值；奖励牌与玻璃牌会改写有效真气值，箔面版本再为该次自身贡献增加 3 点。石头牌没有真气值，不参与普通牌型，但每次触发时固定贡献 10 点；箔面石头牌每次贡献 13 点。赤印可以令同一张真气的自身贡献、强化和版本额外触发一次。详细规则见 6.5 节。

固定牌型倍率只决定牌型基准值。累计心得倍率、倍率牌、幸运牌、镭射版本、多彩版本、功法值固定修正与明确的功法值百分比增幅只改变功法值，不改变牌型基准值；功法或内功只有在效果文本读取功法值时才会受到这些修正。所有功法值百分比增幅与多彩来源统一相加后只乘算一次，不建立多个“最终×功法值”连乘层。没有读取数值的固定效果，例如“下回合手牌上限 +1”，不会被倍率放大。

普通牌型中参与数值计算的真气数量：

```text
高牌：只计算最高的一张
一对：计算组成一对的两张
两对：计算两组对子的四张
三条：计算三张同牌阶真气
顺子：计算组成顺子的五张
同花：计算组成同花的五张
葫芦：计算三条与对子共五张
四条：计算四张同牌阶真气
同花顺：计算组成同花顺的五张
```

例如 `7、7、7、3、3` 组成葫芦，五张牌全部属于最高牌型，所以基础值是 `7+7+7+3+3=27`；牌型倍率取葫芦倍率。

例如打出 `7、7、4、3、A`，最高牌型是一对，只有两张7参与基础值，所以基础值是14；其余三张随本次出牌进入弃牌堆。

例如 `J、J` 可以组成一对，基础值为 `11+11=22`；`J、Q` 虽然真气值同为 11，但牌阶不同，不能组成一对。顺子 `A、2、3、4、5` 的基础值为 26，顺子 `10、J、Q、K、A` 的基础值为 55。

没有参与最高牌型的多余普通真气默认不增加基础值，也不触发自身的强化、版本或气印，只会随本次出牌进入弃牌堆。石头牌的固定贡献是强化规则的明确例外；功法或内功也可以明确改写这条规则，让额外真气参与计算或产生效果。

#### 基础概率

概率统计固定使用以下基线：

```text
52 张未改造基础真气
随机抽取 8 张作为手牌
玩家可以从中选择打出 1～5 张
总手牌样本数 = C(52,8) = 752,538,150
```

“可主动组成概率”表示随机 8 张中至少存在一种选牌方式，可以准确组成该牌型；由于玩家永远可以只出 1 张，所以高牌为 100%。这一列的不同牌型可以同时存在，不能相加。

“最高牌型概率”表示按普通牌型强弱判断，这 8 张能够组成的最高牌型；各行互斥，合计约为 100%。

| 牌型 | 可主动组成概率 | 最高牌型概率 |
| --- | ---: | ---: |
| 高牌 | 100% | 7.1061% |
| 一对 | 88.7920% | 31.3728% |
| 两对 | 43.7409% | 34.2522% |
| 三条 | 12.0075% | 5.1151% |
| 顺子 | 9.8030% | 8.9129% |
| 同花 | 6.9154% | 6.7572% |
| 葫芦 | 6.1846% | 6.0664% |
| 四条 | 0.336124% | 0.336098% |
| 同花顺，不含皇家同花顺 | 0.073168% | 0.072618% |
| 皇家同花顺 | 0.008619% | 0.008619% |
| 五条 | 0% | 0% |
| 同花葫芦 | 0% | 0% |
| 同花五条 | 0% | 0% |

皇家同花顺只是同花顺的特殊名称，固定倍率和机械规则与同花顺相同。把皇家同花顺合回同花顺后，“最高牌型概率”为约 `0.081237%`。主动组成事件可能重叠，例如同一手 8 张牌可能同时含有皇家同花顺和另一组同花顺，所以主动组成概率不能直接把两行相加。

五条、同花葫芦和同花五条在未改造的 52 张牌组中严格不可能；只有增加、复制或修改真气后才可能出现。

#### 不增加统一牌型筹码

《小丑牌》的结算是“牌型基础筹码 + 参与计分的牌面筹码”，再乘倍率。本系统确认不增加统一的牌型基础筹码，也不采用“（牌型基础筹码 + 真气值总和）× 倍率”。牌型基准值只使用“基础值 × 固定牌型倍率”，是否造成伤害由功法、内功或毒异状明确写出。

“功法值”不是另一份伤害或筹码，而是功法和内功在需要数值缩放时读取的计算结果。原作的牌型基础筹码在本系统中由具体功法的固定效果、最低效果或其他战斗作用承接；没有读取功法值的固定效果不会被倍率放大。功法值固定修正用于扶持低基础值牌型；传奇等效果提供的百分比功法值增幅与多彩统一相加，不采用多个独立终乘。这样可以保留牌型特效的价值，而不让高阶牌型、持续回合、防御和反伤随一段统一基础数值整体膨胀。

### 2.3 功法

功法是绑定牌型的特效。本次行动的处理顺序：

```text
识别最高牌型
→ 计算基础值、牌型基准值与功法值，但暂不造成伤害
→ 将本次合格功法与同一时点的已装备内功加入可见触发队列，按玩家排列从左到右逐个结算，建立防御、标记和延迟效果
→ 结算功法、内功、毒异状明确写出的伤害
→ 执行抽牌、弃牌、回收等牌区变化
→ 将打出的牌置入弃牌堆或按效果移出牌组
→ 结算“出牌结算结束时”的留手效果
```

若主牌型功法建立协同，则在主牌型开始结算前先锁定全部协同组；主牌型完成上述流程后，各协同组按锁定顺序分别重复完整流程。全部组结算结束后才视为本次行动结束，并检查通用同属性连击或其他额外行动效果。

玩法流派不由牌型或功法单独定义，而采用双轴关系：牌型负责出招频率、参与牌数、功法值规模、属性条件与序列推进节奏；功法负责伤害、防御、牌区、异状、标记、连击、协同与其他具体战斗行为；内功负责跨牌型连接、路线改写和常驻规则；真气改造负责把目标牌型从偶发变为稳定。完整构筑通常由一个主牌型、一个主要功法效果轴、可选的副牌型，以及配套内功和真气改造组成。

功法同时具有“牌型合格范围”和“效果方向”。牌型合格范围决定功法可以加入哪些具体牌型序列；毒、过牌、连击、借力、封禁等效果方向用于组织玩法流派和跨流派接口，不建立新的触发池、基础资源或额外结算次数。一次牌型组仍只触发其序列当前指向的一门功法。

功法不再为九种普通牌型分别创作九套内容，而是绑定下列六个共用功法池。同一共用池可以获得多个不同功法，新功法进入本局功法库，不会自动替换、遗忘或出售旧功法。

| 共用功法类别 | 对应牌型 |
| --- | --- |
| 高牌 | 高牌 |
| 一对、两对 | 一对、两对 |
| 三条、葫芦 | 三条、葫芦 |
| 四条、五条 | 四条，以及牌组改造后可能出现的五条 |
| 顺子 | 顺子 |
| 同花 | 同花 |

高牌可以由任意手牌主动打出，默认承担启动、保底、过渡和低成本铺垫作用；通常不以高牌单独覆盖一整套玩法流派。只有功法序列、内功和真气改造共同提供了足够的循环与成长时，高牌才可以作为明确例外发展为独立主牌型流派。其他一个或少量精确牌型都可以在获得足够功法与牌组支持后形成完整流派。

五条不是未改造基础牌组中的普通牌型，其固定倍率、心得分组与实战出现率仍待后续确认；当前只确认它未来沿用“四条、五条”共用功法池。

三条与葫芦虽然共用功法池，但不要求同一门功法在两个精确牌型下使用完全相同的固定参数。葫芦的平均牌型基准值已经约为三条的 2.22 倍，因此读取功法值的伤害、防御和规模不会再次获得统一加成；不随功法值成长的固定层数、目标数、展示数、抽牌数或回收数，则可以在葫芦分支中通常增加 1 份，补偿五张牌的出牌成本，少数直接补充运转的效果可以增加 2 份。以固定攻击段表现招式结构、但每段已经读取功法值的效果，不因葫芦而自动增加攻击段数。

具体牌型仍分别决定参与数值计算的真气、固定牌型倍率、累计心得倍率与本次功法值。共用功法池只决定“该牌型的功法序列可以配置哪些功法”，不会合并或修改不同牌型的牌型基准值、心得倍率或功法序列进度。

每个具体牌型拥有一条独立的循环功法序列。玩家可以从该牌型所属共用功法池中，把已经获得的功法按任意顺序加入该牌型序列；序列长度没有统一上限，但同一门功法在同一条序列中最多出现一次。属于同一共用池的不同具体牌型可以分别配置同一门已获功法，例如一对与两对可以各自在自己的序列中使用“双蛊缠脉”，两条序列的顺序与进度互不影响。

复合牌型拥有自己的独立功法序列，并可以从所有明确合格的共用功法池配置功法。同花顺可以使用顺子池与同花池；未来若加入同花葫芦，则可以使用“三条、葫芦”池与同花池；未来若加入同花五条，则可以使用“四条、五条”池与同花池。葫芦虽然包含对子，但只使用“三条、葫芦”池，不使用“一对、两对”池。复合牌型不在出牌时弹出临时功法选择。

每条功法序列按以下规则运行：

- 战斗开始时指向序列第一门；战斗结束后重置到第一门，除非内功明确改写。
- 每次打出该具体牌型，只尝试触发当前指向的一门功法；一次出牌仍只触发一门功法一次。
- 当前功法满足牌型、属性与其他触发条件并成功触发后，序列在该牌型组完整结算结束时前进一格；最后一门之后回到第一门。没有协同时，主牌型组结束即为本次行动结束；有协同时，后续同牌型协同组读取已经推进后的序列位置。
- 当前功法不满足条件时不产生效果，序列也不前进；玩家必须之后再次打出该具体牌型并满足条件，才能继续序列。
- 空序列不产生功法效果，但牌型基准值与功法值仍正常计算；没有其他明确伤害来源时，本次不造成伤害。
- 功法序列的内容与顺序在战斗开始后锁定，不能在战斗中通过普通装备操作临时重排、插入或移除；功法或内功可以明确改写序列位置。

功法的真气条件分为三类：

```text
通用功法：只限制牌型
属性功法：限制牌型，并要求参与最高牌型的真气中至少有指定数量属于某一真气属性
纯属性功法：限制牌型，并要求所有参与最高牌型的真气均视为指定真气属性
```

属性功法必须在文本中同时写明属性和数量，例如“一对，其中至少 1 张为火”或“三条，其中至少 2 张为山”。第一版每门属性功法只要求一种属性；只检查参与最高牌型的真气，不检查额外打出的真气或仍在手中的真气。万能牌在牌型识别和功法属性条件中同时视为风、林、火、山，明确读取原始属性时仍读取其印刷属性。

蛊毒跨越风与林，不强制建立“所有类别 × 风林火山”的完整矩阵。风以烈毒的扩散与快速催毒为主，林以郁毒的削弱与吸收转化为主，少量功法可以跨属性转毒或同时读取两种毒。功法可以只在本次最高牌型属于纯属性时触发，也可以作为通用功法并在纯属性时获得额外效果。“纯风”或“纯林”表示所有参与最高牌型的真气在属性识别中均视为对应属性；高牌只检查参与数值计算的最高一张，一对检查两张，两对检查四张，其他牌型按各自参与最高牌型的真气检查。未参与最高牌型的额外打出真气与没有属性的石头牌不破坏纯属性条件；万能牌视为所有属性。

普通牌型识别与固定牌型倍率只取最高牌型，功法按该具体牌型当前序列指向确定；基础值和功法倍率再按第 2.2 节及其他明确效果修正。组成葫芦的三条和对子不再额外推进其他牌型序列；组成同花顺也只推进同花顺自己的序列，不推进顺子或同花序列。

- 只检查本次实际选出的牌，不检查仍在手中的牌。
- 如果该具体牌型的功法序列为空，牌型的基础值和倍率仍然正常计算，但不产生功法特效。
- 如果装备了属性功法但本次真气不满足其属性与数量条件，牌型基准值仍正常计算，但该功法不触发。
- 功法产生的新牌、新效果不能在同一次出牌中递归触发功法。

高牌功法可以在自己的效果文本中读取本次打出的全部散牌，但只有最高的一张普通真气属于高牌并参与默认功法值计算。高牌的开局基础序列仍待从当前功法池中确定；高牌是否造成伤害、获得防御或建立启动效果，都由序列当前功法明确决定。

功法不设置统一装备数量上限；序列变长会降低其中每门功法再次轮到的频率，本身就是构筑成本。没有加入任何序列的已获功法继续保留在本局功法库。内功仍有六个装备栏位。第一版风林蛊毒与风运转功法池已经完成一次合并重构，但各具体牌型的开局序列与每门功法的最终数值仍待实测冻结。

没有心得、强化、版本或其他倍率修正时，功法值等于牌型基准值；倍率牌、幸运牌、版本或明确的功法与内功效果可以使两者不同。功法值的最终读取结果最低为 0。

#### 普通功法的即时战斗落点

由于出牌不再自动造成牌型基础伤害，除非明确标为特殊功法，否则每门功法完成结算时必须至少产生一个不依赖后续事件的即时战斗落点：直接造成伤害，或者立即获得防御。抽牌、弃牌、附毒、加标记、控顶、回收和延迟效果建立在这个落点之上，不能普遍取代它。

标准功法优先采用“即时伤害或即时防御 + 一个主要机制 + 可选条件强化”的结构。随机目标或合格目标不足时，功法的即时伤害或防御仍正常结算，不能因为敌方没有合格手牌、牌库为空或延迟条件尚未建立而整门空转。

每门功法必须至少有一项实际结算结果有意义地读取本次功法值 `P`。直接读取 `P`，或读取由 `P` 计算出的目标数、层数、持续次数、阈值、抽牌数、回收数等派生参数，都视为功法值参与；只有牌型、属性、异状或其他固定触发条件，不视为功法值参与。不能只在文本中形式化地提到 `P`，但让其在正常数值区间内不会改变任何结果。

普通功法仍必须拥有即时伤害或即时防御。如果主要机制完全使用固定值，则即时伤害或防御必须读取 `P`；如果主要机制本身已经读取 `P`，即时落点可以使用固定值。特殊功法只有在主要机制本身读取 `P` 时，才可以完全省略即时伤害与防御；若特殊机制全部为固定效果，则必须补充读取 `P` 的伤害或防御。功法建立延迟效果时，默认在建立时记录本次 `P` 及所需派生值，之后不因另一场出牌的功法值变化而更新，除非效果明确写出重新读取规则。

下列效果足以独立改变行动结构时，可以明确标为特殊功法并省略即时伤害或防御：建立连击或协同；大规模转换多个牌区；大量创建、复制、移除或回收战斗内临时真气；终结性毒爆；具有显著代价的传奇规则改写；其他能够单独完成完整战术目的的强控制。特殊功法仍必须有清楚的成功条件和失败边界，不能只以“效果复杂”为由省略战斗落点。

蛊毒属于长流程体系，标准蛊毒功法的防御型数量应多于伤害型。第一轮重构可以用约两门防御型对应一门伤害型作为审计目标，但不是所有类别必须严格复制的硬配额。蛊毒功法的直接伤害应低于火的多段连势与山的爆发伤害；主要胜势来自持续附毒、催毒、牌区控制和防御积累。防御会跨回合保存的当前规则可能放大长流程收益，因此附毒范围越广、控制越强，配套的即时防御就应越低。

#### 属性功法关键词与场内外改造边界

属性关键词表示主要倾向，不是排他限制。某个关键词可以少量出现在其他属性或跨流派功法中，但第一版应让玩家仅凭功法文本就能判断一套构筑的主属性与主要节奏。

| 属性 | 第一主轴 | 第二主轴 | 次要接口 |
| --- | --- | --- | --- |
| 风 | 抽牌、弃牌、控顶、回收与牌区流动 | 以烈毒为主的扩散、续毒与快速催毒 | 资源偷取、交换、乱流、协同与连击 |
| 林 | 回血、恢复真气、创建一次性真气资源 | 以郁毒为主的削弱、封穴与吸收转化 | 召回、回收、净化、临时强化、临时版本与临时气印 |
| 火 | 多段攻击、追击、连击与连势 | 借力反击、烧血、烧牌、焚脉与封禁 | 真伤、纯阳、异状衔接与高频响应 |
| 山 | 蓄势、倒计时、爆发与高伤害 | 护盾、反震、破绽与破防 | 稳定终结、真伤与承受伤害后的收益 |

烈毒主要归风、郁毒主要归林，但不硬性禁止另一属性使用。纯风烈毒与纯林郁毒都必须能够独立成型；风林混合时可以通过转毒、双毒收益和蛊印形成跨属性构筑。同一张真气仍只能拥有烈毒或郁毒之一，转换仍必须由效果明确写出。

牌阶、印刷属性、强化、版本和气印的本局常驻修改，主要由战斗外的丹药、天材地宝、事件和其他成长内容完成。普通功法不应在战斗中永久复制或改造基础牌组。林属性功法可以在战斗中创建战后移除的一次性真气资源，或为真气施加持续至本场战斗结束、指定次数耗尽或触发后移除的临时强化、临时版本和临时气印；这些效果必须写明恢复与移除时点。

延迟结算是所有属性都可以使用的通用表现，不单独作为某个属性的流派。山更偏向主动蓄势和倒计时终结，火偏向攻击段与受击响应，风偏向牌区移动后的延迟触发，林偏向持续恢复、成长和资源再生。

资源偷取与交换主要分配给风和林：风偏向夺取、换位和打乱敌方牌区，林偏向吸收敌方削减值并转化为我方生命、防御或临时真气。牌库污染与诅咒优先通过毒、异状、临时伪牌和封禁表达，不另建一个平行的大类关键词。

第一版不普遍加入“取消整门功法”或“中断整次行动”的硬反制。反制优先使用降低真气贡献、封禁、封穴、弃掉、临时移出、防御和反击等可见的软控制；完整取消只保留给具有明确次数、代价和提示的稀有或传奇效果。随机抽牌、随机目标和随机属性属于结算方式，不单独构成流派；风险收益必须来自玩家可理解的代价与回报，例如燃命、烧牌、临时移除、玻璃牌损毁或赌取高收益。

永久牌型识别改写，例如四张组成同花、缩短顺子或改变牌阶关系，应由内功、优惠券对应物或其他在识别牌型前已经生效的规则承担。功法在识别牌型后才触发，不能追溯把本次牌型改成另一个牌型；功法可以明确建立协同，内功或优惠券对应物可以改变允许锁定的协同路线。

#### 同一时点的触发队列

每个功法、内功、真气效果和延迟效果都必须明确自己的触发时点。不同触发时点按行动流程固定先后；只有处于同一触发时点的效果才进入同一条可见触发队列。

同一时点沿用《小丑牌》的实时从左到右结算逻辑：每个效果读取结算当时的最新牌区、异状、标记与数值，完整结算并更新状态后，下一效果再重新读取。玩家可以调整内功的左右顺序；本次合格功法视为一个动态功法结算位，也可以放置在内功之间，其相对位置在不同牌型触发不同功法时保持不变。

功法序列只在当前牌型组完整结算结束时前进。同一牌型组中若效果明确重触本次功法，重触的仍是该组最初指向的同一门功法，不会在同一组中连续播放序列后续功法；该组无论重触多少次，成功后都只前进一格。协同建立的后续牌型组不属于重触，因此同一精确牌型的后一组会读取前一组已经推进后的下一门功法。

- 后置效果可以读取前置效果刚建立的牌区变化、异状、标记与功法增益。
- 已经完成检查的前置效果不会因为后置效果改变状态而追溯重触。
- 同一时点新生成的效果，如果其结算位置已经过去，则等待下一次合格触发时点，不倒回队列。
- 明确写有重触或复制时，只重新执行指定对象，不重新运行整条触发队列；重触时重新读取当前牌区与合格目标。
- 同一个效果在自身结算过程中产生相同触发条件时，不递归触发自己，除非文本明确允许；跨越抽牌、再次出牌或另一个触发时点形成的循环可以正常成立。
- 参与数值计算的真气、留手真气与同一时点的功法／内功，均按界面显示的左右顺序分别结算。

#### 通用连击与协同

连击不是第七类共用功法池，而是一次行动完整结束后开启新行动的通用机制。一个完整回合以双方同步进行的第一击开始：双方各自选择并识别本次行动，先分别建立本次行动产生的防御、标记与其他伤害前状态，再同步结算双方明确写出的伤害；随后各自完成抽牌、弃牌、回收、打出真气离手与留手效果。只有双方第一击及随后双方都持有额外行动机会的连击会同步结算。

双方各自独立检查通用同属性连击：每个完整回合中，若该方一次行动实际打出的所有普通真气都可以视为同一种属性，则该方自然获得 1 次额外出牌机会。万能牌可以配合任意属性满足条件；没有属性的石头牌不破坏同属性条件，也不单独建立一种属性。功法、内功或其他明确效果可以继续给予额外出牌机会；全局不设置额外行动次数上限，但通用同属性连击默认每方每个完整回合只自然触发一次。双方都获得额外行动机会时，下一击再次同步；只有一方获得时，该方单独再次出牌，另一方不触发新的出牌效果。全部连击结算后，完整回合结束。

每次连击出牌都是一次新的完整行动：重新选择 1～5 张牌、识别最高牌型、计算牌型基准值与功法值，并完整结算功法、内功、强化、版本、气印、异状、伤害和牌区变化。同步击中的受击响应按攻击段逐次触发；单方连击不使另一方建立新的出牌效果。连击不默认提高伤害或功法倍率，额外出牌机会不能储存到下一完整回合。“玩家回合”与“敌方回合”效果分别读取各自从第一击开始到其全部连击结束的行动段；只有一方获得单方连击时，只有该方进入新的行动段。

连击期间不自动补牌；回合开始补牌仍遵守第 3 节。连续打出顺子、同花、葫芦等五张牌型，必须依靠明确的抽牌、回收或返还效果取得足够真气，不能暗中重洗弃牌堆或改变基础补牌规则。功法或内功若要求连打某一牌型，“同一牌型”默认指精确牌型；一对与两对、三条与葫芦、顺子与同花均不是同一牌型。

协同不是连击。协同在玩家确认主牌型时，允许从剩余手牌中提前锁定一个或多个符合功法条件的额外牌型；主牌型与协同组属于同一次行动，按界面显示顺序依次完整结算。每一组分别识别自己的精确牌型、计算自己的牌型基准值与功法值、触发功法／内功／强化／版本／气印／异状，并推进自己的具体牌型功法序列。同一张真气不能被两个组重复使用。

协同牌在主牌型开始结算前进入待出区，已经锁定的协同牌不会被主牌型或前置效果的随机弃牌选中。前置效果新抽到的牌不能补入本次已经锁定的协同序列，只能用于之后的连击行动。同一精确牌型连续协同时，前一组成功结算后先推进该牌型序列，后一组读取推进后的下一门功法。

判断通用同属性连击时，统一检查本次行动中主牌型与所有协同组实际打出的普通真气；它们必须共同满足同一种属性。任意一组不满足时，本次行动不能自然触发通用同属性连击。协同的具体起手与续接条件由功法明确给出；内功可以改变协同路线或提供协同奖励，但协同本身不默认增加统一伤害倍率。

#### 第一版风林蛊毒功法池 v0.3

本池由原 46 门蛊毒候选合并为 35 门当前候选：高牌 6 门、一对／两对 6 门、三条／葫芦 6 门、四条／五条 6 门、顺子 5 门、同花 6 门。风以烈毒的扩散、续毒和快速催毒为主，林以郁毒的削弱、回收和吸收转化为主，标为“风林”的功法提供转毒、共用蛊印或双毒收益。被合并的旧效果不再作为独立功法进入当前活跃池。

统一记号：`P` 为本次功法值；`N = max(1, floor(P / 60))`。除标为特殊功法者外，每门功法都立即造成伤害或获得防御；随机目标不足不影响这个即时落点。所有附毒继续遵守第 6.4 节的实时牌区、随机目标、不重复选择与不覆盖规则。

**高牌（6 门）**

- **烈蛊飞针**（风·烈毒）：造成 `max(1, floor(P / 2))` 点伤害；随机给敌方当前手牌 1 张合格真气附烈毒。本次为纯风高牌且实际附毒时，敌方再获得 1 层蛊印。
- **一线悬蛊**（风·烈毒）：获得 `P` 点防御，敌方获得 1 层蛊印；本次为纯风高牌时改为获得 2 层蛊印。
- **郁蛊敛息**（林·郁毒）：获得 `P` 点防御；随机给敌方当前手牌 1 张合格真气附郁毒。本次为纯林高牌且敌方手牌没有合法目标时，改为从敌方牌库顶向下寻找第一张合法目标附郁毒。
- **以毒养息**（林·郁毒）：获得 `max(1, floor(P / 2))` 点防御；随机使我方当前手牌 1 张没有出招异状的普通真气获得郁毒。若实际附毒，再获得等于该牌附毒前有效真气值的防御。
- **百毒敛息**（风林）：获得 `max(1, floor(P / 2))` 点防御；随机移除我方当前手牌 1 张烈毒或郁毒，并随机给敌方当前手牌 1 张合格真气附上相同毒。任一侧没有合格目标时只结算实际部分。
- **毒甲护体**（风林）：获得 `max(1, floor(P / 2))` 点防御与 1 层毒甲；我方下一次毒触发时，烈毒实际伤害或郁毒实际削减值降低 50%，向下取整，随后移除毒甲。

**一对、两对（6 门）**

- **双蛇烈手**（风·烈毒）：造成 `max(1, floor(P / 3))` 点伤害；一对随机给敌方当前手牌至多 1 张、两对至多 2 张合格真气附烈毒。
- **双蛊缠脉**（风·烈毒）：获得 `max(1, floor(P / 2))` 点防御；一对使敌方获得 1 层蛊印，两对使敌方获得 2 层蛊印。
- **双心郁指**（林·郁毒）：获得 `max(1, floor(P / 2))` 点防御；一对随机给敌方当前手牌至多 1 张、两对至多 2 张合格真气附郁毒，本次为纯林时目标数增加 1。
- **毒骨换脉**（林·郁毒）：获得 `max(1, floor(P / 2))` 点防御；一对随机使我方当前手牌至多 1 张、两对至多 2 张合格真气获得郁毒，并获得等量毒骨层。之后我方郁毒触发时消耗 1 层，获得等于该次郁毒实际削减值 50% 的防御，向下取整。
- **子母蛊**（风林）：获得 `max(1, floor(P / 4))` 点防御与 `N+2` 层子母蛊；敌方当前手牌中的真气获得毒时消耗 1 层，随机使敌方牌库 1 张合格真气获得相同毒。一次附毒效果只消耗 1 层，并按该效果实际附毒数量传播。
- **换毒手**（风林）：获得 `max(1, floor(P / 4))` 点防御；随机选择敌方当前手牌中至多 `N` 张带毒真气，先按原毒触发一次，再将烈毒转为郁毒或将郁毒转为烈毒；转化后的毒本次不重复触发。

**三条、葫芦（6 门）**

- **三尸种蛊**（风·烈毒）：获得 `max(1, floor(P / 3))` 点防御；三条使敌方获得 3 层蛊印，葫芦改为 4 层；本次为纯风时再增加 1 层。
- **蛊王蚀气**（风·烈毒）：造成 `max(1, floor(P / 3))` 点伤害；消耗至多 `N` 层蛊印，逐层随机给敌方当前手牌合格真气附烈毒。目标不足时，剩余每层从敌方牌库随机抽取 1 张合格真气，附烈毒后加入手牌；牌库没有合格目标时停止，明确抽牌可以超过敌方当前手牌上限。
- **三郁蚀脉**（林·郁毒）：获得 `max(1, floor(P / 3))` 点防御；随机给敌方当前手牌至多 `N+1` 张合格真气附郁毒，本次为纯林时目标数再增加 1。
- **蛊蜕回元**（林·郁毒）：获得 `max(1, floor(P / 3))` 点防御与 `N` 层蛊蜕；敌方毒触发时消耗 1 层，将我方弃牌堆顶 1 张真气洗回我方牌库。
- **三毒无明**（风林）：获得 `max(1, floor(P / 4))` 点防御；三条获得 3 层无明，葫芦改为 4 层；本次为纯风或纯林时再增加 1 层。毒触发时消耗 1 层，对同一张真气额外结算一次 50% 效果的同种毒；额外结算不视为新的毒触发。
- **逆脉续蛊**（风林）：获得 `max(1, floor(P / 4))` 点防御与 `N` 层续蛊；敌方没有蛊印时发生毒触发，消耗 1 层，使该牌重新获得同种毒并放回敌方牌库顶。

**四条、五条（6 门）**

- **烈毒归库**（风·烈毒）：造成 `max(1, floor(P / 3))` 点伤害；敌方当前手牌中每有 1 张烈毒真气，本次伤害提高 20%。随后将这些烈毒真气洗入我方牌库，战斗结束后归还原持有者。
- **万蛊归巢**（风·烈毒，特殊）：将敌方弃牌堆中本场曾触发过毒且当前没有出招异状的真气重新附上其最后触发的毒并洗回敌方牌库，每洗回 1 张使敌方获得 1 层蛊印；再获得 `N` 层寻毒，之后敌方每次抽牌前消耗 1 层，优先随机抽取带毒真气。
- **天蚕噬蛊**（林·郁毒）：获得 `max(1, floor(P / 3))` 点防御；消耗敌方全部蛊印并获得等量噬蛊层。之后毒触发时消耗 1 层，使该次毒效倍率 +50%，并获得 `max(1, floor(P / 30))` 点防御。
- **蛊潮封脉**（林·郁毒）：获得 `max(1, floor(P / 3))` 点防御与 `N` 层蛊潮；敌方郁毒触发时消耗 1 层，随机使敌方剩余手牌 1 张真气获得封穴。没有合格剩余手牌时不消耗层数。
- **成蛊反噬**（风林）：获得 `max(1, floor(P / 4))` 点防御与 `N` 层成蛊；烈毒触发时消耗 1 层，按当前郁毒规则对同一张真气额外结算一次郁毒；郁毒触发时消耗 1 层，对敌方造成等于该次郁毒实际削减值的伤害。
- **万蛊伪牌**（风林，特殊）：展示敌方牌库顶至多 `N+2` 张真气；其中每有 1 张带毒真气，就生成 1 张与其牌阶、属性相同但有效真气值固定为 0、没有强化、版本和气印的临时真气，洗入敌方牌库，最后重洗敌方牌库。临时真气在战斗结束时移除。

**顺子（5 门）**

- **蛇行烈蛊**（风·烈毒）：造成 `max(1, floor(P / 4))` 点伤害；从敌方牌库顶向下寻找前 `N` 张没有出招异状的普通真气附烈毒，不改变这些牌的相对顺序。
- **毒脉绵延**（风·烈毒）：获得 `max(1, floor(P / 4))` 点防御，使敌方获得 `N+1` 层蛊印，并获得 `N` 层寻脉；蛊印使毒牌洗回牌库时消耗 1 层寻脉，将该牌改置敌方牌库顶。
- **蛇行引蛊**（林·郁毒）：获得 `max(1, floor(P / 4))` 点防御；从敌方牌库随机选择至多 `N` 张合格真气附郁毒并保持相对顺序，本次为纯林顺子时改为从牌库顶向下寻找前 `N+1` 张合法目标。
- **郁林漫卷**（林·郁毒）：获得 `max(1, floor(P / 4))` 点防御，持续 `N` 个敌方回合；每个敌方回合开始时，分别从敌方手牌、牌库与弃牌堆随机选择至多 1 张合格真气附郁毒，各牌区不足时不互相转移次数。
- **百足连环**（风林）：造成 `max(1, floor(P / 5))` 点伤害并获得 5 层百足；毒触发时消耗 1 层，给敌方牌库顶向下第一张没有出招异状的普通真气附上同种毒。

**同花（6 门）**

- **烈瘴灼脉**（风·烈毒）：造成 `max(1, floor(P / 4))` 点伤害；随机给敌方当前手牌至多 `N` 张合格真气附烈毒，手牌目标不足时从敌方牌库随机补足。
- **赤炼毒甲**（风·烈毒）：获得 `max(1, floor(P / 3))` 点防御与 `N` 层赤炼；烈毒触发时消耗 1 层，我方获得等于本次实际烈毒伤害的防御。
- **郁林蚀心**（林·郁毒）：获得 `max(1, floor(P / 3))` 点防御；随机给敌方当前手牌至多 `N` 张合格真气附郁毒，本次为纯林同花时另从敌方牌库随机选择至多 `N` 张合格真气附郁毒。
- **郁瘴封穴**（林·郁毒）：获得 `max(1, floor(P / 3))` 点防御；敌方当前手牌中所有郁毒真气获得封穴，不影响此前已经离开手牌的真气。
- **红玉九香**（风林）：获得 `max(1, floor(P / 4))` 点防御与 3 层九香，本次为纯风或纯林同花时改为 5 层。毒触发时消耗 1 层，敌方当前每有 1 张带毒真气使本次毒效倍率额外提高 10%。
- **风瘴换脉**（风林，特殊，纯风）：获得 `max(1, floor(P / 5))` 点防御；立即使敌方手牌、牌库与弃牌堆中所有烈毒真气各结算一次烈毒并移除烈毒；随后将这些牌区中的所有郁毒转化为烈毒，新转化的烈毒本次不触发。

#### 第一版风运转功法池 v0.3

本池由原 30 门候选合并为 27 门当前候选：高牌 4 门、一对／两对 4 门、三条／葫芦 5 门、四条／五条 5 门、顺子 4 门、同花 5 门。内部按抽换、回收、控牌、风标与连动四组组织；临时手牌上限不再作为普遍效果，明确抽牌仍可超过当前手牌上限。

统一记号：`P` 为本次功法值；`N = max(1, floor(P / 60))`。除标为特殊功法者外，每门功法立即造成伤害或获得防御。风引、回风与乱流继续使用第 6.4 节共享规则。

**高牌（4 门）**

- **清风过隙**：造成 `P` 点伤害；抽 1 张牌，再随机弃掉当前手牌 1 张。若第一次抽到的牌为风属性，则额外抽 1 张；额外抽到的牌不再次检查属性。
- **听风探顶**：获得 `max(1, floor(P / 2))` 点防御；展示我方牌库顶至多 `N+2` 张牌，玩家选择 1 张加入手牌，再从剩余牌中选择 1 张附上风引并放回牌库顶，其余按原相对顺序放回。剩余牌不足时只结算实际部分。
- **一叶回身**：获得 `max(1, floor(P / 2))` 点防御；随机从我方弃牌堆将至多 2 张牌加入手牌。只有实际回手至少 1 张时，玩家才选择当前手牌 1 张放回我方牌库顶。
- **空谷回声**：获得 `max(1, floor(P / 2))` 点防御；我方下个回合正常补牌结束后额外抽 1 张，本次为纯风高牌时改为额外抽 2 张。不修改手牌上限。

**一对、两对（4 门）**

- **双风换气**：造成 `max(1, floor(P / 2))` 点伤害；一对抽 2 张再随机弃掉 1 张，两对抽 3 张再随机弃掉 1 张。若弃掉的是风属性牌，额外造成等于该牌当前有效真气值的伤害。
- **同阶引路**：造成 `max(1, floor(P / 2))` 点伤害；协同“同牌阶的一对”。四张同牌阶真气可以被锁定为主一对与协同一对，两组分别触发并推进一对功法序列。
- **双燕掠手**：一对明确弃掉敌方当前手牌 1 张，两对明确弃掉至多 2 张；造成 `max(1, floor(P / 2))+本次实际弃牌有效真气值总和` 点伤害。
- **双燕回巢**：获得 `max(1, floor(P / 2))` 点防御；一对选择我方当前手牌 1 张附上回风，两对选择至多 2 张附上回风。

**三条、葫芦（5 门）**

- **三环吐纳**：造成 `max(1, floor(P / 2))` 点伤害；三条抽 3 张、葫芦抽 4 张，再随机弃掉 2 张。每抽到 1 张风属性牌，额外造成等于该牌当前有效真气值的伤害。
- **三叠回风**：获得 `max(1, floor(P / 2))` 点防御；三条从我方弃牌堆随机选取至多 3 张牌，葫芦改为至多 5 张，玩家选择其中 1 张放回我方牌库顶，其余洗回牌库。
- **回风续式**（特殊）：获得 `max(1, floor(P / 3))` 点防御；本次参与最高牌型的真气进入弃牌堆后，从其中仍在弃牌堆的牌随机回手：三条回手 1 张，葫芦回手至多 2 张；本次为纯风时再增加 1 张。随后获得 1 次连击机会。
- **三息乱流**：获得 `max(1, floor(P / 3))` 点防御；三条展示敌方牌库顶 3 张牌，葫芦改为展示 5 张，玩家选择其中 1 张附上乱流，本次为纯风时可以选择至多 2 张。
- **三环并奏**：造成 `max(1, floor(P / 2))` 点伤害；协同“一对”。

**四条、五条（5 门）**

- **换海纳气**：获得 `max(1, floor(P / 3))` 点防御；抽牌至当前手牌上限，当前手牌已经达到或超过上限时不抽牌。
- **夺气归巢**：明确弃掉敌方当前手牌至多 `N` 张；造成 `max(1, floor(P / 2))+本次实际弃牌有效真气值总和` 点伤害。再从这些实际弃牌中随机选择 1 张洗入我方牌库，该牌战斗结束后归还原持有者。
- **风尽归一**（纯风，传奇，特殊）：本次出牌进入弃牌堆后，依次执行：明确弃掉我方全部剩余手牌；正常结算回风、紫印与弃牌内功；将此时实际仍在我方弃牌堆的全部牌洗回我方牌库；记录实际洗回数量；造成 `floor[P×(1+实际洗回数量×1%)]` 点伤害；最后抽牌至当前手牌上限。
- **万籁听风**：获得 `max(1, floor(P / 3))` 点防御；展示我方整个牌库，随机使其中至多 `N` 张风属性牌获得风引，随后重洗我方牌库。
- **四象合鸣**（传奇，特殊）：造成 `max(1, floor(P / 2))` 点伤害；协同“任意精确牌型”，该协同组的功法值提高 20%。

**顺子（4 门）**

- **蛇行理脉**：获得 `max(1, floor(P / 3))` 点防御；展示我方牌库顶至多 `N+4` 张牌，玩家选择其中至多 5 张并按任意顺序放回牌库顶，其余按原相对顺序放回。
- **风路控顶**：造成 `max(1, floor(P / 2))` 点伤害；展示敌方牌库顶至多 `N+4` 张牌，玩家必须选择至少 1 张、至多 `N` 张并按任意顺序放回敌方牌库顶，其余展示牌全部被功法明确弃掉。牌库没有牌时只结算伤害。
- **回环长息**（纯风，稀有）：获得 `max(1, floor(P / 3))` 点防御；本次顺子的 5 张真气进入弃牌堆后，仍在弃牌堆的牌全部附上风引并洗回我方牌库。
- **五步余音**：造成 `max(1, floor(P / 2))` 点伤害；协同“高牌”。

**同花（5 门）**

- **同流换手**：获得 `max(1, floor(P / 3))` 点防御；明确弃掉我方当前手牌中所有非风普通真气，展示我方牌库顶“实际弃牌数量 + N”张牌，将其中所有风属性牌加入手牌，其余牌放到牌库底。
- **风潮袭手**：明确弃掉敌方当前手牌至多 `N` 张；造成 `max(1, floor(P / 2))+本次实际弃牌有效真气值总和` 点伤害。本次为纯风同花时，再选择敌方剩余手牌 1 张放回敌方牌库顶并附上封禁。
- **风牢锁袖**：获得 `max(1, floor(P / 4))` 点防御；敌方下个回合的手牌上限 -`N`，最低为 1，不立即弃掉超过上限的现有手牌。本次为纯风同花时持续接下来 2 个敌方回合。
- **风印满袖**：获得 `max(1, floor(P / 3))` 点防御；我方当前手牌中所有风属性普通真气获得回风。
- **花下双生**：造成 `max(1, floor(P / 2))` 点伤害；协同“一对或两对”，协同牌必须与主同花共同满足同一种属性。

#### 第一版火反击功法池 v0.2

本池围绕多段攻击、追击、借力反击、焚烧敌方真气、纯阳、真伤、燃命代价与跨流派衔接建立火属性玩法。火属性不承担主动蓄力后打出巨大单次伤害的定位；高收益主要来自敌方行动、连续攻击、资源转化与延迟结算。每个共用功法类别都同时拥有多段、反击、控制、纯火／纯阳、代价和跨流派接口，使单一牌型或少数牌型也能完成火系构筑。

统一记号：`P` 为本次功法值；`N = max(1, floor(P / 60))`；`L = max(1, floor(P / 30))`。攻击段、追击、反击、真伤、纯阳、借力、焚脉、绝气与连势使用第 6.4 节公共规则。所有数值均为第一版暂定值。

**高牌（8 门）**

- **火星连点**：造成 3 次 `max(1, floor(P / 4))` 点伤害，每个攻击段结算后获得 1 层连势。本次为纯阳时，第三段改为真伤。
- **借火护心**：造成 `floor(P / 2)` 点伤害，获得 1 层借力；结算时我方防御为 0 则改为获得 2 层。
- **点脉灼气**：造成 `floor(P / 2)` 点伤害，敌方获得 1 层焚脉；本次为纯阳时，敌方再获得 1 层绝气。
- **赤心照骨**（纯阳）：造成 2 次 `max(1, floor(P / 3))` 点真伤。
- **燃指换劲**：燃命 `L`，获得 2 层借力与 `P` 点防御。
- **毒焰催发**（跨蛊毒／异状）：造成 `floor(P / 2)` 点伤害；随机使敌方当前手牌至多 1 张带毒真气立即触发其毒。若实际触发，敌方获得 1 层焚脉；没有带毒目标但敌方手牌中存在破绽或封穴时，改为获得 1 层借力。
- **拨火添薪**：造成 `floor(P / 3)` 点伤害，抽 2 张牌，再随机弃掉 1 张当前手牌。每抽到 1 张火属性普通真气，获得 2 层连势；若实际弃掉火属性真气，获得 1 次连击机会。
- **微火长明**：造成 2 次 `max(1, floor(P / 4))` 点伤害，每段结算后获得 1 层连势；本次为纯火高牌时每段改为获得 2 层。

**一对、两对（8 门）**

- **双阳叠响**：一对造成 2 次 `max(1, floor(P / 3))` 点伤害，两对造成 4 次 `max(1, floor(P / 6))` 点伤害；每个原始攻击段结算后获得 1 层连势。本次为纯阳时，最后一段额外进行一次 50% 伤害的追击，该追击结算后获得 2 层连势。
- **双镜返照**：造成 `floor(P / 2)` 点伤害；一对获得 1 层借力，两对获得 2 层借力。本次为纯火时，敌方当前手牌中所有普通真气的有效真气值在本场战斗中降低本次最高牌型的参与张数，一对降低 2 点、两对降低 4 点，最低为 0；每有 1 张真气的有效真气值实际降低，获得 1 层连势。
- **合脉焦灼**：造成 `floor(P / 3)` 点伤害；一对使敌方获得 1 层焚脉，两对使敌方获得 2 层焚脉。本次为纯火时，敌方获得相同数量的绝气。
- **赤锁成环**：造成 `floor(P / 3)` 点伤害；一对随机使敌方当前手牌 1 张获得封禁并放回牌库顶，两对作用于至多 2 张。每实际使 1 张牌获得封禁，获得 2 层连势；若选中的牌已经拥有封禁，则改为将其临时移出本场战斗，战斗结束后归还，获得 3 层连势，并从敌方牌库顶向下寻找 1 张没有封禁的普通真气使其获得封禁，不改变牌库顺序。
- **血火追身**：一对燃命 `L`，两对燃命 `2L`；造成 `max(1, floor(P / 2))` 点伤害，随后追加一次该段 30% 伤害的追击。本次为纯阳时，该追击改为真伤。
- **双异煽焰**（跨异状）：造成 `floor(P / 2)` 点伤害，然后分别检查敌方当前手牌：存在带毒真气则敌方获得 1 层焚脉；存在破绽则进行一次 `floor(P / 4)` 点追击；存在封穴则一对获得 1 层借力、两对获得 2 层；存在封禁则再造成一次 `floor(P / 6)` 点真伤。四项可以同时触发。
- **双薪换气**：一对抽 2 张并随机弃掉 1 张，两对抽 3 张并随机弃掉 2 张；每实际弃掉 1 张真气，获得 2 层连势，弃掉火属性真气时改为 4 层；随后造成 `floor(P / 3)` 点伤害。
- **对影并奏**：造成 `floor(P / 2)` 点伤害；一对协同“高牌”，两对协同“一对”。主牌型与协同组每成功结算 1 组，获得 3 层连势；全部组共同满足纯阳时，行动结束后获得 1 次连击机会。

**三条、葫芦（8 门）**

- **三阳叩关**：造成 3 次 `max(1, floor(P / 4))` 点伤害，每个攻击段结算后获得 1 层连势；三段都实际扣除敌方生命时，敌方获得 1 层焚脉，三条额外获得 3 层连势，葫芦改为 4 层。
- **抱炉候敌**：造成 `floor(P / 3)` 点伤害；三条获得 2 层借力，葫芦改为 3 层；本次为纯阳时再增加 1 层。
- **三焦焚脉**：造成 `floor(P / 3)` 点伤害，敌方获得 `N+1` 层焚脉；本次为纯阳时再增加 1 层。
- **反照真阳**（特殊）：获得 `max(1, floor(P / 3))` 点防御；三条获得 1 层借力，葫芦改为 2 层。下一次借力反击中，等于防御实际减少量的部分造成普通伤害，等于生命实际减少量的部分造成真伤，随后结束。
- **焚血闭关**（特殊）：燃命 `2L`，敌方获得 2 层焚脉；接下来敌方的前 2 个功法攻击段结算后，我方分别进行一次 `max(1, floor(P / 5))` 点反击，无论敌方是否伤到我方都会触发。
- **破绽连灼**（跨异状）：造成 3 次 `max(1, floor(P / 6))` 点伤害。敌方当前手牌每有 1 张破绽真气，追加一次 `max(1, floor(P / 10))` 点追击并在结算后获得 1 层连势；至少有 1 张封穴真气时获得 1 层借力；至少有 1 张带毒真气时敌方获得 1 层焚脉。破绽追加次数不设统一上限。
- **三焰递升**：依次造成 `max(1, floor(P / 8))`、`max(1, floor(P / 6))`、`max(1, floor(P / 4))` 点伤害，每段结算后获得 1 层连势；本次为纯火时，第三段追加一次 50% 伤害的追击。
- **三才并式**：造成 `floor(P / 3)` 点伤害，协同“一对”；三条主牌型结算后获得 3 层连势，葫芦主牌型改为 4 层，协同一对结算后再获得 3 层。整个行动为纯阳时，协同结束后获得 1 次连击机会。

**四条、五条（8 门）**

- **炉火百炼**：四条造成 4 次 `max(1, floor(P / 6))` 点伤害，五条造成 5 次 `max(1, floor(P / 7))` 点伤害；每个攻击段结算后获得 1 层连势。

- **万脉成灰**：造成 `floor(P / 4)` 点伤害，敌方获得 `N+2` 层焚脉与 `N+2` 层绝气。

- **同焚血契**（特殊）：燃命 `3L`，我方下回合手牌上限 -`N`，最低为 1；敌方获得 `2N` 层焚脉，并随机使敌方当前手牌至多 `N` 张获得封禁并放回牌库顶。本次为纯阳时取消手牌上限降低，但燃命代价不变。

- **自焚养势**（特殊）：随机使我方当前手牌至多 `N` 张普通真气的有效真气值在本场战斗中变为 0；每实际减少 2 点有效真气值，获得 1 层连势与 1 点防御，不足 2 点的余数不结算；不改变牌阶、属性、强化、版本或气印。

- **步步回阳**：造成 `floor(P / 3)` 点伤害并获得 2 层借力；当前行动是连击产生的额外行动时再获得 1 层，本次为纯阳时再获得 1 层。

### 2.4 内功

内功承担类似《小丑牌》的常驻规则改写：

- 可以改变抽牌、弃牌、倍率、牌型识别或功法触发条件；
- 暂设四个档位，档位主要用于出现概率与内容组织，不决定固定价格；
- 占用六个内功装备栏位，并受到清楚可见的格式／类型限制；
- 不绑定某一个普通牌型，除非内功文本明确这样写。

获得的内功进入本局内功库，不会因为六个装备栏位已满而自动替换、遗忘或出售已有内功；未装备内功保留但不生效。每个内功必须在文本中明确自己的触发时间，例如玩家回合开始、出牌、玩家回合结束、战斗胜利、完成节点或进入修习。内功不能在同一次出牌中无限生成牌型或递归触发功法。

功法是“某个牌型出现时做什么”，内功是“整套牌组和战斗规则如何被改写”，两者不能混成同一类效果。

功法可以建立立即效果、有限回合效果、敌方标记，或者具有明确层数／次数且耗尽后移除的延迟效果。原则上，持续整场反复读取状态、使用“每当”“每第几次”“实时读取”等文本且没有耗尽时点的我方永久功法增益，应设计为内功，而不是功法。

#### 初始内功候选 v0.1

```text
未参与最高牌型的打出真气，其真气值总和转化为防御。
```

例如打出 `4、4、2、3`，最高牌型是一对，牌型基准值为 `(4+4)×2=16`，实际是否造成伤害由当前一对功法决定；未参与一对的 `2、3` 额外提供 `5` 点防御。

该效果属于内功，不是默认出牌规则。没有装备此内功时，未参与最高牌型的牌只会被弃置，不提供额外防御。

#### 通用与反毒内功候选 v0.1

下列数值均为第一版暂定值。通用内功不计入蛊毒专属内功数量，但可以与蛊毒构筑组合。

- **蛊息护命**（普通）：每个敌方回合，我方第一次将受到伤害前，若当前防御为 0，获得 8 点防御。
- **风引回息**（普通）：战斗开始后的前 2 个玩家回合，正常补牌结束后额外抽 1 张。
- **闭脉禁毒**（罕见）：战斗开始后的前 2 个完整回合，双方真气均不能因为功法获得毒；内功、异状和战斗开始效果不受影响。完整回合以双方同步的第一击开始，并在由该轮产生的全部连击结算后结束。

#### 传奇通用内功候选 v0.1

下列五门以《小丑牌》传奇小丑牌的构筑终点为参照，但按本系统“功法值同时影响伤害、防御、阈值与控制范围”的口径降为同一功法值增幅加法池，不使用彼此独立的终乘。除明确写出的节点效果外，未装备内功不生效。

- **封脉夺诀**（传奇）：每个完整回合开始时、双方第一击同步出招前，随机使敌方 1 门已装备内功封功，持续至该完整回合结束。被封功内功不进入之后的新触发队列；此前已经建立的延迟效果不撤销；该内功附带的版本与负片提供的栏位不因封功失效。

- **毒手增伤**（风）：功法明确造成伤害时，我方当前手牌中每有 1 张带毒真气，本次功法伤害提高 10%；没有统一张数上限。
- **毒甲反震**（风林）：我方防御因承受伤害而减少时，根据本次实际减少的防御反震敌方；我方当前手牌中每有 1 张带毒真气，反震伤害等于实际减少防御的 10%。这次反震不视为功法伤害。
- **逆命藏蛊**（林）：每场战斗一次；我方受到伤害后生命将降至 0 时，改为保留 1 点生命并获得 20 点防御，随后从我方当前仍在战斗牌组中的合格真气随机选择三分之一，分别附上随机毒，数量向下取整并保持各牌原有牌区。
- **天蚕噬气**（风林）：本场每次任意一方毒触发并完成结算后，我方毒效倍率永久提高 10%，最多提高 50%，战斗结束重置；提高只影响之后发生的毒触发。
- **共命蛊契**（风林）：战斗开始时，分别随机使敌我当前手牌各 1 张合格真气获得同一种随机毒。敌我双方当前牌区都至少存在 1 张带毒真气时，每个玩家回合和敌方回合的第一次毒触发，毒效倍率额外提高 50%。
- **蛊印炼毒**（风林）：敌方每有 1 层蛊印，其毒效倍率提高 1%，最多提高 50%。蛊印本身没有毒效倍率；超过 50 层的蛊印仍可用于续毒和洗回。
- **血引播蛊**（风林）：每当我方受到伤害且生命实际减少后，读取我方当前手牌中的所有带毒普通真气；每有 1 张，就按该牌的毒类型从敌方牌库随机选择 1 张合格真气附上相同毒。单次触发内不重复选择目标，合格目标不足时只结算实际数量。普通伤害、真伤和烈毒伤害均可触发；燃命是代价，不视为受到伤害。

**传奇（4 门）**

- **万毒增烈**（风林）：敌方毒效倍率固定提高 40%。
- **万毒无常**（风林）：效果将要使敌方一张没有出招异状的真气获得毒时，改为等概率随机获得烈毒或郁毒；只随机新施加的毒，不覆盖已有毒。敌方毒效倍率同时固定提高 40%。
- **天蚕转命**（林）：每个玩家回合一次；我方烈毒触发时，将实际烈毒伤害的 50% 转化为防御并对敌方造成等量伤害，剩余烈毒伤害正常结算。我方郁毒触发时，随机使我方当前手牌 1 张普通真气的有效真气值临时提高 `floor(本次郁毒实际削减值 × 50%)`，持续至当前战斗结束，不改变牌阶或属性。
- **万蛊归宗**（风林）：战斗开始时敌方获得 3 层蛊印；本场每第 4 次毒触发正常结算后，对同一张真气额外结算一次同种毒。额外结算不视为新的毒触发，也不额外消耗蛊印。

#### 第一批风系内功候选 v0.2

风系内功当前共 13 门：普通 3 门、罕见 5 门、稀有 3 门、传奇 2 门。它们围绕显式抽牌、明确弃牌、协同、连击、控顶与风标建立运转核心；除文本明确限制外不设置每回合次数上限，新赋予的风标不追溯已经完成的触发时点。防御跨回合保存仍是待实测规则，因此高频抽牌产生的防御先采用有效真气值的 50%。

**普通（3 门）**

- **风生水起**：每当我方抽到风属性普通真气时，获得 `max(1, floor(该牌当前有效真气值 × 50%))` 点防御；没有次数上限。
- **掷风换气**：每当我方风属性牌被功法或内功明确弃掉时，抽 1 张牌；没有次数上限。正常打出进入弃牌堆不触发。
- **回风入袖**：我方一张牌的回风触发并将其放回牌库顶时，抽 1 张牌。

**罕见（5 门）**

- **风眼通明**：功法展示我方或敌方牌库顶时，额外展示 1 张；若该功法允许选择、置顶、附风标或弃掉展示牌，对应数量上限同时 +1，不能超过实际展示数量。
- **风脉共鸣**：同一次行动中每成功结算 1 组协同，在该组协同序列结束后抽 1 张牌。
- **飞燕抄水**：敌方真气因我方功法效果被明确弃掉时，使敌方牌库顶 1 张没有风标的牌获得乱流。乱流、内功、敌方自身效果或其他非功法来源造成的弃牌均不触发本内功。
- **逆风回流**：我方手牌变为 0 时立即抽 3 张牌；没有次数上限。
- **风标流转**：我方一张牌的风引或回风被移除时，随机使我方当前手牌 1 张没有风标的牌获得刚被移除的同种风标；新风标不追溯当前事件。

**稀有（3 门）**

- **同气贯日**：同一次行动中的第 1／2／3 组协同功法造成的伤害分别提高 20%／40%／60%；之后每增加 1 组继续线性提高 20%。
- **风卷残云**：同一次行动每累计抽取 3 张牌，对敌方造成等于该行动主牌型功法值 `P` 的 30% 的伤害，向下取整；累计抽到 6／9／12 张及更多时继续触发。
- **乱流封脉**：敌方乱流牌被抽取并明确弃掉时，再随机明确弃掉敌方当前手牌 1 张。

**传奇（2 门）**

- **天风无尽**：通用同属性连击不再受“每方每个完整回合自然触发一次”的限制；每次符合条件的行动结束后都可以再次自然获得连击机会。
- **万流归宗**（风林）：我方牌库为空且仍需要抽牌时，将我方弃牌堆全部洗回牌库并继续抽牌；没有次数上限。

#### 第一批火系内功候选 v0.1

火系内功当前共 17 门：普通 6 门、罕见 6 门、稀有 3 门、传奇 2 门。它们负责为多段攻击提供通用增幅、低伤转真伤、借力与焚气收益、纯阳成长和连击循环；所有数值均为第一版暂定值。连势的公共减半条件固定不变，只有明确效果可以限制单次减少量或在减半后建立其他收益。

**普通（6 门）**

- **星火渐盛**：我方每完成一个功法、追击或反击攻击段后，获得 1 层连势。
- **微焰穿甲**：功法、追击或反击攻击段在所有普通伤害计算完成后、扣除敌方防御前的最终伤害为 1～3 点时，改为造成等量真伤；0 点伤害不转化。
- **抽薪添火**：每当我方抽到 1 张火属性普通真气，获得 1 层连势；正常补牌、风引和功法抽牌均可触发。
- **弃薪催火**：我方真气因功法或内功被明确弃掉时，每张获得 2 层连势；弃掉火属性普通真气时改为 3 层。正常出牌进入弃牌堆不触发。
- **同炉绝脉**：玩家回合与敌方回合开始时，在行动方正常补牌前，展示其牌库顶第一张普通真气，使该牌的有效真气值在本场战斗中变为 0；行动方获得等于本次实际减少值的防御，该牌仍留在牌库顶。牌库顶为空、是石头牌或有效真气值已经为 0 时不触发；战斗结束后恢复真气值。
- **焚脉回息**：敌方焚脉消耗并使一张真气的本次贡献变为 0 后，我方获得等于本次实际削减值 50% 的防御，向下取整。

**罕见（6 门）**

- **炉心不散**：连势因公共规则减半时，本次减少的连势最多为 10 层；不改变减半的触发条件、结算时点或其他效果。
- **细火入骨**：功法、追击或反击攻击段在所有普通伤害计算完成后、扣除敌方防御前的最终伤害为 1～5 点时，改为造成等量真伤；与微焰穿甲同时装备时只使用 5 点阈值。
- **借力连环**：每次借力反击全部结算后，获得 3 层连势。
- **绝气锁经**：绝气使一张敌方真气获得封禁并放回牌库顶后，敌方获得 1 层焚脉；不会自动获得新的绝气。
- **燃命生势**：我方因功法燃命每实际失去 1 点生命，获得 1 层连势；其他伤害和毒伤不触发。
- **烈势悟道**：战斗开始时令 `n=1`。战斗中，每当我方连势第一次达到或超过 `10×n` 层时，获得 `n` 点历练，随后令 `n=n+1`；连势降低不会使 `n` 降低，重新达到已经越过的阈值不会重复获得历练。一次效果跨过多个阈值时依次全部结算，例如连势从 5 层提高到 35 层时依次获得 1、2、3 点历练并令 `n=4`。每场战斗重置 `n`，不设置每场历练上限。

- **借势化真**：借力反击伤害的 30% 改为真伤，向下取整；剩余部分正常经过敌方防御，多个攻击段分别转换。
- **焚气夺息**：敌方真气因我方功法、内功、散气或焚脉而降低有效真气值时，每实际降低 3 点，我方获得 1 点防御与 1 层连势；郁毒不触发本内功。

**传奇（2 门）**

- **万火不息**：每个玩家回合内，我方每累计完成 10 个攻击段，获得 1 次连击机会；第 20、30、40 段及更多可以继续触发，没有次数上限。只统计玩家回合内完成的攻击段，避免敌方回合产生不能跨回合保存的连击机会。
- **纯阳无漏**：纯阳行动中，连势对非真伤攻击的增幅翻倍；效果文本原本明确写为真伤的攻击段获得连势一半的百分比增幅；由微焰穿甲或细火入骨从普通伤害转化而来的真伤已经在转化前读取过连势，不再次获得增幅。每完成一个牌型组，获得 2 层连势。

蛊印只有一个标记，不再拆分为蛊印与蛊引。蛊印的公共规则仍只有“毒触发后消耗 1 层，使该牌续上同种毒并洗回牌库”；它不会公共地提高毒效倍率。只有“蛊印炼毒”读取蛊印数量并提供最高 50% 的毒效增幅。三毒无明、天蚕噬蛊等功法自己的有限层毒效增幅是独立效果，不属于蛊印的固有规则。

### 2.5 获得、装备与遗忘

获得、装备和遗忘是三个独立动作：

```text
获得：加入本局功法库或内功库
装备：将已获功法加入对应具体牌型的循环功法序列，或占用一个内功栏位并使内功生效
遗忘：玩家主动将已获功法或内功移出本局，并获得该武学标明的遗忘所得
```

未装备不等于遗忘，也不会自动换算为历练。功法与内功都可以存在已获得但未装备的状态。功法既可以由心得附带获得，也可以像内功一样在修习中直接购买；第一版普通直接购买价格统一暂定为 3 点历练。内功仍分别记录档位、修习价格和遗忘所得，档位与价格没有固定对应关系，不同档位的价格区间可以重叠。优惠券对应物、事件或其他效果可以明确修改功法价格，但最低价格与叠加方式仍待测试。

## 3. 已确认的牌组与战斗基础规则

```text
基础牌组：风、林、火、山 4 种真气属性 × A、2～10、J、Q、K 13 个牌阶，共 52 张
玩家与敌人的基础手牌上限：默认 8 张
玩家初始生命：100
敌人初始生命：100
单次出牌候选：1～5 张
未选中的手牌：继续留在手牌中
被打出或弃掉的牌：进入弃牌堆
主动弃牌按钮：没有
弃牌动作：只由明确写有“弃掉”的功法或内功效果执行
一场战斗内：牌组只使用一次，不自动将弃牌堆洗回牌库
回合开始时：按当前手牌上限统一补牌，最多补到手牌上限
手牌上限：只决定回合开始时的正常补牌目标，不是持牌硬上限
明确抽牌效果：可以使手牌数量超过当前手牌上限，超过后不自动弃牌
手牌达到或超过上限时：下个回合开始不进行正常补牌；低于上限时才补到上限
牌库不够时：只补到能补的数量，不自动洗回弃牌堆
牌库和手牌都没有可用牌时：本场战斗不能继续
每个完整回合的第一击由双方同步出招；若玩家无法继续行动时敌人尚未倒下，则本场战斗失败
战斗结束后：本场战斗的牌区清空并为下一场战斗重新整理
```

每次出牌不自动立即补牌；正常补牌统一发生在下一回合开始。功法、内功、风引或其他效果明确写出的抽牌不属于正常补牌，可以在行动中发生并超过手牌上限。手牌超过上限不会自动弃牌；下个回合只有在手牌低于当时的上限时才正常补牌。临时手牌上限只用于改变指定回合的补牌目标，不作为显式抽牌的必要前置。52 张基础真气是当前正式基线，后续成长在此基础上增加、删除、复制、修改或附加效果。单次出牌上限仍为 5 张，不随手牌上限提高。

52 张牌组与 8 张基础手牌是配套基线，不拆开视为两个独立调整：完整牌组会稀释同牌阶组合，增加手牌则提供足够的牌型与属性选择。8 张手牌中选择 1～5 张共有 218 种组合，因此战斗界面和规则计算器必须提供：

- 按牌阶与真气属性整理手牌；
- 选牌时即时显示最高牌型；
- 即时显示该具体牌型序列当前指向的功法、条件是否满足，以及成功触发后将轮到的下一门功法；
- 即时显示牌型基准值、功法值，以及当前功法明确会造成的伤害。

打出的牌在行动结算后进入弃牌堆，但这项牌区移动不视为“弃掉”。只有功法或内功明确执行的弃牌动作，才触发“每弃掉一张牌”类效果。

## 4. 固定牌型倍率与心得倍率

固定牌型倍率不成长，始终使用第 2.1 节的基线，只决定牌型基准值。心得提供另一条独立的累计成长：提高指定牌型的功法倍率，但不提高固定牌型倍率或牌型基准值。

使用一份心得时，立即执行两项效果：

1. 按该牌型所在分组增加其累计心得倍率；
2. 从该牌型对应的共用功法池中随机获得一门功法。

| 心得分组 | 对应牌型 | 每份心得增加的功法倍率 |
| --- | --- | ---: |
| 低级牌型 | 高牌、一对、两对 | +1 |
| 中级牌型 | 三条、同花、葫芦 | +2 |
| 高级牌型 | 顺子、四条 | +3 |
| 同花顺 | 同花顺 | +4 |

每种牌型分别累计自己的心得倍率。例如使用两份三条心得后，三条累计心得倍率为 +4，不会提高同花或葫芦。所得功法进入该牌型对应的共用功法池，不自动替换当前装备的功法；例如一对心得与两对心得分别提高各自的累计心得倍率，但都从“一对、两对”共用功法池获得功法，所获功法可供一对与两对共同使用。

同花顺心得仍只提高同花顺自己的累计心得倍率；获得功法时，从顺子与同花两个共用功法池组成的联合候选中随机获得。同花顺可以把所得功法加入自己的独立序列，不会因此推进或修改顺子、同花序列。重复功法优先改为从尚未获得的功法中随机；若对应池已全部获得，则本次心得只增加倍率，不补偿其他资源。

具体真气增益、版本、功法或内功也可以临时或有条件地修正功法倍率。第一版的倍率修正优先采用加减；只有多彩版本明确在功法倍率计算完成后进行百分比增幅。

概率统计统一按第 2.2 节的 52 张基础真气、8 张基础手牌与实际选牌规则计算。当前概率是未改造基础牌组的数学基线，不是完成平衡后的掉落率或实战出招率。

## 5. 玩家成长

一局内的成长由五部分组成：

1. **内功**：六个装备栏位，提供常驻规则改写或触发条件改变；未装备内功保留在本局内功库。
2. **功法**：六类共用功法池负责内容复用，每个具体牌型分别配置一条无限长度但同功法不可重复的循环序列；未加入序列的功法保留在本局功法库。具体牌型的倍率、心得累计与序列进度分别记录。
3. **真气**：可以增加、删除、复制、修改牌阶与属性，并获得增益或异状。普通的牌阶修改会同步更新基础真气值；只有明确写出的强化、版本或其他效果才会在不改变牌阶的情况下修改有效真气值。
4. **心得、丹药与天材地宝**：心得精进牌型并获得功法；丹药定向强化或转化真气；天材地宝进行更稀有、更强力的构筑改造。
5. **优惠券对应物**：由事件、精英和 Boss 提供的本局永久装备道具，独立修改修习、获取、价格、刷新、容量或其他系统规则；不通过普通修习购买，也不占用六个内功栏位，正式名称与持有上限待定。

固定牌型倍率不成长；功法倍率可以来自累计心得倍率、具体真气增益、功法或内功。

一局成长不把“改造真气”和“收集功法”设为互斥路线。前期优先让玩家通过少量真气改造和低门槛功法确定一个稳定主牌型；中期由功法序列、效果方向与内功共同形成玩法循环；后期继续用真气改造提高主牌型与副牌型的稳定性，再由功法排列决定具体的胜利方式。高牌主要承担前期启动和保底，不能因为可主动组成率为 100% 就默认获得与顺子、同花或高阶同牌阶组合相同强度的固定控制与攻击效果。

第一版不为成长占比设置硬配额，但平衡审计采用下列目标：前期更看重牌型可靠性，中期两轴接近，后期功法组合略高于继续堆叠牌组改造。玩家一局可以获得 30～50 门功法，但已获得不等于全部加入序列；主牌型与少量副牌型承担当前构筑，其余功法保留在功法库中，避免为了使用所有所得功法而把序列无限拉长并稀释核心循环。

### 6.2 六类真气效果

每张真气在真气值和属性之外，最多同时拥有三类增益与三类异状：

| 性质 | 类别 | 主要作用 | 单张真气上限 |
| --- | --- | --- | ---: |
| 增益 | 强化 | 改变真气的身份或使用方式 | 1 |
| 增益 | 版本 | 提高真气本身的数值或品质 | 1 |
| 增益 | 气印（讨论术语：蜡封） | 在打出、留手、弃掉等特定时点触发 | 1 |
| 异状 | 出招异状 | 该真气被打出时影响本次行动或持有者 | 1 |
| 异状 | 留手异状 | 该真气位于手牌时持续影响持有者 | 1 |
| 异状 | 特殊异状 | 改变出牌资格、牌区移动或其他特殊规则 | 1 |

一张真气的三个不同增益类别可以同时生效，三个不同异状类别也可以同时生效。例如普通强化真气可以同时具有强化、版本、气印、烈毒、破绽和封禁；但不能同时拥有烈毒与郁毒，因为二者都属于出招异状。石头牌是例外：可以拥有版本和气印，但不能拥有任何异状。

内功不拥有强化、气印或真气异状，但每门内功可以拥有一个版本。箔面、镭射、多彩可以用于真气或内功；负片只能用于内功。功法当前不拥有版本。

同一类别不能同时叠加两个效果。再次获得同名临时效果时只刷新其持续时间；施加另一个同类别临时效果时，新效果覆盖旧的临时效果。战斗中的临时效果可以暂时覆盖同类别的本局常驻效果，但不会删除它；临时效果消失后，原本的常驻效果恢复。用丹药或天材地宝替换同类别的本局常驻效果时，旧效果被永久替换。

### 6.3 常驻与临时

类别和持续性是两个不同维度：

| 持续性 | 主要来源 | 默认结束时间 |
| --- | --- | --- |
| 本局常驻变化 | 丹药、天材地宝、明确写出成长效果的内功 | 本局游戏结束 |
| 当前战斗临时变化 | 敌我功法、敌我内功 | 当前战斗结束，或效果文本写出的更早时点 |

功法默认只施加当前战斗中的临时变化。没有耗尽时点且持续整场反复修改我方结算规则的功法增益，原则上改为内功；功法若建立延迟效果，应写明持续回合、层数、次数或其他结束条件。内功既可以在战斗中临时施加效果，也可以明确产生本局常驻变化，但必须在文本中写清持续时间。普通敌人造成的异状默认在战斗结束时清除；跨战斗异状只由明确写出的丹药、天材地宝、事件、Boss或特殊内功产生。

触发术语统一如下：

- **参与最高牌型**：只有组成最高牌型并以自己的有效真气值计入基础值的真气满足；对应《小丑牌》的普通“参与计分”。
- **参与数值计算**：包括参与最高牌型的牌，以及本次固定为基础值提供 10 点的石头牌。石头牌不因此成为最高牌型的一部分。
- **打出**：玩家本次选择并使用了该真气，不要求它参与最高牌型；出招异状按此口径触发。
- **留手**：该真气当前位于手牌；离开手牌后立刻停止留手效果。
- **弃掉**：只有功法或内功明确执行的弃牌动作；正常打出后进入弃牌堆不算弃掉。

### 6.4 第一批异状候选

| 异状 | 类别 | 当前效果 | 叠加口径 |
| --- | --- | --- | --- |
| 烈毒 | 出招异状 | 打出此牌时，持有者受到等于此牌当前有效真气值 100% 的伤害；此牌的烈毒结算后移除，被效果明确弃掉时也移除烈毒 | 同一张牌不能重复拥有；一次打出多张烈毒牌时分别结算；毒效增幅可以修改 100% 系数 |
| 郁毒 | 出招异状 | 打出此牌时，计算该牌本次自身贡献的郁毒削减值：`floor(该牌原本本次自身贡献 × 50% × 当前毒效倍率)`，再从该牌本次自身贡献中扣除；削减后的真气贡献允许为负数。此牌的郁毒结算后移除，被效果明确弃掉时也移除郁毒 | 每张郁毒牌分别计算，不以整手牌总值重复扣减；毒效增幅可以超过 100%，不设削减率封顶；功法值最终读取最低为 0；默认不把超出部分转为伤害，具体功法或内功可以明确转伤 |

| 破绽 | 留手异状 | 持有者受到伤害时，手牌中每有 1 张破绽牌，本次受到的伤害提高 20% | 按手牌中的破绽牌数量相加；上限待测试 |
| 封穴 | 留手异状 | 持有者造成伤害时，手牌中每有 1 张封穴牌，本次造成的伤害减少 20% | 按手牌中的封穴牌数量相加；最低伤害与数量上限待测试 |
| 封禁 | 特殊异状 | 此牌被抽入手牌后，本回合不能打出；本回合结束后移除封禁 | 同一张牌不能重复拥有；多张牌可以分别被封禁 |

“同一种异状不叠加”限制的是同一张牌上的同一个类别。不同牌可以各自拥有同名异状，并按效果读取的牌张数共同生效。后续异状必须归入出招、留手或特殊三类之一，不再任意增加新的异状槽位。

#### 蛊毒流的牌区、附毒与蛊印框架

烈毒与郁毒同属出招异状，同一张真气不能同时拥有二者。除非功法或内功明确写出“转化”，为真气附毒时不会覆盖其已有出招异状。

为敌方手牌附毒时，只读取效果结算当时仍位于敌方手牌的合格真气。敌方此前已经打出、进入弃牌堆、移出牌组或已经完成毒结算的真气不受追溯影响。多个效果连续附毒时按触发队列逐项结算，后置效果重新读取前置效果已经改变后的手牌与异状状态。

- 附毒默认从当前合格目标中随机选取，单次效果内不重复选择同一张真气。
- 合格目标不足时只结算实际数量，剩余次数不会自动转移到牌库、弃牌堆或其他牌区。
- 功法若要作用于敌方牌库、弃牌堆或已打出的牌，必须在文本中明确写出对应牌区。
- 后获得的毒效增幅、转化或其他功法增益只影响之后发生的毒触发，不追溯修改已经结算的烈毒或郁毒。郁毒削减值按该牌原本本次自身贡献单独计算，允许削减后真气贡献为负数；超出部分默认不转伤，只有明确写出“转化”为伤害的效果才会造成额外伤害。

蛊印是附着于敌方的临时战斗标记，不是玩家持有或支付的基础战斗资源。敌方一张带毒真气触发烈毒或郁毒时，若敌方至少拥有 1 层蛊印，则该次毒正常结算后消耗 1 层蛊印，使该真气重新获得刚刚触发的同种毒异状，并在本次出牌结算后洗回敌方牌库，而不是进入普通弃牌堆。一次毒触发默认最多消耗 1 层蛊印；“蛊印回响”等明确效果可以增加本次消耗并给出相应收益。洗回牌库不会立即再次触发毒，必须等该牌之后重新抽取并打出。蛊印在战斗结束时清除，公共层数上限暂不设置，具体功法可以自行限制施加或消耗数量。

蛊印只有这一种标记，不另设蛊引。蛊印公共规则不提供毒效倍率；只有装备“蛊印炼毒”内功时，才按蛊印数量提高毒效倍率，增幅最高为 50%。功法或其他内功明确提供的有限毒效增幅仍独立结算。

毒效增幅可以同时修改烈毒的 100% 伤害系数与郁毒的 50% 削减系数，但具体倍率、持续时间与叠加方式必须由功法或内功文本明确写出。烈毒转化为防御、郁毒转化为伤害等效果属于具体功法或内功，不是蛊毒流的默认公共规则。

#### 风标公共规则

风标是附着于单张真气的当前战斗临时标记，用于记录抽牌、弃牌与控顶构筑的延迟效果。风标不占用强化、版本、气印或任何异状槽位；同一张真气最多拥有一种风标，新风标覆盖旧风标。风标可以随真气跨手牌、牌库与弃牌堆保留，战斗结束时全部清除。新赋予的风标只响应之后发生的合格事件，不追溯已经完成的抽牌、弃牌或其他触发时点。

当前共享三种风标：

- **风引**：我方带有风引的牌被抽取时，移除风引并普通抽 1 张牌。若新抽到的牌也带有风引，则其风引继续正常触发；这些明确抽牌可以超过手牌上限。
- **回风**：我方带有回风的牌被功法或内功明确弃掉时，该牌仍视为被弃掉并正常触发紫印等弃牌效果；这些效果结算后移除回风，将该牌改为放回我方牌库顶而非停留在弃牌堆。
- **乱流**：敌方带有乱流的牌被抽入手牌时，立即将该牌明确弃掉并移除乱流，不补抽替代牌。乱流可以触发普通的“明确弃牌”效果，但其弃牌来源是风标，不是功法，因此不会触发只响应“因功法效果被明确弃掉”的飞燕抄水。

#### 火系公共规则：攻击段、借力、焚脉、绝气与连势

火系功法使用下列公共语言。它们是功法、内功或其他明确效果建立的战斗机制，不是真气属性本身自动附带的效果。

- **攻击段**：一次独立的伤害结算。例如“造成5次伤害”包含5个攻击段；每段分别读取结算当时的防御、异状、标记与增减伤，并分别触发受伤响应。若攻击者在受击响应中死亡，尚未结算的后续攻击段停止。
- **追击**：不消耗真气、不建立新牌型组、不重新计算牌型、不触发功法或牌上强化／版本／气印／异状、不推进功法序列的额外攻击段。追击正常经过防御并触发一般受伤响应；追击不满足“非追击攻击段”的条件。不同效果可以连续产生追击，但同一个效果不能在自身结算中递归触发自己。
- **反击**：在敌方行动或敌方攻击段结算后触发的追击，遵守追击的全部规则。
- **真伤**：直接扣除生命，不经过防御，也不受普通增伤、减伤或连势影响，除非效果明确写出作用于真伤。由低伤转化得到的真伤，先按普通伤害顺序完成转化判定，再按真伤结算。
- **纯阳**：本次行动的主牌型与全部协同组实际打出的普通真气都可以视为火；万能牌视为火，石头牌不破坏条件。纯火仍然只检查当前牌型组，纯阳检查整个行动。
- **燃命**：直接失去生命作为功法代价；代价结算后若生命降至0，后续效果不结算，除非文本明确允许保留生命或继续结算。
- **燃尽**：将真气临时移出当前战斗牌组，战斗结束后归还；不进入弃牌堆，不触发“被弃掉”效果。
- **借力**：我方战斗临时层数标记。敌方一个功法、追击或反击攻击段实际减少我方防御或生命时，消耗1层借力，将一次反击加入该攻击段的受击响应队列；反击伤害等于本段实际减少的防御与生命之和。没有实际减少时不消耗；敌方多段攻击按攻击段分别检查。借力反击为普通伤害，除非效果明确转为真伤。
- **焚脉**：敌方战斗临时层数标记。敌方确认一个牌型组后、计算该组基础值前，若拥有焚脉则消耗1层，从该组参与最高牌型的普通真气中随机选择1张，使其本次有效真气值变为0；没有普通真气目标时不消耗。焚脉不改变牌阶、属性或牌型识别，不使真气贡献低于0。
- **绝气**：敌方战斗临时层数标记，与焚脉配套。焚脉消耗并选中一张普通真气时，若敌方拥有绝气且该牌没有绝气标记，则同时消耗1层，使该牌获得一次性绝气标记；该牌下一次进入敌方弃牌堆后，移除绝气标记，使其获得封禁并放回敌方牌库顶。绝气牌若先被移往其他牌区，标记保留到下一次进入敌方弃牌堆；触发后移除。绝气标记不占用强化、版本、气印、风标或异状槽位；触发后施加的封禁仍占用该牌的特殊异状槽位。
- **连势**：我方战斗临时层数标记。每层使我方非真伤攻击伤害提高1%；每个攻击段结算时重新读取当前层数；真伤默认不受连势提高。连势不自动增长，战斗结束清除，没有公共层数上限。
- **连势减半**：敌方一个攻击段实际减少我方防御或生命时，在该攻击段及全部受击响应结算结束后，我方连势减半并向下取整。毒、燃命、自身效果和反震不触发该规则；功法或内功可以明确限制本次最多减少多少层，但不能改变公共触发时点。多个限制按实时队列从左到右结算。

低伤转真伤的阈值统一在所有普通伤害计算完成、扣除防御之前检查。若此时最终伤害为0则不转化；转为真伤后不再读取连势或普通增减伤。

### 6.5 《小丑牌》增益映射审计

原作普通扑克牌可以同时具有一个强化、一个版本和一个蜡封；本系统的真气保留“一个强化、一个版本、一个气印”的结构，并根据对战中的牌型基准值、功法值、防御与历练重新解释具体效果。

#### 强化

八种强化平级，不设置普通、罕见、稀有、传奇等强化档位。下列四组只用于修习界面展示和理解功能，不代表强弱顺序；若某个效果要求随机产生一种强化，八种强化默认等权，除非效果文本另有说明。

| 功能组 | 强化 |
| --- | --- |
| 稳定数值 | 奖励牌、倍率牌 |
| 组牌与爆发 | 万能牌、玻璃牌 |
| 留手与填充 | 钢铁牌、石头牌 |
| 经济与随机 | 黄金牌、幸运牌 |

| 强化 | 正式效果 | 结算边界 |
| --- | --- | --- |
| 奖励牌 | 此牌参与最高牌型时，提供的有效真气值为基础真气值 +2 | 牌型识别仍使用原牌阶；增加的 2 点同时进入牌型基准值与功法值 |
| 倍率牌 | 此牌参与最高牌型时，本次功法倍率 +2 | 多张倍率牌正常相加，不设额外上限；不增加固定牌型倍率，也不改变牌型基准值 |
| 万能牌 | 识别牌型与检查功法属性条件时，此牌同时视为风、林、火、山 | 只改变属性识别，不改变真气值；牌仍保留原始印刷属性，供明确读取原始属性的效果使用 |
| 玻璃牌 | 此牌参与最高牌型时，提供的有效真气值为基础真气值 ×2；整次出牌结算后有 1/4 概率永久移出本局牌组 | 只翻倍此牌自己的真气值贡献，不翻倍整次基础值；牌型识别仍使用原牌阶；每次出牌只进行一次损毁判定，不因其他重复触发再次判定 |
| 钢铁牌 | 持有者每次出牌结算结束时，若此牌仍在其手牌中，获得等于此牌真气值的防御 | 多张钢铁牌分别生效，暂不设置额外上限；长期占据手牌位置是其使用代价 |
| 石头牌 | 此牌失去牌阶、真气值和属性，不参与任何普通牌型；与至少一张非石头牌一起打出时，固定为本次基础值提供 10 点 | 不能单独打出；计入一次出牌的 1～5 张上限；多张分别提供 10 点；它不属于最高牌型，但其 10 点计入基础值后，视为参与本次数值计算 |
| 黄金牌 | 战斗胜利时，若此牌仍在持有者手牌中，获得 3 点历练 | 多张分别生效，暂不设置额外上限；战败不结算 |
| 幸运牌 | 此牌参与最高牌型时，分别进行两项独立判定：1/5 概率使本次功法倍率 +3；1/15 概率获得 20 点历练 | 两项可以同时成功；多张分别判定并正常相加，暂不设置额外上限；未参与最高牌型的幸运牌不判定 |

奖励牌示例：一张奖励 7 与普通 7 组成一对，牌型仍是一对 7，基础值为 `(7+2)+7=16`。

倍率牌示例：三条 `7、7、7` 中有两张倍率牌时，基础值为 21，牌型基准值为 `21×3=63`，功法倍率为 `3+2+2=7`，功法值为 `21×7=147`；是否造成 63 点伤害由功法或内功文本决定。

石头牌示例：打出 `7、7、石头牌` 时，最高牌型为一对，基础值为 `7+7+10=24`，牌型基准值为 `24×2=48`。石头牌不占据对子中的牌，但占据本次三张出牌中的一张。

石头牌可以拥有一个版本和一个气印，但不能拥有任何异状。一张真气转化为石头牌时：

- 保留已有版本和气印；
- 清除已有的出招、留手和特殊异状；
- 此后不能再被施加任何异状；
- 仍可被抽取、打出、弃掉、回收、复制、删除、夺取；
- 版本与气印可以作用于石头牌；需要判断该牌是否参与数值计算时，只要本次基础值加入了它的固定贡献，就视为满足。

丹药为真气施加强化时，第一版沿用下列目标数量：

| 强化 | 一次丹药的目标上限 |
| --- | ---: |
| 奖励牌 | 2 张 |
| 倍率牌 | 2 张 |
| 幸运牌 | 2 张 |
| 万能牌 | 1 张 |
| 玻璃牌 | 1 张 |
| 钢铁牌 | 1 张 |
| 石头牌 | 1 张 |
| 黄金牌 | 1 张 |

同一张真气只能拥有一种强化；为已有强化的真气施加另一种强化时，新强化替换旧强化。八种强化的具体数值作为第一版正式基线，后续只通过实测调整。

#### 版本

原作箔面、镭射、多彩可以用于普通扑克牌和小丑牌；负片不能用于普通扑克牌，但可以用于小丑牌。本系统对应保留：箔面、镭射、多彩可以用于真气或内功，负片只能用于内功。真气和内功使用相同版本数值，先保持直觉一致，后续再根据实测分别调整。

| 版本 | 真气上的效果 | 内功上的效果 |
| --- | --- | --- |
| 箔面 | 此牌每次参与数值计算时，该次自身贡献 +3 | 装备期间，每次出招的基础值 +3 |
| 镭射 | 此牌每次参与数值计算时，本次功法倍率 +1 | 装备期间，每次出招的功法倍率 +1 |
| 多彩 | 此牌每次参与数值计算时，本次功法值增幅中的多彩来源 +20% | 装备期间，每次出招的功法值增幅中的多彩来源 +20% |
| 负片 | 不允许施加于真气 | 该内功装备时，内功栏位上限 +1 |

多彩真气与多彩内功的百分比先全部加入功法值增幅，再与功法、内功或其他效果明确提供的功法值百分比增幅统一相加，最后对未增幅功法值乘算一次并向下取整。例如两次多彩真气触发与一门多彩内功共同生效时，多彩来源为 60%，而不是连续乘以三次 1.2；若另有 +50% 功法值增幅，则合计为 110%，而不是 1.6×1.5。多彩只提高功法值，不提高牌型基准值。

只有装备中的负片内功提供额外栏位。负片内功本身占用一个内功栏位，同时令栏位上限 +1，因此净占用为 0；即使当前栏位已满，也允许直接装备负片内功。多门负片内功可以叠加，未装备的负片内功不提供栏位。装备或卸下负片内功时，已装备数量与栏位上限同步增减 1。

同一张真气或同一门内功最多拥有一个版本。再次施加另一个版本时，新版本替换旧版本；负片不能作为真气版本的候选结果。石头牌保留并正常使用箔面、镭射和多彩版本。

#### 气印（讨论术语：蜡封）

| 气印 | 原作蜡封 | 正式效果 |
| --- | --- | --- |
| 金印 | 金色蜡封 | 此牌每次参与数值计算时，获得 3 点历练 |
| 赤印 | 红色蜡封 | 当此牌自身产生一次合格的数值或触发效果时，将该牌自身的这次结算额外执行一次 |
| 蓝印 | 蓝色蜡封 | 战斗胜利时，若此牌仍在手牌中，获得最后一次打出牌型对应的一份心得 |
| 紫印 | 紫色蜡封 | 此牌被功法、内功或敌方效果明确弃掉时，获得一份随机丹药 |

金印使用“参与数值计算”口径：普通真气必须参与最高牌型，石头牌只要提供固定贡献也可以触发；未参与最高牌型的多余普通真气不触发。多张金印分别生效，第一版暂不设置每场上限；若后续回收体系令经济失控，优先改为“每张金印每场最多获得一次”。

赤印只额外结算该张真气自身，不重新识别牌型，不再次触发功法、内功或赤印自身，也不触发其他牌。合格范围包括：

- 该牌自己的数值贡献；
- 该牌强化产生的数值、倍率、概率判定或合格触发；
- 该牌箔面、镭射、多彩版本的结算；
- 该牌在同一时点触发的异状；
- 该牌的留手效果或战斗胜利效果。

万能牌的全属性身份属于持续身份，赤印不会令其进一步增强。玻璃牌的自身贡献可以被赤印额外结算，但整次出牌仍只进行一次 1/4 损毁判定。赤印钢铁牌会额外获得一次防御，赤印黄金牌在胜利留手时会额外获得一次历练，赤印幸运牌会重新进行两项独立判定，赤印石头牌会额外提供一次固定贡献。

蓝印只在战斗胜利时结算，战败不结算；“最后一次打出牌型”读取玩家本场最后一次成功出招识别出的最高牌型。多张蓝印分别获得心得，第一版不额外限制生成数量；若未来心得设有持有栏位，则必须有空位才能生成。

紫印只响应规则术语“弃掉”。正常打出后进入弃牌堆、删除、摧毁、夺取或玻璃牌损毁均不触发；被我方或敌方效果明确弃掉都可以触发。回收后再次被明确弃掉时可以再次触发。多张紫印分别生效；若未来丹药设有持有栏位，则必须有空位才能生成。

同一张真气最多拥有一个气印；施加新气印时替换旧气印。内功和功法不能拥有气印。强化、版本和气印的数值作为第一版正式基线，后续根据实测调整。

四种气印平级，不按颜色划分强弱档位；它们的实际价值取决于出招、留手或弃牌构筑。具体出现率和天材地宝投放方式留待修习内容池设计。

## 7. 修习与历练

历练是本局唯一的经济类资源。修习不再是战斗胜利后的强制流程，而是大地图右下角的常驻入口。玩家只有处于“当前没有未完成节点，且尚未选择下一个节点”的地图待选状态时，才能打开修习；进入任意节点后，修习入口锁定，直到该节点完成并返回地图。初次进入一层、完成普通节点、完成精英节点、完成事件或休息节点后，只要正在等待选择下一节点，都可以反复打开和关闭修习页面。

修习入口使用独立图标按钮，按钮下方持续显示当前持有历练。图标的具体美术不属于冻结规则，可以随界面风格替换；位置、可用时点和历练显示属于操作规则。点击后打开参考《小丑牌》商店信息密度与卡片陈列方式的修习页面，消耗历练进行本局成长：

- 获取内功；
- 获取功法；
- 获取或使用心得、丹药与天材地宝；
- 增加、删除、复制、修改真气，或为真气与内功施加本局常驻效果；
- 冥想，刷新当前修习选项。

地图不设置商店节点。类《杀戮尖塔》地图生成中原本分配给商店节点的比例全部并入事件节点；修习只通过地图右下角按钮打开，不占用路线节点。关闭修习后返回原地图和原待选状态，不自动选择节点。商品数量、购买后是否补充、基础冥想费用和连续冥想费用仍待平衡。

第一版以一局正常获得 30～50 门功法为流程目标，不设硬上限。功法主要通过普通修习直接购买，并由心得、事件、精英、Boss、优惠券对应物或其他明确奖励补充获得；直接购买不是心得之外的新种类，只是同一功法库的另一种获取渠道。获得数量不等于全部装备数量，玩家可以把未加入任何序列的功法保留在功法库中，并集中为少数精确牌型配置较长序列。修习中同时展示多少门功法、购买后是否补充新选项以及各来源所占比例仍待结合地图节点数量测试。

### 7.1 战斗奖励与精进

| 战斗节点 | 胜利奖励 |

| 普通敌人 | 3 点历练 |
| 精英敌人 | 4 点历练 |

每完成一个节点，自我精进一次：

节点奖励、内功收益与精进在同一节点中的准确先后顺序仍待计算器测试；无论顺序如何，一个节点只精进一次。

### 7.2 档位与价格

## 8. 地图与战斗流程

一局游戏分为三层。每层先采用与《杀戮尖塔》普通章节一致的地图基线：横向 7 列、Boss 前 15 行路线节点、6 条初始生成路径；第 16 行为单一 Boss。第 1 行固定为普通战斗，第 8 行固定为宝箱／特殊奖励，第 15 行固定为休息，第 16 行固定为 Boss。其余合格节点的基础分配比例为普通战斗 53%、事件 27%、精英 8%、休息 12%；其中事件的 27% 已包含原商店 5% 的比例，因此地图不再生成商店节点。

路线允许分叉与汇合，不允许连线交叉；每个非 Boss 节点至少属于一条从第 1 行通往 Boss 的完整路径。精英与休息不在前 5 行随机生成，精英或休息不与同类节点沿同一路径直接相连。后续若《杀戮尖塔》参考基线与实测体验发生冲突，再通过版本化地图规则数据调整，不在生成器中散落硬编码参数。

```text
进入第1层
→ 选择本层节点
→ 进入节点后锁定修习入口
→ 完成节点后返回本层地图并开放修习入口
→ 可以打开修习，也可以直接选择下一个相连节点
→ 完成本层路线并进入层末 Boss
→ Boss 胜利后直接进入下一层地图的待选状态并开放修习入口
→ 第3层末 Boss 战胜利后结束本局
```

地图负责路线选择、节点状态与修习入口时机，不提供普通商店节点。战斗胜利只结算战斗奖励并返回地图，不自动弹出修习；修习承担本局内的购买和冥想刷新。

## 9. 对战结果

牌型基准值不是分数，也不是本次行动自动造成的伤害。出牌只计算牌型基准值与功法值；只有功法、内功或毒异状明确写出造成伤害时，才执行伤害结算。它们可以读取牌型基准值或功法值，并产生：

- 伤害或额外伤害；
- 防御；
- 抽取、弃掉、锁定、夺取或回收真气；
- 其他明确写出的战斗效果。

高牌的基础功法可以写成“造成等于本次功法值的伤害，并获得等于本次功法值的防御”，但这只是该门功法的效果，不是高牌或所有牌型的默认规则。

敌人的攻击也应由它当前组成的普通牌型和已装备效果产生，不能退回固定的“攻击值／防御值”两个数字。

防御是功法或内功的效果，不是独立的牌型，也不是某种真气属性的公共效果。

当前原型暂按“防御在本场战斗中持续保留”实现，可以跨回合并在多次出牌中累积。受到伤害时，先从防御中扣除；伤害超过当前防御的部分才扣生命。若伤害没有耗尽防御，剩余防御继续保留；当前版本不会因为回合结束或没有出牌而自动清零，战斗结束时清空。该规则是后续实际游玩必须重点验证的项目：若长流程毒流、林系恢复或山系护盾能够过早形成不可突破的防御雪球，再比较“敌方回合结束后清除部分”“玩家回合开始衰减”或“只保留特定来源防御”等替代方案。在实测前不设置全局防御上限，也不提前改为回合清零。

## 10. 资源控制

资源优先使用牌区表达：

```text
手牌、剩余牌库、弃牌堆、已锁定牌、敌方手牌
```

功法或内功可以明确执行一项或少量牌区操作：

```text
抽牌、保留、弃掉、锁定、夺取、回收
```

这些操作是效果，不是额外的“势”或“能量”数值。第一版每个效果最好只作用于一个牌区、一个时间点，避免一次效果同时抽牌、弃牌、锁牌和夺牌。

弃牌不会在本场战斗中自动回到牌库；只有功法或内功明确写出“回收”时，牌才会重新变为可用资源。

## 11. 下一项实验

制作纯规则计算器，显示：

```text
给定一手8张真气
→ 枚举选择1～5张的方案
→ 识别最高普通牌型
→ 读取该具体牌型功法序列当前指向的功法，并检查牌型、真气属性与其他条件
→ 结算参与数值计算真气的强化、版本与气印触发次数
→ 计算基础值
→ 读取固定牌型倍率、累计心得倍率与其他功法倍率修正
→ 得到牌型基准值与功法值，但暂不造成伤害
→ 本次只尝试触发该具体牌型序列当前指向的一门功法；复合牌型使用自己的独立序列
→ 将同一时点的功法与已装备内功加入可见队列，按玩家排列从左到右逐项读取最新状态并结算
→ 只结算功法、内功、毒异状明确写出的伤害、防御或牌区操作
→ 多段功法按攻击段逐次读取连势、防御、异状与受伤响应；低伤转真伤在普通伤害计算完成、扣除防御前检查
→ 敌方攻击实际减少我方防御或生命时，将借力反击等受击响应加入队列；全部响应结束后按公共规则减半连势
→ 当前功法成功触发时，在该牌型组完整结算结束后将该具体牌型序列前进一格；失败则保持当前位置
→ 若主牌型功法建立协同，在主牌型结算前从剩余手牌锁定协同组，再按顺序分别重复上述完整计算与触发流程
→ 主牌型与协同组全部结束后，检查本次行动实际打出的普通真气是否共同满足同一种属性；满足时按通用连击规则开启额外行动
→ 显示未参与牌型的真气被弃置
→ 回合开始时按手牌上限从剩余牌库补牌，基础上限为8张
→ 功法、内功或风标明确抽牌时允许超过手牌上限，超过后不自动弃牌
→ 牌库不足时只补到能补的数量，不自动洗回弃牌堆
```

计算器先不加入完整敌人 AI、功法卡池或局外成长；先验证这条计算链是否清楚且有选择。
