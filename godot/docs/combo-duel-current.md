# 组合出招当前设计源 v0.4

状态：核心牌组、成长和地图结构已确认；具体敌人参数与部分效果数值仍待测试  
日期：2026-08-01

## 1. 设计目标

验证玩家是否愿意为了下一次更好的牌型，管理手牌、牌库和弃牌机会。

本项目借鉴《小丑牌》的牌型识别、牌面数值、倍率和效果联动，但最终结果是对战行动，不是筹码计分。

## 2. 四层结构

### 2.1 普通牌型

只使用普通扑克牌名称：

```text
高牌、一对、两对、三条、顺子、同花、葫芦、四条、同花顺
```

一次出牌只选择一个最高牌型。牌型只负责决定倍率，不把多个牌型的数值倍率相加。

第一版暂借用《小丑牌》一级牌型的基础倍率：

| 牌型 | 暂定倍率 |
| --- | ---: |
| 高牌 | ×1 |
| 一对 | ×2 |
| 两对 | ×2 |
| 三条 | ×3 |
| 顺子 | ×4 |
| 同花 | ×4 |
| 葫芦 | ×4 |
| 四条 | ×7 |
| 同花顺 | ×8 |

这些倍率只用于建立可计算基线，尚未经过对战生命值与功法效果验证。

### 2.2 牌面数字

暂定采用与《小丑牌》相近的计数方式：只有组成最高牌型的牌参与基础值计算。

```text
基础值 = 组成最高牌型的所有牌面数字之和
```

普通牌型参与基础值的牌数：

```text
高牌：只计算最高的一张
一对：计算组成一对的两张
两对：计算两组对子的四张
三条：计算三张同点数牌
顺子：计算组成顺子的五张
同花：计算组成同花的五张
葫芦：计算三条与对子共五张
四条：计算四张同点数牌
同花顺：计算组成同花顺的五张
```

例如 `7、7、7、3、3` 组成葫芦，五张牌全部属于最高牌型，所以基础值是 `7+7+7+3+3=27`；牌型倍率取葫芦倍率。

例如打出 `7、7、4、3、1`，最高牌型是一对，只有两张7参与基础值，所以基础值是14；其余三张随本次出牌进入弃牌堆。

没有参与最高牌型的多余牌默认不增加基础值，也不触发牌面效果，只会随本次出牌进入弃牌堆。功法或内功可以明确改写这条规则，让额外牌也参与计算或产生效果。

《小丑牌》原规则还会给每种牌型增加一段固定筹码；当前版本暂不复制这层固定数值，只使用“计入牌的数字之和 × 牌型倍率”。

### 2.3 功法

功法是绑定牌型的特效。本次行动的处理顺序：

```text
识别最高牌型
→ 计算基础值与牌型倍率，得到行动数值但暂不造成伤害
→ 先触发该牌型功法与已装备内功，建立护盾、标记和延迟效果
→ 结算基础伤害
→ 结算本次已建立的额外伤害
→ 执行抽牌、弃牌、回收等牌区变化
→ 将打出的牌置入弃牌堆
```

每个功法只能绑定一个触发牌型。九种普通牌型各有一个固定功法位置，开局各自使用一个基础功法；同一牌型可以存在多个不同功法，玩家获得新功法后，只能替换该牌型当前使用的功法。

基础值和倍率只取最高牌型，功法也只取最高牌型对应的功法。一次出牌只触发一个功法一次；组成葫芦的三条和对子、组成同花顺的顺子和同花，都不再额外触发各自的功法。

- 只检查本次实际选出的牌，不检查仍在手中的牌。
- 如果没有装备该牌型的功法，牌型的基础值和倍率仍然正常计算，但不产生功法特效。
- 功法产生的新牌、新效果不能在同一次出牌中递归触发功法。

高牌功法可以在自己的效果文本中读取本次打出的全部散牌。例如五张牌没有组成其他牌型时，仍然只触发一次高牌功法，但该功法可以按五张牌的点数总和提供防御。这不是五次高牌触发。

九种牌型各保有一个当前使用的功法位置，共九个功法位置。每个位置只能装备一个当前功法；获得同牌型的新功法时替换该位置的旧功法。内功另有六个装备栏位。

#### 基础功法候选 v0.1

以下为开局九种牌型各自对应的基础功法候选。所有除法结果默认向下取整。

| 牌型 | 基础功法候选 | 审计备注 |
| --- | --- | --- |
| 高牌 | 获得本次所有打出牌点数总和的防御 | 高牌只触发一次；可以读取全部散牌，作为主动防守选择 |
| 一对 | 下回合手牌上限 +1 | 简单直接，作为一对的低阶节奏收益 |
| 两对 | 云环掌：下回合抽牌后，将 `行动数值 / 10` 张牌的花色改为红桃 | 需要指定目标范围，建议只允许选择我方手牌，避免随机改牌不可控 |
| 三条 | 获得 `行动数值` 点防御；本回合防御减少时，对敌方造成 `本回合防御减少值 × 0.01 × 行动数值` 点伤害 | 按本回合防御减少总量计算；当前 1～10 点牌组中三条行动数值最高 90，不会超过 90% 反伤 |
| 顺子 | 下回合抽牌后，从敌方牌库随机抽 1 张加入我方手牌；若行动数值 > 100，再从敌方手牌随机抽 1 张置入我方牌库 | 效果方向清楚，但“敌方手牌→我方牌库”很慢，可考虑置入我方手牌或牌库顶 |
| 同花 | 获得 `行动数值` 点防御；接下来 `行动数值 / 25` 回合，手牌上限额外 +1 | 以当前数值中位数看通常约 4 回合，偏强；后续需实测 |
| 葫芦 | 将弃牌堆中的 `行动数值 / 25` 张牌洗入抽牌堆 | 适合一次性牌库规则，保留 |
| 四条 | 接下来 `行动数值 / 50` 回合，敌方手牌上限 -1 | 稀有且强控，保留；最低持续 1 回合 |
| 同花顺 | 额外造成 `行动数值 × 0.01 × 我方总卡牌数量` 点伤害 | 先按我方本场总卡牌数计算，包含牌库、手牌、弃牌等未被移除的牌 |

功法中的“行动数值”暂指本次基础伤害，即 `基础值 × 牌型倍率`。

### 2.4 内功

内功承担类似《小丑牌》的常驻规则改写：

- 可以改变抽牌、弃牌、倍率、牌型识别或功法触发条件；
- 有等级；
- 占用六个内功装备栏位，并受到清楚可见的格式／类型限制；
- 不绑定某一个普通牌型，除非内功文本明确这样写。

第一版内功只允许在三个时间点之一生效：出牌前、数值计算后、效果结算后。等级优先提升同一效果的强度或次数，不要让每一级都新增一套规则；内功也不能在同一次出牌中无限生成牌型或递归触发功法。

功法是“某个牌型出现时做什么”，内功是“整套牌组和战斗规则如何被改写”，两者不能混成同一类效果。

#### 初始内功候选 v0.1

```text
未参与最高牌型的打出牌，其点数总和转化为防御。
```

例如打出 `4、4、2、1`，最高牌型是一对，基础伤害为 `(4+4)×2=16`，触发一对功法；未参与一对的 `2、1` 额外提供 `3` 点防御。

该效果属于内功，不是默认出牌规则。没有装备此内功时，未参与最高牌型的牌只会被弃置，不提供额外防御。

## 3. 已确认的牌组与战斗基础规则

```text
基础牌组：4 种花色 × 点数 1～10，共 40 张
手牌上限：默认 6 张
玩家初始生命：100
敌人初始生命：100
单次出牌候选：1～5 张
未选中的手牌：继续留在手牌中
被打出或弃掉的牌：进入弃牌堆
一场战斗内：牌组只使用一次，不自动将弃牌堆洗回牌库
回合开始时：按当前手牌上限统一补牌，最多补到手牌上限
牌库不够时：只补到能补的数量，不自动洗回弃牌堆
牌库和手牌都没有可用牌时：本场战斗不能继续
玩家先行动；若玩家无法继续行动时敌人尚未倒下，则本场战斗失败
战斗结束后：本场战斗的牌区清空并为下一场战斗重新整理
```

每次出牌不自动立即补牌；补牌统一发生在下一回合开始。40 张基础牌是当前正式基线，后续卡牌成长在此基础上增加、删除、复制、修改或附魔牌。

## 4. 牌型倍率升级

牌型升级只提高对应牌型的倍率，不增加另一套“筹码”或计分资源。每次升级按牌型分组增加倍率：

| 牌型分组 | 每次升级的通常倍率增量 |
| --- | ---: |
| 高牌、一对、两对 | +1 |
| 三条、同花、葫芦 | +2 |
| 顺子、四条 | +3 |
| 同花顺 | +4 |

例如三条初始为 ×3，升级一次为 ×5；同花顺初始为 ×8，升级一次为 ×12。具体升级价格与可升级次数属于修炼系统参数。

概率统计以后统一按40张基础牌、实际手牌选择规则重新计算；在计算器完成前不把概率作为平衡承诺。

## 5. 玩家成长

一局内的成长由四部分组成：

1. **内功**：六个装备栏位，提供常驻规则改写或触发条件改变。
2. **功法**：九个牌型位置，每个牌型位置装备一个当前功法；获得新功法后可替换同牌型功法。
3. **卡牌**：可以增加、删除、复制、修改和附魔牌。
4. **牌型倍率**：按上表分组升级对应牌型倍率。

本版不把上述成长拆成额外的独立资源层；卡牌、功法、内功和倍率都是构筑内容。

## 6. 修炼系统与经济

战斗胜利后进入修炼系统。修为是本局唯一的经济类资源，用于：

- 获取或替换内功；
- 获取或替换功法；
- 购买牌型倍率升级；
- 增加、删除、复制、修改或附魔卡牌；
- 刷新当前修炼选项。

地图不设置商店节点。修炼界面在战斗胜利后的流程中出现，商品数量、价格和刷新费用作为后续平衡参数。

## 7. 地图与战斗流程

一局游戏分为三层。每层由不同节点组成，节点类型可以包括普通战斗、精英战斗、事件、休息和特殊战斗；每层末尾固定进入该层 Boss 战。

```text
进入第1层
→ 选择本层节点
→ 战斗节点胜利后进入修炼系统，再返回本层路线
→ 完成本层路线并进入层末 Boss
→ Boss 胜利后进入修炼系统
→ 进入下一层
→ 第3层末 Boss 战胜利后结束本局
```

地图只负责节点选择，不提供普通商店节点；修炼系统承担本局内的购买和刷新。

## 8. 对战结果

基础伤害不是分数，而是本次行动默认造成的伤害。功法或内功可以在此基础上追加：

- 防御；
- 抽牌、弃牌、锁定、夺取或回收牌；
- 其他明确写出的战斗效果。

除非功法或内功明确改写规则，基础伤害不会被改成另一种资源；高牌功法可以在造成高牌基础伤害的同时，按打出的散牌点数提供防御。

敌人的攻击也应由它当前组成的普通牌型和已装备效果产生，不能退回固定的“攻击值／防御值”两个数字。

防御是功法或内功的效果，不是独立的牌型，也不是某个花色的属性。高牌可以使用“造成基础伤害并获得防御”的基础功法。

防御是持续保留的数值，可以在多次出牌中累积。受到伤害时，先从防御中扣除；伤害超过当前防御的部分才扣生命。若伤害没有耗尽防御，剩余防御继续保留；防御不会因为回合结束或没有出牌而自动清零。

## 9. 资源控制

资源优先使用牌区表达：

```text
手牌、剩余牌库、弃牌堆、已锁定牌、敌方手牌
```

功法或内功可以明确执行一项或少量牌区操作：

```text
抽牌、保留、弃掉、锁定、夺取、回收
```

这些操作是效果，不是额外的“势”或“能量”数值。第一版每个效果最好只作用于一个牌区、一个时间点，避免一次效果同时抽牌、弃牌、锁牌和夺牌。

弃牌不会在本场战斗中自动回到牌库；只有功法或内功明确写出“回收”时，牌才会重新变为可用资源。

## 10. 下一项实验

制作纯规则计算器，显示：

```text
给定一手6张牌
→ 枚举选择1～5张的方案
→ 识别最高普通牌型
→ 计算基础值
→ 读取牌型倍率
→ 得到行动数值，但暂不造成伤害
→ 只触发最高牌型对应的功法一次，并触发已装备内功
→ 结算基础伤害、额外伤害、防御或牌区操作
→ 显示未参与牌型的牌被弃置
→ 回合开始时按手牌上限从剩余牌库补牌，最多补到6张
→ 牌库不足时只补到能补的数量，不自动洗回弃牌堆
```

计算器先不加入完整敌人 AI、功法卡池或局外成长；先验证这条计算链是否清楚且有选择。
