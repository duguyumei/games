# 真气效果、重塑与异状

> 其他模块只能通过链接引用，不得复制或重新解释。原章节编号保留用于迁移核对。

### 6.2 按生命周期划分的真气效果

真气上的附加内容先按生命周期分为本局层的**重塑**与战斗层的**异状**。分类只回答效果保存多久、占用哪个槽位，不按伤害、抽牌、留手或出招等具体功能分类；具体触发时点和行为由内容定义另行描述。

| 生命周期层 | 类别 | 单张真气容量 | 默认结束时间 |
| --- | --- | ---: | --- |
| 重塑 | 本源 | 1 | 本局结束；一张真气一局只能接受一次本源改造，不能替换 |
| 重塑 | 强化 | 1 | 本局结束，或被同类新重塑替换／明确移除 |
| 重塑 | 印记 | 1 | 本局结束，或被同类新重塑替换／明确移除 |
| 重塑 | 其他 | 多个 | 各自文本；默认持续至本局结束 |
| 异状 | 标记 | 多个 | 每个标记使用自己的生命周期 |
| 异状 | 毒 | 1 | 实际进入弃牌堆或战斗结束时移除 |
| 异状 | 状态 | 1 | 实际进入弃牌堆或战斗结束时移除 |
| 异状 | 其他 | 多个 | 各自文本；最迟在战斗结束时移除 |

一张真气可以同时拥有一个毒和一个状态；新毒替换旧毒，新状态替换旧状态。标记与两类“其他”允许多个不同内容共存；同名内容是否刷新、叠层或替换由其自身定义，不建立全局同名叠加规则。本源、强化和印记各有一个槽位：本源一经改造即锁定，强化与印记获得同类新内容时替换旧内容。

重塑只存在于本局牌组真气实例中，跨战斗保存。异状只存在于当前战斗，不能作为毒、状态或标记直接跨战斗保存。若事件、Boss 或其他本局内容需要造成跨战斗负面影响，应建立“重塑·其他”；它可以明确在每场战斗开始时为该牌施加一个毒、状态或标记，而不是让异状对象本身跨战斗存在。

临时模拟本源、强化或印记行为的战斗效果仍属于异状，通常归入“异状·其他”，不能因为效果类似重塑就写入重塑槽位。效果行为与生命周期分类保持正交。

真气实际进入弃牌堆时，默认移除其毒和状态。正常打出的真气先完成本次毒或状态的合格出招结算，再执行进入弃牌堆清理；被效果明确弃掉但最终实际进入弃牌堆的真气不触发出招效果，但同样移除毒和状态。蛊印、回风或其他效果若令真气不实际进入弃牌堆，则不触发这条默认清理。标记按各自生命周期处理，“异状·其他”也只按自身文本处理。

内功和功法不拥有真气的本源、强化、印记或异状。旧版箔面、镭射、多彩与负片品相不再属于当前重塑系统；需要保留的数值或栏位能力以后由具体内功、物品或其他规则分别承接。

### 6.3 重塑与异状的运行边界

功法默认只建立当前战斗的异状、层数或延迟效果。没有耗尽时点且持续整场反复修改我方结算规则的功法效果，原则上改为内功；功法若建立延迟效果，应写明持续回合、层数、次数或其他结束条件。内功、丹药、奇珍与事件只有在文本明确写出“重塑”时，才修改本局牌组真气实例。

触发术语统一如下：

- **参与最高牌型**：只有组成最高牌型并以自己的有效真气值计入基础值的真气满足；对应《小丑牌》的普通“参与计分”。
- **参与数值计算**：默认指参与最高牌型并将自身贡献计入基础值的真气；功法、内功或其他效果可以明确让额外打出的真气也参与。
- **打出**：玩家本次选择并使用了该真气，不要求它参与最高牌型；写有“打出此牌时”的毒、状态、标记或其他效果按此口径触发。
- **留手**：该真气当前位于手牌；写有留手条件的异状在离开手牌后立刻停止效果。
- **弃掉**：只有功法或内功明确执行的弃牌动作；正常打出后进入弃牌堆不算弃掉。

### 6.4 第一批异状候选

| 异状 | 类别 | 当前效果 | 生命周期与容量 |
| --- | --- | --- | --- |
| 烈毒 | 毒 | 打出此牌时，持有者受到等于此牌当前有效真气值 100% 的伤害；此牌的烈毒结算后移除，被效果明确弃掉时也移除烈毒 | 占用唯一毒槽；实际进入弃牌堆或战斗结束时移除 |
| 郁毒 | 毒 | 打出此牌时，计算该牌本次自身贡献的郁毒削减值：`floor(该牌原本本次自身贡献 × 50% × 当前毒效倍率)`，再从该牌本次自身贡献中扣除；削减后的真气贡献允许为负数。此牌的郁毒结算后移除，被效果明确弃掉时也移除郁毒 | 占用唯一毒槽；实际进入弃牌堆或战斗结束时移除 |
| 散气 | 状态 | 此牌参与最高牌型时，提供的有效真气值减半，向下取整；牌型识别仍读取原牌阶与原始属性 | 占用唯一状态槽；实际进入弃牌堆或战斗结束时移除 |
| 破绽 | 状态 | 持有者受到伤害时，手牌中每有 1 张破绽牌，本次受到的伤害提高 20% | 占用唯一状态槽；实际进入弃牌堆或战斗结束时移除 |
| 封穴 | 状态 | 持有者造成伤害时，手牌中每有 1 张封穴牌，本次造成的伤害减少 20% | 占用唯一状态槽；实际进入弃牌堆或战斗结束时移除 |
| 封禁 | 状态 | 此牌被抽入手牌后，本回合不能打出；本回合结束后移除封禁 | 占用唯一状态槽；进入弃牌堆时也按状态默认规则移除 |
| 风标记 | 标记 | 属性识别时，此牌同时视为风；明确读取原始属性时仍读取其印刷属性 | 可与其他标记共存；战斗结束时移除 |
| 风引 | 标记 | 此牌被抽取时移除风引并额外抽 1 张牌 | 可与其他标记共存；抽取触发后移除 |
| 回风 | 标记 | 此牌被明确弃掉时，结算弃牌响应后改为放回牌库顶 | 可与其他标记共存；成功改置后移除 |
| 乱流 | 标记 | 敌方抽到此牌时立即明确弃掉该牌且不补抽 | 可与其他标记共存；触发后移除 |
| 绝气标记 | 标记 | 此牌下一次进入弃牌堆后获得封禁并改置牌库顶 | 可与其他标记共存；成功触发后移除 |
| 燃尽 | 标记 | 此牌的当前有效真气值为 0；不改变牌阶、基础真气值、印刷属性或牌型识别 | 可与其他标记共存并随牌跨牌区保留；可以被净化，战斗结束时移除 |
| 净化 | 标记 | 获得净化时，令该牌当时已有的全部重塑失效，并清除当时已有的全部其他异状；最后建立净化自身。净化之后新施加的重塑与异状正常生效 | 战斗结束移除；已清除的异状不恢复，未被后来同类重塑替换的原有重塑恢复 |

净化只在获得瞬间处理既有内容，不持续禁止后续施加。净化前重塑继续保存在本局牌组实例中，只在当前战斗被屏蔽；净化之后若同一强化或印记槽获得新的重塑，新内容视为替换，旧内容不再恢复。本源槽不能在战斗中借净化重新改造。净化属于标记，因此会清除获得前已有的风引、回风、乱流、绝气标记、燃尽和异状·其他，再建立自身。

#### 蛊毒流的牌区、附毒与蛊印框架

烈毒与郁毒同属“异状·毒”，共用单张真气唯一毒槽，因此不能同时存在。施加新毒时替换旧毒；若效果只允许选择无毒目标，必须在自身文本中明确写出。

为敌方手牌附毒时，只读取效果结算当时仍位于敌方手牌的合格真气。敌方此前已经打出、进入弃牌堆、移出牌组或已经完成毒结算的真气不受追溯影响。多个效果连续附毒时按触发队列逐项结算，后置效果重新读取前置效果已经改变后的手牌与异状状态。

- 附毒默认从当前合格目标中随机选取，单次效果内不重复选择同一张真气。
- 合格目标不足时只结算实际数量，剩余次数不会自动转移到牌库、弃牌堆或其他牌区。
- 功法若要作用于敌方牌库、弃牌堆或已打出的牌，必须在文本中明确写出对应牌区。
- 后获得的毒效增幅、转化或其他功法增益只影响之后发生的毒触发，不追溯修改已经结算的烈毒或郁毒。郁毒削减值按该牌原本本次自身贡献单独计算，允许削减后真气贡献为负数；超出部分默认不转伤，只有明确写出“转化”为伤害的效果才会造成额外伤害。

蛊印是附着于敌方的临时战斗标记，不是玩家持有或支付的基础战斗资源。敌方一张带毒真气触发烈毒或郁毒时，若敌方至少拥有 1 层蛊印，则该次毒正常结算后消耗 1 层蛊印，使该真气重新获得刚刚触发的同种毒异状，并在本次出牌结算后洗回敌方牌库，而不是进入普通弃牌堆。一次毒触发默认最多消耗 1 层蛊印；“蛊印回响”等明确效果可以增加本次消耗并给出相应收益。洗回牌库不会立即再次触发毒，必须等该牌之后重新抽取并打出。蛊印在战斗结束时清除，公共层数上限暂不设置，具体功法可以自行限制施加或消耗数量。

蛊印只有这一种标记，不另设蛊引。蛊印公共规则不提供毒效倍率；只有装备“蛊印炼毒”内功时，才按蛊印数量提高毒效倍率，增幅最高为 50%。功法或其他内功明确提供的有限毒效增幅仍独立结算。

毒效增幅可以同时修改烈毒的 100% 伤害系数与郁毒的 50% 削减系数，但具体倍率、持续时间与叠加方式必须由功法或内功文本明确写出。烈毒转化为防御、郁毒转化为伤害等效果属于具体功法或内功，不是蛊毒流的默认公共规则。

#### 风标公共规则

风标是异状·标记的一组内容，用于记录属性转化以及抽牌、弃牌与控顶构筑的延迟效果。风标记、风引、回风与乱流可以和其他标记共存，也可以彼此共存；同名风标的重复施加默认刷新，不建立重复实例。风标可以随真气跨手牌、牌库与弃牌堆保留，按各自触发文本移除，未触发者在战斗结束时清除。新赋予的风标只响应之后发生的合格事件，不追溯已经完成的抽牌、弃牌或其他触发时点。

当前共享四种风标：

- **风标记**：带有风标记的普通真气在牌型识别与功法属性条件中同时视为风；明确读取原始属性时仍读取其基础属性。风标记持续至战斗结束。
- **风引**：我方带有风引的牌被抽取时，移除风引并普通抽 1 张牌。若新抽到的牌也带有风引，则其风引继续正常触发；这些明确抽牌可以超过手牌上限。
- **回风**：我方带有回风的牌被功法或内功明确弃掉时，该牌仍视为被弃掉并正常触发化丹印等弃牌效果；这些效果结算后移除回风，将该牌改为放回我方牌库顶而非停留在弃牌堆。
- **乱流**：敌方带有乱流的牌被抽入手牌时，立即将该牌明确弃掉并移除乱流，不补抽替代牌。乱流可以触发普通的“明确弃牌”效果，但其弃牌来源是风标，不是功法，因此不会触发只响应“因功法效果被明确弃掉”的飞燕抄水。

#### 纳气公共规则

纳气是附着于持有者的临时战斗层数。持有至少 1 层纳气时，手牌上限统一增加 1；纳气层数只表示这项加成的剩余持续时间，不随层数继续增加手牌上限。重复获得纳气时只增加层数。每个完整回合开始时，持有者先按包含纳气加成的当前手牌上限完成正常补牌，再移除 1 层纳气；层数降至 0 后移除手牌上限加成。明确抽牌仍可超过当前手牌上限。纳气在战斗结束时清除。

#### 夺风、盈袖与束袖公共规则

- **夺风**：附着于持有者的临时战斗层数。敌方通过正常补牌、功法、内功、风引或其他任意来源每实际抽到 1 张在属性识别中视为风的牌时，若我方至少拥有 1 层夺风，则消耗 1 层，将该牌从敌方手牌移入我方手牌。一次多张抽牌按实际抽牌顺序逐张检查；牌在移动后仍归原持有者所有，我方可以正常打出、弃掉与移动，战斗结束后归还。第一轮测试中，夺风的移动响应先于该牌自身的“被抽入敌方手牌”响应；牌已被夺风移走时，不再结算要求它仍位于敌方手牌的乱流等响应。抽牌来源不改变夺风是否触发，层数耗尽后结束，未耗尽层数在战斗结束时清除。
- **盈袖**：附着于持有者的本场战斗层数。每层使持有者当前手牌上限 +1，可以叠加，战斗结束时清除。
- **束袖**：附着于持有者的本场战斗层数。每层使持有者当前手牌上限 -1，可以叠加；第一轮测试中最终手牌上限最低为 1，降低上限不会立即弃掉已经超过上限的现有手牌，战斗结束时清除。

纳气、盈袖、束袖以及其他手牌上限修正分别计算：纳气只要至少有 1 层就统一提供 +1，盈袖与束袖按各自层数增减，最后应用手牌上限最低为 1 的限制。它们都只改变正常补牌目标；明确抽牌仍可超过结算后的当前手牌上限。

#### 火系公共规则：攻击段、借力、焚脉、绝气与连势

火系功法使用下列公共语言。它们是功法、内功或其他明确效果建立的战斗机制，不是真气属性本身自动附带的效果。

- **攻击段**：一次独立的伤害结算。例如“造成5次伤害”包含5个攻击段；每段分别读取结算当时的防御、异状、标记与增减伤，并分别触发受伤响应。若攻击者在受击响应中死亡，尚未结算的后续攻击段停止。
- **追击**：不消耗真气、不建立新牌型组、不重新计算牌型、不触发功法或牌上重塑／异状、不推进功法序列的额外攻击段。追击正常经过防御并触发一般受伤响应；追击不满足“非追击攻击段”的条件。不同效果可以连续产生追击，但同一个效果不能在自身结算中递归触发自己。
- **反击**：在敌方行动或敌方攻击段结算后触发的追击，遵守追击的全部规则。
- **真伤**：直接扣除生命，不经过防御，也不受普通增伤、减伤或连势影响，除非效果明确写出作用于真伤。由低伤转化得到的真伤，先按普通伤害顺序完成转化判定，再按真伤结算。
- **纯阳**：本次行动的主牌型与全部协同组实际打出的普通真气都可以视为火；混元强化视为火。纯火仍然只检查当前牌型组，纯阳检查整个行动。
- **燃命**：直接失去生命作为功法代价；代价结算后若生命降至0，后续效果不结算，除非文本明确允许保留生命或继续结算。
- **消散**：将真气临时移出当前战斗牌组，战斗结束后归还；不进入弃牌堆，不触发“被弃掉”效果。消散不是永久移出本局牌组。
- **燃尽**：使真气获得同名异状·标记；该牌仍可抽取、留手、组牌、打出和移动，但当前有效真气值为 0。燃尽随牌跨牌区保留，可以被净化，战斗结束时移除。
- **虚无**：每个完整回合的其他回合结束效果结算完毕后，若此牌仍在手牌中，则此牌消散。已经离开手牌的虚无牌不因该次检查消散。
- **借力**：我方战斗临时层数标记。敌方一个功法、追击或反击攻击段实际减少我方防御或生命时，消耗1层借力，将一次反击加入该攻击段的受击响应队列；反击伤害等于本段实际减少的防御与生命之和。没有实际减少时不消耗；敌方多段攻击按攻击段分别检查。借力反击为普通伤害，除非效果明确转为真伤。
- **焚脉**：敌方战斗临时层数标记。敌方确认一个牌型组后、计算该组基础值前，若拥有焚脉则消耗1层，从该组参与最高牌型的普通真气中随机选择1张，使其本次有效真气值变为0；没有普通真气目标时不消耗。焚脉不改变牌阶、属性或牌型识别，不使真气贡献低于0。
- **绝气**：敌方战斗临时层数标记，与焚脉配套。焚脉消耗并选中一张普通真气时，若敌方拥有绝气且该牌没有绝气标记，则同时消耗1层，使该牌获得异状·标记“绝气标记”；该牌下一次进入敌方弃牌堆后，移除绝气标记，使其获得状态“封禁”并放回敌方牌库顶。绝气牌若先被移往其他牌区，标记保留到下一次进入敌方弃牌堆；触发后移除。绝气标记可以与风标及净化以外后来施加的其他标记共存；封禁占用唯一状态槽并替换此前状态。
- **连势**：我方战斗临时层数标记。每层使我方非真伤攻击伤害提高1%；每个攻击段结算时重新读取当前层数；真伤默认不受连势提高。连势不自动增长，战斗结束清除，没有公共层数上限。
- **连势减半**：敌方一个攻击段实际减少我方防御或生命时，在该攻击段及全部受击响应结算结束后，我方连势减半并向下取整。毒、燃命、自身效果和反震不触发该规则；功法或内功可以明确限制本次最多减少多少层，但不能改变公共触发时点。多个限制按实时队列从左到右结算。

低伤转真伤的阈值统一在所有普通伤害计算完成、扣除防御之前检查。若此时最终伤害为0则不转化；转为真伤后不再读取连势或普通增减伤。

### 6.5 本源、强化与印记

本局层的真气重塑不再使用“品相”类别。当前正式结构为：一张真气最多拥有一个本源改造、一个强化和一个印记。本源、强化与印记的生命周期均跨战斗保存至本局结束；战斗中的临时变化仍归入异状。

#### 本源改造

本源改造直接决定真气本体的一次身份变化。一张真气一局只能接受一次本源改造，三种操作互相排斥；接受其中任一种后，本源槽锁定，不能再通过普通效果改变。

| 本源改造 | 正式效果 |
| --- | --- |
| 转属 | 将此真气的基础属性改为指定的风、林、火或山；觉醒本源读取改造完成后的基础属性。 |
| 易阶 | 按效果指定方向将此普通真气的牌阶改变一级；升阶为 `2→3→…→10→J→Q→K→A`，降阶为 `A→K→Q→J→10→…→2`。A不能继续升阶，2不能继续降阶；基础真气值同步改为新牌阶对应的标准值。 |
| 觉醒 | 激发此真气当前基础属性对应的觉醒效果；觉醒本源完成后，本源槽锁定，不能再转属或易阶。 |

“转属”和“易阶”本身不自动赋予觉醒；“觉醒”也不能再改变基础属性或牌阶。混元强化、风标记等只改变属性识别，不改变基础属性，因此不改变觉醒效果。特殊物品若要同时完成两种本源操作，必须明确标为本源规则例外。

**完整复制**属于新增真气实例，不是对源牌执行本源改造。源牌保持不变；复制牌继承复制时源牌的牌阶、基础属性、基础真气值、本源、强化、印记与重塑·其他，不复制毒、状态、标记、异状·其他或临时真气值变化。源牌已有本源时，复制牌继承相同本源且本源槽已经锁定；源牌没有本源时，复制牌的本源槽也保持未改造。复制本身不消耗源牌的本源机会，也不需要本源规则例外。

觉醒效果如下：

| 属性 | 觉醒效果 |
| --- | --- |
| 风 | 此真气被抽到时，额外抽 1 张牌。 |
| 林 | 此真气实际进入我方弃牌堆时，将此真气从弃牌堆洗入我方抽牌堆。 |
| 火 | 此真气参与功法的数值计算时，有效真气值 ×2；该功法完整结算后，此真气获得燃尽标记。 |
| 山 | 每个回合结束阶段，若此真气仍在我方手牌中，获得等于此真气当前有效真气值的防御。 |

燃尽牌的有效真气值已经为 0，因此火觉醒不需要额外判断；同一次功法只在完整结算结束后施加一次燃尽。觉醒不设置额外次数或数量上限。山觉醒读取触发时的当前有效真气值；增元、虚暴、散气、燃尽等修正按各自规则先后影响该值。

#### 强化

八种强化平级，不设置普通、罕见、稀有、传奇等强化档位。下列功能组只用于修习界面展示，不代表强弱顺序；随机获得一种强化时，八种强化默认等权，除非效果文本另有说明。

| 功能组 | 强化 |
| --- | --- |
| 稳定数值 | 增元、乘势 |
| 组牌与爆发 | 混元、虚暴 |
| 留手与填充 | 无漏、磐石 |
| 经济与随机 | 藏金、机缘 |

| 强化 | 正式效果 | 结算边界 |
| --- | --- | --- |
| 增元 | 此真气参与功法的数值计算时，有效真气值 +8。 | 牌阶和基础属性不变；增加值进入本次自身贡献、牌型基准值与功法值。 |
| 乘势 | 此真气参与功法的数值计算时，本次功法倍率 +1。 | 不增加固定牌型倍率，不改变牌型基准值；多张乘势真气分别生效并相加。 |
| 混元 | 识别牌型与检查功法属性条件时，此真气同时视为风、林、火、山。 | 只改变属性识别，不改变基础属性、觉醒、牌阶或有效真气值；明确读取原始属性时仍读取其基础属性。 |
| 虚暴 | 此真气参与功法的数值计算时，有效真气值 ×2；此真气具有虚无。 | 只翻倍此真气自身贡献；虚无不影响已经离开手牌的牌。 |
| 无漏 | 此真气不能成为施加毒、破绽或封穴的合法目标；此真气被打出时，获得等于其当前有效真气值的防御。 | 不免疫其他异状；打出时读取当前有效真气值，燃尽时获得 0 点防御。 |
| 磐石 | 此真气不能被明确弃掉，也不能成为明确弃牌效果的合法目标；此真气被打出时，对敌方造成等于其当前有效真气值的伤害。 | 正常打出后仍可进入弃牌堆；不改变牌阶、属性或本体真气值。 |
| 藏金 | 战斗胜利时，若此真气位于我方手牌或我方抽牌堆中，获得 3 点历练。 | 位于弃牌堆、待出区或已经消散时不结算；燃尽不改变牌区，因此不妨碍藏金；战败不结算。 |
| 机缘 | 此真气参与功法的数值计算时，独立进行两项判定：`1/5` 概率使本次功法倍率 +1；`1/10` 概率获得 20 点历练。 | 两项可以同时成功；多张机缘真气分别判定并正常相加；未参与数值计算时不判定。 |

“参与功法的数值计算”先读取本次当前有效真气值，再应用增元、虚暴等自身修正；乘势和机缘随后进入功法倍率修正。旧石头牌不再是失去牌阶、属性和真气值的特殊牌；磐石强化保留普通真气的本体字段。

机缘的随机判定只发生在行动正式确认时。预览、AI 候选枚举和协同候选校验均不判定机缘，也不推进随机源或提前增加历练。所有选牌与协同合法性确认、真气成功进入待出区后，主组与协同组分别对各自参与数值计算的机缘真气冻结倍率与历练两项独立结果；两组先使用各自冻结结果重新计算功法值，再按协同规则计算共享功法值。

冻结结果按真气实例 ID 进入行动记录。等待选择、选择恢复、协同组后续结算或同一行动的重复收口只能复用该结果，不得重掷，也不得重复发放历练。藏金和机缘产生的历练先写入战斗中的绝对历练余额，战斗进度同步时以绝对值覆盖本局余额；同一战斗快照重复同步不会重复增加奖励。

同一张真气只能拥有一种强化；为已有强化的真气施加另一种强化时，新强化替换旧强化。八种强化的目标数量、出现率与投放方式由丹药、奇珍和其他本局内容分别规定。

#### 印记

印记统一按效果命名，不再使用金、赤、蓝、紫等颜色作为正式规则名称；颜色可以保留为界面表现。同一张真气最多拥有一个印记，新印记替换旧印记。

| 印记 | 正式效果 |
| --- | --- |
| 回响印 | 此真气产生一次合格触发时，将此真气本次自身触发完整重演一次，并重新结算所有由此真气直接触发的内功效果；不重触整门功法、其他真气、回响印自身或整条内功队列。 |
| 悟道印 | 战斗胜利时，若此真气仍在我方手牌中，获得最后一次成功出招识别出的最高牌型对应的一份心得。 |
| 化丹印 | 此真气被明确弃掉时，获得一份随机丹药；正常打出后进入弃牌堆、删除、摧毁、夺取或虚暴牌因虚无消散均不触发。 |
| 先天印 | 战斗开始组成起始手牌时，优先抽取此真气；所有先天印真气处理后，再按正常规则补足剩余手牌。 |

多个先天印按本场洗牌结果中原有的相对抽取顺序优先进入起始手牌，不为此重新洗牌。先天印少于手牌上限时以普通牌补足；多于手牌上限时，尚未抽取的先天印继续按原相对顺序留在牌库顶。起始优先抽取每场战斗只执行一次，后续回合不重新置顶。

悟道印所称“成功出招”是功法条件满足且该牌型组完整结算成功；条件失败、空功法或执行失败均不覆盖此前的成功记录。主组与协同组分别记录，后成功完成的组成为本场最后一次成功牌型。悟道印与化丹印生成的心得、丹药都进入丹药／心得／奇珍共用的 3 格消耗品栏；没有空位时不生成，也不覆盖已有内容。

化丹印的随机候选读取统一正式消耗品内容中 `kind="pill"` 的完整集合，不读取修习商店白名单。真气成功完成明确弃牌移动后即触发化丹印；即使回风等弃牌响应随后将它改置到其他牌区，本次化丹仍正常结算。未成功的弃牌请求不触发。

回响印的“合格触发”包括此真气自身的数值贡献、强化、觉醒、异状、留手或战斗胜利效果；由该真气直接触发的内功可以在回响中再次结算。回响不重新识别牌型，不推进功法序列，不触发其他真气，也不递归触发自身。

内功和功法不能拥有印记。本源、强化和印记的具体数值与出现率作为当前设计基线，后续只通过实测或明确的重构决议调整。
