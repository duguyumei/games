# 真气效果、重塑与异状

> 本文件是当前 v0.30 模块化权威设计源的一部分。原文规则段落仅在此处维护；
> 其他模块只能通过链接引用，不得复制或重新解释。原章节编号保留用于迁移核对。

### 6.2 真气附加内容与生命周期

真气上的附加内容分为本局层的**重塑**与战斗层的**异状**。分类首先回答内容保存多久、占用什么容量；具体效果再回答它读取哪个牌区、在什么时点触发。

| 生命周期层 | 类别 | 单张真气容量 | 默认结束时间 |
| --- | --- | ---: | --- |
| 重塑 | 本源 | 1 | 本局结束；一张真气一局只能接受一次本源改造，不能替换 |
| 重塑 | 强化 | 1 | 本局结束，或被同类新重塑替换／明确移除 |
| 重塑 | 印记 | 1 | 本局结束，或被同类新重塑替换／明确移除 |
| 重塑 | 其他 | 多个 | 各自文本；默认持续至本局结束 |
| 异状 | 增益 | 多种；同名可叠层 | 各自文本；最迟在战斗结束时移除 |
| 异状 | 减益 | 多种；同名可叠层 | 各自文本；最迟在战斗结束时移除 |
| 异状 | 状态 | 最多一种状态 | 各自文本；默认在实际进入弃牌堆或战斗结束时移除 |
| 异状 | 标记 | 多种 | 各自文本；最迟在战斗结束时移除 |
| 异状 | 临时重塑 | 按临时子槽分别计算 | 被同子槽新内容替换、明确移除或战斗结束 |

不同增益、不同减益和不同标记可以共存；同名增益或减益叠加层数。同名标记默认不建立重复实例，是否刷新持续时间或产生再次施加效果由该标记正文决定。

一张真气同时最多拥有一种状态。再次施加同名状态时按该状态自身规则处理；目标已有另一种状态时，默认不是合法目标。只有效果明确写出“替换状态”时，才先移除旧状态并施加新状态。状态容量不影响增益、减益、标记或临时重塑。

第一版临时重塑开放三个子槽：**临时强化槽**、**临时属性槽**与**临时牌阶槽**。新临时强化替换旧临时强化，不覆盖或删除永久强化；永久强化与临时强化可以同时存在并分别生效。临时属性令真气在属性识别中额外视为指定属性，不改变基础属性或觉醒效果；新的临时属性替换旧临时属性。临时牌阶令真气在后续牌型识别与标准真气值查询中视为指定牌阶；新的临时牌阶替换旧临时牌阶。三类内容都在战斗结束时清除。以后需要临时印记时，应新增独立子槽，不能借用状态或标记容量。

重塑只存在于本局牌组真气实例中，跨战斗保存。异状只存在于当前战斗；若事件、Boss 或其他本局内容需要造成跨战斗影响，应建立重塑·其他，并由它在每场战斗开始时施加相应异状，不能直接保存异状对象。

真气实际进入弃牌堆时，先结算本次入堆响应，再按各异状的生命周期清理。毒、破绽、封穴和封禁默认移除；成长、衰败按自身规则移除；标记只有正文明确写出时才移除。正常打出的真气可以在离手前触发“打出时”效果，被效果明确弃掉则不触发“打出时”效果。

内功和功法不拥有真气的本源、强化、印记或异状。它们可以拥有自己的规则文本，并在结算时给真气施加上述内容。旧版箔面、镭射、多彩与负片品相不再属于当前重塑系统；需要保留的数值或栏位能力由具体内功、物品或其他规则承接。

### 6.2.1 功法／内功／物品来源标识

功法、内功或物品需要保存自身进度、倒计时、命元或其他可被多项效果读写的数值时，使用统一的来源标识，不把它伪装成角色状态或真气异状。一个标识键至少由 `source_kind`（`technique`／`inner_skill`／`item`）、稳定来源实例键、内容 ID、`marker_id` 与 `scope`（`battle`／`run`）组成，并保存整数值、是否公开及显示名称；同一来源可以同时拥有多个不同标识。

来源标识支持增加、设置、减少、消费、清除、捕获，以及同阵营来源间的显式转移。每次实际变化发送一次 `source_marker_changed`，事件必须携带来源键、变化前后值、实际变化量、公开属性与行动令牌。条目生命周期也是实际变化：创建值为0的新条目、删除值为0的已有条目分别公开`created/removed`及`existed_before/exists_after`并发送事件；已有条目重复set同值、清理不存在条目不发送。战斗标识在战斗结束时统一清理；本局标识进入本局快照与存档。临时功法实例默认拥有独立战斗标识；显式 `share_origin` 时读取原功法实例的来源标识，但临时副本不能复制或重复结算原功法的本局永久装备收益。

来源地址只由唯一 `SourceMarkerAddressResolver` 解析。功法 battle 标识默认绑定稳定
`slot_instance_id`；`share_origin` 临时功法实例绑定 `origin_slot_instance_id`；功法 run 标识绑定
不随战斗位置改变的永久功法来源键。独立临时副本不能创建、复制或写入 run 范围永久收益。
物品地址固定为`item:<stable_owner_id>:<content_id>`：玩家的`GrowthInventory`和战斗工作副本
`BattleSide`统一解析为`player`，地址不含`item_ids`下标；库存顺序只影响Invocation顺序，不影响状态身份。
同一持有者不能重复持有同一物品，非持有物品不能建立持久贡献；item、inner_skill和technique即使使用
同名marker也因来源类别和实例键隔离。
来源标识效果、自动触发、数值查询、UI 和 AI 投影必须使用同一解析结果。

功法实例主要蓄力值是来源marker的类型化角色，不是第二份状态。定义声明charging后，只有实际
`slot_instance_id`地址下的primary battle marker存在才算正在蓄力；值为0仍活跃，clear才结束。
该主要marker窄例外地始终使用实际slot地址，即使临时功法普通marker采用`share_origin`也不能合并
charging值。`source_marker_changed`对它另公开`marker_role=charging_primary`、slot、technique和hand。
begin/write/end、只读枚举及冻结目标后的批量写都经现有`BattleEffectPorts`和
`BattleSourceResourceEffectService`，不得直接操作store或建立ChargingManager。

玩家可见功法进度只保存在 `SourceMarkerStore`。战斗功法实例和 `TechniqueInstance` 不再保存
另一份通用 `battle_state` 字典；确有专用原子记录时必须是具有独立公共语义的正式服务，
不能成为第四套功法状态事实源。

由来源标识贡献的最大生命等角色属性统一通过 `SourceContributedStatService` 计算，
本局成长与战斗角色调用同一实现。run 标识变化后立即重算本场有效最大生命，不恢复当前生命；
上限降低时把当前生命限制到新上限。战斗 UI 按解析后的 battle／run 来源关系显示标识，
不能只用当前 `slot_instance_id` 匹配。

物品获得先在现有Run事务工作副本写入`item_ids`，此后才初始化其run marker并统一重算最大生命；
预览、取消、失败和存档恢复都不会重放获得效果。失去物品沿用`forget_policy`：`clear`删除条目，
`retain`保留数据但失活来源不再贡献；重新获得不会恢复已clear的数据。物品压制只暂停贡献，不删除marker。
marker、库存、生命、事件与Run快照继续由现有事务一起提交或回滚，只发布`source_marker_changed`。
最大生命始终是`base_max_life + 活跃来源贡献`，来源变化不能反写`base_max_life`。

来源标识可以成为细粒度响应的输入与输出。`defense_gained`、`damage_resolved`、`card_drawn`、`card_explicitly_discarded`、`action_confirmed`、`action_resolved`、`round_start`、`turn_end`、`source_marker_changed` 等公共已提交事件均可由通用响应记录监听，并修改来源功法标识。自动功法条件可直接监听这些事件，或按事件字段推进标识阈值；相同事件 token 只能推进一次。由此表达蓄力、倒计时与自动调用，不建立按具体功法 ID 判断的封闭蓄力管理器。主要蓄力值的修改本身不减少延迟occurrence、不推进观察次数或触发功法；StatusDelay/Response只保存并恢复发起实例的slot及root/invocation/execution token。自动功法的移动与结算顺序见[行动结算、触发队列与连击](./12-action-resolution.md#功法调用自动调用与序列推进)。

### 6.3 触发术语与有效真气值

- **参与最高牌型**：组成最高牌型并以自己的有效真气值计入默认贡献的真气。
- **参与数值计算**：默认等同于参与最高牌型；功法、内功或其他效果可以明确让额外打出的真气也参与。
- **打出**：本次行动选择并使用了该真气，不要求它参与最高牌型。
- **留手**：该真气当前位于手牌；离开手牌后立刻停止留手效果。
- **明确弃掉**：只有效果明确执行的弃牌动作；正常打出后进入弃牌堆不算明确弃掉。
- **实际进入弃牌堆**：真气确实完成入堆移动。之后被重聚洗回，仍视为曾经实际进入弃牌堆。

有效真气值先结算当前生效的真气贡献层效果，再交给牌型基准值与初始功法值 `P₀`。增元、虚暴、觉醒、炽气、枯气以及回响产生的合格贡献都属于这一层；燃尽最后把结果覆盖为 0。牌型与功法倍率层的乘势、机缘等也计入 `P₀`。直接写作“功法值 +X”或“功法值 +X%”的效果不属于真气贡献层，不能反向改变有效真气值或 `P₀`。完整公式见[牌型、真气值与倍率](./10-hand-ranking-and-values.md#22-真气值与数值计算)。

### 6.4 当前异状词条

#### 增益与减益

| 异状 | 类别 | 正式效果 | 生命周期 |
| --- | --- | --- | --- |
| 炽气 | 增益 | 每层使此真气的有效真气值 +1。 | 层数随牌跨牌区保留，战斗结束移除。 |
| 成长 | 增益 | 每个完整回合结束时，若此真气仍在手牌中，获得等于成长层数的炽气。 | 不消耗层数；实际进入弃牌堆时移除，战斗结束移除。 |
| 枯气 | 减益 | 每层使此真气的有效真气值 -1，最低为 0。 | 层数随牌跨牌区保留，战斗结束移除。 |
| 衰败 | 减益 | 每个完整回合结束时，若此真气仍在手牌中，获得等于衰败层数的枯气。 | 不消耗层数；实际进入弃牌堆时移除，战斗结束移除。 |

炽气与枯气分别累计后共同修改有效真气值；它们不会互相抵消层数。成长与衰败也可以同时存在，在同一回合结束时按可见触发队列依次结算。

#### 状态

| 异状 | 正式效果 | 重复施加与移除 |
| --- | --- | --- |
| 毒 | 打出此真气时，持有者受到等于此牌当前有效真气值的毒伤。被明确弃掉时不触发毒伤。 | 毒伤结算后移除；实际进入弃牌堆或战斗结束时移除。再次施加毒不增加层数。 |
| 破绽 | 持有者受到伤害时，手牌中每有 1 张破绽真气，本次受到的伤害 +20%。 | 再次施加不叠层；实际进入弃牌堆或战斗结束时移除。 |
| 封穴 | 持有者造成伤害时，手牌中每有 1 张封穴真气，本次造成的伤害 -20%。 | 再次施加不叠层；实际进入弃牌堆或战斗结束时移除。 |
| 封禁 | 此真气不可打出。 | 再次施加同名状态时层数相加；每个完整回合结束时层数 -1，降至 0 后移除；实际进入弃牌堆或战斗结束时移除。 |

毒不再区分烈毒与郁毒，不再具有毒效倍率、转毒、同种毒、双毒或郁毒削减值等公共接口。所有这些旧接口随旧功法归档。回响印重演毒时，重演本次已经执行的伤害条目，不因第一遍移除毒而丢失第二遍。

毒伤默认绕过普通防御但不等同于真伤，完整伤害边界见[伤害、防御与对战结果](./13-damage-defense-and-results.md)。“令一张带毒真气的毒立即触发”表示该牌不移动牌区，其持有者受到等于该牌当前有效真气值的毒伤，随后清除该牌的毒；没有毒的牌不是合法目标。

#### 毒量

毒量是双方公开的实时派生指标，不是独立角色资源：

```text
手牌毒量 H = 手牌中带毒普通真气的当前有效真气值总和
牌库毒量 D = 牌库中带毒普通真气的当前有效真气值总和
总毒量 T = H + D
```

界面同时公开手牌与牌库各自的毒牌张数和毒量，但不因此揭示隐藏牌库中的具体真气。弃牌堆、待出区与已经消散的真气不计入上述毒量或张数。真气移动牌区、获得或清除毒，以及有效真气值变化时，毒量随当前状态重新计算；内容不能直接获得、保存、转移或消耗脱离真实毒牌的“毒量”。

功法需要读取本次出毒规模时，可以明确冻结“出毒量 `X`”：本牌型组实际打出的全部带毒普通真气，在行动确认时的当前有效真气值总和。主组、协同组与重新识别形成的新牌型组分别冻结；同组重触复用原值。进入待出区的真气已经不属于手牌或牌库，因此不会同时计入 `H`、`D` 或 `T`。

#### 标记

| 异状 | 正式效果 | 移除时点 |
| --- | --- | --- |
| 风引 | 抽到此真气时，移除风引，再从持有者牌库当前可以视为风属性的真气中随机抽 1 张；没有合格风真气时不抽。 | 抽到并检查时移除；战斗结束移除。 |
| 乱流 | 抽到此真气时，移除乱流，再从持有者当前手牌中随机明确弃掉 1 张不视为风属性的真气；刚抽到的此牌若不视为风，也属于合格目标。 | 抽到并检查时移除；战斗结束移除。 |
| 重聚 | 此真气实际进入弃牌堆并完成正常入堆响应与状态清理后，移除重聚，将此真气从弃牌堆洗入持有者牌库。 | 成功洗回时移除；战斗结束移除。 |
| 燃尽 | 此真气最终有效真气值为 0，覆盖此前全部有效真气值增减与倍乘；不改变牌阶、基础真气值、基础属性、重塑、其他异状、牌型识别或同气身份。 | 可以被净化或被效果明确移除；打出、抽牌、明确弃牌、洗回及实际进入弃牌堆都不自动移除；战斗结束移除。 |
| 净化 | 第一次获得净化时，清除该牌当时已有的全部其他异状与临时重塑，最后建立净化自身。 | 已有净化的真气不能再次获得净化；净化不提供持续免疫，之后仍可获得其他异状；战斗结束移除。 |
| 归元 | 此真气的全部永久重塑与临时重塑效果无效，但内容与槽位不被删除；归元移除后恢复生效。 | 可以被净化；战斗结束移除。 |
| 虚无 | 此真气被打出或被成功明确弃掉时，完成该次打出或弃牌响应后消散，不进入弃牌堆。 | 洗回、交换、夺取、抽到或留手均不触发；可以被净化；战斗结束移除。 |
| 寄脉 | 此真气位于手牌时不占用八脉容量，但仍是实际手牌并参与全部其他手牌查询。 | 可以被净化；预览进入待出区时保留，正式打出或因其他原因真实离开手牌时立即移除；战斗结束移除。 |

风引是定向抽风，而不是普通抽一张；它只从当前牌库的合格风真气中选择，不改变其他牌的相对顺序。乱流执行的是明确弃牌，可以触发普通的明确弃牌响应。重聚取代旧“回风”，既响应正常打出后的实际入堆，也响应明确弃牌后的实际入堆；如果牌没有实际进入弃牌堆，重聚不触发。

虚无不再在回合结束时检查留手。虚无牌正常打出时先完成本次打出响应，再在普通入堆流程开始前消散；被明确弃掉时，该弃牌仍算成功并完整触发明确弃牌响应，随后消散。两条路径都不发送实际入堆事件，也不触发重聚、化丹印、林觉醒或其他入弃牌堆响应。洗回牌库、交换、夺取、普通抽牌与继续留手都不会令虚无消散。消散后该实体只离开当前战斗，战斗结束时仍按原归属处理。

净化只在获得瞬间清理当前内容，不屏蔽以后施加的异状；净化自身也可以被其他明确清除标记的效果移除。归元只压制重塑的效果，不清空或改写本源、强化、印记、重塑·其他或临时重塑的存储内容；归元存在期间，结算查询忽略这些重塑带来的牌阶、属性、有效真气值、觉醒与其他效果，移除归元后按原存储内容恢复。

风标记已经取消。战斗中临时令真气视为某属性，应使用对应的临时重塑内容，不再使用标记。散气与绝气标记也已取消；降低有效真气值改用枯气或衰败，其他控制直接使用当前状态与标记。

#### 临时重塑

临时重塑属于战斗层真气内容，但在效果结构上复用重塑接口。临时强化、临时属性与临时牌阶使用三个独立子槽；同子槽新内容替换旧内容，不同子槽可以共存。净化会清除临时重塑，归元会使其暂时失效，战斗结束统一清除。永久重塑不因临时重塑的获得、替换、净化或战斗结束而改变。

临时牌阶生效时，牌型识别读取该牌阶，参与数值计算时以该牌阶的标准真气值代替原牌阶标准值，再继续结算强化、增益、减益与其他有效真气值修正。原本的永久牌阶与基础真气值不被改写；临时牌阶被替换、净化、归元压制或在战斗结束清除后，重新读取原本牌阶。已经正式确认并冻结的主牌型组或协同组不追溯改变，只有后续新确认的牌型组读取最新临时牌阶。

#### 战斗临时真气

功法生成的临时普通真气默认同时获得虚无，只有正文明确写出例外时才不获得。生成牌属于当前战斗的临时实体，不继承来源牌的本源、强化、印记、重塑·其他、异状或临时重塑；正文明确赋予的牌阶、基础属性、成长等内容除外。

净化可以移除生成牌的虚无，使其继续留在当前战斗各牌区，但不会把它变为本局永久牌。无论虚无是否仍在，所有战斗临时真气都在战斗结束时移除，不进入本局牌组，也不参与战斗外保存。

### 6.5 角色战斗状态与公共战斗语言

角色本体不再用大量命名“层数词条”包装可以直接表达的数值。界面与权威文本直接显示和修改聚合后的状态，例如“本回合手牌上限 +2”“获得 1 次额外行动”“当前反震 50%”“下一门功法值 -10%”。实现可以保存来源、持续时间和队列记录，但这些记录不是面向内容设计的新资源或新词条。

当前保留的角色战斗状态只有：生命、防御、手牌上限修正、连势、独立的上一次成功精确牌型记录、同气槽当前值与有效最大值、当前反震比例、额外行动次数、直接功法值临时修正，以及明确的延迟效果。蛊印、纳气、夺风、盈袖、束袖、借力、焚脉、绝气、四象合鸣等旧命名层数全部退出当前公共规则；旧“反击”也不再作为公共受击资源，受防御削减响应统一优先使用反震。

- **攻击段**：一次独立伤害结算；多段伤害逐段读取最新防御、异状与增减伤。
- **追击**：不消耗真气、不建立新牌型组、不重新识别牌型、不触发整门功法、不推进功法序列的额外攻击段。同一效果不能递归触发自己。所有正式追击统一携带攻击段类型`chase`并复用同一伤害事务；旧`source_kind`标签、专用多段追击字段或功法 ID 不能成为第二套追击判定。追击完成后提交统一细粒度结果，公开伤害类型、请求值、防御损失、生命损失、来源与行动令牌，供功法、内功和物品监听。
- **真伤**：直接扣除生命，不经过防御，也不受普通增伤、减伤影响，除非文本明确说明。
- **纯阳**：本次行动的主牌型与全部协同组实际打出的普通真气都可以视为火；纯火只检查当前牌型组，纯阳检查整个行动。
- **燃命**：直接失去生命作为代价，不视为受到伤害；代价使生命降至 0 时，后续效果停止，除非文本明确例外。
- **消散**：将真气临时移出当前战斗牌组，战斗结束后按其原归属处理；消散动作本身不进入弃牌堆，也不触发明确弃牌或入弃牌堆响应。若虚无牌先被成功明确弃掉，则该次弃牌响应在消散前已经成立。
- **消耗真气**：以真气作为效果代价，使用`reason=cost/cause=cost`临时移出当前战斗；不属于弃牌、虚无或其他消散。每张实际支付的真气提交一份`qi_consumed`，战后仍按临时牌与原持有者规则处理。
- **格挡**：取消一个满足来源条件的敌方直接攻击段；成功后不减少防御、不触发反震。具体目标、消费与事件见[伤害、防御与对战结果](./13-damage-defense-and-results.md#格挡)。
- **反震**：当前比例是一个角色状态；最新仍有效来源暂时覆盖旧来源，来源到期后恢复下一项仍有效来源。具体伤害时点、来源与取整见[伤害、防御与对战结果](./13-damage-defense-and-results.md#反震)。
- **邀战**：公开记录敌方下一出牌轮次的实际伤害与阈值，到期按差额执行来源效果。具体窗口见[行动结算、触发队列与连击](./12-action-resolution.md#邀战)。
- **连势**：保存当前数值与有效上限。基础上限等于战斗开始时我方初始牌库中的真气数量，并在起手抽牌和任何战斗效果发生前冻结；起手抽牌、战斗临时真气、消耗、消散或战斗中永久移出均不追溯改变该基础上限。被动可以通过只读查询提高或降低有效上限，所有正式写入均限制在`0～有效上限`。成功功法把连势快照加入本次最终功法值`P`；本门功法实际增加或消耗过连势时保留剩余值，否则在本门及其回响结束后清空。上一次成功精确牌型是独立行动历史，不再控制连势。完整时序见[行动结算、触发队列与连击](./12-action-resolution.md#同一时点的触发队列)。

连势不进入初始功法值`P₀`。功法若根据自身规模产生连势，必须读取`P₀`；同组重触复用已经计算完成的`P₀`与`P`，不能再次加入连势。正文明确写出的连势快照前消费先改变当前连势，再冻结剩余值并计算`P`。功法失败时不使用或清空连势，也不更新上一次成功精确牌型。

#### 唯一临时移出事务

公开消散能力保持 `capture_query → dissipate_captured → temporarily_remove_card`；支付能力使用
`prepare_qi_consumption → commit_qi_consumption`或通用`consume_captured`，但不新增牌区或第二份离场
算法。`CardZoneService` 内部只有一份临时移出步骤：冻结来源牌区与`pre_move_snapshot`、清理离场状态、
从来源牌区移除、加入`temporarily_removed_cards`、发送统一移动事实，并返回标准结果。

主动 `temporarily_remove`、虚无正常打出、虚无明确弃置以及同步移动中的虚无分支都调用
该事务。虚无包装层只额外保证明确弃置响应先成立；主动消散不触发明确弃牌或入弃牌堆响应。
原子交换和同步弃置可以保持为原子事务，但共同的离手、到达与虚无处理必须调用
`CardZoneService` 内部共享步骤，不能复制牌区状态写入。

批量消耗先冻结调用方给定的精确实例顺序，再一次验证全部持有者和来源活动牌区；不足、重复或任一
目标失效时一张也不移动。提交时先让全批离开活动牌区并进入现有临时移出区，再依次执行生命周期、
全批`card_moved`、全批`qi_consumed`及后效。两类事实共享稳定批次令牌和索引。支付、后效、事件、
RNG与日志属于同一战斗运行时事务；失败全部恢复。虚无牌作为代价时直接按cost处理，不先成立打出、
明确弃置或入堆响应；其他消散原因不得发送`qi_consumed`。

### 6.6 本源、强化与印记

本局层的真气重塑不再使用“品相”类别。当前正式结构为：一张真气最多拥有一个本源改造、一个永久强化和一个印记。本源、强化与印记跨战斗保存至本局结束；临时强化使用 6.4 节的独立战斗槽。

#### 本源改造

本源改造直接决定真气本体的一次身份变化。一张真气一局只能接受一次本源改造，三种操作互相排斥；接受其中任一种后，本源槽锁定，不能再通过普通效果改变。

| 本源改造 | 正式效果 |
| --- | --- |
| 转属 | 将此真气的基础属性改为指定的风、林、火或山；觉醒本源读取改造完成后的基础属性。 |
| 易阶 | 按效果指定方向将此普通真气的牌阶改变一级；升阶为 `2→3→…→10→J→Q→K→A`，降阶为 `A→K→Q→J→10→…→2`。A不能继续升阶，2不能继续降阶；基础真气值同步改为新牌阶对应的标准值。 |
| 觉醒 | 激发此真气当前基础属性对应的觉醒效果；觉醒本源完成后，本源槽锁定，不能再转属或易阶。 |

转属和易阶本身不自动赋予觉醒；觉醒也不能再改变基础属性或牌阶。混元强化与临时属性重塑只改变属性识别，不改变基础属性，因此不改变觉醒效果。特殊物品若要同时完成两种本源操作，必须明确标为本源规则例外。

**完整复制**属于新增真气实例，不是对源牌执行本源改造。源牌保持不变；复制牌继承复制时源牌的牌阶、基础属性、基础真气值、本源、永久强化、印记与重塑·其他，不复制任何异状或临时重塑。源牌已有本源时，复制牌继承相同本源且本源槽已经锁定；源牌没有本源时，复制牌的本源槽保持未改造。复制不消耗源牌的本源机会。

觉醒效果如下：

| 属性 | 觉醒效果 |
| --- | --- |
| 风 | 此真气被抽到时，额外普通抽 1 张牌。 |
| 林 | 此真气实际进入我方弃牌堆时，将此真气从弃牌堆洗入我方牌库。 |
| 火 | 此真气参与功法的数值计算时，有效真气值 ×2；该功法完整结算后，此真气获得燃尽。 |
| 山 | 每个完整回合结束阶段，若此真气仍在我方手牌中，获得等于此真气当前有效真气值的防御。 |

火觉醒的燃尽一定在本次功法完整结算后施加，因此本次翻倍计入 `P₀`；下一次参与时燃尽把最终有效真气值覆盖为 0。山觉醒读取触发时的当前有效真气值，并在本回合既有防御完成衰减后获得防御。

#### 强化

八种永久强化平级；随机获得一种强化时默认等权，除非内容文本另有说明。

| 功能组 | 强化 |
| --- | --- |
| 稳定数值 | 增元、乘势 |
| 组牌与爆发 | 混元、虚暴 |
| 留手与填充 | 无漏、磐石 |
| 经济与随机 | 藏金、机缘 |

| 强化 | 正式效果 | 结算边界 |
| --- | --- | --- |
| 增元 | 此真气参与功法的数值计算时，有效真气值 +8。 | 计入自身贡献与 `P₀`；牌阶和基础属性不变。 |
| 乘势 | 此真气参与功法的数值计算时，本次功法倍率 +1。 | 计入功法倍率 `M` 与 `P₀`，不改变属性集中数 `N` 或牌型基准值。 |
| 混元 | 识别牌型与检查功法属性条件时，此真气同时视为风、林、火、山。 | 只改变属性识别，不改变基础属性、觉醒、牌阶或有效真气值。 |
| 虚暴 | 此真气参与功法的数值计算时，有效真气值 ×2；每场战斗开始时，此真气获得虚无。 | 倍乘计入自身贡献与 `P₀`；虚无是可被净化的战斗标记。 |
| 无漏 | 此真气不能成为施加毒、破绽或封穴的合法目标；此真气被打出时，获得等于其当前有效真气值的防御。 | 不免疫其他异状；燃尽时获得 0 点防御。 |
| 磐石 | 此真气不能被明确弃掉，也不能成为明确弃牌效果的合法目标；此真气被打出时，对敌方造成等于其当前有效真气值的伤害。 | 正常打出后仍可进入弃牌堆；不改变牌阶、属性或基础真气值。 |
| 藏金 | 战斗胜利时，若此真气位于我方手牌或我方牌库中，获得 3 点历练。 | 位于弃牌堆、待出区或已经消散时不结算；战败不结算。 |
| 机缘 | 此真气参与功法的数值计算时，独立判定：`1/5` 概率使本次功法倍率 +1；`1/10` 概率获得 20 点历练。 | 两项可同时成功；倍率成功计入 `M` 与 `P₀`。 |

机缘只在行动正式确认后判定。预览、AI 候选枚举与协同候选校验不推进随机源；主组与协同组分别冻结结果，等待选择、选择恢复、同组重触和重复收口只能复用，不得重掷或重复发放历练。

同一张真气只能拥有一种永久强化；新永久强化替换旧永久强化。临时强化使用独立槽，不触发这次替换。

#### 印记

印记统一按效果命名；颜色只可作为界面表现。同一张真气最多拥有一个印记，新印记替换旧印记。

| 印记 | 正式效果 |
| --- | --- |
| 回响印 | 此真气产生一次合格触发时，将此真气本次自身触发完整重演一次，并重新结算所有由此真气直接触发的内功效果；不重触整门功法、其他真气、回响印自身或整条内功队列。 |
| 悟道印 | 战斗胜利时，若此真气仍在我方手牌中，获得最后一次成功出招识别出的最高牌型对应的一份心得。 |
| 化丹印 | 此真气被明确弃掉并实际完成入堆移动时，获得一份随机丹药；正常打出后入堆、删除、夺取或虚无消散均不触发。 |
| 先天印 | 战斗开始组成起始手牌时，优先抽取此真气；所有先天印真气处理后，再按正常规则补足剩余手牌。 |

多个先天印按本场洗牌结果中的原相对顺序优先进入起始手牌，不为此重新洗牌。先天印多于手牌上限时，尚未抽取者按原相对顺序留在牌库顶。

悟道印只记录功法条件满足且牌型组完整结算成功的最高牌型。主组与协同组分别记录，后成功者覆盖；条件失败、空功法或执行失败不覆盖此前记录。没有空余消耗品栏位时，悟道印与化丹印不生成内容。

化丹印从全部正式 `kind="pill"` 内容中随机。真气明确弃掉并实际入堆后即触发；重聚随后把它洗回牌库，不撤销已经成立的化丹触发。未成功的弃牌请求不触发。

回响印重演的是单张真气在本次时点实际执行过的自身触发包，回响深度固定为 1。属性身份查询、牌型识别、功法条件、整门功法、行动级效果、其他真气、追击、反震、序列推进与回响印自身不重演。两遍从同一原始牌面输入分别计算有效真气值、贡献和功法倍率修正，再汇总进 `C` 与 `M`；例如 5 点增元回响贡献 `(5+8)+(5+8)=26`，5 点虚暴回响贡献 `(5×2)+(5×2)=20`，乘势回响提供 `+2` 功法倍率。回响结果因此计入 `P₀`，但不会重复加入连势。

由真气直接触发的内功只有在来源明确归因到该真气实例时才属于同一触发包；回响只重演本次已经实际生效的直接监听器，不重新扫描全部已装备内功。第一遍已经改变牌区的效果在第二遍读取最新状态，条件不再满足时允许自然无效。

内功和功法不能拥有印记。本源、强化和印记的具体数值作为当前设计基线，后续只通过实测或明确重构决议调整。
