# 牌型、真气值与倍率

> 本文件是当前 v0.30 模块化权威设计源的一部分。原文规则段落仅在此处维护；
> 其他模块只能通过链接引用，不得复制或重新解释。原章节编号保留用于迁移核对。

### 2.1 普通牌型

只使用普通扑克牌名称：

```text
高牌、一对、两对、三条、顺子、葫芦、四条、五条
```

一次出牌只选择一个最高牌型。牌型只负责决定倍率，不把多个牌型的数值倍率相加。

同花、同花顺、皇家同花顺、同花葫芦、同花五条及未来其他仅由同属性结构建立的复合牌型均已废弃，不再参与牌型识别，也不拥有固定倍率、心得、功法池或独立功法序列。同属性构筑改用本节“打出五张同属性真气”的通用直接功法值百分比修正，不再建立牌型。

当前使用以下固定基础倍率：

| 牌型 | 基础倍率 |
| --- | ---: |
| 高牌 | ×1 |
| 一对 | ×2 |
| 两对 | ×2 |
| 三条 | ×3 |
| 顺子 | ×4 |
| 葫芦 | ×4 |
| 四条 | ×7 |
| 五条 | ×12 |

这些倍率是当前计算基线，具体数值仍需与生命、功法和内功效果共同测试。

五条由五张牌阶相同的普通真气组成，是强于四条的最高普通牌型；五张真气全部参与数值计算。
它在未改造的 52 张基础真气牌组中不可能自然形成，只能通过增加、复制或修改真气建立。
五条固定倍率确认为 `×12`：同牌阶下，四条的牌型基准值相当于 `4×7=28` 份该牌阶
真气值，五条相当于 `5×12=60` 份，实际约为四条的 `2.14` 倍。该差距已经包含第五张
参与牌的贡献，足以体现改造后牌型的稀有度；五张同属性、心得和其他增幅仍按各自规则叠加。

### 2.2 真气值与数值计算

暂定采用与《小丑牌》相近的计数方式：通常只有组成最高牌型的真气参与基础值计算。

每张普通真气同时记录三个基础属性：

```text
牌阶：负责识别高牌、对子、两对、三条、顺子、葫芦、四条、五条
真气值：负责基础值及其他读取牌值的效果
真气属性：风、林、火、山；负责功法属性条件、五张同属性通用增幅与通用同属性连击
```

普通牌阶与真气值固定对应如下：

| 牌阶 | 真气值 | 牌阶顺序 |
| --- | ---: | --- |
| 2～10 | 等于牌面数字 | 2 < 3 < … < 10 |
| J | 11 | 10 < J |
| Q | 11 | J < Q |
| K | 11 | Q < K |
| A | 12 | K < A |

J、Q、K虽然真气值都为 11，但牌阶不同，不能互相组成对子、三条、葫芦或四条。A是最高牌阶，高牌判断中高于K；顺子是唯一例外，A既可以作为低端组成 `A、2、3、4、5`，也可以作为高端组成 `10、J、Q、K、A`，不能用于其他首尾相接的顺子。A在两种顺子中的真气值都固定为 12。

```text
功法贡献总和 C（亦称本牌型组的基础值）
= 所有参与数值计算的真气，在真气自身与贡献层效果结算后的贡献之和
+ 其他明确属于真气贡献层的修正

功法倍率 M
= 固定牌型倍率
+ 参与数值计算的乘势真气触发次数 × 1
+ 本次机缘强化倍率判定成功次数 × 1
+ 其他明确修改功法倍率的效果

初始功法值 P₀ = floor(C × M)

连势前功法值
= floor[(P₀ + 所有直接功法值固定修正)
        ×（1 + 所有直接功法值百分比修正）]

最终功法值 P = max(0, 连势前功法值 + 本次使用的连势值)

牌型基准值 = C × 固定牌型倍率
```

`P₀` 是一门功法从本次真气与倍率中自然得到的初始规模。它包含所有真气贡献层变化与所有功法倍率变化；它不包含任何直接写作“功法值 +X”或“功法值 +X%”的效果，也不包含连势。固定修正与百分比修正是在 `P₀` 之后对功法值本体进行的直接修改；所有百分比修正仍进入同一加法池，只乘算一次。

现有内容文本中的“功法值固定修正”统一视为直接功法值固定修正；“功法值增幅 +X%”统一视为直接功法值百分比修正。只有明确写作“功法倍率 +X”的效果才进入 `M` 与 `P₀`。

“本次使用的连势值”只在当前功法成功触发时取连势快照；功法失败、空序列或只为其他效果计算功法值时，该项为 0。

牌型基准值只供功法、内功或毒状态在文本中明确读取；本次出牌不再自动造成伤害。牌型基准值不读取乘势、机缘、其他功法倍率修正、直接功法值修正或连势。

普通真气每次触发时的自身贡献等于结算当时的有效真气值；增元使合格真气的有效真气值 +8，虚暴使其 ×2，燃尽则使当前有效真气值为 0。觉醒火真气参与功法数值计算时再将有效真气值 ×2，并在该功法完整结算后燃尽。回响印可以令同一张真气的合格自身触发包及由它直接触发的内功效果额外结算一次。详细规则见[真气效果、重塑与异状](./14-qi-effects-and-statuses.md#66-本源强化与印记)。

回响数值包的正常遍与重演遍各自从相同原始牌面和当前战斗状态开始，分别完成有效真气值、自身贡献、该牌功法倍率修正与该牌直接功法值百分比修正，再累加两遍输出；不能把第一遍的输出继续交给第二遍复合。因而普通 5 点回响牌贡献 `5+5=10`，增元回响贡献 `(5+8)+(5+8)=26`，虚暴回响贡献 `(5×2)+(5×2)=20`，乘势回响提供 `+1+1=+2` 功法倍率。混元是属性身份查询，不产生第二份身份收益；固定牌型倍率和牌型基准值的定义不因回响改变。

一张回响牌只影响它所在牌型组的自身数值触发。主组与协同组分别计算各自的单牌触发包和机缘冻结结果，然后才按既有公式合并共享功法值；主组不能重演协同组真气，协同组也不能重演主组真气。同一真气实例不得同时进入两个组。回响不重新识别牌型、不重新检查或执行整门功法、不重复创建功法选择，也不推进第二次功法序列。

固定牌型倍率同时进入牌型基准值与功法倍率。乘势、机缘和其他功法倍率修正计入 `M`，因此计入 `P₀`，但不改变牌型基准值。牌型熟练度固定修正、其他直接功法值固定修正以及五张同属性等直接功法值百分比修正只改变 `P`，不改变 `P₀` 或牌型基准值。心得不进入功法倍率，也不建立独立的最终乘区。所有直接功法值百分比修正统一相加后只乘算一次，不建立多个“最终×功法值”连乘层。没有读取数值的固定效果，例如“下回合手牌上限 +1”，不会被倍率放大。

例如一对 `7、7` 中有一张乘势真气时，`C=14`、`M=2+1=3`，所以 `P₀=42`。若另有“本次功法值 +50%”，`P₀` 仍是 42，连势前功法值为 63；该百分比不会反向进入 `P₀`。

#### 打出五张同属性真气的通用增幅

一个牌型组实际打出恰好 5 张普通真气，且这 5 张在属性识别中均可以视为同一种属性时，该牌型组的直接功法值百分比修正 +50%。混元与临时重塑中明确提供的属性身份可以配合任意共同属性。这个修正加入其他直接功法值百分比修正所在的同一加法池，只乘算一次，不提高 `P₀` 或牌型基准值。

这项规则检查该牌型组实际打出的全部 5 张普通真气，包括没有参与最高牌型的额外真气，而不只检查参与数值计算的牌。它不是牌型，不改变最高牌型、固定牌型倍率、心得、功法池或功法序列。协同行动中每个牌型组分别检查；若主牌型组或协同组满足条件，先在该组自身功法值中加入 +50%，再按协同共享功法值规则计算。它与通用同属性连击相互独立，同一次行动可以同时获得本增幅与连击机会。

普通牌型中参与数值计算的真气数量：

```text
高牌：只计算最高的一张
一对：计算组成一对的两张
两对：计算两组对子的四张
三条：计算三张同牌阶真气
顺子：计算组成顺子的五张
葫芦：计算三条与对子共五张
四条：计算四张同牌阶真气
五条：计算五张同牌阶真气
```

例如 `7、7、7、3、3` 组成葫芦，五张牌全部属于最高牌型，所以基础值是 `7+7+7+3+3=27`；牌型倍率取葫芦倍率。

例如打出 `7、7、4、3、A`，最高牌型是一对，只有两张7参与基础值，所以基础值是14；其余三张随本次出牌进入弃牌堆。

例如 `J、J` 可以组成一对，基础值为 `11+11=22`；`J、Q` 虽然真气值同为 11，但牌阶不同，不能组成一对。顺子 `A、2、3、4、5` 的基础值为 26，顺子 `10、J、Q、K、A` 的基础值为 55。

没有参与最高牌型的多余普通真气默认不增加基础值，也不触发要求“参与数值计算”的强化、觉醒或印记，只会随本次出牌进入弃牌堆；无漏、磐石等明确写为“打出时”的效果仍会触发。功法或内功也可以明确改写这条规则，让额外真气参与数值计算或产生效果。

#### 基础概率

概率统计固定使用以下基线：

```text
52 张未改造基础真气
随机抽取 8 张作为手牌
玩家可以从中选择打出 1～5 张
总手牌样本数 = C(52,8) = 752,538,150
```

“可主动组成概率”表示随机 8 张中至少存在一种选牌方式，可以准确组成该牌型；由于玩家永远可以只出 1 张，所以高牌为 100%。这一列的不同牌型可以同时存在，不能相加。

“最高牌型概率”表示按普通牌型强弱判断，这 8 张能够组成的最高牌型；各行互斥，合计约为 100%。

| 牌型 | 可主动组成概率 | 最高牌型概率 |
| --- | ---: | ---: |
| 高牌 | 100% | 7.9771% |
| 一对 | 88.7920% | 34.2675% |
| 两对 | 43.7409% | 36.2061% |
| 三条 | 12.0075% | 5.3722% |
| 顺子 | 9.8162% | 9.7736% |
| 葫芦 | 6.1846% | 6.0674% |
| 四条 | 0.336124% | 0.336124% |
| 五条 | 0% | 0% |

删除全部同花相关牌型后，最高牌型概率已按剩余牌型优先级重新计算；表中最高牌型各行互斥并合计约为 100%。五条在未改造的 52 张牌组中严格不可能，只有增加、复制或修改真气后才可能出现。

#### 基线数值统计

下表统一使用理论牌型基准值（只用于比较牌型的数值规模，不会自动造成伤害）：

```text
牌型基准值 = 参与数值计算的真气值总和 × 固定牌型倍率
```

不计心得、功法、内功、本源、强化、印记或其他修正。平均值与中位数按该牌型所有合法牌阶结构统计，不是“随机抽到 8 张以后，玩家最优出牌”的条件伤害；范围是该牌型在当前真气值规则下的理论最小值与最大值。

| 牌型 | 平均牌型基准值 | 中位数 | 范围 |
| --- | ---: | ---: | ---: |
| 高牌 | 7.6 | 8 | 2～12 |
| 一对 | 30.5 | 32 | 8～48 |
| 两对 | 60.9 | 60 | 20～92 |
| 三条 | 68.5 | 72 | 18～108 |
| 顺子 | 150.8 | 150 | 80～220 |
| 葫芦 | 152.3 | 156 | 48～232 |
| 四条 | 213.2 | 224 | 56～336 |
| 五条 | 456.9 | 480 | 120～720 |

五条一行按已确认的固定倍率 `×12` 计算。该数值只表示牌组改造后可能出现的理论牌阶结构，
不代表它在实际构筑中的出现概率；未改造基础牌组中的概率仍严格为 0。

#### 不增加统一牌型筹码

《小丑牌》的结算是“牌型基础筹码 + 参与计分的牌面筹码”，再乘倍率。本系统确认不增加统一的牌型基础筹码，也不采用“（牌型基础筹码 + 真气值总和）× 倍率”。牌型基准值只使用“基础值 × 固定牌型倍率”，是否造成伤害由功法、内功或毒状态明确写出。

“功法值”不是另一份伤害或筹码，而是功法和内功在需要数值缩放时读取的计算结果。原作的牌型基础筹码在本系统中由具体功法的固定效果、最低效果或其他战斗作用承接；没有读取功法值的固定效果不会被倍率放大。直接功法值固定修正用于扶持低基础值牌型；不同直接功法值百分比修正统一相加，不采用多个独立终乘。这样可以保留牌型特效的价值，而不让高阶牌型、持续回合、防御和反震随一段统一基础数值整体膨胀。

## 4. 固定牌型倍率与牌型功法槽位

固定牌型倍率不成长，始终使用第 2.1 节的基线；它同时作为牌型基准值的固定倍率与功法倍率 `M` 的基础部分。心得不再提高固定牌型倍率、功法倍率、牌型基准值或最终伤害，而是提升指定具体牌型的功法槽位。

每个具体牌型初始拥有 1 个功法槽位。使用一份对应心得时，立即执行两项效果：

1. 该具体牌型的功法槽位增加 1；
2. 从该牌型可以读取的基础功法池并集中，随机获得一门尚未加入该牌型当前序列的正式功法，并默认填入新增槽位。

玩家可以在战斗外重新排序或替换当前序列中的功法；替换下来的功法仍保留在本局功法库。战斗开始后，该具体牌型的序列与槽位内容锁定。

| 心得 | 槽位变化 | 获得功法的池 |
| --- | ---: | --- |
| 高牌心得 | +1 | 高牌池 |
| 一对心得 | +1 | 对子池 |
| 两对心得 | +1 | 对子池 |
| 三条心得 | +1 | 三条池 |
| 葫芦心得 | +1 | 对子池与三条池的去重并集 |
| 顺子心得 | +1 | 顺子池 |
| 四条心得 | +1 | 炸弹池 |
| 五条心得 | +1 | 炸弹池 |

一对与两对虽然都读取对子池，但槽位、序列和进度分别记录；一对心得不增加两对槽位。葫芦拥有独立槽位、序列和进度，只是从对子池与三条池的去重并集中获得功法；它仍只运行自己当前序列的一门功法。四条与五条同样分别拥有独立槽位、序列和进度，只共同读取炸弹池。八种心得从开局起均正常进入普通心得随机池；五条初始槽位为 1，不以当前牌组能否立即组成五条为生成条件。若可读取的基础池并集中已没有可加入当前序列的正式功法，心得仍成功消耗并只增加该具体牌型 1 个槽位，不跨池改抽、不回滚，也不写入旧的累计倍率字段。

牌型熟练度固定修正是后续可选的受控数值接口。若内容明确提供该修正，它属于 `P₀` 之后的直接功法值固定修正，不进入功法倍率、`P₀`、牌型基准值或独立乘区；第一版不冻结具体修正数值，先验证功法槽位成长和序列频率。

具体真气重塑、异状、功法或内功仍可以临时或有条件地修正功法倍率。第一版的倍率修正优先采用加减；心得不属于这条倍率修正池。

概率统计统一按第 2.2 节的 52 张基础真气、8 张基础手牌与实际选牌规则计算。当前概率是未改造基础牌组的数学基线，不是完成平衡后的掉落率或实战出招率。
