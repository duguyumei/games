# 牌型、真气值与倍率

### 2.1 普通牌型

只使用普通扑克牌名称：

```text
高牌、一对、两对、三条、顺子、葫芦、四条
```

一次出牌只选择一个最高牌型。牌型只负责决定倍率，不把多个牌型的数值倍率相加。

同花、同花顺、皇家同花顺、同花葫芦、同花五条及未来其他仅由同属性结构建立的复合牌型均已废弃，不再参与牌型识别，也不拥有固定倍率、心得、功法池或独立功法序列。同属性构筑改用本节“打出五张同属性真气”的通用功法值增幅，不再建立牌型。

当前使用以下固定基础倍率：

| 牌型 | 基础倍率 |
| --- | ---: |
| 高牌 | ×1 |
| 一对 | ×2 |
| 两对 | ×2 |
| 三条 | ×3 |
| 顺子 | ×4 |
| 葫芦 | ×4 |
| 四条 | ×7 |

这些倍率是当前计算基线，具体数值仍需与生命、功法和内功效果共同测试。

### 2.2 真气值与数值计算

暂定采用与《小丑牌》相近的计数方式：通常只有组成最高牌型的真气参与基础值计算。

每张普通真气同时记录三个基础属性：

```text
牌阶：负责识别高牌、对子、两对、三条、顺子、葫芦、四条
真气值：负责基础值及其他读取牌值的效果
真气属性：风、林、火、山；负责功法属性条件、五张同属性通用增幅与通用同属性连击
```

普通牌阶与真气值固定对应如下：

| 牌阶 | 真气值 | 牌阶顺序 |
| --- | ---: | --- |
| 2～10 | 等于牌面数字 | 2 < 3 < … < 10 |
| J | 11 | 10 < J |
| Q | 11 | J < Q |
| K | 11 | Q < K |
| A | 12 | K < A |

J、Q、K虽然真气值都为 11，但牌阶不同，不能互相组成对子、三条、葫芦或四条。A是最高牌阶，高牌判断中高于K；顺子是唯一例外，A既可以作为低端组成 `A、2、3、4、5`，也可以作为高端组成 `10、J、Q、K、A`，不能用于其他首尾相接的顺子。A在两种顺子中的真气值都固定为 12。

```text
基础值
= 所有参与数值计算的真气自身贡献之和
+ 装备中的箔面内功数量 × 3
+ 其他明确的基础值修正

牌型基准值 = 基础值 × 固定牌型倍率

牌型基准值只供功法、内功或毒异状在文本中明确读取；本次出牌不再自动造成伤害。

未增幅功法值
= 基础值 × 功法倍率
+ 其他明确的功法值固定修正

功法值增幅
= 参与数值计算的多彩真气触发次数 × 20%
+ 装备中的多彩内功数量 × 20%
+ 本牌型组打出五张同属性普通真气时 × 50%
+ 功法、内功或其他效果明确提供的功法值百分比增幅

功法值 = 向下取整[未增幅功法值 ×（1 + 功法值增幅）]

功法倍率
= 固定牌型倍率
+ 该牌型累计心得倍率
+ 参与最高牌型的倍率牌触发次数 × 2
+ 本次幸运牌成功触发次数 × 3
+ 参与数值计算的镭射真气触发次数 × 1
+ 装备中的镭射内功数量 × 1
+ 其他真气、功法或内功明确提供的倍率修正
```

普通真气每次触发时的自身贡献等于有效真气值；奖励牌与玻璃牌会改写有效真气值，箔面品相再为该次自身贡献增加 3 点。石头牌没有真气值，不参与普通牌型，但每次触发时固定贡献 10 点；箔面石头牌每次贡献 13 点。赤印可以令同一张真气的自身贡献、强化和品相额外触发一次。详细规则见 6.5 节。

固定牌型倍率只决定牌型基准值。累计心得倍率、倍率牌、幸运牌、镭射品相、多彩品相、功法值固定修正与明确的功法值百分比增幅只改变功法值，不改变牌型基准值；功法或内功只有在效果文本读取功法值时才会受到这些修正。所有功法值百分比增幅与多彩来源统一相加后只乘算一次，不建立多个“最终×功法值”连乘层。没有读取数值的固定效果，例如“下回合手牌上限 +1”，不会被倍率放大。

#### 打出五张同属性真气的通用增幅

一个牌型组实际打出恰好 5 张普通真气，且这 5 张在属性识别中均可以视为同一种属性时，该牌型组的功法值增幅 +50%。万能牌可以配合任意共同属性；风标记等明确改变属性识别的效果正常参与；没有属性的石头牌不满足“5 张普通真气”条件。这个增幅加入多彩与其他功法值百分比增幅所在的同一加法池，只乘算一次，不提高牌型基准值。

这项规则检查该牌型组实际打出的全部 5 张普通真气，包括没有参与最高牌型的额外真气，而不只检查参与数值计算的牌。它不是牌型，不改变最高牌型、固定牌型倍率、心得、功法池或功法序列。协同行动中每个牌型组分别检查；若主牌型组或协同组满足条件，先在该组自身功法值中加入 +50%，再按协同共享功法值规则计算。它与通用同属性连击相互独立，同一次行动可以同时获得本增幅与连击机会。

普通牌型中参与数值计算的真气数量：

```text
高牌：只计算最高的一张
一对：计算组成一对的两张
两对：计算两组对子的四张
三条：计算三张同牌阶真气
顺子：计算组成顺子的五张
葫芦：计算三条与对子共五张
四条：计算四张同牌阶真气
```

例如 `7、7、7、3、3` 组成葫芦，五张牌全部属于最高牌型，所以基础值是 `7+7+7+3+3=27`；牌型倍率取葫芦倍率。

例如打出 `7、7、4、3、A`，最高牌型是一对，只有两张7参与基础值，所以基础值是14；其余三张随本次出牌进入弃牌堆。

例如 `J、J` 可以组成一对，基础值为 `11+11=22`；`J、Q` 虽然真气值同为 11，但牌阶不同，不能组成一对。顺子 `A、2、3、4、5` 的基础值为 26，顺子 `10、J、Q、K、A` 的基础值为 55。

没有参与最高牌型的多余普通真气默认不增加基础值，也不触发自身的强化、品相或印记，只会随本次出牌进入弃牌堆。石头牌的固定贡献是强化规则的明确例外；功法或内功也可以明确改写这条规则，让额外真气参与计算或产生效果。

#### 基础概率

概率统计固定使用以下基线：

```text
52 张未改造基础真气
随机抽取 8 张作为手牌
玩家可以从中选择打出 1～5 张
总手牌样本数 = C(52,8) = 752,538,150
```

“可主动组成概率”表示随机 8 张中至少存在一种选牌方式，可以准确组成该牌型；由于玩家永远可以只出 1 张，所以高牌为 100%。这一列的不同牌型可以同时存在，不能相加。

“最高牌型概率”表示按普通牌型强弱判断，这 8 张能够组成的最高牌型；各行互斥，合计约为 100%。

| 牌型 | 可主动组成概率 | 最高牌型概率 |
| --- | ---: | ---: |
| 高牌 | 100% | 7.9771% |
| 一对 | 88.7920% | 34.2675% |
| 两对 | 43.7409% | 36.2061% |
| 三条 | 12.0075% | 5.3722% |
| 顺子 | 9.8162% | 9.7736% |
| 葫芦 | 6.1846% | 6.0674% |
| 四条 | 0.336124% | 0.336124% |
| 五条 | 0% | 0% |

删除全部同花相关牌型后，最高牌型概率已按剩余牌型优先级重新计算；表中最高牌型各行互斥并合计约为 100%。五条在未改造的 52 张牌组中严格不可能，只有增加、复制或修改真气后才可能出现。

#### 基线数值统计

下表统一使用理论牌型基准值（只用于比较牌型的数值规模，不会自动造成伤害）：

```text
牌型基准值 = 参与数值计算的真气值总和 × 固定牌型倍率
```

不计心得、功法、内功、强化、品相、印记或其他修正。平均值与中位数按该牌型所有合法牌阶结构统计，不是“随机抽到 8 张以后，玩家最优出牌”的条件伤害；范围是该牌型在当前真气值规则下的理论最小值与最大值。

| 牌型 | 平均牌型基准值 | 中位数 | 范围 |
| --- | ---: | ---: | ---: |
| 高牌 | 7.6 | 8 | 2～12 |
| 一对 | 30.5 | 32 | 8～48 |
| 两对 | 60.9 | 60 | 20～92 |
| 三条 | 68.5 | 72 | 18～108 |
| 顺子 | 150.8 | 150 | 80～220 |
| 葫芦 | 152.3 | 156 | 48～232 |
| 四条 | 213.2 | 224 | 56～336 |
| 五条 | 456.9 | 480 | 120～720 |

五条的数值只表示牌组改造后可能出现的理论牌阶结构，不代表它在实际构筑中的出现概率；其固定倍率与正式启用时点仍待后续确认。

#### 不增加统一牌型筹码

《小丑牌》的结算是“牌型基础筹码 + 参与计分的牌面筹码”，再乘倍率。本系统确认不增加统一的牌型基础筹码，也不采用“（牌型基础筹码 + 真气值总和）× 倍率”。牌型基准值只使用“基础值 × 固定牌型倍率”，是否造成伤害由功法、内功或毒异状明确写出。

“功法值”不是另一份伤害或筹码，而是功法和内功在需要数值缩放时读取的计算结果。原作的牌型基础筹码在本系统中由具体功法的固定效果、最低效果或其他战斗作用承接；没有读取功法值的固定效果不会被倍率放大。功法值固定修正用于扶持低基础值牌型；传奇等效果提供的百分比功法值增幅与多彩统一相加，不采用多个独立终乘。这样可以保留牌型特效的价值，而不让高阶牌型、持续回合、防御和反伤随一段统一基础数值整体膨胀。

## 4. 固定牌型倍率与心得倍率

固定牌型倍率不成长，始终使用第 2.1 节的基线，只决定牌型基准值。心得提供另一条独立的累计成长：提高指定牌型的功法倍率，但不提高固定牌型倍率或牌型基准值。

使用一份心得时，立即执行两项效果：

1. 按该牌型所在分组增加其累计心得倍率；
2. 从该牌型对应的共用功法池中随机获得一门功法。

| 心得分组 | 对应牌型 | 每份心得增加的功法倍率 |
| --- | --- | ---: |
| 低级牌型 | 高牌、一对、两对 | +1 |
| 中级牌型 | 三条、葫芦 | +2 |
| 高级牌型 | 顺子、四条 | +3 |

每种牌型分别累计自己的心得倍率。例如使用两份三条心得后，三条累计心得倍率为 +4，不会提高葫芦。所得功法进入该牌型对应的共用功法池，不自动替换当前装备的功法；例如一对心得与两对心得分别提高各自的累计心得倍率，但都从“一对、两对”共用功法池获得功法，所获功法可供一对与两对共同使用。重复功法优先改为从尚未获得的功法中随机；若对应池已全部获得，则本次心得只增加倍率，不补偿其他资源。

具体真气重塑、异状、功法或内功也可以临时或有条件地修正功法倍率。第一版的倍率修正优先采用加减；只有多彩品相明确在功法倍率计算完成后进行百分比增幅。

概率统计统一按第 2.2 节的 52 张基础真气、8 张基础手牌与实际选牌规则计算。当前概率是未改造基础牌组的数学基线，不是完成平衡后的掉落率或实战出招率。
