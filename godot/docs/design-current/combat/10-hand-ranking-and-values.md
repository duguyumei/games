# 牌型、真气值与倍率

> 本文件是当前 v0.30 模块化权威设计源的一部分。原文规则段落仅在此处维护；
> 其他模块只能通过链接引用，不得复制或重新解释。原章节编号保留用于迁移核对。

### 2.1 普通牌型与强弱顺序

只使用普通扑克牌名称：

```text
高牌、一对、两对、三条、顺子、葫芦、四条、五条
```

一次出牌只选择一个最高牌型。牌型负责确定强弱顺序、参与数值计算的真气、功法池与当前功法序列；牌型本身不再提供固定倍率。

同花、同花顺、皇家同花顺、同花葫芦、同花五条及未来其他仅由同属性结构建立的复合牌型均已废弃，不再参与牌型识别，也不拥有心得、功法池或独立功法序列。同属性构筑统一使用“属性集中倍率”与“同气槽”，不再使用“同花”命名，避免与扑克牌型概念混淆。

五条由五张牌阶相同的普通真气组成，是强于四条的最高普通牌型；五张真气全部参与数值计算。
它在未改造的 52 张基础真气牌组中不可能自然形成，只能通过增加、复制或修改真气建立。
五条的稀有度由其独立功法序列、炸弹功法池与五张贡献牌承接，不再通过旧 `×12` 固定倍率制造统一数值跳变。

### 2.2 真气值与数值计算

暂定采用与《小丑牌》相近的计数方式：通常只有组成最高牌型的真气参与基础值计算。

每张普通真气同时记录三个基础属性：

```text
牌阶：负责识别高牌、对子、两对、三条、顺子、葫芦、四条、五条
真气值：负责基础值及其他读取牌值的效果
真气属性：风、林、火、山；负责功法属性条件、属性集中倍率与同气槽
```

普通牌阶与真气值固定对应如下：

| 牌阶 | 真气值 | 牌阶顺序 |
| --- | ---: | --- |
| 2～10 | 等于牌面数字 | 2 < 3 < … < 10 |
| J | 11 | 10 < J |
| Q | 11 | J < Q |
| K | 11 | Q < K |
| A | 12 | K < A |

J、Q、K虽然真气值都为 11，但牌阶不同，不能互相组成对子、三条、葫芦或四条。A是最高牌阶，高牌判断中高于K；顺子是唯一例外，A既可以作为低端组成 `A、2、3、4、5`，也可以作为高端组成 `10、J、Q、K、A`，不能用于其他首尾相接的顺子。A在两种顺子中的真气值都固定为 12。

```text
功法贡献总和 C（亦称本牌型组的基础值）
= 所有参与数值计算的真气，在真气自身与贡献层效果结算后的贡献之和
+ 其他明确属于真气贡献层的修正

属性集中数 N
= 分别统计参与数值计算的真气可视为风、林、火、山的张数
  后取四者中的最大值

功法倍率 M
= 属性集中数 N
+ 参与数值计算的乘势真气触发次数 × 1
+ 本次机缘强化倍率判定成功次数 × 1
+ 其他明确修改功法倍率的效果

初始功法值 P₀ = floor(C × M)

连势前功法值
= floor[(P₀ + 所有直接功法值固定修正)
        ×（1 + 所有直接功法值百分比修正）]

最终功法值 P = max(0, 连势前功法值 + 本次使用的连势值)

牌型基准值 = C
```

`N` 只读取组成最高牌型并实际参与数值计算的真气。每张实体真气在某一种属性的候选计数中最多计算一次，最后只取一个属性的最大张数；混元与临时属性身份可以让同一张牌进入多个候选属性的比较，但不会把多个属性的张数相加。回响只重演该牌的数值触发包，不把一张实体牌变成两张，因此不会额外增加 `N`。未参与最高牌型的额外打出真气默认不增加 `C` 或 `N`；若功法或内功明确使其参与数值计算，则它同时进入 `C` 与 `N`。

`P₀` 是一门功法从本次真气与倍率中自然得到的初始规模。它包含所有真气贡献层变化与所有功法倍率变化；它不包含任何直接写作“功法值 +X”或“功法值 +X%”的效果，也不包含连势。固定修正与百分比修正是在 `P₀` 之后对功法值本体进行的直接修改；所有百分比修正仍进入同一加法池，只乘算一次。

现有内容文本中的“功法值固定修正”统一视为直接功法值固定修正；“功法值增幅 +X%”统一视为直接功法值百分比修正。只有明确写作“功法倍率 +X”的效果才进入 `M` 与 `P₀`。

“本次使用的连势值”只在当前功法成功触发时取连势快照；功法失败、空序列或只为其他效果计算功法值时，该项为 0。

牌型基准值只供功法、内功或毒状态在文本中明确读取；它等于未经过功法倍率放大的贡献总和 `C`，本次出牌不再自动造成伤害。牌型基准值不读取属性集中数、乘势、机缘、其他功法倍率修正、直接功法值修正或连势。

基础通用功法也遵循同一数值链：散招造成 `floor(P/4)` 普通伤害，守招获得 `floor(P/4)` 防御；两者读取最终 `P`，不设最少 1 点。

普通真气每次触发时的自身贡献等于结算当时的有效真气值；增元使合格真气的有效真气值 +8，虚暴使其 ×2，燃尽则使当前有效真气值为 0。觉醒火真气参与功法数值计算时再将有效真气值 ×2，并在该功法完整结算后燃尽。回响印可以令同一张真气的合格自身触发包及由它直接触发的内功效果额外结算一次。详细规则见[真气效果、重塑与异状](./14-qi-effects-and-statuses.md#66-本源强化与印记)。

回响数值包的正常遍与重演遍各自从相同原始牌面和当前战斗状态开始，分别完成有效真气值、自身贡献、该牌功法倍率修正与该牌直接功法值百分比修正，再累加两遍输出；不能把第一遍的输出继续交给第二遍复合。因而普通 5 点回响牌贡献 `5+5=10`，增元回响贡献 `(5+8)+(5+8)=26`，虚暴回响贡献 `(5×2)+(5×2)=20`，乘势回响提供 `+1+1=+2` 功法倍率。混元是属性身份查询，不产生第二份身份收益；回响也不把一张实体牌变成两张属性计数，因此不额外增加 `N`。

一张回响牌只影响它所在牌型组的自身数值触发。主组与协同组分别计算各自的单牌触发包和机缘冻结结果，然后才按既有公式合并共享功法值；主组不能重演协同组真气，协同组也不能重演主组真气。同一真气实例不得同时进入两个组。回响不重新识别牌型、不重新检查或执行整门功法、不重复创建功法选择，也不推进第二次功法序列。

属性集中数 `N` 是功法倍率的基础部分。乘势、机缘和其他明确功法倍率修正计入 `M`，因此计入 `P₀`，但不改变牌型基准值。牌型熟练度固定修正和其他直接功法值固定／百分比修正只改变 `P`，不改变 `P₀` 或牌型基准值。心得不进入功法倍率，也不建立独立的最终乘区。所有直接功法值百分比修正统一相加后只乘算一次，不建立多个“最终×功法值”连乘层。没有读取数值的固定效果，例如“下回合手牌上限 +1”，不会被倍率放大。

例如一对 `7、7` 分别为风、火，其中风牌拥有乘势时，`C=14`、`N=1`、`M=1+1=2`，所以 `P₀=28`。若两张牌经过改造后都可视为风，则 `N=2`、`M=2+1=3`，`P₀=42`。若另有“本次功法值 +50%”，该百分比只在 `P₀` 之后进入统一加法池，不会反向改变 `C`、`N` 或 `P₀`。

#### 属性集中倍率与同气槽的边界

属性集中倍率与牌型结构并行，但不是第九种精确牌型。每个牌型组只用本组参与数值计算的真气独立得到 `N`；主组与协同组不得跨组合并属性张数。同组重触复用已经冻结的 `C`、`N`、`M`、`P₀` 与 `P`，不重新计数。

旧的“同气投入 1～5 张给予 `0% / +10% / +20% / +30% / +50%` 直接功法值修正”已经废弃，不能与新的 `N` 倍率同时存在。额外打出但未参与最高牌型的真气仍会换牌、进入牌区并触发明确写作“打出时”的效果，但默认不提高 `C`、`N` 或 `P`。

同气槽是另一项行动级战斗资源：它检查整次行动实际打出的全部普通真气，包括额外投入和所有协同组，不参与 `C`、`N`、`M` 或 `P` 的计算。其完整获得、充满和连动规则见[行动结算、触发队列与连击](./12-action-resolution.md#同气槽与通用连动)。

普通牌型中参与数值计算的真气数量：

```text
高牌：只计算最高的一张
一对：计算组成一对的两张
两对：计算两组对子的四张
三条：计算三张同牌阶真气
顺子：计算组成顺子的五张
葫芦：计算三条与对子共五张
四条：计算四张同牌阶真气
五条：计算五张同牌阶真气
```

例如 `7、7、7、3、3` 组成葫芦，五张牌全部属于最高牌型，所以 `C=7+7+7+3+3=27`。若其中 3 张可视为风、2 张可视为林且不存在覆盖更多牌的其他共同属性，则 `N=3`、基础 `M=3`、`P₀=81`。

例如打出 `7、7、4、3、A`，最高牌型是一对，只有两张7参与基础值，所以基础值是14；其余三张随本次出牌进入弃牌堆。

例如 `J、J` 可以组成一对，基础值为 `11+11=22`；`J、Q` 虽然真气值同为 11，但牌阶不同，不能组成一对。顺子 `A、2、3、4、5` 的基础值为 26，顺子 `10、J、Q、K、A` 的基础值为 55。

没有参与最高牌型的多余普通真气默认不增加基础值，也不触发要求“参与数值计算”的强化、觉醒或印记，只会随本次出牌进入弃牌堆；无漏、磐石等明确写为“打出时”的效果仍会触发。功法或内功也可以明确改写这条规则，让额外真气参与数值计算或产生效果。

#### 基础概率

概率统计固定使用以下基线：

```text
52 张未改造基础真气
随机抽取 8 张作为手牌
玩家可以从中选择打出 1～5 张
总手牌样本数 = C(52,8) = 752,538,150
```

“可主动组成概率”表示随机 8 张中至少存在一种选牌方式，可以准确组成该牌型；由于玩家永远可以只出 1 张，所以高牌为 100%。这一列的不同牌型可以同时存在，不能相加。

“最高牌型概率”表示按普通牌型强弱判断，这 8 张能够组成的最高牌型；各行互斥，合计约为 100%。

| 牌型 | 可主动组成概率 | 最高牌型概率 |
| --- | ---: | ---: |
| 高牌 | 100% | 7.9771% |
| 一对 | 88.7920% | 34.2675% |
| 两对 | 43.7409% | 36.2061% |
| 三条 | 12.0075% | 5.3722% |
| 顺子 | 9.8162% | 9.7736% |
| 葫芦 | 6.1846% | 6.0674% |
| 四条 | 0.336124% | 0.336124% |
| 五条 | 0% | 0% |

删除全部同花相关牌型后，最高牌型概率已按剩余牌型优先级重新计算；表中最高牌型各行互斥并合计约为 100%。五条在未改造的 52 张牌组中严格不可能，只有增加、复制或修改真气后才可能出现。

#### 新数值基线

旧固定牌型倍率下的平均值、中位数与范围表已经失效，不得继续用于平衡。新的牌型基准值只等于贡献总和 `C`；正式平衡同时观察 `C`、属性集中数 `N`、`P₀=C×M`、实际功法效果、牌型出现率和战斗生命。稀有牌型不再天然拥有更高的固定倍率，它的价值主要来自更多贡献牌、独立功法序列与对应功法效果。

若试玩后发现稀有牌型的公共数值回报不足，应优先调整具体功法或增加一项受控的直接功法值固定修正；不得恢复 `×7`、`×12` 这类按牌型陡增的统一倍率，也不得再增加一套与 `N` 并行的同气百分比终乘。

#### 不增加统一牌型筹码

《小丑牌》的结算是“牌型基础筹码 + 参与计分的牌面筹码”，再乘倍率。本系统确认不增加统一的牌型基础筹码，也不采用“（牌型基础筹码 + 真气值总和）× 倍率”。牌型基准值只等于贡献总和 `C`，是否造成伤害由功法、内功或毒状态明确写出。

“功法值”不是另一份伤害或筹码，而是功法和内功在需要数值缩放时读取的计算结果。原作的牌型基础筹码在本系统中由具体功法的固定效果、最低效果或其他战斗作用承接；没有读取功法值的固定效果不会被倍率放大。直接功法值固定修正用于扶持低基础值牌型；不同直接功法值百分比修正统一相加，不采用多个独立终乘。这样可以保留牌型特效的价值，而不让高阶牌型、持续回合、防御和反震随一段统一基础数值整体膨胀。

## 4. 牌型功法槽位

牌型不再拥有固定倍率。心得不提高属性集中数 `N`、功法倍率、牌型基准值或最终伤害，而是提升指定具体牌型的功法槽位。

每个具体牌型初始拥有 1 个功法槽位。使用一份对应心得时，立即执行两项效果：

1. 该具体牌型的功法槽位增加 1；
2. 从该牌型可以读取的基础功法池并集中，随机获得一门尚未加入该牌型当前序列的正式功法，并默认填入新增槽位。

玩家可以在战斗外重新排序或替换当前序列中的功法；替换下来的功法仍保留在本局功法库。战斗开始后，该具体牌型的序列与槽位内容锁定。

| 心得 | 槽位变化 | 获得功法的池 |
| --- | ---: | --- |
| 高牌心得 | +1 | 高牌池 |
| 一对心得 | +1 | 对子池 |
| 两对心得 | +1 | 对子池 |
| 三条心得 | +1 | 三条池 |
| 葫芦心得 | +1 | 对子池与三条池的去重并集 |
| 顺子心得 | +1 | 顺子池 |
| 四条心得 | +1 | 炸弹池 |
| 五条心得 | +1 | 炸弹池 |

一对与两对虽然都读取对子池，但槽位、序列和进度分别记录；一对心得不增加两对槽位。葫芦拥有独立槽位、序列和进度，只是从对子池与三条池的去重并集中获得功法；它仍只运行自己当前序列的一门功法。四条与五条同样分别拥有独立槽位、序列和进度，只共同读取炸弹池。八种心得从开局起均正常进入普通心得随机池；五条初始槽位为 1，不以当前牌组能否立即组成五条为生成条件。若可读取的基础池并集中已没有可加入当前序列的正式功法，心得仍成功消耗并只增加该具体牌型 1 个槽位，不跨池改抽、不回滚，也不写入旧的累计倍率字段。

牌型熟练度固定修正是后续可选的受控数值接口。若内容明确提供该修正，它属于 `P₀` 之后的直接功法值固定修正，不进入功法倍率、`P₀`、牌型基准值或独立乘区；第一版不冻结具体修正数值，先验证功法槽位成长和序列频率。

具体真气重塑、异状、功法或内功仍可以临时或有条件地修正功法倍率。第一版的倍率修正优先采用加减；心得不属于这条倍率修正池。

概率统计统一按第 2.2 节的 52 张基础真气、8 张基础手牌与实际选牌规则计算。当前概率是未改造基础牌组的数学基线，不是完成平衡后的掉落率或实战出招率。
