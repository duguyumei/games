## 模块所有权

| 模块 | 权威正文 | 禁止承载 |
|---|---|---|
| 战斗规则核 | `combat/` | 不重复功法池内容、成长商品和 AI 协议 |
| 武学内容 | `martial-arts/` | 不重定义牌型、伤害、地图和经济规则 |
| 成长与经济 | `progression/`、`economy/` | 不复制战斗时序和真气生命周期 |
| 地图流程 | `run/` | 不重定义战斗内部结算 |
| 敌方 AI | `ai/` | 只能选择规则核提供的合法候选，不能产生第二套规则 |
| 验证与开放问题 | `validation/` | 未确认项不得写成已确认规则 |
