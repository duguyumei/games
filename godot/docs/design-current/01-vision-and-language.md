# 设计目标与术语

## 1. 设计目标

验证玩家是否愿意为了下一次更好的牌型，管理手牌、牌库和弃牌机会。

本项目借鉴《小丑牌》的牌型识别、牌面数值、倍率和效果联动，但最终结果是对战行动，不是筹码计分。

数值不是唯一成长目标。功法和内功负责提供更多战术效果、资源控制和敌我互动；公共真气成长应克制纯倍率叠加，避免最终仍变成只追求最高数值的计分游戏。

即时伤害最高的出牌不必永远是整场战斗的最佳选择；玩家可以结合同步受击、连击路线、剩余手牌、有限牌库和跨战斗生命作出取舍。这只是提供选择空间的设计参考，不要求每次出牌都牺牲眼前收益；能够安全击败敌人时，直接选择最高即时收益仍然应当合理。

### 1.1 正式世界观映射与讨论术语

卡牌本身不是招式，而是供功法调动的真气；真正的招式由功法产生。正式描述统一使用以下映射：

| 《小丑牌》或讨论术语 | 正式术语 | 含义 |
| --- | --- | --- |
| 扑克牌、卡牌 | 真气 | 被抽取、留在手中并用于组合出招的基础单位 |
| 牌面、牌阶 | 牌阶 | A、2～10、J、Q、K；负责识别对子、顺子、高牌等普通牌型 |
| 计分值、牌值 | 真气值 | 负责基础值和读取牌值的效果；数字牌按牌面，J／Q／K 为 11，A 为 12；基础真气值最高为 12 |
| 花色 | 真气属性 | 风、林、火、山四种属性 |
| 牌型 | 牌型 | 真气组成的结构，继续使用通用扑克牌名称 |
| 小丑牌 | 内功 | 六个有限装备栏位中的、可替换的战斗构筑引擎 |
| 塔罗牌 | 丹药 | 一次性增加、删除、复制、强化或转化真气 |
| 星球牌 | 心得 | 提升指定牌型的功法槽位，并从该牌型所属共用功法池获得功法 |
| 幻灵牌 | 奇珍 | 一次性、稀有且强力地改造真气、内功或整个构筑 |
| 优惠券对应物（原称） | 物品 | 《小丑牌》优惠券的正式系统对应物；功能上可借鉴《杀戮尖塔》遗物，但不另设遗物类别；不占内功栏位，使用独立物品持有区 |
| 版本、强化 | 强化 | 真气的一个本局战斗性质槽位；当前包括增元、乘势、混元、虚暴、无漏、磐石、藏金与机缘 |
| 蜡封 | 印记 | 在出招、留手、弃掉等特定时点触发的本局重塑 |

风、林、火、山在第一版只是真气属性标签，不各自附带公共攻击、防御、抽牌或恢复效果；这些差异由具体功法、内功与觉醒建立。物品是本局全局生效的独立构筑内容，具体效果可以作用于战斗、修习、商店、奖励或成长；“优惠券对应物”只保留为《小丑牌》来源对照，不是第二种正式内容类型。旧品相类别已经废弃，箔面、镭射、多彩与负片不再是当前正式重塑。为了便于对照《小丑牌》和讨论概率，设计讨论中仍可继续使用“卡牌、花色、小丑牌、塔罗牌、星球牌、幻灵牌、蜡封、优惠券”等原术语；正式界面、世界观说明和最终规则统一使用右侧术语。完整牌组中牌阶与真气值不再完全相同，因此涉及 A、J、Q、K 时不能笼统使用“点数”，必须明确说牌阶或真气值。
