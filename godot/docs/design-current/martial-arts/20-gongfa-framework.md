### 2.4 功法

功法是绑定牌型的特效。本次行动中每个牌型组的处理顺序如下：

```text
识别最高牌型
→ 计算基础值、牌型基准值与功法值，但暂不造成伤害
→ 将本次合格功法与同一时点的已装备内功加入可见触发队列，按玩家排列从左到右逐个结算，建立防御、标记和延迟效果
→ 结算功法、内功、毒异状明确写出的伤害
→ 执行抽牌、弃牌、回收等牌区变化
→ 将打出的牌置入弃牌堆或按效果移出牌组
→ 结算“出牌结算结束时”的留手效果
```

若主牌型功法建立协同，则在主牌型开始结算前先锁定全部协同组；主牌型完成上述流程后，各协同组按锁定顺序分别重复完整流程。全部组结算结束后才视为本次行动结束，并检查通用同属性连击或其他额外行动效果。

玩法流派不由牌型或功法单独定义，而采用双轴关系：牌型负责出招频率、参与牌数、功法值规模、属性条件与序列推进节奏；功法负责伤害、防御、牌区、异状、标记、连击、协同与其他具体战斗行为；内功负责跨牌型连接、路线改写和常驻规则；真气改造负责把目标牌型从偶发变为稳定。完整构筑通常由一个主牌型、一个主要功法效果轴、可选的副牌型，以及配套内功和真气改造组成。

功法同时具有“牌型合格范围”和“效果方向”。牌型合格范围决定功法可以加入哪些具体牌型序列；毒、过牌、连击、借力、封禁等效果方向用于组织玩法流派和跨流派接口，不建立新的触发池、基础资源或额外结算次数。一次牌型组仍只触发其序列当前指向的一门功法。

功法不再为每种普通牌型分别创作独立牌池，而是按牌型的底层结构绑定下列五个基础功法池。同一基础池可以获得多个不同功法，新功法进入本局功法库，不会自动替换、遗忘或出售旧功法。

| 基础功法池 | 可以读取该池的精确牌型 |
| --- | --- |
| 高牌池 | 高牌 |
| 对子池 | 一对、两对；葫芦交叉读取 |
| 三条池 | 三条；葫芦交叉读取 |
| 顺子池 | 顺子 |
| 炸弹池 | 四条、五条 |

高牌可以由任意手牌主动打出，默认承担启动、保底、过渡和低成本铺垫作用；通常不以高牌单独覆盖一整套玩法流派。高牌表示没有形成更高结构时的散手，不是其他牌型自动包含的公共结构，因此其他牌型默认不能读取整个高牌池。具体功法可以明确同时归入多个基础池，建立受控的跨池通用效果；高牌池本身不因此成为通用池。只有功法序列、内功和真气改造共同提供了足够的循环与成长时，高牌才可以作为明确例外发展为独立主牌型流派。其他一个或少量精确牌型都可以在获得足够功法与牌组支持后形成完整流派。

五条是由五张牌阶相同普通真气组成的最高普通牌型，固定倍率为 `×12`；未改造基础牌组中
无法自然形成，只能通过增加、复制或修改真气建立。五条与四条共同读取炸弹池，
但拥有自己的独立功法槽位、循环序列和序列进度。这里共同读取炸弹池只表示四条和五条
抽取功法时读取同一组候选，不表示两者共用槽位、序列或当前指针；四条已装备的功法不会
自动进入五条序列，五条心得也不会增加四条槽位。五条心得从开局起正常进入普通心得随机池，
不以当前牌组能否立即组成五条为生成条件。

葫芦由一组对子与一组三条共同建立，因此它的功法候选是对子池与三条池去重后的并集。葫芦从对子池获得功法时，默认按该功法的一对分支结算；从三条池获得功法时，默认按三条分支结算；功法正文可以明确提供葫芦专属分支覆盖默认值。同一门功法同时归入两个池时，在葫芦候选中只出现一次，不增加抽取权重。葫芦仍只运行自己序列当前的一门功法，不会因为交叉读取两个池而同时触发对子与三条功法。葫芦的平均牌型基准值已经约为三条的 2.22 倍，因此读取功法值的伤害、防御和规模不会再次获得统一加成；不随功法值成长的固定层数、目标数、展示数、抽牌数或回收数，可以由功法的葫芦专属分支单独调整。

具体牌型仍分别决定参与数值计算的真气、固定牌型倍率、功法槽位与本次功法值。基础功法池只决定“该牌型的功法序列可以配置哪些功法”，不会合并或修改不同牌型的牌型基准值、功法槽位或功法序列进度。

每个具体牌型拥有一条独立的循环功法序列。每个具体牌型初始拥有 1 个功法槽位；每使用一份对应心得，槽位增加 1，并从该牌型可以读取的基础功法池并集中随机获得一门尚未加入该牌型当前序列的正式功法，默认填入新增槽位。当前序列长度不得超过该牌型槽位数，同一门功法在同一条序列中最多出现一次。读取同一基础池的不同具体牌型仍然独立记录槽位、序列和进度，例如一对心得只增加一对槽位，不增加两对槽位；一对与两对可以分别在自己的序列中使用同一门已获功法。

若该精确牌型可读取的基础池并集中没有可抽取的正式功法，心得仍只增加该具体牌型 1 个槽位；本次不获得功法，
也不跨池改抽或回滚心得操作。

同花、同花顺、同花葫芦、同花五条及其他仅由同属性结构建立的复合牌型均已废弃；同属性构筑统一读取战斗规则核中的“五张同属性真气使本组功法值增幅 +50%”以及通用同属性连击，不再拥有同花功法池或独立序列。

每条功法序列按以下规则运行：

- 战斗开始时指向序列第一门；战斗结束后重置到第一门，除非内功明确改写。
- 每次打出该具体牌型，只尝试触发当前指向的一门功法；一次出牌仍只触发一门功法一次。
- 当前功法满足牌型、属性与其他触发条件并成功触发后，序列在该牌型组完整结算结束时前进一格；最后一门之后回到第一门。没有协同时，主牌型组结束即为本次行动结束；有协同时，后续同牌型协同组读取已经推进后的序列位置。
- 当前功法不满足条件时不产生效果，序列也不前进；玩家必须之后再次打出该具体牌型并满足条件，才能继续序列。
- 空序列不产生功法效果，但牌型基准值与功法值仍正常计算；没有其他明确伤害来源时，本次不造成伤害。
- 功法序列的内容与顺序在战斗开始后锁定，不能在战斗中通过普通装备操作临时重排、插入或移除；功法或内功可以明确改写序列位置。

功法的真气条件分为三类：

```text
通用功法：只限制牌型
属性功法：限制牌型，并要求参与最高牌型的真气中至少有指定数量属于某一真气属性
纯属性功法：限制牌型，并要求所有参与最高牌型的真气均视为指定真气属性
```

属性功法必须在文本中同时写明属性和数量，例如“一对，其中至少 1 张为火”或“三条，其中至少 2 张为山”。第一版每门属性功法只要求一种属性；只检查参与最高牌型的真气，不检查额外打出的真气或仍在手中的真气。混元强化在牌型识别和功法属性条件中同时视为风、林、火、山，明确读取原始属性时仍读取其基础属性。

蛊毒跨越风与林，不强制建立“所有类别 × 风林火山”的完整矩阵。风以烈毒的扩散与快速催毒为主，林以郁毒的削弱与吸收转化为主，少量功法可以跨属性转毒或同时读取两种毒。功法可以只在本次最高牌型属于纯属性时触发，也可以作为通用功法并在纯属性时获得额外效果。“纯风”或“纯林”表示所有参与最高牌型的真气在属性识别中均视为对应属性；高牌只检查参与数值计算的最高一张，一对检查两张，两对检查四张，其他牌型按各自参与最高牌型的真气检查。未参与最高牌型的额外打出真气不破坏纯属性条件；混元视为所有属性。

普通牌型识别与固定牌型倍率只取最高牌型，功法按该具体牌型当前序列指向确定；基础值和功法倍率再按第 2.2 节及其他明确效果修正。组成葫芦的三条和对子不再额外推进其他牌型序列。

- 只检查本次实际选出的牌，不检查仍在手中的牌。
- 如果该具体牌型的功法序列为空，牌型的基础值和倍率仍然正常计算，但不产生功法特效。
- 如果装备了属性功法但本次真气不满足其属性与数量条件，牌型基准值仍正常计算，但该功法不触发。
- 功法产生的新牌、新效果不能在同一次出牌中递归触发功法。

高牌功法可以在自己的效果文本中读取本次打出的全部散牌，但只有最高的一张普通真气属于高牌并参与默认功法值计算。高牌的开局基础序列仍待从当前功法池中确定；高牌是否造成伤害、获得防御或建立启动效果，都由序列当前功法明确决定。

功法不设置跨牌型的统一装备数量上限；每条具体牌型序列受自己的功法槽位限制，序列变长会降低其中每门功法再次轮到的频率，本身就是构筑成本。没有加入任何序列的已获功法继续保留在本局功法库。内功仍有六个装备栏位。第一版风林蛊毒与风运转功法池已经完成一次合并重构，但各具体牌型的初始序列、槽位成长与每门功法的最终数值仍待实测冻结。

没有心得、强化或其他倍率修正时，功法值等于牌型基准值；乘势、机缘或明确的功法与内功效果可以使两者不同。功法值的最终读取结果最低为 0。

#### 普通功法的即时战斗落点

由于出牌不再自动造成牌型基础伤害，除非明确标为特殊功法，否则每门功法完成结算时必须至少产生一个不依赖后续事件的即时战斗落点：直接造成伤害，或者立即获得防御。抽牌、弃牌、附毒、加标记、控顶、回收和延迟效果建立在这个落点之上，不能普遍取代它。

标准功法优先采用“即时伤害或即时防御 + 一个主要机制 + 可选条件强化”的结构。随机目标或合格目标不足时，功法的即时伤害或防御仍正常结算，不能因为敌方没有合格手牌、牌库为空或延迟条件尚未建立而整门空转。

每门普通功法必须至少有一项实际结算结果有意义地读取本次功法值 `P`。直接读取 `P`，或读取由 `P` 计算出的目标数、层数、持续次数、阈值、抽牌数、回收数等派生参数，都视为功法值参与；只有牌型、属性、异状或其他固定触发条件，不视为功法值参与。不能只在文本中形式化地提到 `P`，但让其在正常数值区间内不会改变任何结果。

普通功法仍必须拥有即时伤害或即时防御。如果主要机制完全使用固定值，则即时伤害或防御必须读取 `P`；如果主要机制本身已经读取 `P`，即时落点可以使用固定值。特殊功法原则上仍应让主要机制读取 `P`，只有文本明确标为“固定规则例外”且该例外已经单独确认时，才可以同时省略即时伤害／防御与 `P` 读取；固定规则例外只用于足以独立改写整场战术结构的少量特殊功法，不成为普通功法模板。功法建立延迟效果时，默认在建立时记录本次 `P` 及所需派生值，之后不因另一场出牌的功法值变化而更新，除非效果明确写出重新读取规则。

下列效果足以独立改变行动结构时，可以明确标为特殊功法并省略即时伤害或防御：建立连击或协同；大规模转换多个牌区；大量创建、复制、移除或回收战斗内临时真气；终结性毒爆；具有显著代价的传奇规则改写；其他能够单独完成完整战术目的的强控制。特殊功法仍必须有清楚的成功条件和失败边界，不能只以“效果复杂”为由省略战斗落点。

蛊毒属于长流程体系，标准蛊毒功法的防御型数量应多于伤害型。第一轮重构可以用约两门防御型对应一门伤害型作为审计目标，但不是所有类别必须严格复制的硬配额。蛊毒功法的直接伤害应低于火的多段连势与山的爆发伤害；主要胜势来自持续附毒、催毒、牌区控制和防御积累。防御会跨回合保存的当前规则可能放大长流程收益，因此附毒范围越广、控制越强，配套的即时防御就应越低。

#### 四属性底层系统与场内外改造边界

风、林、火、山不作为四个彼此隔离的角色卡池，而是从同一套战斗规则中分别读取四层底层系统。属性归属优先由一门功法主要读取、操作的对象决定，不由其最终造成伤害、获得防御、回血或抽牌等结果决定；这些结果以及协同、连击、生命、防御、毒、状态和标记都是各属性可以共同使用的连接接口。属性倾向不是排他限制，但第一版应让玩家仅凭功法文本就能判断其主要读取哪层系统、用什么方式把输入转换为结果。

| 属性 | 主要对应的底层系统 | 核心对象与问题 | 主要操作 | 当前常用输出与接口 |
| --- | --- | --- | --- | --- |
| 风 | 卡牌与牌区系统 | 敌我手牌、牌库、弃牌堆、待出区中的资源位于哪里、何时可用 | 抽牌、弃牌、控顶、回手、洗回、夺取、交换，并把实际流转数量、真气值或附加内容转化为效果 | 风标、烈毒扩散与催发、资源干扰、协同与连击续接 |
| 林 | 真气实例与生命周期系统 | 单张真气经历消耗、留手、附毒或其他异状传播、回收后能否恢复、成长或转化 | 回收、培育、创建临时真气、恢复与净化、附毒、传播异状与吸收；成长优先附着于已有真气、已有牌区事件或实际削减值，不预设独立成长资源 | 郁毒削弱、封穴、回血、防御、临时真气、模拟本源／强化／印记行为的异状·其他 |
| 火 | 功法运行系统 | 各精确牌型的独立功法序列如何发动、推进、重触、循环并把一次结算传播为后续事件 | 读取功法是否成功触发、当前序列位置与长度、循环完成、协同后续组和攻击段；在明确边界内推进、重触或串联功法及其结果 | 多段、追击、反击、连势、连击、燃命、烧牌、焚脉、封禁、真伤与高频响应 |
| 山 | 牌型结构系统 | 真气怎样成型，精确牌型的参与张数、主副结构、频率、投入和数值规模具有什么价值 | 读取已经识别的精确牌型、参与牌、额外牌、结构关系与功法值；稳定结构、承载投入并把结构差异转化为即时或后续收益 | 防御、反震、破绽、破防、蓄势、稳定终结与高投入爆发 |

四层系统按战斗流程形成循环，而不是四条封闭的流派管线：

```text
风调度敌我牌区中的可利用资源
→ 林改变具体真气的生命周期、异状传播与成长状态
→ 山读取真气之间形成的牌型结构
→ 火运行该精确牌型当前指向的功法并传播效果
→ 功法结果重新改变牌区、真气、牌型机会与后续功法运行
```

风与林都可以发生回收或牌区移动，但主要读取对象不同：强调资源现在从哪里移动到哪里、移动本身产生什么效果时归风；强调同一张真气经过消耗与回收后恢复、成长或转化时归林。风的敌方干扰偏向夺取、换位、弃牌、控顶和打乱可用时机；林的敌方干扰偏向附毒与传播异状、削减、阻止恢复，以及把敌方实际损失吸收为我方生命、防御、临时真气或成长。

当前只确认林以回收、异状传播与成长读取真气生命周期；成长具体附着于留手、回收次数、临时有效真气值、实际削减值还是其他已有状态，以及它的触发时点、清除时点和数值，仍待后续设计确认。四属性底层分工也不自动证明现有功法池中的每门候选已经符合新框架，旧候选仍需逐门审计。

山功法在牌型识别后读取本次已经成立的结构，不能追溯改变本次最高牌型；改变组成条件、参与范围或牌阶关系的常驻规则仍由内功、物品或其他在识别前生效的内容承担。火可以读取和有限改写功法序列位置，但仍遵守每个牌型组默认只触发当前指向的一门功法、同组重触不播放后续功法、成功后只推进一格以及禁止自身递归等公共边界。跨牌型、跨序列或持续整场的普遍功法运行规则优先由内功承担。

牌型和功法系统并非山、火的排他所有物：所有属性功法都由牌型触发并进入功法序列。山只是优先从牌型内部结构获得主要机制，火只是优先从功法发动、推进与结算传播获得主要机制。同理，其他属性可以抽牌、回收、读取牌型或改写序列，但这些效果应服务于该功法自己的主要系统输入。第一版不要求建立“所有牌型类别 × 四属性 × 全部功能”的对称矩阵。

##### 子系统讨论索引

四层底层系统可以继续拆分为下列优先观察对象。本表不是完整功能清单，也不限制某项效果只能属于一个属性；它只规定后续讨论从哪些已有状态、事件和规则关系中挖掘主要机制。

| 属性与底层系统 | 优先观察的子系统与变量 |
| --- | --- |
| 风／卡牌与牌区 | 基础手牌上限与正常补牌目标、明确抽牌、超过手牌上限、正常打出与明确弃掉的区别、敌我手牌／牌库／弃牌堆／待出区、牌库顶底与顺序、不自动重洗、回手、洗回、锁定、夺取、交换、所有权与实际移动数量 |
| 林／真气实例与生命周期 | 牌阶、基础与有效真气值、基础与识别属性、本源／强化／印记、毒／状态／标记／异状·其他、槽位替换、跨牌区保留与清理、临时真气、留手、回收、附毒与异状传播、削减、净化、吸收、恢复、成长和同一张真气的使用历史 |
| 火／功法运行 | 基础功法池、各精确牌型独立序列、序列内容／长度／当前位置、触发条件与成败、停滞、推进与循环、同组重触、协同后续组、跨牌型或跨序列影响、可见触发队列、功法值读取、功法建立的临时层数、攻击段／追击／反击、连击新行动、复制与递归边界 |
| 山／牌型结构 | 最高牌型与优先级、七种当前精确牌型与未来五条、参与最高牌型与额外打出真气、参与张数、出现频率、固定倍率、牌型基准值与功法值、对子／主副／连续／同属性／集中结构、扩展牌型、连续成型、协同锁定、多组拆分、投入牌数与剩余手牌 |

生命、防御、伤害、真伤、毒、状态、攻击段、触发队列、连击、协同、延迟效果、敌我互动与战斗胜负是四层系统之间的公共连接接口，不因某个属性优先观察它们而成为该属性专属。牌型本身仍不自动造成伤害或获得防御；山功法只是可以把牌型结构转换为伤害、防御、破防、蓄势或其他结果。连击仍是通用额外行动机制；火只是优先观察它怎样增加功法运行机会以及功法结算怎样继续传播。协同仍是通用多牌型组机制；山只是优先观察它怎样从同一批手牌中锁定和拆分不重复的牌型结构。

功法建立的临时层数同样属于公共表现，不自动归火，也不应仅为单门功法增加封闭资源。新增层数优先要求多个效果可以生产、读取或消耗，或确实无法由现有牌区、真气异状、序列位置、生命和防御表达；否则直接使用已有状态与事件。后续设计一门功法时，依次说明“主要读取哪层底层系统、操作什么具体状态或事件、产生什么公共输出、该输出可以成为哪些其他系统的输入”，以系统间自然输入输出代替点名指定功法的预制组合。

烈毒主要归风、郁毒主要归林，但不硬性禁止另一属性使用。纯风烈毒与纯林郁毒都必须能够独立成型；风林混合时可以通过转毒、双毒收益和蛊印形成跨属性构筑。同一张真气仍只能拥有烈毒或郁毒之一，转换仍必须由效果明确写出。

本源、强化和印记等本局重塑，主要由战斗外的丹药、奇珍、事件和其他成长内容完成。普通功法不应在战斗中永久复制或改造基础牌组。林属性功法可以在战斗中创建战后移除的一次性真气资源，或施加归入“异状·其他”、持续至本场战斗结束、指定次数耗尽或触发后移除的模拟本源／强化／印记效果；这些效果必须写明移除时点，不能写入重塑槽位。

延迟结算是所有属性都可以使用的通用表现，不单独作为某个属性的流派。山更偏向主动蓄势和倒计时终结，火偏向攻击段与受击响应，风偏向牌区移动后的延迟触发，林偏向持续恢复、成长和资源再生。

资源偷取与交换主要分配给风和林：风偏向夺取、换位和打乱敌方牌区，林偏向吸收敌方削减值并转化为我方生命、防御或临时真气。牌库污染与诅咒优先通过毒、异状、临时伪牌和封禁表达，不另建一个平行的大类关键词。

第一版不普遍加入“取消整门功法”或“中断整次行动”的硬反制。反制优先使用降低真气贡献、封禁、封穴、弃掉、消散、防御和反击等可见的软控制；完整取消只保留给具有明确次数、代价和提示的稀有或传奇效果。随机抽牌、随机目标和随机属性属于结算方式，不单独构成流派；风险收益必须来自玩家可理解的代价与回报，例如燃命、燃尽、消散、虚暴的虚无或赌取高收益。

永久牌型识别改写，例如缩短顺子或改变牌阶关系，应由内功、物品或其他在识别牌型前已经生效的规则承担。功法在识别牌型后才触发，不能追溯把本次牌型改成另一个牌型；功法可以明确建立协同，内功或物品可以改变允许锁定的协同路线。
