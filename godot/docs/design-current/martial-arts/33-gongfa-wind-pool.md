# 风·运转与扰乱流正式功法目录

> 状态：当前正式设计正文，51门风系功法均已完成独立资源、运行时、AI语义与专项测试接入。
> 本文共记录51门风系功法：8门保留原稳定实现，`惊风`与`风·换流`沿用稳定ID并按本文重做，另外41门已新增正式资源。
> 当前运行时普通正式池为169门，连同散招、守招共171个正式资源。

## 设计方向

风系围绕两条可以交叉使用的大方向展开，不把牌型写成固定职责：

- 运转／聚手：过牌、寄脉、回手、洗回与定向检索，积累足够手牌并形成高投入牌型。
- 扰乱／耗竭：读取敌方手牌位置、牌阶、有效真气值、属性、重塑与异状，定向弃置、控顶、乱流、交换或夺取。

两条方向通过实际手牌数、八脉占用、格挡、临时属性、明确弃牌和牌库差自然连接，也能与林的毒、成长、虚无与临时牌阶，火的连势及山的格挡发生公共联动。

## 公共读取口径

- `P`为本牌型组冻结的最终功法值，`C`为本组参与数值计算的真气贡献总和，所有除法向下取整。
- `K`为炸弹组成牌数量：四条为4，五条为5。
- “实际手牌数”包含寄脉牌；“占脉数量”不包含寄脉牌。完整规则见[牌组、手牌与牌区](../combat/11-deck-hand-and-zones.md#八脉容量与寄脉)。
- 当前牌阶读取正在生效的临时牌阶；基础属性始终读取牌本体。归元压制临时重塑时，相关查询读取压制后的结果。
- 明确弃牌只选择当时可以被明确弃掉的普通真气；磐石等非法目标不占目标数量。虚无牌成功明确弃掉后先完成弃牌响应，再消散。
- 夺取或交换的牌保留原持有者记录，战斗结束后归还；寄脉在牌离开手牌时移除，临时属性在战斗结束时清除。
- 定向抽牌没有足够合法目标时少抽，不改为普通抽牌。新抽到的牌只需避开被冻结的旧牌阶或基础属性，新牌彼此可以同阶或同属性。
- 展示只公开指定范围。正文未另行允许排序时，未被移动的展示牌保持原相对顺序。

## 精确结算边界

- `惊风`、`扫尾`与所有“最左／最右”效果读取当前界面手牌顺序。`折巅`与`齐坠`按当前牌阶从高到低选择，同阶从右到左；`沉浮`按当前有效真气值从高到低选择，并列同样从右到左。
- `换流`先冻结全部待弃牌及各自基础属性，再完成弃牌，最后逐个匹配一次定向抽牌；后续抽到的牌不会成为本次第二个弃牌目标。
- `易手`同时完成双方离区和入区，不能先把第一张送出的牌再选作第二步目标；本门当前只交换1张。
- `四散`只有初次执行可以产生2次功法回响。每次回响重新随机属性并读取敌方最新手牌；回响执行不能再次产生回响。
- `齐坠`与`沉浮`服从公共同步弃置：先冻结双方目标，再完成全部移动，最后处理逐牌弃牌响应。
- `剥形`读取本源、强化、印记、重塑·其他及三个临时重塑槽中存储的内容，即使其正被归元压制仍算“存有重塑”。`荡秽`读取增益、减益、状态与标记，不把临时重塑本身算作异状。
- 多属性牌分别计入每一种可视属性的数量，但同一实体在一次批量效果中只弃置一次。`离群`并列最多时只随机选择一种属性。
- `满帆`在每次抽牌与抽牌响应完成后重新读取占脉数量；牌库耗尽或占脉数量达到上限时停止。
- `换羽`、`乾坤袖`与`改途`都在移动前冻结排除集合。合法目标不足时少抽；抽到的新牌彼此可以同阶或同属性。
