# 林·成长流正式功法正文

> 状态：当前正式设计正文。本文共记录28门成长、培育与临时塑形支持：5门属于首批高牌正式池，另外23门见[扩展功法目标索引](./28-gongfa-expanded-formal-pool-index.md)。原`林·落叶归根`已删除；本批重做3门并新增4门，运行时状态见文末接入边界。
> 本文只定义具体功法内容；成长、炽气、有效真气值和入弃牌堆清理仍以[真气效果、重塑与异状](../combat/14-qi-effects-and-statuses.md)为准。

## 设计方向

成长流不建立脱离真气实例的“培养值”或其他角色资源，而是直接经营一张张普通真气已有的成长与炽气：

- 成长决定真气以后每个完整回合结束时的生长速度；
- 炽气记录本场战斗已经取得的培养成果，并随牌跨牌区保留；
- 玩家可以集中培养一张高值核心牌，也可以让多张真气共同生长；
- 培养成果可以保留并反复读取，也可以转移、分润或消耗后兑现为伤害、防御和其他公共资源；
- 真气打出后，成长会在实际进入弃牌堆时移除，因此回收路线需要明确保存、转移或重新建立成长；
- 牌型只记录当前效果最自然的投入，不为任何牌型预设固定职责、配额或上限。

## 公共读取口径

本文使用以下只读记号：

```text
G = 一张指定真气当前拥有的成长层数
Q = 一张指定真气当前拥有的炽气层数
R = max(0，当前有效真气值－当前基础真气值)
```

`G`、`Q`和`R`都从真实真气实例实时读取，不另行保存。`R`不仅包含炽气，也会自然读取强化、觉醒及其他当前生效的有效真气值变化；若枯气或其他降低使当前有效值不高于基础值，则该牌的`R`为0。

“转移成长／炽气”表示从来源牌移除指定层数，并给目标牌增加相同层数；整个操作不凭空增加被转移的层数。选择效果没有合法目标时不进行相应移除。

## 当前自然结构

当前内容自然形成三种可以互相转换、但不被规则写死的玩法：

- 集中成长与炽气，长期保留一张高值核心牌；
- 将成长分枝、让多张留手真气同步成熟；
- 打出培养牌，再通过重聚、回收或重新施加成长令其循环。

23门扩展功法当前分布为：高牌6门、对子7门、三条3门、顺子3门、炸弹4门。这个结果不构成配额；任何功法都可以在后续审计中迁移基础池，也可以继续直接增加新的核心或桥接功法。

跨蛊毒、抽弃、燃尽、连势、防御、反震和协同的已确认设计另见[跨系统桥接功法当前候选池](./27-gongfa-bridge-candidate-pool.md)。
