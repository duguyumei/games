# 林·成长流正式功法正文

> 状态：当前正式设计正文。本文共记录25门成长支持：5门属于首批高牌正式池，另外20门已经按[扩展正式功法索引](./28-gongfa-expanded-formal-pool-index.md)接入。
> 本文只定义具体功法内容；成长、炽气、有效真气值和入弃牌堆清理仍以[真气效果、重塑与异状](../combat/14-qi-effects-and-statuses.md)为准。

## 设计方向

成长流不建立脱离真气实例的“培养值”或其他角色资源，而是直接经营一张张普通真气已有的成长与炽气：

- 成长决定真气以后每个完整回合结束时的生长速度；
- 炽气记录本场战斗已经取得的培养成果，并随牌跨牌区保留；
- 玩家可以集中培养一张高值核心牌，也可以让多张真气共同生长；
- 培养成果可以保留并反复读取，也可以转移、分润或消耗后兑现为伤害、防御和其他公共资源；
- 真气打出后，成长会在实际进入弃牌堆时移除，因此回收路线需要明确保存、转移或重新建立成长；
- 牌型只记录当前效果最自然的投入，不为任何牌型预设固定职责、配额或上限。

## 公共读取口径

本文使用以下只读记号：

```text
G = 一张指定真气当前拥有的成长层数
Q = 一张指定真气当前拥有的炽气层数
R = max(0，当前有效真气值－当前基础真气值)
```

`G`、`Q`和`R`都从真实真气实例实时读取，不另行保存。`R`不仅包含炽气，也会自然读取强化、觉醒及其他当前生效的有效真气值变化；若枯气或其他降低使当前有效值不高于基础值，则该牌的`R`为0。

“转移成长／炽气”表示从来源牌移除指定层数，并给目标牌增加相同层数；整个操作不凭空增加被转移的层数。选择效果没有合法目标时不进行相应移除。

下表只说明它们如何支持成长流，正式效果仍以[高牌正式功法目录](./24-gongfa-high-card-pool.md)为唯一正文。

| 名称 | 当前作用 |
| --- | --- |
| **蕴林式** | 从弃牌堆回收普通真气，为已经培养后打出的牌提供循环入口。 |
| **聚林** | 使额外林牌获得重聚，并在林同气时培养牌库中的重聚牌。 |
| **林·培元** | 选择 1 张普通手牌获得 1 层成长，是稳定的单牌播种入口。 |
| **林·凝气** | 生成临时普通真气，为培养、转移和牌型重组提供新素材。 |
| **林·传功** | 让当前有效值已经高于基础值的普通手牌继续获得成长。 |

## 当前 20 门新增候选

`P`为本牌型组最终功法值。除特别说明外，选择效果没有合法目标时仍结算本门功法的即时伤害或防御。

| **林·催芽** | 对子 | 获得`floor(P/2)`点防御。选择我方1张剩余普通手牌，记录其成长层数`G`，使其获得1层成长；若`G>0`，再使其获得`G`层炽气。 |

## 当前自然结构

当前内容自然形成三种可以互相转换、但不被规则写死的玩法：

- 集中成长与炽气，长期保留一张高值核心牌；
- 将成长分枝、让多张留手真气同步成熟；
- 打出培养牌，再通过重聚、回收或重新施加成长令其循环。

20门新增候选当前暂定分布为：高牌5门、对子7门、三条3门、顺子2门、炸弹3门。这个结果不构成配额；任何功法都可以在后续审计中迁移基础池，也可以继续直接增加新的核心或桥接功法。

跨蛊毒、抽弃、燃尽、连势、防御、反震和协同的已确认设计另见[跨系统桥接功法当前候选池](./27-gongfa-bridge-candidate-pool.md)。

## 接入边界与观察项

- 本文20门新增内容均已有稳定ID、独立资源、正式池归属、AI语义与专项行为测试。
- 成长转移、炽气转移、平均分配和生成临时牌必须原子处理；目标或生成失败时不能先行扣除来源内容。
- `林·接木`与`林·万木归一`都只收集本组打出的普通真气，不收割其他剩余手牌；同组重触应重新读取当时仍存在的内容，但不能复用第一次已经移除的层数。
- `林·宿根`必须等待正常入堆清除原成长后再重新施加1层成长，不能暗中保留原层数。
- `林·根深`、`林·木秀`和`林·百木争荣`可以反复读取未消耗的培养成果；`林·四时轮转`可以大规模回收带炽气真气。这些属于当前有意保留的构筑收益，但需要在接入前进行数值与循环压力测试。
- 本批已经完成工程接入；成长、炽气与循环收益仍需持续实战观察，但不得据此改变本文正文。
