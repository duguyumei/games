# 林·蛊毒流正式功法正文

> 状态：当前目标设计正文。本文共记录22门蛊毒支持，其中“伏林”属于首批高牌正式池，其余21门见[扩展功法目标索引](./28-gongfa-expanded-formal-pool-index.md)。原`林·蛊壳`已从目标池删除，运行时资源将在本批实现时移除。
> 本文取代的是本轮讨论草稿，不取代[历史蛊毒归档](./21-gongfa-poison-pool.md)；烈毒、郁毒、蛊印、毒效倍率等旧接口仍然废弃。

## 设计方向

蛊毒首先是一条围绕真实毒牌运转的构筑路线，不为它新增“蛊印”“毒势”“蚕食”等角色资源。

- 给我方手牌或牌库施毒，补足自毒来源；
- 保留毒牌，由功法在结算时读取毒量或毒牌张数；
- 打出毒牌，立即承担毒伤并换取更高收益；
- 通过明确弃牌、藏回牌库、转移或立即触发调整风险；
- 通过林属性回收让带毒真气重新进入战斗循环；
- 给敌方施毒后，可以等待其自行打出，也可以用功法手动触发或集中爆发。

牌型不是预先分配的流派职责。下文的“暂定基础池”只记录当前效果最自然的出招投入，后续可以迁移；不为五个基础池设置固定数量，也不要求某个牌型只能启动、经营或终结。

## 公共读取口径

毒伤、毒状态和真气生命周期以[伤害、防御与对战结果](../combat/13-damage-defense-and-results.md)和[真气效果、重塑与异状](../combat/14-qi-effects-and-statuses.md)为准。

### 毒量与毒牌张数

对任意一方实时派生：

```text
手牌毒量 H = 手牌中带毒普通真气的当前有效真气值总和
牌库毒量 D = 牌库中带毒普通真气的当前有效真气值总和
总毒量 T = H + D
```

毒量不是可以独立获得、保存或消耗的角色资源。真气移动牌区、获得或清除毒，以及有效真气值变化时，查询结果随之变化。

毒牌张数与毒量同时公开，但只作为同一批真实毒牌的辅助结构信息。一张高值毒牌和多张低值毒牌可以被不同功法分别利用，不建立第二种角色资源。弃牌堆、待出区和已经消散的牌不计入上述毒量或张数。

界面建议显示：

```text
毒量：31
手牌：3张／22
牌库：2张／9
```

敌方只公开汇总数字，不因此展示其隐藏牌库中的具体真气。

### 出毒量

需要读取本次打出毒牌规模时，使用：

```text
出毒量 X = 本牌型组实际打出的全部带毒普通真气，在行动确认时冻结的当前有效真气值总和
```

真气进入待出区后不再属于手牌或牌库，因此不同时计入 `H`、`D` 或 `T`。主组、协同组与重新识别形成的新牌型组分别冻结自己的 `X`；同组重触复用原值。

### 令毒立即触发

“令一张带毒真气的毒立即触发”表示：该牌不移动牌区，其持有者受到等于该牌当前有效真气值的毒伤，随后清除该牌的毒。没有毒的牌不是合法目标。一次效果处理多张牌时，按文本规定的目标与顺序处理；明确写为同时触发时，先冻结全部目标及其数值。

## 当前 22 门支持

`P` 为本牌型组最终功法值。除特别说明外，随机目标不足时仍结算即时伤害或防御；选择效果没有合法目标时不进行该项选择。

## 当前自然偏向

现有候选暂时自然集中在高牌与对子：高牌投入低，容易保留其他毒牌；对子投入适中，可以同时经营留手与出毒。三条、顺子和炸弹已经出现适合它们当前投入规模的效果，但这只是本轮结果，不是后续设计约束。

当前目标分布为：高牌5门（含伏林）、对子7门、三条3门、顺子4门、炸弹3门。

当前已经确认的蛊毒与成长、抽弃、燃尽、连势、防御及协同桥接功法另见[跨系统桥接功法当前候选池](./27-gongfa-bridge-candidate-pool.md)。桥接功法直接追加，不占用本文22门核心支持的当前数量。

## 接入边界

- 除“伏林”外，其余21门保留功法继续使用稳定ID、独立资源、正式池归属、AI语义与专项行为测试；`three_forest_poison_shell`已经从资源、索引、奖励、AI与测试清单同步移除。
- 毒量应由牌区和真气状态实时查询，不保存为独立角色字段。
- `X`、随机展示、立即触发、批量净化后施毒、批量回收和同时毒爆都需要在接入时明确预览、冻结、等待选择、死亡中止与随机目标不足边界。
- “林·万蛊同寂”可能造成双方同时倒下；胜负仍服从公共同步倒下规则，不能由该功法私自决定。
- 除上述删除项外，本池已完成工程接入；数值与循环压力仍需持续实战观察，但不得据此改变本文正文。
