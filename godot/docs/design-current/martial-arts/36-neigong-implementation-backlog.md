# 待实现内功目录

> 状态：当前已经确认效果、但尚未进入生产内功池、修习随机池、运行时 JSON 或代码实现的内功清单。
>
> 本文是下列同名候选的当前唯一正文。`31-neigong-general-catalog.md` 中的同名旧文本仅作来源迁移记录；发生差异时以本文为准。本文不因当前底层尚未支持而缩窄设计，后续实现必须补充通用事件、查询、选择和效果端口。

## 1. 共通口径

- 下列内功只有装备时生效；正文明确写为本局常驻的进度在卸下后保留。
- “功法成功触发”读取公共 `technique_succeeded`，不区分正常、自动或调用功法；功法回响复用原功法冻结结果时，不重复支付或推进只应发生一次的成本。
- 功法在序列中会流动。指定某一门功法时绑定被选中的稳定功法来源实例并跟随其移动，不绑定整数位置；其他同名功法来源不视为该目标。
- 玩家正文统一使用“真气”。临时真气、虚无、异状和重塑按正文另行说明，不再使用含义不清的“普通真气”作为默认前缀。
- 除正文已经确认的限制外，不为历练收益增加统一上限。

## 2. 第一批经济内功

### 免费冥想

- **稳定 ID 候选**：`free_meditation_charge`
- **档位／原修习价格**：普通／4
- **效果**：每次完成一个节点后，获得 1 次免费冥想机会。免费机会不可叠加。使用免费冥想不增加付费冥想次数；若当前节点结算后尚未进行过付费冥想，免费机会使用后的下一次冥想费用仍为 5 点历练。
- **时点**：节点完整结算后把免费机会设置为 1；冥想正式提交时优先消费免费机会。

### 回流生息

- **稳定 ID 候选**：`technique_discard_recycle_experience`
- **档位／原修习价格**：普通／4
- **效果**：每当我方功法成功将 1 张真气从我方弃牌堆洗回我方牌库时，获得 1 点历练。
- **边界**：按实际洗回张数逐张触发。只有功法来源触发；内功、重塑、异状或公共规则造成的相同移动不触发。从弃牌堆返回手牌不触发。

### 遗忘增值

- **稳定 ID 候选**：`growing_forget_value`
- **档位／原修习价格**：普通／4
- **效果**：每次战斗结束后，本内功的遗忘所得本局常驻增加 3 点历练。
- **边界**：不设上限。卸下后停止增长，但既有累计保留；重新装备后继续增长。

### 连续牌型

- **稳定 ID 候选**：`repeated_exact_pattern_experience`
- **档位／原修习价格**：普通／4
- **效果**：每当连续 3 次成功行动的主牌型均为同一种精确牌型时，获得 5 点历练，然后重新开始计算连续次数。
- **边界**：第 3 次触发，第 4、5 次不触发；若没有中断，第 6 次形成新一组连续 3 次并再次触发。协同牌型不进入记录，其他精确牌型会清空当前连续记录。

### 节点所得

- **稳定 ID 候选**：`node_completion_experience`
- **档位／原修习价格**：普通／6
- **效果**：每完成一个节点，获得 4 点历练。
- **时点**：节点自身结果、奖励与功行生息均成功结算后，在路线阶段推进前处理。

### 随机功法

- **稳定 ID 候选**：`random_equipped_technique_bounty`
- **档位／原修习价格**：普通／4
- **效果**：战斗开始时，随机指定我方当前已装备的一门功法。本场战斗中，每当这门被指定的功法成功触发时，获得 4 点历练。
- **边界**：目标绑定被抽中的稳定功法来源实例并跟随其在序列中的流动，不绑定当时的位置。其他同名功法不触发。正常、自动与调用触发均可生效。

### 随机牌阶

- **稳定 ID 候选**：`random_rank_discard_bounty`
- **档位／原修习价格**：普通／4
- **效果**：战斗开始时，从 13 个牌阶中随机指定一个，本场不再改变。功法或内功效果每明确弃掉 1 张该牌阶的真气，获得 5 点历练。
- **边界**：随机池固定为 `A、2～10、J、Q、K`，不检查当前牌组或手牌。正常打出后进入弃牌堆不触发；一次弃掉多张合格真气时逐张触发。

### 十值留手

- **稳定 ID 候选**：`multiple_of_ten_cards_in_hand`
- **档位／原修习价格**：普通／6
- **效果**：每次成功行动完整结算后，手牌中每有 1 张当前有效真气值为 10 的正整数倍的真气，获得 1 点历练。
- **边界**：有效真气值 `10、20、30……` 均满足，0 不满足。同一张留手真气可以在多次行动结束时重复提供历练，不设上限。

## 3. 现有目录中迁入的历练内功

### 交易卡

- **稳定 ID 候选**：`trading_card`
- **档位**：罕见
- **效果**：每场战斗第一次由我方功法明确弃置我方真气时，将该次功法实际弃置的我方真气改为永久移出本局牌组，并获得 3 点历练。
- **边界**：判断第一次合格弃牌效果，不是第一张牌。若该次弃置多张，则全部永久移出，但整次只获得 3 点。内功、异状、重塑或其他来源弃牌不触发；被移出的真气不进入弃牌堆。

### 冲向月球

- **稳定 ID 候选**：`to_the_moon`
- **档位**：罕见
- **效果**：每次完成节点并结算功行生息后，额外获得 `floor(当前持有历练 / 5)` 点历练。
- **边界**：不设旧单次 5 点上限。额外所得不递归产生第二次功行，也不再次触发本内功。

### 卫星

- **稳定 ID 候选**：`satellite`
- **档位**：罕见
- **效果**：战斗胜利时，本局每成功触发过 1 门不同功法，获得 1 点历练。
- **边界**：按稳定功法 ID 去重；同名功法的不同来源只算一门。正常、自动和调用触发均可记录。获得本内功时读取本局此前的成功功法历史。

### 璞玉

- **稳定 ID 候选**：`rough_jade`
- **档位**：罕见
- **效果**：我方当前可视为山属性且拥有任意重塑的真气，每次参与数值计算时，获得 1 点历练。
- **边界**：本源、强化、印记、重塑·其他或临时重塑均满足；不要求永久重塑。回响重演该牌自身数值触发包时可以再次触发。

### 9霄云外

- **稳定 ID 候选**：`beyond_the_ninth_heaven`
- **档位**：罕见
- **效果**：战斗胜利时，我方本局牌组中每有 1 张牌阶为 9 的真气，获得 1 点历练。
- **边界**：读取牌阶 9，不读取有效真气值；不设上限。

### 斗牛

- **稳定 ID 候选**：`bull`
- **档位**：罕见
- **效果**：我方每次功法值的固定修正，增加等于当前持有历练的数值。
- **边界**：每个牌型组或调用功法正式冻结功法值时实时读取余额；获得或花费历练后立即更新。

### 无面小丑

- **稳定 ID 候选**：`faceless_joker`
- **档位**：普通
- **效果**：同一次功法、内功或其他效果明确弃置至少 2 张带有异状的我方真气时，获得 5 点历练。
- **边界**：按带异状的真气张数判断，不按异状总数判断。永久重塑不属于异状，临时重塑满足条件。一次效果只触发一次，不同效果可以分别触发。

### 穷途得药

- **稳定 ID 候选**：`desperate_medicine`
- **档位**：稀有
- **效果**：我方每次成功行动时，若触发前持有历练不超过 4 点，则尝试获得 1 个随机丹药，再获得 1 点历练。
- **边界**：没有空余消耗品栏位时只跳过丹药，仍获得历练。若战斗中再次降至 4 点或以下，可以再次触发。

### 毒中得历

- **稳定 ID 候选**：`poisoned_side_experience`
- **档位**：普通
- **效果**：每当任意一方的毒成功触发并完成毒伤结算时，获得 1 点历练；若中毒的一方是我方，额外获得 1 点历练。
- **边界**：只判断谁中毒，不判断毒由哪一方或什么行为施加、触发。敌方中毒获得 1 点，我方中毒获得 2 点。不设置每回合或每场上限。

### 烈势悟道

- **稳定 ID 候选**：`momentum_enlightenment`
- **档位**：罕见
- **效果**：战斗开始时令 `n=1`。每当我方连势第一次达到或超过 `10×n` 层时，获得 `n` 点历练，然后令 `n=n+1`；一次增加跨过多个阈值时依次结算。
- **边界**：连势降低不使 `n` 降低，重新达到已越过阈值不重复获得。每场重置 `n`，不设历练上限。

### 无影藏功

- **稳定 ID 候选**：`invisible_inner_skill`
- **档位**：稀有
- **效果**：装备期间每完成 1 场战斗，进度增加 1，最多 2 点。进度达到 2 的战斗结束时，随机选择另一门当前已装备内功，将无影藏功自身的效果永久改为该内功的可复制效果。
- **边界**：化影不获得、复制或删除内功；无影藏功仍占据原栏位，名称、档位、价格与遗忘所得不变。化影后原进度效果消失。复制类内功及不可复制效果不能成为目标；当时没有合法目标时保留 2 点进度，此后每场战斗结束时重新尝试。

## 4. 跨游戏原型扩展经济内功

### 空脉生财

- **稳定 ID 候选**：`empty_inner_slots_experience`
- **档位**：待定
- **效果**：战斗胜利时，战斗开始时每有 1 个空置的有效内功栏位，获得 2 点历练。
- **边界**：本内功自身占用一个栏位。容量与装备数量在战斗开始冻结。

### 余劲取利

- **稳定 ID 候选**：`overkill_experience`
- **档位**：待定
- **效果**：我方伤害击败敌人时，每有 10 点溢出伤害，获得 1 点历练。
- **边界**：溢出伤害等于终结伤害段穿过防御后本应造成的生命伤害减去敌人受击前剩余生命。普通伤害、真伤、毒伤和反震只要归因于我方均可触发。

### 化气得资

- **稳定 ID 候选**：`temporary_qi_generation_experience`
- **档位**：待定
- **效果**：每当我方功法、内功或真气效果在战斗中生成 1 张只持续本场的我方临时真气时，获得 3 点历练。
- **边界**：临时复制属于生成；抽牌、回收、洗回和移动已有真气不算。会正式加入本局牌组的永久真气不触发；敌方效果生成的临时真气不触发。

### 血财相济

- **稳定 ID 候选**：`experience_gain_life_recovery`
- **档位**：待定
- **效果**：每当我方获得历练时，恢复等于本次实际所得的生命。
- **边界**：生命已满时实际恢复为 0。被阻止而没有实际增加的历练不触发；恢复生命不递归产生历练。

### 存钱罐

- **稳定 ID 候选**：`progressive_node_savings`
- **档位**：待定
- **效果**：本内功的节点收益初始为 1 点历练。每完成一个节点，获得当前收益，然后令收益增加 1。每当我方实际花费历练时，将收益重置为 1。
- **边界**：免费购买、免费冥想和支付 0 点不重置。收益跨节点保留，不设上限。

### 断财炼气

- **稳定 ID 候选**：`experience_fueled_technique_power`
- **档位**：待定
- **效果**：装备期间，我方不能获得历练。每当我方功法即将成功触发时，若至少持有 1 点历练，消耗 1 点，使该次功法值增幅 +100%；历练不足时本内功不产生效果。
- **边界**：功法本身仍正常触发。正常、自动和调用功法分别支付；功法回响不重复支付。支付发生在启动确认后、最终功法值冻结前，事务失败时返还。

### 化烬得财

- **稳定 ID 候选**：`burned_qi_play_experience`
- **档位**：待定
- **效果**：每当我方成功打出 1 张拥有燃尽的真气时，获得 1 点历练。
- **边界**：明确弃掉燃尽真气不触发；同一张真气被洗回或回收后再次打出，可以再次触发。

### 净秽得财

- **稳定 ID 候选**：`cleansed_content_experience`
- **档位**：待定
- **效果**：每当我方真气受到净化时，净化每实际移除 1 项其他异状或临时重塑，获得 1 点历练。
- **边界**：按内容种类计算，不按炽气、枯气等层数计算；没有实际移除内容时不获得历练。

## 5. 手牌、牌库与真气生命周期内功

### 旁脉藏气

- **稳定 ID 候选**：`rightmost_qi_gains_extra_vein`
- **档位**：普通
- **效果**：每个完整回合开始完成正常补牌后，使我方最右侧手牌获得寄脉。
- **边界**：没有手牌时不触发；最右侧真气已经拥有寄脉时不改选其他真气。多个副本通常不会产生额外结果。

### 易手换气

- **稳定 ID 候选**：`hand_mulligan_cycle`
- **档位**：罕见
- **效果**：每个行动窗口开始时，可以将 1 张手牌放到牌库底，然后抽 1 张牌。
- **边界**：每个行动窗口每个副本提供一次选择。放回牌库不算明确弃置，也不触发弃牌和入堆效果。

### 空脉回潮

- **稳定 ID 候选**：`empty_hand_draw`
- **档位**：罕见
- **效果**：我方手牌实际从非 0 变为 0 张时，抽 3 张牌。
- **边界**：牌库不足时只抽实际数量；后续再次从非 0 变为 0 可以再次触发。

### 留气生华

- **稳定 ID 候选**：`leftmost_qi_gains_growth`
- **档位**：普通
- **效果**：每个完整回合结束时，使我方最左侧手牌获得 1 层成长。
- **边界**：没有手牌时不触发。新成长不追溯本回合已经完成的成长结算，从下一完整回合结束时开始产生炽气。

### 同阶相引

- **稳定 ID 候选**：`matching_rank_draw`
- **档位**：罕见
- **效果**：每当 1 张真气抽入手牌时，如果手牌中已经有另一张相同当前牌阶的真气，再抽 1 张牌。
- **边界**：J、Q、K 是不同牌阶。后续抽到的牌可以继续触发。

### 观脉知机

- **稳定 ID 候选**：`scry_top_deck`
- **档位**：稀有
- **效果**：每次正常补牌前，查看牌库顶 3 张；可以将其中任意张放到牌库底，剩余牌保持原顺序，然后进行正常补牌。
- **边界**：不直接增加抽牌数量，只改变抽牌顺序。

### 孤气回环

- **稳定 ID 候选**：`single_qi_cycle_and_resonance`
- **档位**：罕见
- **效果**：一次行动实际只打出 1 张真气时，同气槽 +1；该真气结算完成后若将要进入弃牌堆，改为放到我方牌库底。
- **边界**：临时真气可以触发。虚无真气仍消散，不能放回牌库底，但同气槽仍 +1。多个副本各自令同气槽 +1，不重复移动同一张牌。

### 退气归经

- **稳定 ID 候选**：`discard_to_deck_bottom`
- **档位**：稀有
- **效果**：我方真气因明确弃牌而离开手牌时，不进入弃牌堆，改为放到牌库底。
- **边界**：仍发送明确弃牌事实，但不发送实际入堆事实，因此不触发化丹印、重聚和其他入堆响应。正常打出仍进入弃牌堆。

### 万流归宗

- **稳定 ID 候选**：`once_per_battle_discard_recycle`
- **档位**：传奇
- **效果**：每场战斗一次；我方需要抽牌但牌库为空时，将我方全部弃牌堆洗回牌库，然后继续完成本次抽牌。
- **边界**：没有弃牌可以洗回时不消耗机会；成功洗回至少 1 张后机会耗尽。多个副本各自拥有一次机会。

### 化虚为实

- **稳定 ID 候选**：`solidify_hand_at_battle_end`
- **档位**：传奇
- **效果**：战斗结束时，固化我方手牌中的全部临时真气、异状和临时重塑。
- **边界**：手牌中的临时真气全部转化为永久真气并加入本局牌组；手牌中所有真气当前拥有的异状和临时重塑不在战斗结束时清除，改为写入本局真气状态并在后续战斗继续保留。只处理手牌。

### 炼气相承

- **稳定 ID 候选**：`reshape_inheritance_on_discard`
- **档位**：稀有
- **效果**：我方一张拥有任意重塑的真气实际进入弃牌堆后，从我方牌库中随机选择 1 张没有任何重塑的真气，使其获得来源真气全部重塑的临时版本。
- **边界**：来源重塑可以是永久或临时；来源不失去重塑。没有合格牌库目标时不触发。虚无真气不进入弃牌堆，因此不触发。

### 引风乱脉

- **稳定 ID 候选**：`persistent_effect_draw_enemy_bottom_discard`
- **档位**：罕见
- **效果**：本场战斗中，我方每累计通过效果抽到 5 张牌，明确弃置敌方牌库底 1 张真气，然后重新计数。
- **边界**：完整回合开始的正常补牌不计入。功法、内功、真气效果、风引及其他明确抽牌均计入；计数跨行动和回合保留。一次抽到多张时逐张累计，超过 5 的余数进入下一轮计数。敌方牌库为空时仍消耗本次 5 张计数。

### 先声夺气
