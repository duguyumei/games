# 待实现内功目录

> 状态：当前共 166 门已经确认效果、但尚未进入生产内功池、修习随机池、运行时 JSON 或代码实现的内功清单。
>
> 本文是下列同名候选的当前唯一正文。`31-neigong-general-catalog.md` 中的同名旧文本仅作来源迁移记录；发生差异时以本文为准。本文不因当前底层尚未支持而缩窄设计，后续实现必须补充通用事件、查询、选择和效果端口。

## 1. 共通口径

- 下列内功只有装备时生效；正文明确写为本局常驻的进度在卸下后保留。
- “功法成功触发”读取公共 `technique_succeeded`，不区分正常、自动或调用功法；功法回响复用原功法冻结结果时，不重复支付或推进只应发生一次的成本。
- 功法在序列中会流动。指定某一门功法时绑定被选中的稳定功法来源实例并跟随其移动，不绑定整数位置；其他同名功法来源不视为该目标。
- 每个精确牌型的功法槽位是容量，实际循环序列只包含已经装备或成功生成的功法。玩家必须为每种精确牌型至少装备一门功法，但可以保留空余槽位；战斗临时功法必须占用空余槽位，没有容量时不生成。
- 玩家正文统一使用“真气”。临时真气、虚无、异状和重塑按正文另行说明，不再使用含义不清的“普通真气”作为默认前缀。
- 除正文已经确认的限制外，不为历练收益增加统一上限。

## 2. 第一批经济内功

### 免费冥想

- **稳定 ID 候选**：`free_meditation_charge`
- **档位／原修习价格**：普通／4
- **效果**：每次完成一个节点后，获得 1 次免费冥想机会。免费机会不可叠加。使用免费冥想不增加付费冥想次数；若当前节点结算后尚未进行过付费冥想，免费机会使用后的下一次冥想费用仍为 5 点历练。
- **时点**：节点完整结算后把免费机会设置为 1；冥想正式提交时优先消费免费机会。

### 回流生息

- **稳定 ID 候选**：`technique_discard_recycle_experience`
- **档位／原修习价格**：普通／4
- **效果**：每当我方功法成功将 1 张真气从我方弃牌堆洗回我方牌库时，获得 1 点历练。
- **边界**：按实际洗回张数逐张触发。只有功法来源触发；内功、重塑、异状或公共规则造成的相同移动不触发。从弃牌堆返回手牌不触发。

### 遗忘增值

- **稳定 ID 候选**：`growing_forget_value`
- **档位／原修习价格**：普通／4
- **效果**：每次战斗结束后，本内功的遗忘所得本局常驻增加 3 点历练。
- **边界**：不设上限。卸下后停止增长，但既有累计保留；重新装备后继续增长。

### 连续牌型

- **稳定 ID 候选**：`repeated_exact_pattern_experience`
- **档位／原修习价格**：普通／4
- **效果**：每当连续 3 次成功行动的主牌型均为同一种精确牌型时，获得 5 点历练，然后重新开始计算连续次数。
- **边界**：第 3 次触发，第 4、5 次不触发；若没有中断，第 6 次形成新一组连续 3 次并再次触发。协同牌型不进入记录，其他精确牌型会清空当前连续记录。

### 节点所得

- **稳定 ID 候选**：`node_completion_experience`
- **档位／原修习价格**：普通／6
- **效果**：每完成一个节点，获得 4 点历练。
- **时点**：节点自身结果、奖励与功行生息均成功结算后，在路线阶段推进前处理。

### 随机功法

- **稳定 ID 候选**：`random_equipped_technique_bounty`
- **档位／原修习价格**：普通／4
- **效果**：战斗开始时，随机指定我方当前已装备的一门功法。本场战斗中，每当这门被指定的功法成功触发时，获得 4 点历练。
- **边界**：目标绑定被抽中的稳定功法来源实例并跟随其在序列中的流动，不绑定当时的位置。其他同名功法不触发。正常、自动与调用触发均可生效。

### 随机牌阶

- **稳定 ID 候选**：`random_rank_discard_bounty`
- **档位／原修习价格**：普通／4
- **效果**：战斗开始时，从 13 个牌阶中随机指定一个，本场不再改变。功法或内功效果每明确弃掉 1 张该牌阶的真气，获得 5 点历练。
- **边界**：随机池固定为 `A、2～10、J、Q、K`，不检查当前牌组或手牌。正常打出后进入弃牌堆不触发；一次弃掉多张合格真气时逐张触发。

### 十值留手

- **稳定 ID 候选**：`multiple_of_ten_cards_in_hand`
- **档位／原修习价格**：普通／6
- **效果**：每次成功行动完整结算后，手牌中每有 1 张当前有效真气值为 10 的正整数倍的真气，获得 1 点历练。
- **边界**：有效真气值 `10、20、30……` 均满足，0 不满足。同一张留手真气可以在多次行动结束时重复提供历练，不设上限。

## 3. 现有目录中迁入的历练内功

### 交易卡

- **稳定 ID 候选**：`trading_card`
- **档位**：罕见
- **效果**：每场战斗第一次由我方功法明确弃置我方真气时，将该次功法实际弃置的我方真气改为永久移出本局牌组，并获得 3 点历练。
- **边界**：判断第一次合格弃牌效果，不是第一张牌。若该次弃置多张，则全部永久移出，但整次只获得 3 点。内功、异状、重塑或其他来源弃牌不触发；被移出的真气不进入弃牌堆。

### 冲向月球

- **稳定 ID 候选**：`to_the_moon`
- **档位**：罕见
- **效果**：每次完成节点并结算功行生息后，额外获得 `floor(当前持有历练 / 5)` 点历练。
- **边界**：不设旧单次 5 点上限。额外所得不递归产生第二次功行，也不再次触发本内功。

### 卫星

- **稳定 ID 候选**：`satellite`
- **档位**：罕见
- **效果**：战斗胜利时，本局每成功触发过 1 门不同功法，获得 1 点历练。
- **边界**：按稳定功法 ID 去重；同名功法的不同来源只算一门。正常、自动和调用触发均可记录。获得本内功时读取本局此前的成功功法历史。

### 璞玉

- **稳定 ID 候选**：`rough_jade`
- **档位**：罕见
- **效果**：我方当前可视为山属性且拥有任意重塑的真气，每次参与数值计算时，获得 1 点历练。
- **边界**：本源、强化、印记、重塑·其他或临时重塑均满足；不要求永久重塑。回响重演该牌自身数值触发包时可以再次触发。

### 9霄云外

- **稳定 ID 候选**：`beyond_the_ninth_heaven`
- **档位**：罕见
- **效果**：战斗胜利时，我方本局牌组中每有 1 张牌阶为 9 的真气，获得 1 点历练。
- **边界**：读取牌阶 9，不读取有效真气值；不设上限。

### 斗牛

- **稳定 ID 候选**：`bull`
- **档位**：罕见
- **效果**：我方每次功法值的固定修正，增加等于当前持有历练的数值。
- **边界**：每个牌型组或调用功法正式冻结功法值时实时读取余额；获得或花费历练后立即更新。

### 无面小丑

- **稳定 ID 候选**：`faceless_joker`
- **档位**：普通
- **效果**：同一次功法、内功或其他效果明确弃置至少 2 张带有异状的我方真气时，获得 5 点历练。
- **边界**：按带异状的真气张数判断，不按异状总数判断。永久重塑不属于异状，临时重塑满足条件。一次效果只触发一次，不同效果可以分别触发。

### 穷途得药

- **稳定 ID 候选**：`desperate_medicine`
- **档位**：稀有
- **效果**：我方每次成功行动时，若触发前持有历练不超过 4 点，则尝试获得 1 个随机丹药，再获得 1 点历练。
- **边界**：没有空余消耗品栏位时只跳过丹药，仍获得历练。若战斗中再次降至 4 点或以下，可以再次触发。

### 毒中得历

- **稳定 ID 候选**：`poisoned_side_experience`
- **档位**：普通
- **效果**：每当任意一方的毒成功触发并完成毒伤结算时，获得 1 点历练；若中毒的一方是我方，额外获得 1 点历练。
- **边界**：只判断谁中毒，不判断毒由哪一方或什么行为施加、触发。敌方中毒获得 1 点，我方中毒获得 2 点。不设置每回合或每场上限。

### 烈势悟道

- **稳定 ID 候选**：`momentum_enlightenment`
- **档位**：罕见
- **效果**：战斗开始时令 `n=1`。每当我方连势第一次达到或超过 `10×n` 层时，获得 `n` 点历练，然后令 `n=n+1`；一次增加跨过多个阈值时依次结算。
- **边界**：连势降低不使 `n` 降低，重新达到已越过阈值不重复获得。每场重置 `n`，不设历练上限。

### 无影藏功

- **稳定 ID 候选**：`invisible_inner_skill`
- **档位**：稀有
- **效果**：装备期间每完成 1 场战斗，进度增加 1，最多 2 点。进度达到 2 的战斗结束时，随机选择另一门当前已装备内功，将无影藏功自身的效果永久改为该内功的可复制效果。
- **边界**：化影不获得、复制或删除内功；无影藏功仍占据原栏位，名称、档位、价格与遗忘所得不变。化影后原进度效果消失。复制类内功及不可复制效果不能成为目标；当时没有合法目标时保留 2 点进度，此后每场战斗结束时重新尝试。

## 4. 跨游戏原型扩展经济内功

### 空脉生财

- **稳定 ID 候选**：`empty_inner_slots_experience`
- **档位**：待定
- **效果**：战斗胜利时，战斗开始时每有 1 个空置的有效内功栏位，获得 2 点历练。
- **边界**：本内功自身占用一个栏位。容量与装备数量在战斗开始冻结。

### 余劲取利

- **稳定 ID 候选**：`overkill_experience`
- **档位**：待定
- **效果**：我方伤害击败敌人时，每有 10 点溢出伤害，获得 1 点历练。
- **边界**：溢出伤害等于终结伤害段穿过防御后本应造成的生命伤害减去敌人受击前剩余生命。普通伤害、真伤、毒伤和反震只要归因于我方均可触发。

### 化气得资

- **稳定 ID 候选**：`temporary_qi_generation_experience`
- **档位**：待定
- **效果**：每当我方功法、内功或真气效果在战斗中生成 1 张只持续本场的我方临时真气时，获得 3 点历练。
- **边界**：临时复制属于生成；抽牌、回收、洗回和移动已有真气不算。会正式加入本局牌组的永久真气不触发；敌方效果生成的临时真气不触发。

### 血财相济

- **稳定 ID 候选**：`experience_gain_life_recovery`
- **档位**：待定
- **效果**：每当我方获得历练时，恢复等于本次实际所得的生命。
- **边界**：生命已满时实际恢复为 0。被阻止而没有实际增加的历练不触发；恢复生命不递归产生历练。

### 存钱罐

- **稳定 ID 候选**：`progressive_node_savings`
- **档位**：待定
- **效果**：本内功的节点收益初始为 1 点历练。每完成一个节点，获得当前收益，然后令收益增加 1。每当我方实际花费历练时，将收益重置为 1。
- **边界**：免费购买、免费冥想和支付 0 点不重置。收益跨节点保留，不设上限。

### 断财炼气

- **稳定 ID 候选**：`experience_fueled_technique_power`
- **档位**：待定
- **效果**：装备期间，我方不能获得历练。每当我方功法即将成功触发时，若至少持有 1 点历练，消耗 1 点，使该次功法值增幅 +100%；历练不足时本内功不产生效果。
- **边界**：功法本身仍正常触发。正常、自动和调用功法分别支付；功法回响不重复支付。支付发生在启动确认后、最终功法值冻结前，事务失败时返还。

### 化烬得财

- **稳定 ID 候选**：`burned_qi_play_experience`
- **档位**：待定
- **效果**：每当我方成功打出 1 张拥有燃尽的真气时，获得 1 点历练。
- **边界**：明确弃掉燃尽真气不触发；同一张真气被洗回或回收后再次打出，可以再次触发。

### 净秽得财

- **稳定 ID 候选**：`cleansed_content_experience`
- **档位**：待定
- **效果**：每当我方真气受到净化时，净化每实际移除 1 项其他异状或临时重塑，获得 1 点历练。
- **边界**：按内容种类计算，不按炽气、枯气等层数计算；没有实际移除内容时不获得历练。

## 5. 手牌、牌库与真气生命周期内功

### 旁脉藏气

- **稳定 ID 候选**：`rightmost_qi_gains_extra_vein`
- **档位**：普通
- **效果**：每个完整回合开始完成正常补牌后，使我方最右侧手牌获得寄脉。
- **边界**：没有手牌时不触发；最右侧真气已经拥有寄脉时不改选其他真气。多个副本通常不会产生额外结果。

### 易手换气

- **稳定 ID 候选**：`hand_mulligan_cycle`
- **档位**：罕见
- **效果**：每个行动窗口开始时，可以将 1 张手牌放到牌库底，然后抽 1 张牌。
- **边界**：每个行动窗口每个副本提供一次选择。放回牌库不算明确弃置，也不触发弃牌和入堆效果。

### 空脉回潮

- **稳定 ID 候选**：`empty_hand_draw`
- **档位**：罕见
- **效果**：我方手牌实际从非 0 变为 0 张时，抽 3 张牌。
- **边界**：牌库不足时只抽实际数量；后续再次从非 0 变为 0 可以再次触发。

### 留气生华

- **稳定 ID 候选**：`leftmost_qi_gains_growth`
- **档位**：普通
- **效果**：每个完整回合结束时，使我方最左侧手牌获得 1 层成长。
- **边界**：没有手牌时不触发。新成长不追溯本回合已经完成的成长结算，从下一完整回合结束时开始产生炽气。

### 同阶相引

- **稳定 ID 候选**：`matching_rank_draw`
- **档位**：罕见
- **效果**：每当 1 张真气抽入手牌时，如果手牌中已经有另一张相同当前牌阶的真气，再抽 1 张牌。
- **边界**：J、Q、K 是不同牌阶。后续抽到的牌可以继续触发。

### 观脉知机

- **稳定 ID 候选**：`scry_top_deck`
- **档位**：稀有
- **效果**：每次正常补牌前，查看牌库顶 3 张；可以将其中任意张放到牌库底，剩余牌保持原顺序，然后进行正常补牌。
- **边界**：不直接增加抽牌数量，只改变抽牌顺序。

### 孤气回环

- **稳定 ID 候选**：`single_qi_cycle_and_resonance`
- **档位**：罕见
- **效果**：一次行动实际只打出 1 张真气时，同气槽 +1；该真气结算完成后若将要进入弃牌堆，改为放到我方牌库底。
- **边界**：临时真气可以触发。虚无真气仍消散，不能放回牌库底，但同气槽仍 +1。多个副本各自令同气槽 +1，不重复移动同一张牌。

### 退气归经

- **稳定 ID 候选**：`discard_to_deck_bottom`
- **档位**：稀有
- **效果**：我方真气因明确弃牌而离开手牌时，不进入弃牌堆，改为放到牌库底。
- **边界**：仍发送明确弃牌事实，但不发送实际入堆事实，因此不触发化丹印、重聚和其他入堆响应。正常打出仍进入弃牌堆。

### 万流归宗

- **稳定 ID 候选**：`once_per_battle_discard_recycle`
- **档位**：传奇
- **效果**：每场战斗一次；我方需要抽牌但牌库为空时，将我方全部弃牌堆洗回牌库，然后继续完成本次抽牌。
- **边界**：没有弃牌可以洗回时不消耗机会；成功洗回至少 1 张后机会耗尽。多个副本各自拥有一次机会。

### 化虚为实

- **稳定 ID 候选**：`solidify_hand_at_battle_end`
- **档位**：传奇
- **效果**：战斗结束时，固化我方手牌中的全部临时真气、异状和临时重塑。
- **边界**：手牌中的临时真气全部转化为永久真气并加入本局牌组；手牌中所有真气当前拥有的异状和临时重塑不在战斗结束时清除，改为写入本局真气状态并在后续战斗继续保留。只处理手牌。

### 炼气相承

- **稳定 ID 候选**：`reshape_inheritance_on_discard`
- **档位**：稀有
- **效果**：我方一张拥有任意重塑的真气实际进入弃牌堆后，从我方牌库中随机选择 1 张没有任何重塑的真气，使其获得来源真气全部重塑的临时版本。
- **边界**：来源重塑可以是永久或临时；来源不失去重塑。没有合格牌库目标时不触发。虚无真气不进入弃牌堆，因此不触发。

### 引风乱脉

- **稳定 ID 候选**：`persistent_effect_draw_enemy_bottom_discard`
- **档位**：罕见
- **效果**：本场战斗中，我方每累计通过效果抽到 5 张牌，明确弃置敌方牌库底 1 张真气，然后重新计数。

## 8. 特殊内功

本节的“复制内功效果”只复制目标内功的可复制规则正文，不获得、删除或复制内功本体，也不复制名称、档位、价格与遗忘所得。复制者在自己的装备顺序位置作为独立稳定来源执行，代价与负面效果一并复制；需要计数时使用复制者自己的独立计数器。复制类内功、改变全局结算顺序的效果及正文明确不可复制的效果不能成为复制目标，复制效果不能建立复制链或循环。

### 左右互搏

- **稳定 ID 候选**：`copy_left_adjacent_inner_skill`
- **档位**：传奇
- **自然倾向**：内功复制、栏位排列
- **效果**：实时复制左侧相邻已装备内功的可复制效果。
- **时点**：复制目标拥有的全部触发、生命周期和只读查询时点；复制效果在左右互搏自身的装备顺序位置结算。
- **边界**：左侧为空、目标被永久移出装备或目标效果不可复制时不生效。目标临时压制期间只停止目标自身建立新执行，不自动压制左右互搏复制出的独立来源。内功顺序改变后实时更换复制目标。多个副本分别复制各自当前左侧目标。左右互搏不可被复制。

## 11. 山·阵势与壁垒内功

本节围绕山属性、出牌结构、防御、格挡、卸力、反震、邀战与防御自然衰减建立持续运转规则。下列“格挡／卸力”与“消耗真气”是本批内容确认需要的通用底层能力；在本批进入生产前，应同步写入对应战斗权威文档并迁移受影响的现有功法正文，不能仅作为单门内功的私有定义实现。

#### 待实现公共规则：格挡与卸力

- **格挡**：取消一次敌方直接攻击，不比较该攻击的伤害数值。格挡来源仍可以拥有手牌数量等非伤害数值条件；条件不满足时不参与本次攻击，也不消耗。
- **卸力 N**：敌方直接攻击到来时，按稳定来源顺序检查并消耗该次卸力。若攻击伤害不高于 `N`，取消该攻击；若攻击伤害高于 `N`，卸力仍被消耗，但不取消攻击，继续检查后续卸力或格挡。
- 同一个攻击段先依次检查全部卸力，再检查格挡，最后才进入防御与生命结算。例如同时拥有“卸力 10”和“格挡 1 次”时，9 点攻击由卸力取消；20 点攻击先消耗并击穿卸力，再由格挡取消。
- 格挡与卸力均只处理敌方直接攻击，包括普通伤害与允许格挡的真伤；不能处理毒伤、反震、燃命、自毒或其他非直接攻击生命变化。
- 玩家正文中的“格挡成功”只指格挡取消攻击，“卸力成功”只指卸力取消攻击；需要同时监听两者时必须明确写作“格挡或卸力成功”。底层应提供统一的攻击取消事实及 `block`／`deflection` 子类型，并另外提交卸力被击穿和消费的结果。
- 正文未另写持续时间的格挡与卸力，均沿用公共格挡来源的默认到期时点。多个卸力按稳定来源与 Invocation 顺序检查，不能按数值大小自动重排。

#### 待实现公共规则：消耗真气

- **消耗真气**：将真气作为效果代价移出当前战斗，战斗结束后按原归属返回本局牌组。底层可以复用消散牌区事务，但必须携带稳定 `cause=cost` 并提交逐张消耗事实。
- 消耗的真气不进入弃牌堆，不触发明确弃牌或实际入堆响应。虚无自动消散、敌方强制消散、正常打出、明确弃牌、战斗结束清理和永久移出本局牌组均不属于消耗。

## 12. 林·真气培育与生命周期内功

本节围绕林属性、成长、炽气、毒、净化、临时重塑、消耗、入堆、回收与跨阵营牌区转移建立持续规则。林的重点是让同一张真气在多种状态和牌区之间改变用途，而不是把抽牌、弃牌或固定数值收益换一种属性名称。

当前正式功法池没有使用“燃命”的功法。该术语只存在于公共规则预留、旧火功法归档和历史内功目录；后续实现不得把“公共术语仍存在”误判为当前已有正式内容。若未来重新加入燃命，它仍是生命代价，不属于伤害，不能被万木代命、余垣护命或其他伤害免疫取消。

#### 待实现公共规则：燃尽改为减益

- `燃尽` 从标记分类迁移到减益分类，既有效果保持不变：此真气最终有效真气值为 0，覆盖此前全部有效真气值增减与倍乘；不改变牌阶、基础真气值、基础属性、重塑、其他异状、牌型识别或同气身份。
- 燃尽重复施加不叠加；可以被净化或被效果明确移除；打出、抽牌、明确弃牌、洗回和实际进入弃牌堆均不自动移除，战斗结束时移除。
- 所有按异状类别筛选“减益”的 ConditionSpec、目标查询、净化结果、AI 语义和玩家说明都必须把燃尽视为减益；现有按稳定内容 ID 读取燃尽牌的功法行为不因此改变。

#### 待实现公共增益：焕发

- `焕发` 属于不叠层的增益：此真气最终有效真气值 ×2。再次施加焕发不产生额外倍乘。
- 有效真气值先完成基础值、牌阶、强化、觉醒、炽气、枯气及其他合格增减与倍乘，再应用焕发 ×2；燃尽最后覆盖为 0。因此同一张真气同时拥有焕发与燃尽时，最终有效真气值仍为 0。
- 焕发改变所有正式读取当前有效真气值的结果，包括真气贡献、毒量、毒伤和其他明确查询；回响的两遍数值包分别读取并应用焕发，不能把第一遍结果继续交给第二遍复合。
- 焕发可以被净化或被效果明确移除；跨牌区保留，战斗结束时移除。它不是层数资源，也不因打出、弃置、洗回或实际入堆自动移除。
- 后续实现必须为焕发提供通用异状定义、有效真气值计算阶段、目标与 ConditionSpec 支持、净化结果、事件、预览、AI 投影和界面说明，不能在单门内功中按 ID 特判倍乘。

## 13. 火·功法运行与燃尽内功

本节围绕功法序列、回响、调用、自动触发、临时功法、追击、蓄力、燃尽、炽气、同气槽、连势和破防建立持续规则。功法明面没有属性分类，因此下列效果不读取“火属性功法”；火只是这些内功的自然设计倾向。

#### 待实现公共规则：连势上限

- 基础连势上限等于战斗开始时我方初始牌库中的真气数量，并在起手抽牌及任何战斗效果发生前冻结。
- 起手抽牌、战斗临时真气、消耗、消散或战斗中永久移出真气均不追溯改变基础上限。内功和物品可以通过纯查询修改有效上限，多个固定修正相加。
- 所有连势写入统一限制在`0～有效上限`。达到上限后的无效增加不算实际改变，不能借此跳过功法结束后的连势清空。
- 继续沿用当前连势保留规则：成功功法读取连势快照；该功法及其回响实际增加或消耗过连势时保留剩余值，否则在功法及其回响结束后清空。连势不改为全额消费资源，也不改为完整回合结束统一清空。

#### 待实现公共能力：蓄力累计值

- 蓄力仍是具体功法的来源标识，不新增角色级蓄力资源。蓄力功法必须声明当前是否正在蓄力，以及一个用于最终主要结算的公开整数累计值。
- 通用查询可以枚举正在蓄力且拥有累计值的功法实例，通用写端口可以修改该值；查询、预览和 AI 评估不能推进倒计时或写入数值。
- 当前三门正式目标分别为风·长风蓄海的蓄风值、火·三劫悬炉的`L`、山·悬岳待敌的当前累计`Z`。临时功法副本分别保存自己的蓄力状态与累计值。

#### 待实现公共能力：追击完成事件

- 追击统一使用攻击段类型`chase`并复用正式伤害事务。追击完成事件公开伤害类型、请求值、防御损失、生命损失、来源、行动令牌与追击令牌。
- 旧`source_kind`标签、专用多段追击字段和功法 ID 不能形成平行追击定义。相同追击令牌只能推进一次计数；查询、预览和 AI 评估不发送追击完成事件。

### 护焰周天

- **稳定 ID 候选**：`damage_builds_ember_shield`
- **档位**：传奇
- **自然倾向**：直接伤害缓冲、功法伤害循环
- **效果**：战斗开始时获得 20 层护焰，最多 40 层。敌方直接攻击即将减少我方生命时，每消耗 1 层护焰，减少 1 点生命损失。我方功法每累计使敌方防御与生命合计减少 5 点，获得 1 层护焰。
- **边界**：护焰是本内功的独立战斗计数器。格挡或卸力已经取消的攻击、毒伤、反震、燃命和其他生命代价不消耗护焰。功法、功法回响、自动与调用功法造成的实际防御和生命损失均可累计；追击只有来源仍属于该功法明确产生的攻击段时才计入。每跨过一个完整 5 点阈值获得 1 层并保留余数。多个副本独立计数、分别拥有层数并按 Invocation 顺序减伤。
- **需要的通用底层能力**：敌方直接攻击生命写入前减量、按功法来源累计实际防御与生命损失，以及有上限的来源级战斗计数器。

## 15. 实现改动总清单

本节集中记录本目录全部已经确认、但尚未完成的公共规则和工程改动。实现任务不得只逐门装配内功而遗漏本节；完成某项后，应同时更新权威文档、内容状态、专项测试与本清单状态。下列文件名只表示当前已知落点，实际重构可以移动职责，但不能把规则重新写成按内功或功法 ID 分支。

#### A. 功法槽容量、配装与心得

- 永久数据继续保存每个精确牌型的`slot_count`与`sequence`，但校验由`sequence.size()==slot_count`改为`slot_count>=1`且`1<=sequence.size()<=slot_count`；序列中不保存空值，差额就是空余功法槽。
- 每个精确牌型必须至少装备一门功法。卸下、遗忘、归墟、容量降低和完整配装提交都必须保持该约束；不得随机删除超容量功法，必须由玩家提交合法调整。
- 心得基础令槽位容量`+1`并把随机所得功法加入本局功法库，不自动装备。单个精确牌型槽位容量上限为 9；物品“望远镜”通过统一查询把单次心得增量改为`+2`。没有合格新功法时仍增加容量，不跨池抽取，也不使用散招／守招强制填槽。
- `GrowthInventory`、`TechniqueLoadoutPolicy`、`HandTechniqueLoadoutDTO`、`RunBuildQueryService`、`RunProgressSnapshot`、`RunSaveData`和对应 DTO／校验器必须统一采用新不等式；当前“序列必须填满槽位”的错误信息与断言全部删除。
- `GainInsightConsumableHandler`、`RunConsumableUseContext`、`ConsumableUseService`和战斗内兼容心得入口必须把“增加容量”“获得功法”“装备功法”拆为三个事实；失败回滚不能重新把所得功法塞入序列。
- 配装 UI 显示每种牌型的`已装备数量/槽位容量`与空余槽位，允许玩家从本局功法库装备、卸下、移动和排序，但禁止清空某个牌型。
- 存档兼容不提高 schema 时，旧存档中已填满的序列按原样合法恢复；新存档允许空余容量。恢复、深复制、校验和战斗装配不得自动补功法。
- 重点现有代码落点：`growth_inventory.gd`、`technique_loadout_policy.gd`、`hand_technique_loadout_dto.gd`、`run_build_query_service.gd`、`run_save_data.gd`、`gain_insight_consumable_handler.gd`、`run_consumable_use_context.gd`、`consumable_use_service.gd`与功法配装 UI。

#### B. 战斗临时功法

- `TechniqueSequenceBook`必须同时读取各牌型冻结槽位容量与当前永久／临时占用量。生成临时功法前查询空余容量，不再通过`insert_temporary_slots()`无上限新增槽位。
- 用通用`generate_temporary_techniques`能力取代内容操作码`insert_technique_slots`：声明来源功法、目标牌型、份数、插入位置、来源共享模式和批次原子策略，并返回逐门成功／失败回执。
- 默认批次按目标牌型、Invocation和份数的稳定顺序逐门尝试；容量不足只令后续目标失败，正文要求整批原子时才整体回滚。随机插入位置必须在正式确认时冻结，等待选择恢复不能重掷。
- 临时功法占用现有容量，但仍拥有独立`slot_instance_id`、来源标识、插入序号、触发历史和计数器。`slot_instance_id`表示稳定执行身份，不代表新容量。
- 战斗结束删除全部临时功法并释放占用；不写回永久序列或功法库，不重复提供原功法的 run 范围装备收益。
- 新增一次`temporary_technique_generated`已提交事件，至少公开宿主牌型、功法 ID、稳定实例 ID、来源实例、插入位置、生成批次令牌与剩余容量；容量不足的尝试不发送成功事件。
- `BattleSetupService`、`TechniqueSequenceBook`、`TechniqueSequenceEffectHandler`、`TechniqueInvocationService`、`SourceMarkerAddressResolver`、快照／恢复、内容校验、AI 投影和序列 UI 必须读取同一事实源。
- 正式内容同步：火·万法传薪改为只向其余七种牌型的空余槽位生成临时副本；演法成章改为消耗本牌型一次首次机会并尝试占用空余槽位；临诀燃灯监听临时功法实际成功触发，不监听失败尝试。

#### C. 功法实例、槽位容量与标记身份

- 空余槽位不能成为标记、随机目标、回响目标、成功来源或 Invocation；只有实际装备或成功生成的功法实例进入这些查询。
- 首章立意标记初始序列第一门实际功法；群法归型按初始实际装备功法数量统计，不按槽位容量；应机复响只随机实际功法；双位同鸣按不同稳定功法实例判断。
- 普通功法重复配装不再由内功修改。待实现物品“三才并位”通过`technique_loadout_copy_limit_query`把普通功法的全局装配次数上限改为 3，但不增加任何精确牌型的槽位容量；配装前仍须检查目标牌型空余容量。
- 永久功法 run 标识绑定不随战斗位置变化的永久功法来源；临时功法默认使用独立 battle 标识，`share_origin`只共享明确声明的原来源读写，不能复制永久装备收益。

#### D. 连势上限与既有清空规则

- 战斗建立时，在起手抽牌和任何战斗效果前冻结“初始牌库真气数量”，作为基础连势上限。临时真气、抽牌、消耗、消散和战斗内移出不追溯修改基础值。
- 新增`momentum_cap_query`只读整数查询，从基础上限合并内功、物品和其他来源固定修正；查询错误时正式写入失败关闭，预览显示有效上限及来源明细。
- `BattleSide.write_momentum`及所有端口统一把结果限制在`0～有效上限`，回执公开请求值、上限、实际前后值、实际变化量与是否被截断。达到上限后的无效增加不算改变。
- `BattleSideSnapshot`、战斗快照／恢复、AI 状态、预览、日志和 UI 同时公开当前连势与有效上限；恢复后不能用当前牌库数量重新计算已经冻结的基础上限。
- 保留现有规则：功法及其回响实际增加或消耗过连势才保留剩余值，否则结算后清空。不得改为完整回合结束清空，也不得把所有连势全额消费。
- 广炉容火通过上限查询每副本`+20`；开炉蓄势和五运生势仍通过统一`write_momentum`写入并受上限限制。

#### E. 蓄力累计值

- `TechniqueDefinition`或统一来源标识元数据新增通用蓄力声明：是否正在蓄力、主要累计值 marker、公开显示名和允许的写操作。不得建立按三门现有功法 ID 判断的蓄力管理器。
- 新增枚举“当前正在蓄力且拥有主要累计值的功法实例”的只读查询，以及通过通用来源标识端口增加、减少、设置累计值的效果能力。
- 风·长风蓄海声明蓄风值，火·三劫悬炉声明`L`，山·悬岳待敌声明当前累计`Z`；不修改各自倒计时、观察窗口和最终公式。
- 伏火延烧在完整回合结束时枚举合格实例并逐个`+10`；不缩短倒计时、不立即自动触发。临时功法副本分别保存累计值。
- 查询、预览、AI 候选和 UI 展示只读，不得推进倒计时、消费记录或增加累计值。

#### F. 追击统一

- 所有追击统一为伤害事务中的攻击段类型`chase`，继续复用普通／真伤、防御、生命、格挡和卸力流程；不建立第二套追击伤害执行器。
- 迁移现有`source_kind="chase"`兼容标签、`chase_on_consecutive_life_hits_percent`等专用字段，使其生成同一种结构化追击攻击段；中央流程不能按功法 ID 判断追击。
- 新增统一`chase_resolved`已提交事件，公开追击令牌、来源、行动令牌、伤害类型、请求值、防御损失、生命损失、是否被取消和取消子类型。同一追击令牌只能提交一次。
- 追击不能建立牌型组、触发整门功法、推进序列或递归触发产生自己的同一响应；功法正文明确监听“功法或追击攻击段”时仍可通过统一事件筛选。
- 追焰留痕只在正式追击完成事件后计数；查询、预览和 AI 评估不得发送事件或推进计数器。

#### G. 格挡、卸力与攻击取消

- 按本目录山章节实现格挡与卸力的分离语义：先全部卸力，再格挡，最后防御／生命；卸力必定消费并可能被击穿，格挡不比较伤害数值。
- 统一攻击取消事实，同时提供`block`、`deflection`子类型、卸力击穿与消费回执。格挡成功与卸力成功必须是两个可独立筛选的事件事实。
- 更新现有格挡内容、伤害预览、AI、日志和 UI，明确显示当前格挡次数与各卸力阈值，不按阈值大小自动重排来源。
- 受阻愈烈、卸劲破隙、朽甲成关及其他监听内容必须使用统一事件，不复制攻击取消逻辑。

#### H. 消耗真气

- 唯一临时移出事务增加`cause=cost`，提交逐张`qi_consumed`事实；消耗牌战后按原归属返回本局牌组。
- 消耗不进入弃牌堆，不算明确弃牌，不触发入弃牌堆响应。虚无消散、敌方强制消散、正常打出、永久移出和战斗结束清理均不属于消耗。
- 选择、实际支付、后续效果和失败回滚必须属于同一原子事务；不足支付时不触发后续效果。
- 灰烬化形、耗气补垣、万木代命及其他消耗联动统一监听`qi_consumed`，不能各自复制牌区移除逻辑。

#### I. 燃尽、焕发与异状迁移

- 燃尽从标记迁移为减益，保持最终有效真气值为 0；更新异状定义、内容校验、ConditionSpec、TargetQuery、净化、AI、预览、UI和全部正式资源引用。
- 焕发新增为不叠层增益，最终有效真气值`×2`；计算顺序为其他合格增减／倍乘后应用焕发，最后由燃尽覆盖为 0。
- 燃尽与焕发跨牌区保留、可被净化、战斗结束清除。迁移不能恢复旧毒、旧连势或旧标记规则。
- 余烬存真只覆盖燃尽牌在功法值计算中的自身贡献，不改变毒量或其他有效真气值读取；蛊火蔓延在入堆清理毒之前施加燃尽。

#### J. 新增事件、查询、计数器与效果端口汇总

- 事件：临时功法生成成功、临时功法成功触发、统一追击完成、卸力成功／击穿／消费、逐张消耗真气、功法攻击段清空防御、功法执行汇总实际防御与生命损失。
- 查询：空余功法槽、初始实际装备功法数量、其他实际功法实例、连势有效上限、正在蓄力的功法实例、主要蓄力累计值、功法攻击段来源、当前卸力来源、合法燃尽／破绽目标。
- 计数器：护焰及伤害余数、五运运数、每行动首次燃尽功法、每场首次临时功法、追击三次计数、毒伤三次计数，以及各既有内功正文声明的 battle／run 计数器。所有计数器必须声明来源、范围、重置时点和重复副本语义。
- 效果端口：生成临时功法、修改连势上限查询、修改蓄力累计值、移除全部炽气并捕获实际量、追加稳定序列推进、生成指定牌阶与属性的临时真气、按攻击段实际防御损失造成派生伤害。
- 所有正式事件只在事务提交后发送；查询、预览、AI 评估和失败回滚不得写计数器、消费资源、移动牌或消耗随机数。
