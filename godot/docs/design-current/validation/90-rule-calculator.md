## 11. 下一项实验

制作纯规则计算器，显示：

```text
给定一手8张真气
→ 枚举选择1～5张的方案
→ 识别最高普通牌型
→ 结算参与数值计算真气的本源、永久／临时强化、印记与异状
→ 汇总真气贡献 C 与功法倍率 M，得到初始功法值 P₀ = floor(C × M)
→ 检查该牌型组实际打出的全部普通真气是否构成同气；若满足，按投入 1～5 张分别将 0% / +10% / +20% / +30% / +50% 加入直接功法值百分比修正池
→ 依次结算直接功法值固定修正与百分比修正，得到连势前功法值
→ 读取该具体牌型当前序列功法并检查条件；成功时快照当前连势，得到最终功法值 P
→ 精确牌型与上一次成功牌型不同时，本次仍使用旧连势，随后在功法效果开始前清空；相同时保留
→ 得到牌型基准值、P₀ 与 P，但牌型本身不造成伤害
→ 本次只尝试当前序列的一门功法；复合牌型使用自己的独立序列
→ 将同一时点的功法与已装备内功加入可见队列，按玩家排列从左到右逐项读取最新状态并结算
→ 只结算功法、内功、毒状态明确写出的伤害、防御或牌区操作
→ 多段功法按攻击段逐次读取防御、异状与受伤响应；反震按每次实际减少的防御和当时最新比例结算
→ 同组重触复用已经冻结的 P₀ 与 P，不重新加入连势；按 P₀ 产生的新连势正常保留
→ 当前功法成功触发时，在该牌型组完整结算结束后将该具体牌型序列前进一格；失败则保持当前位置
→ 若主牌型功法建立协同，在主牌型结算前从剩余手牌锁定协同组，再按顺序分别重复上述完整计算与触发流程
→ 主牌型与协同组全部结束后，检查本次行动实际打出的全部普通真气是否构成同气；满足时按同气连动规则开启额外行动
→ 显示未参与牌型的真气被弃置
→ 回合开始时按手牌上限从剩余牌库补牌，基础上限为8张
→ 功法、内功、觉醒或风引明确抽牌时允许超过手牌上限，超过后不自动弃牌
→ 牌库不足时只补到能补的数量，不自动洗回弃牌堆
```

计算器先不加入完整敌人 AI、全部 77 门普通正式功法内容或局外成长；即使使用只装配两门基础通用功法与显式空序列的最小夹具，也应能够验证牌型、`P₀`、直接修正、连势与异状行为。

### 11.1 S2.0A 修习经济与节点结算验证

本节只定义验证样例，规则正文仍分别以[修习与历练经济](../economy/50-training-and-experience.md)和[地图与战斗流程](../run/60-map-run-and-health.md#81-节点统一结算顺序)为准。

经济计算器至少覆盖：

- 按每层 12 个随机楼层、固定普通战斗、固定宝箱、固定休息和 Boss 计算，基础历练期望为 `30.92`；代表路径允许因实际类型分配产生离散差异。
- 规则变更后的功行总量、三层未消费余额和消费次数待重新校验；不得继续使用 S2.0A 旧方案 A／方案 B 的利息数字。
- 以功法、丹药和心得 3 点、奇珍 4 点及三档补充包 4／6／8 点作为购买输入；功行规则变更后，三层购买次数与冥想取舍待重新校验。
- 将“每完成一个节点获得 4 点历练”的经济内功作为压力样例，验证它在 15 个普通楼层加 Boss 的完整层中会增加 64 点节点收益，因此不能被 S2 默认展示池抽中。

确定性与拒绝行为至少覆盖：

- 同一本局种子、相同白名单和相同购买／冥想操作序列产生完全相同的 `2 个普通商品 + 2 个补充包 + 1 个物品` 及后续刷新结果；任一被排除内容 ID 都不得出现。
- 购买普通商品、打开补充包或买下物品后对应槽位为空；冥想只替换普通商品栏中尚未购买的候选，补充包和物品不参与普通刷新；关闭再打开页面不改变候选、空位、冥想次数或下一次费用。
- 同一间商店冥想费用依次为 `5、6、7……`；历练不足时余额、候选、空位、冥想次数与随机流位置全部不变。
- 同一节点令牌即使重复收到完成、领取或恢复请求，也只发放一次节点奖励，并至多执行一次功行生息。
- 普通战斗、精英、Boss、事件、休息、第 9 层宝箱和 Boss 后隐藏宝箱均各触发一次功行生息；当前历练 0、7、10、25 的代表断言分别覆盖 0→3、7→8、10→12、25→35（Boss 基础奖励 5 点）这四种结算。
- 第 1、2 层 Boss 依次完成节点结算、Boss 宝箱奖励和跨层生命成长；第 3 层 Boss 完成节点结算后直接通关。
