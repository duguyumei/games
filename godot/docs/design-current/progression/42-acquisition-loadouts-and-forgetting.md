### 2.6 获得、装备与遗忘

获得、装备和遗忘是三个独立动作：

```text
获得：加入本局功法库或内功库
装备：将已获功法加入对应具体牌型的循环功法序列，或占用一个内功栏位并使内功生效
遗忘：玩家主动将已获功法或内功移出本局，并获得该武学标明的遗忘所得
```

未装备不等于遗忘，也不会自动换算为历练。功法与内功都可以存在已获得但未装备的状态。功法既可以由心得附带获得，也可以像内功一样在修习中直接购买；第一版普通直接购买价格统一暂定为 3 点历练。内功仍分别记录档位、修习价格和遗忘所得，档位与价格没有固定对应关系，不同档位的价格区间可以重叠。物品、事件或其他效果可以明确修改功法价格，但最低价格与叠加方式仍待测试。

本局永久功法序列与内功配装只能在地图待选状态修改：当前没有进行中的节点、战斗、待领取奖励或 Boss 宝箱流程；查询不受此门禁限制。内功基础装备容量为 6，有效容量可以由物品、拟提交配装中的内功或其他明确效果增减，但不得低于 0。完整配装按提交顺序保存并进入下一场战斗，功法位置可以位于装备数量的 `0～N` 之间。相同内功 ID 可以拥有和装备多个副本，装备合法性按每个 ID 的已获数量分别校验，不为副本建立持久化实例 ID。

配装提交依次校验 ID、已获副本数、拟提交完整配装的有效容量、装备数量和功法位置，然后原子提交。容量不足时整项操作失败，不截断、不自动卸下最右侧内功，也不移动功法位置；降低容量的操作若没有同时给出合法卸下／替换结果，同样整体失败。

普通遗忘每次只移除一份当前未装备的内功副本，并获得该内功当前有效的遗忘所得；如果同 ID 的全部副本均已装备，必须先卸下一份。普通遗忘计入本局 `forgotten_inner_skill_count`。自动消失、替换、奇珍清理及其他特殊效果造成的永久移除不属于普通遗忘，不获得默认遗忘所得，也不增加该计数。内功自身或其他被动规则改写遗忘行为时，由被动规则运行时处理，不进入普通配装命令的内容 ID 分支。

内功定义的 `forget_value` 是基础遗忘所得；配装展示和正式遗忘都通过 `inner_skill_forget_value_query` 从该基础值计算有效所得。正式遗忘在删除副本前重新查询，查询或已提交事件失败时不删除副本、不增加历练，也不增加普通遗忘计数。只有副本删除、有效所得发放和计数增加全部成功后才触发一次 `inner_skill_forgotten`；特殊清理不触发。
