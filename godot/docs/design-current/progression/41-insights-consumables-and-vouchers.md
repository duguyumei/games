## 6. 心得、丹药、天材地宝、重塑与异状

### 6.1 三类一次性修习内容与优惠券对应物

组合出招系统使用三类一次性修习内容与一种优惠券对应物：

| 内容 | 参考来源 | 当前职责 |
| --- | --- | --- |
| 心得 | 《小丑牌》星球牌 | 对应一种具体普通牌型；提高该牌型的累计功法倍率，并从其所属共用功法池随机获得一门功法 |
| 丹药 | 《小丑牌》塔罗牌 | 定向增加、删除、复制真气，修改牌阶或属性，或为真气施加强化及其他常规转化 |
| 天材地宝 | 《小丑牌》幻灵牌 | 稀有且强力地改造真气牌组或内功，是施加品相与印记的主要来源，并允许比普通丹药更大幅度的收益、代价与结构变化 |
| 优惠券对应物，正式名称待定 | 《小丑牌》优惠券 | 由事件、精英与 Boss 提供的本局永久装备道具；修改修习选项、功法价格、冥想刷新、奖励、容量或获取倾向，不通过普通修习购买 |

心得的倍率分组与累计规则见第 4 节。丹药和天材地宝主要在战斗外使用，产生持续至本局结束的构筑变化。丹药、心得与天材地宝共用 3 个消耗品栏位；使用或失去一个消耗品后立即释放对应栏位。效果随机生成消耗品时，若没有空位则不生成，除非效果文本明确允许立即使用或溢出保存。

三类消耗品在修习中直接出现时沿用《小丑牌》的基础价格并按 `1 金钱 = 1 历练` 映射：丹药 3 点历练、心得 3 点历练、天材地宝 4 点历练。修习也可以提供丹药包、心得包与天材地宝包；普通、大型、豪华补充包的基础价格分别为 4、6、8 点历练。优惠券对应物和其他明确效果可以修改价格。

| 补充包 | 普通 | 大型 | 豪华 |
| --- | --- | --- | --- |
| 丹药包 | 展示 3，选择 1 | 展示 5，选择 1 | 展示 5，选择 2 |
| 心得包 | 展示 3，选择 1 | 展示 5，选择 1 | 展示 5，选择 2 |
| 天材地宝包 | 展示 2，选择 1 | 展示 4，选择 1 | 展示 4，选择 2 |

开启补充包是一项独立事件，不等同于使用其中内容；新生成的消耗品也不会自行再次开启补充包。玩家不能选择超过当前空余消耗品栏位数量的内容。

#### 第一批丹药候选：22 种

下列牌组修改默认持续至本局结束，不是局外永久。为普通真气转换牌阶时，基础真气值随牌阶同步改变；转换属性只改变印刷属性，不改变牌阶、基础真气值或已有重塑。

| --- | --- |
| 愚者 | 生成本局最近一次使用的丹药或心得，不包括愚者自身。没有合格使用记录时不能使用。 |
| 魔术师 | 选择至多 2 张真气，使其获得幸运牌强化。 |
| 女祭司 | 随机获得至多 2 份当前已启用精确牌型的心得，受消耗品栏位限制。 |
| 皇后 | 选择至多 2 张真气，使其获得倍率牌强化。 |
| 皇帝 | 随机获得至多 2 种丹药，受消耗品栏位限制。 |
| 教皇 | 选择至多 2 张真气，使其获得奖励牌强化。 |
| 恋人 | 选择 1 张真气，使其获得万能牌强化。 |
| 战车 | 选择 1 张真气，使其获得钢铁牌强化。 |
| 正义 | 选择 1 张真气，使其获得玻璃牌强化。 |
| 隐者 | 当前持有历练翻倍，但本次最多获得 20 点历练。 |
| 命运之轮 | 有 1/4 概率随机选择 1 门没有品相的已装备内功，为其施加箔面、镭射或多彩品相。没有合格内功时不能使用。 |
| 力量 | 选择至多 2 张普通真气，使牌阶提高一级：`2→3→…→10→J→Q→K→A→2`，基础真气值随牌阶同步改变。 |
| 倒吊人 | 选择至多 2 张我方真气，永久移出本局牌组。 |
| 死神 | 依次选择 2 张真气，将第一张转化为第二张的完整副本。复制牌阶、属性、基础真气值及全部重塑，不复制任何异状。 |
| 节制 | 获得当前全部已装备内功的遗忘所得总和，最多获得 50 点历练；不会遗忘这些内功。 |
| 恶魔 | 选择 1 张真气，使其获得黄金牌强化。 |
| 塔 | 选择 1 张真气，使其获得石头牌强化。 |

| 月亮 | 选择至多 3 张普通真气，将其印刷属性转化为林。 |
| 太阳 | 选择至多 3 张普通真气，将其印刷属性转化为火。 |
| 审判 | 随机获得 1 门内功并加入本局内功库，不要求内功装备栏有空位。 |

属性转化沿用下列对应：方块映射为山，梅花映射为林，红桃映射为火，黑桃映射为风。该映射只用于说明四种基础属性的原型来源，不建立牌型或额外属性分组。

#### 第一批心得候选：8 种

正常使用一份心得仍执行第 4 节确认的两项效果：提高对应精确牌型的累计心得倍率，并从其合格共用功法池随机获得一门尚未获得的功法。心得不提高固定牌型倍率或牌型基准值，不追加统一基础筹码。

| 心得 | 累计心得倍率 | 获得功法的池 |
| --- | ---: | --- |
| 高牌心得 | +1 | 高牌池 |
| 一对心得 | +1 | 一对、两对池 |
| 两对心得 | +1 | 一对、两对池 |
| 三条心得 | +2 | 三条、葫芦池 |
| 葫芦心得 | +2 | 三条、葫芦池 |
| 顺子心得 | +3 | 顺子池 |
| 四条心得 | +3 | 四条、五条池 |
| 五条心得 | 暂定 +3 | 四条、五条池 |

五条固定牌型倍率已经确认为 `×12`，但五条心得的 `+3` 仍为暂定值；在心得获取时点与
出现频率完成测试前，五条心得不进入普通心得随机池。同花心得、同花顺心得、同花葫芦心得
与同花五条心得均已废弃，不再生成。

#### 第一批天材地宝候选：18 种

原作依赖“当前手牌”的整手改造效果，在修习阶段使用时改为从本局牌组随机展示至多等于当前基础手牌上限数量的合格真气，并对全部展示目标结算；玩家可以在看到展示结果后决定是否使用，但不能只挑其中一部分。涉及永久移出本局牌组的效果不视为遗忘、弃掉或燃尽。

| 天材地宝 | 效果 |
| --- | --- |
| 使魔 | 从我方本局牌组随机永久移出 1 张真气；随后生成 3 张随机真元牌加入牌组。生成牌的基础牌阶从 J、Q、K 中随机，属性随机，并各自获得一种随机强化。 |

| 咒语 | 从我方本局牌组随机永久移出 1 张真气；随后生成 4 张随机数字牌加入牌组。生成牌的牌阶从 2～10 中随机，属性随机，并各自获得一种随机强化。 |
| 护身符 | 选择 1 张真气，为其施加金印。 |
| 光环 | 选择 1 张真气，为其随机施加箔面、镭射或多彩品相。 |

| 符印 | 从本局牌组随机展示至多等于当前基础手牌上限数量的普通真气；随机确定风、林、火、山之一，将全部展示真气的印刷属性转化为该属性。 |
| 占卜 | 从本局牌组随机展示至多等于当前基础手牌上限数量的普通真气；随机确定一个牌阶，将全部展示真气转化为该牌阶，随后基础手牌上限本局常驻 -1。 |

优惠券对应物不是一次性消耗品，也不与功法、内功争夺普通修习购买位置。事件可以提供带代价或改变路线的版本，精英可以提供构筑强化版本，层末 Boss 应稳定提供更强或可升级的版本。第一版优先让它们作用于功法展示数量、价格、冥想、锁定修习选项、精英额外功法、心得获取倾向、遗忘所得和一次性内容容量；直接增加伤害、防御、手牌上限或额外出牌次数的战斗型效果暂不作为主要方向。
