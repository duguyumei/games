## 6. 心得、丹药、奇珍、重塑与异状

### 6.1 三类一次性修习内容与物品

组合出招系统使用三类一次性修习内容与一种本局物品：

| 内容 | 参考来源 | 当前职责 |
| --- | --- | --- |
| 心得 | 《小丑牌》星球牌 | 对应一种具体普通牌型；使该牌型的功法槽位 +1，并从该牌型可以读取的基础功法池并集中随机获得一门功法 |
| 丹药 | 《小丑牌》塔罗牌 | 定向增加、删除、复制真气，施加本源改造、强化或其他常规转化 |
| 奇珍 | 《小丑牌》幻灵牌 | 一次性、稀有且强力地改造真气牌组或内功，是施加印记与特殊规则改写的主要来源，并允许比普通丹药更大幅度的收益、代价与结构变化 |
| 物品（原优惠券对应物） | 《小丑牌》优惠券；功能可借鉴《杀戮尖塔》遗物 | 本局永久修改修习、商店、奖励或成长规则；使用独立物品持有区，不占内功栏位 |

心得的牌型槽位与功法获得规则见本节“第一批心得候选”及[牌型与真气值](../combat/10-hand-ranking-and-values.md#4-固定牌型倍率与牌型功法槽位)。丹药和奇珍主要在战斗外使用，产生持续至本局结束的构筑变化。丹药、心得与奇珍共用 3 个消耗品栏位；使用或失去一个消耗品后立即释放对应栏位。效果随机生成消耗品时，若没有空位则不生成，除非效果文本明确允许立即使用或溢出保存。

三类消耗品在修习中直接出现时沿用《小丑牌》的基础价格并按 `1 金钱 = 1 历练` 映射：丹药 3 点历练、心得 3 点历练、奇珍 4 点历练。修习也可以提供丹药包、心得包与奇珍包；普通、大型、豪华补充包的基础价格分别为 4、6、8 点历练。物品和其他明确效果可以修改价格。

| 补充包 | 普通 | 大型 | 豪华 |
| --- | --- | --- | --- |
| 丹药包 | 展示 3，选择 1 | 展示 5，选择 1 | 展示 5，选择 2 |
| 心得包 | 展示 3，选择 1 | 展示 5，选择 1 | 展示 5，选择 2 |
| 奇珍包 | 展示 2，选择 1 | 展示 4，选择 1 | 展示 4，选择 2 |

开启补充包是一项独立事件，不等同于使用其中内容；新生成的消耗品也不会自行再次开启补充包。玩家不能选择超过当前空余消耗品栏位数量的内容。

#### 当前丹药池：23 种

下列牌组修改默认持续至本局结束，不是局外永久。本源改造包括转属、易阶和觉醒；一张真气一局只能接受其中一次，已经拥有任意本源改造的真气不能再成为普通本源改造的合法目标。升阶或降阶都属于易阶，基础真气值随牌阶同步改变；A 不能继续升阶，2不能继续降阶。转属只改变基础属性，不改变牌阶和基础真气值；觉醒读取使用时的当前基础属性。完整复制属于新增真气实例，不是本源改造，并按[本源、强化与印记](../combat/14-qi-effects-and-statuses.md#66-本源强化与印记)中的完整复制规则继承源牌状态。

| 丹药 | 效果 |
| --- | --- |
| 溯忆丹 | 生成本局最近一次使用的丹药或心得，不包括溯忆丹自身。没有合格使用记录时不能使用。 |
| 机缘丹 | 选择至多 2 张真气，使其获得机缘强化。 |
| 通悟丹 | 随机获得至多 2 份当前已启用精确牌型的心得，受消耗品栏位限制。 |
| 乘势丹 | 选择至多 2 张真气，使其获得乘势强化。 |
| 万化丹 | 随机获得至多 2 种丹药，受消耗品栏位限制。 |
| 增元丹 | 选择至多 2 张真气，使其获得增元强化。 |
| 混元丹 | 选择 1 张真气，使其获得混元强化。 |
| 无漏丹 | 选择 1 张真气，使其获得无漏强化。 |
| 虚暴丹 | 选择 1 张真气，使其获得虚暴强化。 |
| 聚功丹 | 当前持有历练翻倍，但本次最多获得 20 点历练。 |
| 升阶丹 | 选择至多 2 张尚未接受本源改造且牌阶不是 A 的普通真气，对其进行升阶：`2→3→…→10→J→Q→K→A`，基础真气值随牌阶同步改变。 |
| 降阶丹 | 选择至多 2 张尚未接受本源改造且牌阶不是 2 的普通真气，对其进行降阶：`A→K→Q→J→10→9→…→2`，基础真气值随牌阶同步改变；每张实际完成降阶的真气随后分别获得一种随机强化，已有强化按全局强化替换规则被新强化替换。 |
| 启灵丹 | 选择 1 张尚未接受本源改造的普通真气，根据其当前基础属性进行觉醒；不改变牌阶、基础属性或基础真气值。 |
| 散元丹 | 选择至多 2 张我方真气，永久移出本局牌组。 |
| 衍元丹 | 选择 1 张我方本局牌组中的真气，生成 1 张完整复制并加入我方本局牌组；源牌不改变。 |
| 纳功丹 | 获得当前全部已装备内功的遗忘所得总和，最多获得 50 点历练；不会遗忘这些内功。 |
| 藏金丹 | 选择 1 张真气，使其获得藏金强化。 |
| 磐石丹 | 选择 1 张真气，使其获得磐石强化。 |
| 山相丹 | 选择至多 3 张尚未接受本源改造的普通真气，对其进行转属，将基础属性改为山。 |
| 林相丹 | 选择至多 3 张尚未接受本源改造的普通真气，对其进行转属，将基础属性改为林。 |
| 火相丹 | 选择至多 3 张尚未接受本源改造的普通真气，对其进行转属，将基础属性改为火。 |

| 风相丹 | 选择至多 3 张尚未接受本源改造的普通真气，对其进行转属，将基础属性改为风。 |

实现边界：最近一次可溯忆记录只在丹药或心得成功完成整次事务提交后更新；
溯忆丹自身不覆盖该记录，失败、预览与可用性查询也不更新。执行中的消耗品会
为其成功消耗预留一个栏位，因此通悟丹、万化丹和溯忆丹在满栏时仍可利用自身
释放的栏位保存生成内容。所有随机候选先按稳定 ID 排序，再使用本次消耗品事务
的确定性随机源抽取；降阶丹对每张实际降阶真气分别独立抽取强化。传功丹只将
所得加入本局内功库，不自动装备。没有合法真气目标、可溯忆记录、消耗品候选
或内功候选时不能使用，且不会消耗当前内容或递增随机序号。

属性转化沿用下列对应：方块映射为山，梅花映射为林，红桃映射为火，黑桃映射为风。该映射只用于说明四种基础属性的原型来源，不建立牌型或额外属性分组。

#### 当前心得池：8 种

正常使用一份心得执行两项效果：

1. 对应具体牌型的功法槽位增加 1；每个具体牌型初始槽位为 1，槽位与其他具体牌型独立记录。
2. 从该牌型可以读取的基础功法池并集中，随机获得一门尚未加入该牌型当前序列的正式功法，并默认填入本次新增槽位。玩家可以在战斗外重新排序或替换，战斗开始后序列锁定。

若该牌型可以读取的基础池并集中没有可抽取的正式功法，心得仍然成功消耗并只完成第 1 项：槽位照常 `+1`，
本次不获得功法、不跨池改抽，也不使整次操作失败。

心得不提高固定牌型倍率、牌型基准值或最终伤害。功法值如需读取心得成长，只能读取受控的牌型熟练度固定修正；本规则不建立无限累计倍率。

| 心得 | 槽位变化 | 获得功法的池 |
| --- | ---: | --- |
| 高牌心得 | +1 | 高牌池 |
| 一对心得 | +1 | 对子池 |
| 两对心得 | +1 | 对子池 |
| 三条心得 | +1 | 三条池 |
| 葫芦心得 | +1 | 对子池与三条池的去重并集 |
| 顺子心得 | +1 | 顺子池 |
| 四条心得 | +1 | 炸弹池 |
| 五条心得 | +1 | 炸弹池 |

八种心得从开局起均正常进入普通心得随机池。五条固定牌型倍率为 `×12`，五条心得不以当前牌组能否立即组成五条为生成条件；五条与四条分别拥有独立功法槽位、序列和进度，只共同读取炸弹池。葫芦心得增加葫芦自己的槽位，并从对子池与三条池的去重并集中获得一门功法，不增加一对、两对或三条槽位，也不会同时触发两个池的功法。同花心得、同花顺心得、同花葫芦心得与同花五条心得均已废弃，不再生成。

| 高牌 | +1 |
| 一对 | +1 |
| 两对 | +1 |
| 三条 | +2 |

归墟修正只加入对应牌型的功法倍率并影响功法值，不改变固定牌型倍率或牌型基准值。多个归墟是否允许重复获得及其倍率修正能否叠加，沿用奇珍默认不可重复规则。

物品不是一次性消耗品，也不与功法、内功争夺普通修习购买位置。事件可以提供带代价或改变路线的版本，精英可以提供构筑强化版本，层末 Boss 应稳定提供更强或可升级的版本。第一版优先让物品作用于功法展示数量、价格、冥想、锁定修习选项、精英额外功法、心得获取倾向、遗忘所得和一次性内容容量；直接增加伤害、防御、手牌上限或额外出牌次数的战斗型效果暂不作为主要方向。物品的实际效果类别由内容定义的 `kind` 与注册 Handler 决定，不再按“遗物”和“优惠券对应物”拆成两套系统。
