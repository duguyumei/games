# 四属性花色图标

这组图标将标准扑克牌花色映射为太吾组合出招的四种属性：

- `wind.svg`：风 = 黑桃；保留完整黑桃，右侧增加一束收尖风尾。
- `forest.svg`：林 = 梅花；在梅花内部以留白加入克制的主干与双侧枝脉。
- `fire.svg`：火 = 红桃；在红桃内部以留白加入向上的火舌。
- `mountain.svg`：山 = 方块；在方块内部以留白加入单道折线山脊。

所有文件统一使用 `viewBox="0 0 1024 1024"`、透明背景和 `currentColor` 单色填充。使用方可通过 CSS、SVG 调色或 Godot 的节点调制颜色统一着色；图形没有滤镜、纹理或细碎笔刷，适合缩小到牌角标尺寸。
