## 当前边界

- 采用类《小丑牌》的“手牌中选择若干张、识别一个主牌型”思路。
- 当前牌型暂时直接使用普通扑克牌名称。
- 不存在固定每次出三张牌的规则。
- 牌面数字提供基础值，普通牌型提供倍率，功法与内功负责把结果改写为伤害、防御或牌区操作。
- 不加入旧战斗系统、固定攻势数值、距离或旧 UI。
- 在牌流和牌型计算通过前，只验证少量基础功法与内功，不建立正式卡池与敌人系统。
